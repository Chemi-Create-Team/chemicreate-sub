# 設計：電解セルを「上から電極板が降りる」形にする

> **更新（2026-11-16）**：続く指示で、セルは2×2の断面から1列・1段（1×1×長さ1～8）にし、ヘッドは各セルに1個・電極板16枚、制御盤は縦2個（下にダイヤル、上に計器とSTART/STOP）にした。陰極ガスは小さいX側（軸Xなら小さいZ側）の側面、陽極ガスは反対の側面、原料は底面と奥の端面、苛性ソーダ・再生酸は奥の端面。以下の本文は2×2断面のときの記述を含む。現行の仕様は[フィルタープレス型電解槽](../filter-press-electrolysis.md)。
>
> **更新（2026-11-17）**：ヘッドは回転動力を使わず、START/STOPだけで16 tickかけて自分で上下する。以下の回転・軸・応力・歯車の記述は古い。

2026-11-16にユーザーと合意した方針です。

- 電解セルの上に電極ヘッドを載せ、電極板はヘッドに吊るして上から槽へ降ろす。電源（CEEの配線）もヘッドの上に挿す。
- ヘッドはCreateの回転で上下させる。
- 気体を作る電解（水・重水・塩水・フッ化水素）と金属の電解採取の両方をこの形にする。
- 電解採取でできた金属は、ヘッドを上げて取り出す。

## 構造

| 部分 | 内容 |
| --- | --- |
| 電解セル | 今と同じ2×2の断面を長さ1～8。上段のハッチ（`OPEN`）を廃止し、上段の天面は開いた槽にする |
| 電極ヘッド（新規、`electrolysis_electrode_head`） | 上段の各セルの真上に1個ずつ、2×長さで並べる。全部そろわないと形成しない |
| 制御盤 | 今と同じ2×2を端面に。START／STOP、稼働率ダイヤル、計器はそのまま。電源端子はなくし、ヘッドへ移す |

## 電極ヘッド

- **回転**：軸は長さ方向。両端に軸がつながり、幅方向の隣のヘッドとは小さい歯車として噛み合う。どのヘッドに回転を入れても、全部のヘッドが回る。応力は1個あたり4 SU/RPM。
- **上下**：STARTで下降、STOPで上昇を始める。動くのは回転しているときだけで、32 RPMなら16 tickで全行程。回転が止まると、その位置で止まる。サーバーが位置を持ち、クライアントは同期した目標と回転数から補間する。
- **電極板**：1個のヘッドに通常極板・ニッケル極板を合わせて8枚まで、アスベスト隔膜も入れられる（今の上段セルの役割をそのまま移す）。最大128枚は変わらない。
- **出し入れ**：完全に上がっているときだけ。手で右クリックして入れる、しゃがんで素手で1枚取り出す、素手で金属を取り出す。上面と露出した側面のファンネルにも同じ在庫を公開する。
- **金属**：電解採取の金属は電極板（ヘッド）に付く。ヘッドごとに1スロット。
- **電源端子**：制御盤の右上区画の奥にあたるヘッド（端子ヘッド）の上面に2本立てる。CEEの抵抗はこのヘッドだけが登録する。

## 運転条件

| 状態 | 動作 |
| --- | --- |
| ヘッドが全部下がっている | 電解する |
| どれか一つでも下がりきっていない | 「電極が上がっている」で停止。原料・電力を使わない |
| 赤石信号 | 今と同じく停止。ヘッドは動かさない |
| STOP | 電解を止め、ヘッドを上げる |

## 入出力

- 給液・苛性ソーダは下段、気体は上段の露出した側面から（今と同じ）。上段の天面はヘッドで塞がるので公開しない。
- 金属は、ヘッドが上がっているときにヘッドから取り出す。セル側面の金属の取り出し口は廃止する。
- 再生酸は今と同じく下段から。

## 削除・置き換え

- 電解セルの`OPEN`、ハッチの操作・描画・音、`hatch`の停止理由、上段セルの電極在庫と金属在庫。
- 制御盤の電源端子（CEEの装置登録はヘッドへ移す）。
- 旧ワールドで電解セルに入っていた電極板・金属は失われる（本格運用前のため移行処理なし）。

## 描画

- ヘッド：固定の枠と、回転する歯車・軸（Flywheelあり・なし両対応）。吊るした電極板は位置に合わせて下の槽へ下がる。
- 電解セル：ハッチと電極板の描画をやめ、液面と泡だけにする。泡は電極が下がって電解しているときだけ。

## 確認

- 形成（ヘッド不足・軸の向き違い）、回転で上下すること、下がりきるまで電解しないこと、STOPで上がること。
- 上がっているときだけ電極板・金属を出し入れできること（手・ファンネル）。
- 端子ヘッドだけが電力を受けること、保存・再読込で位置と在庫を保つこと。
- 既存の電解テスト（水・塩水・フッ化水素・電解採取）を新しい構造で通すこと。
- Ponder「電解セル」をヘッド付きの組み立てと操作に作り直す。
