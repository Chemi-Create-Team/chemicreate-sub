# Codex依頼文：放射線のリアルな実装

下の枠内をそのままCodexに渡す。数値は実在の物理量を基準にした初期案で、遊びやすさに合わせて変える場合は「決めること」を先に確定しておく。

```text
AGENTS.mdとDESIGN.mdを読んでから、放射線をリアルな仕組みに作り直してください。作業はmainブランチで行い、検証後にコミットしてプッシュしてください。

## 現状（必ず読む）
- src/main/java/net/createplant/nuclear/Radiation.java：RBMK炉心だけが線源。炉室6面の「遮蔽されていない割合」と距離の逆2乗で毎秒の線量を出し、プレイヤーの添付データCENuclear.DOSE（Sv）に足す。急性放射線症の5段階と、1 Sv/20分の回復がある。
- ReactorPhysics.doseRate（2.56e-9 × W × 開口率 / 距離²）、ReactorCore（20 tickごとにirradiate、100 tickごとに遮蔽を再計算）。
- ProtectiveClothingItem：防護服の「protection」の割合だけ線量を減らしている。実際の防護服はガンマ線を止めないので、この扱いは誤り。
- 使用済み燃料棒・使用済み制御棒・照射済みリチウムターゲット・高レベル放射性廃液・ガラス固化体・燃料プールなどは、現在は放射線を出していない。
- 関連テスト：RbmkGameTests、FuelPoolGameTests、NuclearSavedValueGameTests。文書：docs/rbmk-reactor.md。

## 目標
放射線の種類・線源の強さ・距離・遮蔽材・時間減衰・汚染・被ばく管理を、実在の物理に沿って1つの共通処理で扱う。炉心だけの特別扱いをやめ、炉心も共通の線源の1つにする。

## 仕様
1. 線源（共通の登録）
   - アイテム・流体・ブロックごとに、ガンマ線の線量率定数（1 mでのSv/s）、ベータ線の有無、アルファ汚染の有無、半減期を持つ核種グループ（短寿命・Cs-137相当・長寿命など2〜3群）を登録する。登録は、物性や凝固点と同じく共通処理と表で行う（AGENTS.mdの「必要な仕事に絞る」に従う）。
   - 線源にするもの：運転中・停止後の炉心（崩壊熱分は既存のDECAY_SHAREを流用）、使用済み燃料棒・制御棒、照射済みターゲット、使用済みブランケット・ダイバータ、高レベル放射性廃液と使用済み燃料溶解液、ガラス固化体、汚染された場所。新燃料・イエローケーキ・ウラン鉱石は弱いアルファ線源（外部被ばくはほぼ無し、吸入時のみ）。
   - 置かれたブロック、容器（タンク・ベイスン・キャニスター・燃料プール）、地面に落ちたアイテム、プレイヤーやチェストの中身も線源になる。容器の中身は内容物の量に比例させる。
   - 使用済み品は取り出してからの経過時間（ゲーム内時間×時間倍率の定数）で減衰する。経過時間は保存する。

2. 透過と遮蔽
   - 線源からプレイヤーまでの直線上のブロックを辿り、材質ごとの半価層（または線減弱係数）で指数減衰させる。距離は逆2乗。
   - ガンマ線の半価層の初期値（Cs-137相当）：水9 cm、コンクリート5 cm、鋼1.6 cm、蛇紋岩・バイオロジカルシールド4 cm相当、空気は無視。1ブロック＝1 mとして計算する。材質はブロックタグで分類し、未分類の固体ブロックは密度の近い値を使う。
   - ベータ線は空気中数m・薄い金属1枚・衣服で止まる。アルファ線は外部被ばくなし。中性子は運転中の炉心だけとし、水・コンクリート・蛇紋岩で減衰させる。
   - 既存の6面開口率の計算は、炉心という線源の遮蔽計算に置き換える。旧処理は残さない。

3. 汚染と内部被ばく
   - 放射性の流体がこぼれる・容器が壊れる・炉心が爆発すると、周囲のブロック面に汚染（Bq相当）が付く。汚染はチャンク単位の粗い格子で保存し、時間で減衰し、歩くと靴に付いて広がる。
   - 汚染された場所では、ガスマスクなしで吸入による内部被ばく（預託線量）を受ける。防護服は皮膚汚染とベータ線を防ぐが、ガンマ線は防がない（ProtectiveClothingItemの意味をこれに直す）。
   - 既存の石けん・水で除染できる。脱いだ防護服は汚染物として線源になる。

4. 計測（新アイテム。Ponderも作る）
   - 個人線量計：積算線量（mSv）と現在の線量率を表示する。
   - サーベイメーター（ガイガーカウンター）：線量率に応じたクリック音と表示。ベータ／ガンマの切替窓があると良い。
   - 既存の急性症状の段階は残し、被ばく時の線量率による違い（急性と慢性）と、生涯積算線量の記録を加える。確率的影響（がん）は表示・統計のみとし、ゲームの死亡には使わない。

5. 性能（AGENTS.mdの最適化表を守る）
   - 線源はチャンク単位の登録表で管理し、全ブロック走査はしない。評価は20 tickごと、対象はプレイヤーのみ（他の生物は対象外）。
   - プレイヤーごとに影響範囲内の線源だけを、強い順に上限数まで評価する。線量率がしきい値未満で寄与しない線源は打ち切る。
   - 経路の遮蔽値は線源とプレイヤーの位置・ブロック変更で無効化するキャッシュにする。別スレッドからワールドに触れない。
   - 通信はプレイヤー自身の線量・線量率の変化時だけ同期する。

## 決めること（初期値。変えるなら実装前に定数で調整）
- 実在値どおりだと、取り出し直後の使用済み燃料棒は1 mで数千Sv/h級となり、手で持つと即死する。初期値は実在値とし、Createのデプロイヤー・ファンネル・燃料プールで遠隔・水中で扱う前提にする。時間倍率の定数で減衰の速さだけを調整できるようにする。

## 検証
- GameTest：逆2乗、各材質の半価層での減衰、遮蔽の有無による炉心周辺の線量差、使用済み燃料の時間減衰と保存・再読込、容器の中身の量による線量、汚染の付着・拡散・除染、防護服がベータと汚染だけを防ぐこと、ガスマスクと吸入、線量計の表示値。
- 多数の線源（使用済み燃料プール1基分）とプレイヤー複数での、変更前後のサーバーtick時間。
- 専用サーバーで起動できること（クライアント専用クラスを共通処理から参照しない）。
- docs/rbmk-reactor.mdと、関連するPonder（新アイテム・除染・燃料プール）を実際の仕様どおりに更新する。
- 完了時にdocs/reports/へ完了レポートを書き、実装内容・数値の根拠・未検証事項を残す。
```
