# 変更計画：温度・圧力を「等級」にする

状態：実施中（ユーザー承認済み）。続きの作業の仕様は[引き継ぎ仕様書](thermal-grades-codex-spec.md)を正本とする。高圧タンクほど気体が多く入る仕組みは残す。この計画は、作業担当（Claude・Codex）が同じ方針で進めるための正本とする。着手前に、下の「未決事項」をユーザーが決める。

## 目的

- テストプレイで「何をすればいいかわからない」という声が出た。原因の一つは、温度（K）と圧力（bar）を連続した数値で計算し、配管・タンク・反応のすべてに関わらせていること。数値の調整、温まるまでの待ち時間、見えない破裂が、Createらしい遊び方から外れている。
- 一方で、温度と圧力にはこのmodの個性がある。配管・タンクの素材を使い分ける理由になり、反応の条件や蒸気タービンの応力にも使われている。概念そのものはなくさない。
- **方針**：温度と圧力を、数値ではなく少数の**等級**として扱う。
  - 流体の状態は流体の種類（または種類ごとに決まった等級）で表す。
  - 設備は等級を上げ下げする変換装置にする。
  - 配管・タンクは扱える等級で使い分ける。
  - 反応は等級を条件にする。
  - プレイヤーに見せるのは等級の名前だけで、数値・待ち時間・破裂はなくす。

## 等級

| 温度等級 | 目安（今の値からの対応） | 例 |
| --- | --- | --- |
| 極低温 | 150 K未満 | 液体窒素・液体酸素・液体ヘリウム |
| 低温 | 150〜283 K | 冷やした生成ガス、液体アンモニア |
| 常温 | 283〜373 K | 水・原油・多くの薬品 |
| 高温 | 373〜773 K | 予熱した原油、加熱ナフサ、熱い反応生成物、普通の蒸気 |
| 超高温 | 773 K以上 | 過熱蒸気、高温の一酸化窒素混合物 |

| 圧力等級 | 目安 | 例 |
| --- | --- | --- |
| 常圧 | 2 bar未満 | 大半の流体 |
| 加圧 | 2〜20 bar | 圧縮した合成ガス（今の12 bar） |
| 高圧 | 20 bar以上 | 水素化処理（30 bar）、水素化分解（50 bar）、高圧蒸気 |

境目の値は、今の`FluidHazards`の表と`PipeMaterial`の限界値から自動で振り分けられるように決める。プレイヤーには数値を見せない。

## 流体の等級の持ち方

- **等級は流体の種類ごとに固定する**。流体の量（スタック）ごとの温度は持たない。今の`FluidHazards.Properties(kelvin, bar, …)`を、`Grade(temperature, pressure, corrosion, gas)`に置き換える。
- 同じ物質で状態だけが違うものは**別の流体**にする。すでにこの形のものが多くある：
  - 加熱ナフサ・加熱エチレン・加熱プロピレン・加熱軽油・加熱重油・加熱合成ガス（`ThermalStreams`の6組）
  - 高温／冷却の生成ガス（5組）、圧縮合成ガス
- 新たに別流体が要るもの（洗い出しが必要）：
  - 予熱した原油（今は「620 K以上の原油」）
  - 蒸気の等級（低圧・高圧・過熱）
  - そのほか`ProcessRecipe.temperature()`・`pressure()`を持つレシピの入力
- 水と蒸気の二相（`WaterPhase`・`PhaseTank`）はやめる。水は水、蒸気は蒸気として、ボイラーや復水器が変換する。

## 設備ごとの変更

| 設備 | 今 | 変更後 |
| --- | --- | --- |
| ふた付き槽 | 内容物の温度が条件に達すると反応 | 下の熱源の段階で決まる（Createの鉢と同じ「加熱／超加熱」）。槽そのものは温度を持たない。生成物の等級はレシピで決まる |
| 流体の予熱（槽） | 加熱して温度を上げ、名前が自動で変わる | 「原油 → 予熱した原油」「ナフサ → 加熱ナフサ」のような加熱レシピ |
| 熱交換器（2×2・3×3・ジャケット管） | ε-NTUで熱を移す | レシピ型。「熱い流れ＋冷媒 → 冷えた流れ＋温まった冷媒」。大きさ・長さで処理速度が上がる。対向流は処理速度の割り増しとして残すかを未決事項で決める |
| ラジエーター・冷却ファン | 外気への放熱を計算 | 1段冷やす変換装置（高温→常温など） |
| コールドボックス・極低温 | 温度計算で液化 | 気体→液化ガスの変換装置 |
| 圧縮機 | 吐出圧力を設定 | 「常圧 → 加圧」「加圧 → 高圧」の変換（圧縮合成ガスと同じ形）。吐出圧力の設定はなくす |
| 配管・タンク | 温度・圧力・腐食で徐々に損傷し、破裂 | 素材ごとに扱える等級と耐食性を決める。合わない流体は**受け付けない**（つながらない・入らない）。ゴーグルに理由を出す |
| 減圧弁・背圧弁・安全弁・フレア | 圧力の制御と逃がし | 減圧弁は「高圧→加圧」の変換にする。背圧弁・安全弁は流量の制御か削除を未決事項で決める。フレアは可燃ガスの処分だけ残す |
| 配管計器（温度計・圧力計・流量計） | 数値を測る | 温度計・圧力計は等級を表示し、比較器出力も等級で出す。流量計はそのまま |
| ボイラー・横置き管束ボイラー | 温度・圧力のある蒸気 | 出す蒸気の等級で区別（Createのボイラーは低圧、管束ボイラーは高圧、超加熱なら過熱蒸気） |
| 蒸気タービン | 蒸気の圧力・温度で出力と応力 | 蒸気の等級で出力と応力（摩耗）が決まる。タービンの中だけで完結させる |
| 原子炉（RBMK）・核融合炉 | 内部の温度計算 | **残す**。1台の装置の中で完結する値で、Createのボイラーの熱量と同じ扱い。外へ出す蒸気・冷却材は等級にする |
| 外気との熱、配管の凍結、冷却塔の湿球温度、熱い配管でのやけど | 計算あり | 削除。冷却塔は冷却の変換装置にする |
| 過圧での破裂・爆発 | 設定でオン | 削除。原子炉の暴走と可燃ガスの漏れは残す |

## コードの扱い

- **残す・拡張する**
  - `transport/FluidHazards`（等級の表にする）
  - `transport/PipeMaterial`（扱える等級にする）
  - `safety/ToxicGas`・`CorrosiveContact`・`FlammableGas`（破裂を起点にする部分は外す）
  - `thermal/ThermalStreams`（加熱・冷却の対応表として残す）
  - 原子炉・核融合炉の内部計算
- **書き換える**
  - `thermal/ThermalEquipment`（変換装置にする）
  - `chemistry/ProcessRecipe`（`minimumKelvin`・`minimumPa`を、熱源の段階と入力の等級に）
  - `TurbineThermal`・`SteamMain`・`SteamThermal`（蒸気の等級）
  - 槽の加熱の処理
  - ゴーグル・ディスプレイリンクの表示（`compat/display/MachineReadings`など）
  - JEIの表示
- **削除する**（使われなくなったものは同じ作業で消す。本格運用前のため互換処理は作らない）
  - `FluidThermal`（スタックの温度）、`PassiveHeat`、`PassiveTank`の熱部分、`PhaseTank`、`WaterPhase`、`FluidPhase`、`PhaseChange`の連続計算部分、`GasCompression`、`GasInflow`、`PressureSections`、`PressureSetting`、`PressureVesselBehaviour`、`EquipmentSafety`
  - `HotSurfaces`、`CoolingTowerPhysics`、`ThermalMath`、`ThermalRoutes`、`FlowingWaterTank`、`WorldLiquidTemperature`
  - `PipeWearBehaviour`の損傷部分
  - Createの流体網に温度を運ばせているmixin：`ThermalFluidNetworkMixin`、`ThermalFluidTransportMixin`、`ThermalPipeConnectionMixin`、`ThermalConnectivityMixin`、`ThermalCreateTankMixin`、`ThermalFilterMixin`、`ThermalOpenEndHandlerMixin`、`PassiveFluidNetworkMixin`
  - 関連する設定（`TransportConfig`の破裂・摩耗・外気熱の項目）
  - 削除前に各クラスの利用箇所を確かめ、残す機能が使っていないことを確認する。
- **Create連携が軽くなる**：Createの流体網へのmixinが大きく減る。Create更新時の追従と、流れのバグの元が減る。
- **保存データ**：流体スタックの温度データの登録をやめると、旧ワールドの該当データは読み込めなくなる。本格運用前のため移行処理は作らず、文書に明記する。

## 未決事項（着手前にユーザーが決める）

1. 等級の数：温度5段階・圧力3段階でよいか。
2. 熱交換器の対向流：処理速度の割り増しとして残すか、なくすか。
3. 合わない流体：受け付けないだけにするか、ゆっくり漏れる・壊れる要素も残すか（設定で選べるようにするか）。
4. 背圧弁・安全弁・圧力計：流量の制御や表示として残すか、削除するか。
5. ふた付き槽の熱源：ブレイズバーナーのままにするか、電熱ヒーターや蒸気ジャケットにするか。
6. 段階3以降まで進めるか、段階2までで一度テストプレイするか。

## 決定事項（ユーザー承認）

- 計画の全段階を実施する。高圧のタンクほど同じ大きさで気体が多く入る仕組みは残す。
- 未決事項は計画の既定値で進める：
  - 温度5段階・圧力3段階。
  - 熱交換器の対向流は処理速度の割り増しとして残す。
  - 合わない流体は受け付けないだけ（漏れ・破損なし）。
  - ふた付き槽の熱源はブレイズバーナーと電熱ヒーターの両方。
  - 減圧弁は変換装置、圧力計・温度計は等級の表示にする。

## 段階ごとの記録

- S2（配管）：
  - Create・このmodの全配管が、素材の等級で流体を受け付けるかを決める（Createのバルブ・スマートパイプと同じ`canPullFluidFrom`での拒否）。ポンプやタンクは対象外。
  - 配管の摩耗・凍結・熱い面のやけど・漏れ・破裂、配管の圧力の記録（`PipeWearBehaviour`・`HotSurfaces`・`PipeGasLeak`）を削除した。
  - 物理の確認用だったRBMKプラントのプレイテスト（`RbmkPlaytestPlant`・`RbmkPlaytestWorld`・`RbmkExplosionPlaytestWorld`）も削除した。
  - 配管のゴーグル・アイテムの説明は、運べる流体の等級と耐食性を表示する。
  - ウラン六フッ化物などフッ化物はニッケル合金管でしか運べなくなるため、関連する試験の配管を合わせた。
  - ディスプレイリンクの配管系の項目は空の値を返すだけになっている。並び順は保存されているため、S6でまとめて整理する。

- A2（タンク）：
  - 共通表 `TankGrade` に全貯蔵槽の受入等級・種類・耐食性を集約。水・蒸気も同じ判定を通す。
  - 気体容量はタンクの圧力等級で×1・×16・×64。Createの結合・分割と保存で総量を保持する。
  - タンクから圧力破損・熱損傷を除去。異種ガスは拒否し、ガスホルダーで汚染・混合爆発しない。
  - 破裂設定を廃止し、可燃ガスの着火設定を独立化。処理装置の旧圧力表示・計算は後続段階で削除する。
  - 記録：[A2完了レポート](../reports/thermal-grades-a2.md)。

- A3（弁・計器）：
  - 安全弁・信号式逃がし弁・背圧弁を削除。減圧弁は共通表で圧力等級を一段下げる。
  - 温度計・圧力計の針・警報・比較器を等級に変更。PIDと発信器は流量・液位用。
  - フレアと除害装置は直接配管から受け入れる。水素の圧縮用流体はA4で生産に接続する。
  - buildと関連GameTest 15件、3種の静的検証を合格。詳細は[A3レポート](../reports/thermal-grades-a3.md)。

- A4（ガス配管・圧縮機）：
  - ガス配管の独自在庫・圧力差移送を削除し、Createの通常ポンプで移送する。
  - 往復式圧縮機は1段の等級変換と有限量の搬送。軸の動力負荷と停止・再開を維持。
  - GasNetworks・GasInflow・PressureSections・PressureSettingを削除。流量弁・電動ポンプの仕事・共通在庫の予約だけを通常流体網へ残す。
  - 加圧空気を既存の空気分留へ接続。ガス配管・圧縮機のPonderを更新。
  - buildと関連GameTest 22件合格。詳細は[A4レポート](../reports/thermal-grades-a4.md)。

- B1（流体状態・配管・貯蔵）：
  - 流体スタックの温度と熱エネルギーの登録を削除。公称温度は流体種類の表から読み、atは無操作、mixは同じ種類の量だけを加算する。
  - 外気による変化・PassiveHeat・PassiveTank・WorldLiquidTemperatureと温度輸送専用mixinを削除。タンクの等級・結合判定と流量用の構造通知は独立して維持。
  - CDGの元の燃料容器へ戻し、搬送バレルの過容量ガードだけを保持。海水・ホース・液体源の機能も維持。
  - buildと関連GameTest 41件、静的検証3種、全140 Ponderコンパイル・代表2シーン描画を合格。
  - 機器に残る連続計算は、その利用箇所をB2・B3・Cで更新してから削除する。詳細は[B1レポート](../reports/thermal-grades-b1.md)。

- B2（ふた付き槽・レシピ）：
  - VesselClimateとモル平衡を削除。加熱・超加熱はCreate熱源で判定し、水素化反応は高圧水素を使用。
  - 原油予熱・液体アンモニア蒸発・液体窒素による製氷の固定レシピを追加。加熱名流体の別名判定を廃止。
  - 鉄触媒は10,000 mB→高温混合ガス9,000 mB、分離器は冷混合ガス9,000 mB→液体アンモニア1 mB＋加圧循環原料8,000 mB。
  - 実在庫、触媒消耗、満杯停止、途中保存、所有者維持、古い搬送ポートの失効を確認。関連GameTest62件、ビルド、検証スクリプト3種を合格。
  - 全140 Ponderをコンパイルし、触媒槽・気液分離器を実描画。終了時の既知NVIDIA EGL異常は未解消。
