# 構想：密閉鉢（序盤用の簡易撹拌反応器）

2026-11-18記録。**未実装・保留**。ユーザーの指示で記録だけ行い、実装はしない。

## 背景

装置は基本的にステンレス鋼製という設定にした（[DESIGN.md「装置の材質」](../../DESIGN.md#装置の材質)）。ふた付き槽（撹拌反応槽）がステンレス鋼を必要とするため、ステンレス鋼より前に気体や酸を使う反応を少量だけ行える装置として検討した。

## 案

| 項目 | 案 |
| --- | --- |
| 形 | Createの鉢にふたを付けた「密閉鉢」。上にCreateのメカニカルミキサーをそのまま置き、ミキサーの軸がふたの穴を通って中をかき混ぜる。下にブレイズバーナー。1マスで完結 |
| 気体 | 開放の鉢は気体を受け付けない（`mixin/BasinBlockEntityMixin.java`）。密閉鉢は気体の搬入・搬出ができる |
| 処理 | ふた付き槽（撹拌翼）のレシピのうち、加熱までで、触媒・特別な部品の要らないもの。1回1バッチ、時間はふた付き槽の2倍（ふた付き槽の下位互換） |
| 酸 | 鉢とふたの内側をほうろう（ガラス引き）か陶器にする案。未決定 |
| 容量 | Createの鉢は1槽1000 mBで、浸出（スラリー4000 mB）や空気での硫黄の燃焼（空気2400 mB）の1バッチが入らない。密閉鉢だけ容量を増やす案（レシピを共用でき、JEIの表示も同じ）が有力。量を1/4にした専用レシピを作る案もある |
| 実装の要点 | 密閉鉢をCreateの鉢（`BasinBlockEntity`）として扱えば、ミキサーの頭が下りる動きはCreateのまま使える。ミキサーがこの鉢のレシピを処理対象と認めるよう、範囲を絞ったCreate連携が必要 |

## 決めること（実装するとき）

- 内側の材質（ほうろうか陶器か）。
- 容量を増やすか、小さいバッチのレシピにするか。
- 処理できるレシピの範囲。
