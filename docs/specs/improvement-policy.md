## 2. 追加した方がよいもの

- **二酸化炭素・一酸化炭素**：現在CO₂は登録がなく、尿素・ソーダ灰・メタノール・石炭ガス化の前提になる。
- **旧ワールドへの対応**：旧電解槽・旧制御盤・旧圧縮機などは変換なしで撤去された。公開前に少なくとも読み込み時の警告を検討する。
- **全GameTestの一括実行**：直近の作業は一部の試験だけを実行している。

## 3. 新しい化学反応の候補

既存設備と共通処理（[AGENTS.md](../../AGENTS.md)の「必要な仕事に絞る」）で実現できる順に並べる。

| 案 | 主な反応・工程 | 使う設備 | 狙い |
| --- | --- | --- | --- |
| 尿素 | 2NH₃ + CO₂ → 尿素 + H₂O（高圧） | 触媒反応槽、圧縮機 | アンモニア系統の発展先、強い肥料 |
| ソルベー法 | 塩水 + NH₃ + CO₂ → NaHCO₃ → Na₂CO₃ | 撹拌反応槽、焼成 | アンモニアの再利用、ガラスと石けんの原料 |
| 石炭ガス化・メタノール | C + H₂O → CO + H₂、CO + 2H₂ → CH₃OH | 炭化木材、触媒反応槽 | 石油を使わない合成燃料 |
| 銅の電解採取 | 硫酸浸出 → 硫酸銅溶液 → 電解析出 | フィルタープレス式電解セル | 新しい電解セルの用途を増やす |
| 接触改質 | ナフサ → 芳香族 + 水素（白金触媒） | 触媒反応槽、分離塔 | 脱硫・水素化分解の水素源 |
| PTFE | クロロホルム + HF → TFE → PTFE | 既存のHF・塩素 | フッ素・HF用の上位配管・ガスケット |
| 高純度シリコン | SiO₂ + C → Si、Si + HCl → SiHCl₃ → Si | アーク炉、分離塔 | 終盤素材、余った塩酸の用途 |
| リン酸肥料 | 骨粉・リン鉱石 + 硫酸 → 過リン酸石灰 | 撹拌反応槽 | 硫酸の大量消費先 |
| 活性炭 | 木炭 + 水蒸気（900 °C） | 加熱器、焼成 | 排水処理のろ材 |
| 過酸化水素 | アントラキノン法（H₂ + O₂） | 触媒反応槽 | 余った水素の用途 |

優先する組み合わせは、CO₂・尿素・ソルベー法（アンモニア・塩・化学の系統をつなぐ）、銅の電解採取、接触改質（製油所の水素不足を補う）。

## 4. 遊びにくさの原因候補

- Createの配管・ポンプ・開放パイプ・ホースプーリーにも温度・圧力・凍結が適用され、寒冷地の水配管の凍結、60 °C以上での火傷、−40 °C以下での凍傷、非対応流体による配管の劣化と破裂が起きる。
- 工程ごとに温度条件があり、加熱器・反応槽・冷却器・分離塔を毎回並べる必要がある。
- ゴーグルは4行まで、詳細はディスプレイリンクで、停止理由をその場で確かめにくい。
- 配管が6種類あり、温度・圧力・腐食の組み合わせを覚える負担が大きい。
- 設備の置き換えが頻繁で、変換なしで撤去される。

このうち、現時点で最も影響が大きいと考える原因はPonderの導線とする。

## 5. Ponderの改善方針

### 現状の問題

| 問題 | 内容 |
| --- | --- |
| タグがない | `registerTags`が未実装で、Createの思案索引から分野別に探せない |
| 1アイテムに解説が集中 | `tank_casing`に30シーン（うち29は開放円筒形タンクの直径4〜32の差分）、`lidded_vessel`に9シーン |
| 中間気体から開けない | バケツのない中間流体からPonderを開けない |
| 説明文が長い | 説明文806件中39件が100文字超。温度がKと°Cで混在 |
| 内容が古い | 撤去済みの鉢の電解槽が案内に残っている |
| 全体の道筋がない | 「最初に何を作るか」「原子炉までに何が要るか」を示すシーンがない |

### 対策（優先順）

1. Ponderタグを追加する（例：はじめに、化学、金属、発電・蒸気、配管・安全、原子力）。
2. タンク直径のシーンを代表サイズの少数シーンに統合し、作れる範囲は説明文で示す。
3. 入門シーンを追加し、水 → 電解 → 空気分離 → アンモニア、および次章の原子炉までの道筋を示す。
4. 100文字超の説明文を分割し、温度は°Cを基本にする。
5. 中間気体の工程を、関係する設備のPonderから開けるようにする。
6. 撤去済み設備の記述を削除する。

## 6. RBMK型炉までの道筋

入門シーンと文書で、次の順序を示す。

| 段階 | 内容 |
| --- | --- |
| ① 資源 | ウラン鉱石、蛇紋岩、ジルコン、ペントランド鉱、クロム鉄鉱、輝水鉛鉱、チタン鉄鉱、ボーキサイト、方解石（砕いて蛍石）、石炭ブロック、ネザーラック（砕いて硫黄） |
| ② 基礎化学品 | 電解セルで水素・酸素。硫黄 → 二酸化硫黄 → 三酸化硫黄 → 硫酸。蛍石＋硫酸でフッ化水素。フッ化水素の電解でフッ素。腐食性流体は耐食配管 |
| ③ 金属 | ニッケル・モリブデンは焙焼と水素還元。アルミニウム・チタン・ジルコニウムは溶融塩電解炉。クロムはテルミット還元。ステンレス鋼は鉄7・クロム2・ニッケル1 |
| ④ 処理設備 | ふた付き槽（棚段入り・撹拌翼入り）、遠心ロータ柱を入れた1×1槽、超加熱のブレイズバーナー |
| ⑤ 燃料 | 粉砕 → 焙焼 → 水素還元 → HFでフッ化 → フッ素でガス化（超加熱）→ 遠心濃縮 → 粉末化 → プレス → 焼成 → 完成ペレット7個＋ジルカロイ被覆管2個で燃料棒 |
| ⑥ 炉 | 最小は炉心5×5、遮蔽込み9×9。最初は7段・通常燃料（約85 MW）を推奨。3段の直径5・7炉は5%燃料が必要 |
| ⑦ 冷却・発電 | 炉 → 気液分離器 → 主循環ポンプ → 給水細管束の循環に超耐圧配管を使う。蒸気はタービンと復水器へ |
| ⑧ 起動 | 燃料と制御棒を上部キャップへ装荷し、MANで少しずつ引き抜く。AUTOは冷態起動の不具合が直るまで使わない。使用済み燃料は燃料プールへ |

原子炉までに、電解・硫酸・フッ素・6種類の金属・2種類の槽・遠心分離が必要で、燃料工程だけで9段階ある。この全体像を入門Ponderで示すことを、Ponder改善の一部とする。
