## 守ること（前回の「蒸気発電と三酸製造」の確認はこれを満たしていないので、そのやり方を流用しない）
1. 装置と装置の間の物の受け渡しは、すべてゲームの仕組み（配管・ポンプ・ファンネル・ベルト・シュート・デプロイヤーなど）で行う。テストコードが装置のハンドラーから取り出して別の装置へ入れる処理（SteamAcidPlaytestWorld.java の move() のようなもの）、BasinRecipe.apply などのレシピの直接適用、ブロックエンティティの値の書き換えは禁止。配管でつなげない・流れない箇所が見つかったら、それ自体が重要な結果なので、代行せずに止めてレポートに書く。
2. 回転はその段階で手に入る動力（水車・風車・Createの蒸気エンジンなど、またはその段階までに作った発電・タービン）で回す。クリエイティブモーター、クリエイティブの流体タンク・クレートは使わない。
3. 外から渡してよいのは、採掘や採集で手に入る原料だけ（鉱石・石炭・木材・砂・粘土・ネザーラック・水源・ブレイズロッドや卵・砂糖などブレイズケーキの材料・ネザーの物など）。設備や部品は、その段階までに作れるものだけを置く。置いた設備ごとに、レシピから材料を集計して「その段階までに作れたか」を表で確かめる（レシピマネージャーから自動で集計してよい）。
4. 段階A → B → C の順に、前の段階で作った物だけを使って進める。前の段階の生産物は、配管・タンク・チェストで次の段階へ実際に渡す。
5. 各工程は1バッチで終わらせず、続けて3バッチ以上（または24000 tick以上）運転し、詰まり・あふれ・停止が起きないかを見る。

## 進め方
- 既存の確認用ワールド（src/main/java/net/createplant/client/RbmkVariantsPlaytestWorld.java、FusionPlaytestWorld.java）を参考に、1つの通しの確認用ワールドを作る。テストコードがしてよいのは、ブロックを置く（プレイヤーが置くのと同じ向き・状態で）、プレイヤーと同じ操作（右クリック・レンチ・アイテムを持って使う）を行う、時間を進める、計測して記録する、だけ。
- 時間を進めるのに、バニラの /tick sprint（または /tick rate）を使ってよい。1 tickの処理は変わらないので結果はtick数で記録する（実時間・TPSは結果に使わない）。スクリーンショットと動きの見た目の確認は /tick rate 20 に戻してから行う。速度を上げたときに起きた不具合（チャンクの読み込み遅れなど）は、通常速度で再現するか確かめてから報告する。
- 終わったワールドは保存してリポジトリには入れず、作り方（起動設定と確認用ワールドのコード）をコミットして再現できるようにする。
- 画面の確認はXvfbとrunClient（ClientQualityCheckの仕組み）で行い、スクリーンショットを docs/quality/survival-playtest/ に保存する。
- 時間は「ゲーム内tick」で測る。回転数・バーナーの熱・ポンプの速さは、その段階で現実的に用意できる値（例：Createの水車・蒸気エンジン程度）にする。

## 段階と確認項目
A. ステンレス鋼まで（Createの鉢とメカニカルミキサーだけ。装置は使わない）
  - 炭素粉 → 鋼鉄（超加熱・プレス5回）。
  - ペントランド鉱2 → 酸化ニッケル1＋鉄塊3（加熱した鉢）。酸化ニッケル＋炭素粉 → ニッケル（超加熱）。
  - クロム鉄鉱2＋炭素粉 → フェロクロム（超加熱）。鉄6＋フェロクロム2＋ニッケル1 → ステンレス鋼10（超加熱）。ステンレス鋼板（プレス）。
  - 実際のミキサーで各レシピが選ばれるか（同じ材料で別のレシピが先に動かないか）。ステンレス鋼板を16枚作るのに必要な鉱石・炭・ブレイズケーキの量と時間。
B. ステンレス鋼の装置
  - ふた付き槽（ステンレス鋼板）を3×3で組み、撹拌翼、底の中央を32 RPM以上、下から加熱。電解セル（ステンレス鋼板）・電極ヘッド・2段の制御盤をCEEで配線し、STARTで回転なしに電極板が下りて水素と酸素が出るか、STOPで上がるか。
  - 硫黄：ネザーラックを粉砕 → 加熱した槽で空気で燃やす（硫黄粉1＋空気2400 mB）。空気は何もつないでいない配管の口からポンプで吸う。吸う速さで1バッチ分が実用的な時間で集まるか（要計測）。
  - 撹拌槽で水・二酸化硫黄・空気・鉄ナゲット → 希硫酸。セラミック管（粘土 → 未焼成 → かまど）とCreateのポンプで浸出の槽へ送れるか。銅管・強化管では止まるか。
  - 浸出（砕いた鉱石3＋希硫酸750 mB＋酸素250 mB、加熱）→ 円形沈殿池 → 電解で金属回収。鉄・銅で、鉱石1個あたりの金属の増え方。
C. その先（時間があれば）
  - 吸収塔（ステンレス鋼板）での亜硫酸と、電解セルでの硫酸。反応塔（ステンレス鋼板・モリブデン）での接触法。
  - 説明書と実績の順番（鋼鉄 → ニッケル → ステンレス鋼 → ふた付き槽 → 電解セル → 硫酸 → 浸出・ジルコニア → アルミ）どおりに進められるか。
