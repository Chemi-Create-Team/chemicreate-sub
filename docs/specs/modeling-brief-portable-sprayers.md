# モデル・テクスチャ指示書：消火器・火炎放射器・液体噴射器

この作業では、この文書と「読むファイル」に挙げたものだけを読んでください。リポジトリの探索、`docs/`・`src/main/java/`・ほかの`tools/`の読み込み、ビルドは不要です。器具の仕組み・レシピ・翻訳・Ponderは別の担当が済ませています。

## 目的

手で持って使う3つの器具のアイテムモデルとテクスチャを、ひと目で何の道具か分かり、Createの機械と並べてもなじむものに作り直す。

- 消火器（`fire_extinguisher`）
- 火炎放射器（`flamethrower`）
- 液体噴射器（`chemical_sprayer`）

今のモデルの問題：

- **消火器**：断面が四角い箱で、ボンベに見えない。黒地に白い十字のラベルが救急箱に見える。ホースはまっすぐな棒で、手で持つ取っ手もない。
- **火炎放射器と液体噴射器**：板の上にボンベが2本立った形で、台車か家電に見える。握り・引き金・銃身がなく、手に持って構える道具に見えない。2つは色が違うだけでほぼ同じ形をしている。
- **テクスチャ**：他のブロックの画像（クレーンの梁、コンクリート、テラコッタなど）を流用し、どの面にも16ピクセル1枚分を引き伸ばして貼っている。面ごとにピクセルの大きさがばらばらで、模様が読めない。

## 3つの器具の姿

3つとも、片手（右手）で持って先端を前へ向け、右クリック長押しで先端から噴射する。形は次のとおり。

### 消火器

実物の蓄圧式粉末消火器（手提げ式）に倣う。

- **ボンベ**：円筒の胴。交差した箱と45°回した板で八角柱にするなど、丸く見せる。上は丸く絞った肩、下は一回り太い台座のリング。高さは約11〜12ピクセル。
- **色**：赤い塗装の鋼。ボンベの周りに、文字のない白か銀の帯を1本入れる。
- **頭部**：真鍮の弁の頭に、上下2枚の握りレバー（下が固定の取っ手、上が押し下げるレバー）。手で持つのはこの取っ手。
- **安全ピン**：輪の付いた小さな安全ピン。
- **圧力計**：小さな丸い計器（白い盤面と、緑の範囲を示す色の帯）。
- **ホースとノズル**：黒いホースが頭部から出て胴の横を下へ回り、先端に短いノズル（または小さなラッパ口）。ホースは途中で角度を変えた2〜3本の箱で、曲がって見せる。
- **使用中のモデル**：上のレバーが押し下がった状態。

### 火炎放射器

Createの道具（ポテトキャノンなど）と同じ系統の、真鍮と安山岩合金でできた工業用の手持ち器具にする。

- **本体**：前後に長い本体に、ピストル型の握りと引き金。その前に支え用の前握り。
- **銃身**：細長い銃身を、穴あきの放熱カバーで覆う。先端は少し太い燃焼口で、その下か横に小さな点火器（種火の口）。
- **燃料タンク**：本体の下か後ろに、横向きの円筒タンクを1本。暗い鋼か、燃料を思わせる色。タンクから本体の弁へ短い配管かホースをつなぐ。今の「2本のボンベを板に載せた形」はやめる。
- **配色**：真鍮（金物・弁）、安山岩合金（本体の骨組み）、銅（配管）、暗い鋼（タンク・銃身）。危険を示す黄と黒の縞を小さく入れるのはよい。
- **使用中のモデル**：引き金が引かれ、点火器の先に小さな炎が付く（`minecraft:block/fire_0`などの炎の画像を小さな面に使ってよい）。

### 液体噴射器

背負わない、手持ちの加圧式噴霧器（農薬や薬液の噴霧器）に倣い、火炎放射器と形がはっきり違うものにする。

- **タンク**：耐食合金の円筒タンク。このmodの耐食合金バケツと同じ系統の、明るい銀灰色でやや青みがかった色。火炎放射器と違い、本体の上か後ろに縦か斜めに付ける。
- **ポンプ**：タンク上部に、手押しポンプのハンドル（T字の取っ手と軸）と、銅のポンプ部。
- **噴射棒**：細く長い噴射棒（ランス）の先に、平たい扇形のノズル。手元に握りと引き金のレバー。
- **ホース**：タンクから握りへつながる細いホース。
- **使用中のモデル**：引き金のレバーが握られた状態。

## 見せ方（`display`）

- **一人称（右手）**：画面の右下に置き、先端が画面の中央（照準）の方を向く。器具が視界をふさがない大きさにする。
- **三人称**：握り（消火器は取っ手）を手の位置に合わせ、先端が前を向く。
- **GUI**：斜め上から見た姿で、スロットにぎりぎり収まる大きさ。器具の種類が16×16の大きさでも見分けられること（消火器は赤い縦長、火炎放射器は横長の銃形、液体噴射器は銀のタンクと長い棒）。
- **地面・額縁**：寝かせた、または立てた自然な姿。
- 左手用も、右手用を左右反転した値にそろえる。

## 読むファイル

- `tools/generate_portable_sprayers.py`：3つの器具のモデル・使用中モデル・レシピ・Ponder構造の生成元（正本）。今の形は`extinguisher()`（消火器）と`gun(flame)`（火炎放射器と液体噴射器の共通形）、見せ方・使用中モデル・`overrides`は`models()`にある。火炎放射器と液体噴射器は別々の関数に分けてよい。
- `src/main/resources/assets/create_refinery_n_reactors/models/item/`の`fire_extinguisher.json`・`flamethrower.json`・`chemical_sprayer.json`と、それぞれの`_active.json`（今の出力、参考）。
- 色の手本（読んでよいが、上書きや画像の流用はしない）
  - Createのjarの`assets/create/textures/block/`：`brass_casing.png`、`andesite_casing.png`、`copper_casing.png`。
  - Createのjarの`assets/create/textures/item/potato_cannon.png`と、`assets/create/models/item/potato_cannon/item.json`（ポテトキャノンの立体モデル）。Createの手持ち道具の部品の大きさ・色の段階・持たせ方の手本にする。
  - `src/main/resources/assets/create_refinery_n_reactors/textures/item/corrosion_resistant_bucket.png`：耐食合金の色。

モデルJSONは生成物です。手で直さず、生成元を変更して`python3 tools/generate_portable_sprayers.py`で出力してください。

## 変えてよいもの・変えないもの

| 変えてよい | 変えない |
| --- | --- |
| 3つの器具の形（部品の数・位置・大きさ・回転）と、使用中モデルの差分 | アイテムID（`fire_extinguisher`・`flamethrower`・`chemical_sprayer`）と、モデルのファイル名（`<id>.json`と`<id>_active.json`） |
| `display`の値 | 使用中モデルへ切り替える条件（`overrides`の`create_refinery_n_reactors:spraying`） |
| テクスチャの割り当てと、面ごとのUV | レシピ、Ponder構造、流体タグ、翻訳（生成元のそれらの部分） |
| 新しいテクスチャを`textures/item/portable_sprayers/`に描き、生成元から書き出すこと | Javaのコード |
| 他のブロックの画像の流用をやめること（`TEXTURES`の置き換え） | ほかのブロック・アイテムの画像 |

## モデルの規則

- 部品は箱（直方体）で組む。回転は1軸だけ、角度は-45・-22.5・0・22.5・45のいずれか（Minecraftの制限）。
- 座標は-16〜32の範囲に収める。
- 部品の数は、1つの器具につき60個以下を目安にする。今のように同じ形を少しずつずらした箱を重ねて太さを出すのではなく、1つの部品は1つの形を表す。
- 裏に隠れて見えない面は省いてよい。重なった面のちらつき（同じ位置の面）は作らない。
- 使用中モデルは、通常モデルとの差（レバー・引き金・炎）だけを変える。全体の位置がずれないこと。

## テクスチャの規則

- テクスチャは器具ごとに専用の画像を描く。1枚にまとめたアトラス（例：32×32や64×64）でもよい。
- 密度：1ピクセル＝1/16ブロック。各面のUVは、その面の大きさに合わせて切り出す。今のように、どの面にも画像1枚分を引き伸ばして貼らない。
- 1枚あたり24色以下。ざらつきは2ピクセル以上の塊で表し、1ピクセル単位のノイズで埋めない。
- 光源は左上。写真、写真から作った画像、画像生成AIの出力、なめらかなグラデーション、広い鏡面ハイライトは使わない。
- 金属は、明るい面・基本・暗い面・継ぎ目の3〜4段階で、Createの真鍮・安山岩合金・銅の色に合わせる。
- 文字・ロゴ・実在のメーカー名・医療の十字・実在の規格表示は描かない。消火器のラベルは文字のない帯か、単純な炎の形の絵記号までにする。

## 完了時に確認すること

1. `python3 tools/generate_portable_sprayers.py`がエラーなく終わる。
2. 次のコマンドで、すべての画像が16の倍数の大きさで、24色以下である。

```bash
python3 -c "from PIL import Image;import glob
for f in sorted(glob.glob('src/main/resources/assets/create_refinery_n_reactors/textures/item/portable_sprayers/*.png')):
    i=Image.open(f).convert('RGBA');print(f.split('/')[-1],i.size,len(set(i.get_flattened_data())))"
```

3. 次のコマンドで、各モデルの部品数・回転の角度・座標の範囲が規則に収まっている。

```bash
python3 -c "import json
for n in ['fire_extinguisher','flamethrower','chemical_sprayer']:
  for s in ['','_active']:
    m=json.load(open(f'src/main/resources/assets/create_refinery_n_reactors/models/item/{n}{s}.json'));e=m['elements']
    bad=[x['name'] for x in e if 'rotation' in x and x['rotation']['angle'] not in (-45,-22.5,0,22.5,45)]
    out=[x['name'] for x in e if min(x['from']+x['to'])<-16 or max(x['from']+x['to'])>32]
    print(n+s,len(e),'bad angle',bad,'out of range',out)"
```

4. `git status`で、変更が次の範囲に収まっている。レシピ・Ponder構造・タグも再出力されるが、内容は変わらない。
   - `tools/generate_portable_sprayers.py`
   - `models/item/`の6つのモデル
   - `textures/item/portable_sprayers/`

変更したファイル、器具ごとの部品数と画像の大きさ・色数、見せ方（`display`）で決めた向き、気になった点を短く報告してください。
