# テクスチャ指示書：ガスタンクコンテナ

この作業では、この文書と「読むファイル」に挙げたものだけを読んでください。リポジトリの探索、`docs/`・`src/main/java/`・ほかの`tools/`の読み込み、ビルドは不要です。ブロックの仕組み・形状・Ponder・文書・ゲーム内確認は別の担当が済ませています。

## 目的

ガスタンクコンテナ（`gas_tank_container`）のテクスチャを、実物のISOタンクコンテナらしく作り直す。今のテクスチャは単色に近い仮のもので、リアルに見えない。形は実物のタンクコンテナに倣い、色はCreateの部品になじむ金属にする（実物のオレンジ塗装・白塗装は使わない）。

見た目（20フィートのタンクコンテナの形をもとに）：

- **枠**：Createの安山岩ケーシング（`andesite_casing`）の縁と同じ系統の、灰色がかった安山岩合金の金属でできた角形フレーム。角ごとに、楕円の穴が開いた隅金具（コーナーキャスティング）がある。梁は角形鋼管で、継ぎ目と陰影が見える。
- **端面**：四角い枠の中に、ひし形に組んだ板状の筋かいがあり、その奥に鋼の鏡板（タンクのふた）が見える。
- **タンク**：塗装していない鋼の横置きの胴。このmodの鋼鉄ブロック（`steel_block`）の色に合わせる。長さ方向に一定間隔で、周方向の溶接線（胴の継ぎ目）が入る。
- **汚れ**：うっすらとした使用感はよいが、錆だらけにはしない。

## 形（変えない）

ブロックは決まった大きさでだけタンクになる：断面1×1で長さ2、2×2で長さ5、3×3で長さ7。モデルは生成スクリプトが作る。

- 枠：4本の長手レール（2×2ピクセルの断面）、両端の四角い枠（2ピクセル幅）、角の隅金具（約3ピクセル角）。
- タンク：八角柱の胴。2本の交差した箱と、45°回した4枚の板でできている。
- 端：一回り小さな八角柱の鏡板と、ひし形の筋かい（45°回した板）。
- 胴の大きさ：断面1×1ではアポセム5ピクセル、2×2では13ピクセル、3×3では21ピクセル。1つの面は最大で約40ピクセル四方になる。
- 環境光の陰（ambient occlusion）は切ってある。面の明るさは、Minecraftが面の向きで付ける陰だけ。

## 読むファイル

- `tools/generate_gas_tank_container.py`：このブロックのテクスチャ・モデル・ブロックステート・Ponder構造の生成元（正本）。今のテクスチャは`textures()`が描く`frame`・`casting`・`shell`の3枚。
- `src/main/resources/assets/create_refinery_n_reactors/textures/block/gas_tank_container/`の今の画像（参考）。
- 枠の色の手本：Createの`andesite_casing.png`の縁（Createのjarの`assets/create/textures/block/`）。縁の金属の色・陰影・リベットの描き方を手本にする。読んでよいが、上書きや画像の流用はしない。
- タンクの色の手本：`src/main/resources/assets/create_refinery_n_reactors/textures/block/steel_block.png`（このmodの鋼鉄ブロック）。読んでよいが、上書きしない。

モデルJSON（`models/block/gas_tank_container/`）とブロックステートは生成物です。手で直さず、生成元を変更して`python3 tools/generate_gas_tank_container.py`で出力してください。

## 変えてよいもの・変えないもの

| 変えてよい | 変えない |
| --- | --- |
| `textures()`の中身。テクスチャの枚数を増やしてよい（例：枠の梁、端の枠、隅金具、筋かい、胴の側面、鏡板を別の画像にする） | 各部品の位置・大きさ・回転（`cell_model()`・`octagon()`・`braces()`の座標と角度） |
| `cell_model()`・`octagon()`・`braces()`の中の、どの部品にどのテクスチャを使うかの割り当て | モデル名（`loose`、`size_<幅>_<位置>_<端>`）と数、ブロックステートの条件 |
| `element()`のUVの付け方。今は16ピクセルを超える面に画像を1枚分引き伸ばしている（面の大きさの上限16で切っている）ので、密度がそろうように直してよい | `data()`・`tank()`・`lesson()`・`tutorials()`の中身 |
| 胴の溶接線を、決まった間隔で入れる工夫（UVのずらし方など） | `ambientocclusion: false` |

UVについての注意：Minecraftのモデルの面は1枚の画像を繰り返し貼れない。大きな面に同じ密度で模様を出したいときは、次のどちらかで行う。

- その面専用の大きめの画像（32×32や48×48）を作り、UVでその一部を使う。
- 引き伸ばしても不自然にならない、大きな塊だけで描いた画像にする。

## テクスチャの規則

- 基本は1面あたり16×16の密度。大きな面に専用画像を使う場合は、16の倍数の大きさで、ほかの面と同じ密度にそろえる。
- 1枚あたり24色以下。ざらつきは2ピクセル以上の塊で表し、1ピクセル単位のノイズで埋めない。
- 光源は左上。写真、写真から作った画像、画像生成AIの出力、なめらかなグラデーション、広い鏡面ハイライトは使わない。
- 色の目安
  - 枠：安山岩ケーシングの縁の金属の色に合わせる（明るい面・基本・暗い面・継ぎ目の4段階程度）。
  - 隅金具：枠より一段暗い同じ系統の金属。穴は黒に近い色。
  - 胴：鋼鉄ブロックの色に合わせた鋼（3〜4段階）。枠と同じ色に見えないよう、明るさか色みで区別する。溶接線は胴より暗い1ピクセルの線にし、その脇に1ピクセルの明るい線を添える。
- 文字・ロゴ・実在のメーカー名や表示（CIMCなど）は描かない。危険表示のひし形ラベルやプレートを小さく入れるのはよいが、文字は入れない。

## 完了時に確認すること

1. `python3 tools/generate_gas_tank_container.py`がエラーなく終わる。
2. 次のコマンドで、すべての画像が16の倍数の大きさで、24色以下である。

```bash
python3 -c "from PIL import Image;import glob
for f in sorted(glob.glob('src/main/resources/assets/create_refinery_n_reactors/textures/block/gas_tank_container/*.png')):
    i=Image.open(f).convert('RGBA');print(f.split('/')[-1],i.size,len(set(i.get_flattened_data())))"
```

3. `git status`で、変更が次の範囲に収まっている。Ponder構造・翻訳・タグ・ルートも再出力されるが、内容は変わらない。
   - `tools/generate_gas_tank_container.py`
   - `models/block/gas_tank_container/`
   - `blockstates/gas_tank_container.json`
   - `models/item/gas_tank_container.json`
   - `textures/block/gas_tank_container/`
4. 使わなくなった画像を残していない（生成元は毎回フォルダーの画像を消してから書く）。

変更したファイル、画像ごとの用途と色数、UVの付け方を変えた場合はその方法、気になった点を短く報告してください。
