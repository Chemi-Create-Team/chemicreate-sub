# 指示書：用途の少ない素材に使い道を足す

この文書は、Codexへの作業依頼です。作業の前に `AGENTS.md` と `DESIGN.md` を読み、その規約に従ってください。数値は目安です。釣り合いが悪いと分かったら変えてよいですが、変えた理由をレポートに書いてください。

## 背景

これまでに足した素材の中に、使い道がないものや1つしかないものがあります。次の8項目で、それぞれに使い道を足します。顔料（大量の着色）と、アルミ・チタン・ニッケルの板は、この作業に含めません。

## 全体の約束

- 作業ブランチは `main` です。項目ごと（またはいくつかずつ）にコミットしてください。プッシュの前に `git fetch origin main` → `git rebase origin/main` を行い、強制プッシュはしないでください。
- 原子炉（Mhikenekoさんの担当）のJava（`nuclear/`、`FuelChannelBlockEntity`、`FuelPoolBlockEntity`、`CraneDriveBlockEntity` など）は変えないでください。項目2は、レシピを足すだけで済ませます。
- 新しい流体やアイテムは、どうしても必要なときだけ足してください。まず、既存の流体・アイテム・設備で済ませます。
- レシピ・アセット・翻訳は、関係する `tools/generate_*.py` の書き方に合わせて作ってください。翻訳は英・日・中の3言語です。
- 新しい仕組み（項目1・2・4）には、Ponderを作るか、既存のPonderに手順を足してください。Ponderの文に `%` を書かないでください（日本語は `％`、英語は `percent`）。
- 撹拌反応槽のレシピは `recipe/pressure_reaction/`、Createのミキサーは `recipe/mixing/` にあります。どちらも既存のJSONの形に合わせてください。
- 腐食性の流体を足したり使い方を変えたりしたら、`transport/FluidHazards.java` の区分も確かめてください。

## 1. 苛性ソーダの排ガススクラバー（安全弁）

- 今の動き：`ReliefValveBlockEntity` は、逃がし先が使えないとき、吹出口の上へ気体を大気放出します（`ToxicGas.release`、89行目付近）。
- 足すこと：吹出口の真上に、苛性ソーダ液（`CEChlorAlkali.CAUSTIC_SODA`）の入ったタンク（流体ハンドラーを持つブロックなら何でもよい）を置けるようにします。置いてあれば、酸性の有毒ガスを大気へ出す前に中和します。
  - 中和するガス：塩素、塩化水素、硫化水素、二酸化硫黄、三酸化硫黄、二酸化窒素、フッ化水素、フッ素。アンモニアは塩基性なので中和しません。
  - 量：ガス1 mBにつき苛性ソーダ液1 mBを使い、そのガスは消えます。苛性ソーダが足りなければ、足りない分のガスは今までどおり雲になります。
  - 生成物：作らなくてよいです（廃液として捨てる扱い）。
- 状態表示：ゴーグルの経路表示（`route`）に「スクラバーで中和中」を足し、翻訳キーで出します。
- 確認：GameTestで次の3つを確かめてください。
  - 塩素を逃がすと苛性ソーダが減り、雲ができないこと。
  - 苛性ソーダが足りないと、残りが雲になること。
  - アンモニアは中和されないこと。
- Ponder：「有毒ガスとガスマスク」に手順を1つ足すか、安全弁のPonderに足します。
- 文書：`docs/toxic-gas.md`、`docs/chlor-alkali.md`。

## 2. 使用済み燃料の再処理（PUREX法）

- 足すこと：撹拌反応槽のレシピ（`pressure_reaction`、加熱あり）。
  - 使用済み燃料棒1＋硝酸1,000 mB → 硝酸ウラニル溶液（既存）＋ジルコニウムインゴット（被覆管の回収）。
  - 使用済み制御棒1＋硝酸500 mB → 制御棒の材料の一部（例：原子炉用黒鉛）。
- 量：`fuel_rod` の材料（ウランペレット・ジルカロイ被覆管）より少なく戻るようにしてください。再処理だけで燃料が増えることは許しません。硝酸ウラニル溶液の量は、新燃料1本に要るウランの半分程度が目安です。
- 硝酸ウラニル溶液から先は、今ある工程（三酸化ウラン →…）がそのまま使えます。
- Ponder：新しく「使用済み燃料を再処理する」を作ります。使用済み燃料棒から開けるようにしてください。
- 文書：`docs/fuel-pool.md`、`docs/rbmk-reactor.md`（使用済み燃料のその後の説明だけ）、ウランの工程表。
- 確認：GameTestで、撹拌反応槽がこのレシピを実際に処理することを確かめます。`ReactorGameTests.everyStirredReactionRunsWithItsHeat` に自動で含まれるなら、それで足ります。

## 3. アルゴンを使うステンレス鋼の精錬（AOD法）

- 足すこと：`recipe/mixing/stainless_steel_ingot_aod.json`。
  - 材料：今のレシピ（`mixing/stainless_steel_ingot.json`）と同じ（鉄7・クロム2・ニッケル1）に、アルゴン（`argon_gas`）100 mBを足します。
  - 結果：ステンレス鋼インゴット12（今のレシピは10）。超高温（superheated）。
- 文書：`docs/metals.md` のステンレス鋼の表、`docs/distillation-plant.md`（アルゴンの用途）。

## 4. 石綿の隔膜（ソーダ工業）

- 今の動き：`basin/BasinElectrolysis.java` は、塩水2 mBを水素1・塩素1・苛性ソーダ液2 mBにします。
- 足すこと：電解槽の鉢のどれかに石綿（`asbestos`）があると、隔膜として働きます。
  - 効果：塩水電解の苛性ソーダ液が1.25倍になります（塩素・水素・電力は同じ）。
  - 消耗：塩水10,000 mBごとに石綿1を使います。鉢の中身の扱いは、既存の材料消費のやり方に合わせてください。
  - 水・フッ化水素の電解には効きません。
- 石綿の粉じん（粉砕で有毒な雲が出る）は、実装が大きくなるなら見送り、レポートに書いてください。
- JEI：鉢の電解槽のカテゴリーに、隔膜ありの場合を足します。
- Ponder：「塩・塩素・苛性ソーダ」に手順を1つ足します。
- 文書：`docs/chlor-alkali.md`。
- 確認：GameTestで、隔膜ありとなしの苛性ソーダの量と、石綿の消耗を確かめます。

## 5. 塩酸で作る二酸化チタン（合成ルチル法）

- 足すこと：撹拌反応槽のレシピ（加熱あり）。
  - チタン鉄鉱2＋塩酸500 mB → 二酸化チタン1＋鉄塊3。
- 硫酸法（`titanyl_sulfate_solution` → `titanium_dioxide`）より有利になりすぎないようにしてください。硫酸法は、熱い酸を樹脂パイプで扱う手間があります。塩酸法は手順が1つ少ない代わりに、二酸化チタンを少なめにします。
- 文書：`docs/metals.md`、`docs/chlor-alkali.md`（塩酸の用途）。

## 6. ジルコニアの耐火物

- 足すこと：溶融塩電解炉の外殻（`electrolysis_furnace_shell`）の作業台レシピに、ジルコニアを1〜2個足します（今の材料の一部と置き換えてもよい）。
- 必ず確かめること：ジルコニアを作るのに、この2つの設備が要らないこと。
  - 今は、撹拌反応槽で硫酸ジルコニウム溶液からジルコニアを作っています。硫酸の製造や撹拌反応槽の加熱工程を確認し、電解炉へジルコニアを足しても循環しないことを確認してください。
  - `CraftingRecipeGameTests` の製作経路のテストが通ることも確かめてください。
- 文書：`docs/reports/crafting-recipe-review.md` の流れに合わせ、設備の文書のレシピ欄を直します。

## 7. 炭素粉による鋼鉄

石炭・木炭1個を石臼または破砕ホイールで炭素粉1個にする。鉄インゴット4個と炭素粉1個を超加熱したブレイズバーナー上の鉢・ミキサーで混ぜ、鋼鉄の中間素材4個を得る。それぞれ5回プレスして鋼鉄計4個にする。パドル鉄と蛍石による増産レシピは廃止。蛍石の既存の化学用途と入手経路は維持する。

## 8. 工業用ガラス・工業用樹脂を部品に使う

- 工業用ガラス：配管の計器3種（`pipe_pressure_gauge`、`pipe_thermometer`、`pipe_flow_meter`）のレシピに、文字盤のガラスとして工業用ガラスを1つ足します（今のレシピにガラスは入っていません）。
- 工業用樹脂：燃料電池（`fuel_cell`、電解質膜）と流量調節器（`flow_regulator`）のレシピに足します。
- 序盤に作るものなので、素材を作るまでの手順が重くなりすぎないか確かめてください。
- 液化酸素：レシピは足しません。保冷タンクで液のまま運び、普通のタンクや熱交換器で気化させて酸素として使う、という使い方を確かめます。
  - まず、その動き（`PhaseChange`）が今もそのとおりに動くことを確かめます。
  - 動くなら、`docs/distillation-plant.md` と保冷タンクのPonderに書きます。動かないなら、直してから書きます。
