# 液体の設置・耐食バケツ・硫酸炭化

## 決定した仕様

2026-11-09のユーザー選択を正本とする。

- 自Modのすべての液体を、バケツから液源として設置し、流水として流し、再び汲めるようにする。気体は既存の放出操作を維持する。
- 今回は設置した液体を自然気化・凝固させない。ユーザーの追加指示により、設置した瞬間に温度情報を破棄する。汲み上げ時に温度情報がなければ、その採取場所の環境温度を設定する。温度を持つ容器・タンク間の移送では既存の情報を保持する。
- 追加液体を無限液源化しない。Createのホースプーリーでも無限供給にしない。
- 耐食合金バケツをニッケル3個、クロム1個、モリブデン1個から1個製作する。新しい中間合金は追加しない。
- 金属精錬に酸を使う既存工程は残す。最初の酸は従来どおり配管・タンクで製造・移送でき、耐食バケツを初回の酸製造条件にはしない。
- 腐食性液体は耐食合金バケツ、通常液体は通常バケツで扱う。注液・排液・クラフト・ディスペンサーで容器の金属が入れ替わらないようにする。
- 腐食性の酸・アルカリに触れた生物へ、液源・流水とも毎秒2HPの防具貫通ダメージを与える。複数の液体マスに触れても同じ周期で加算しない。金属の腐食区分に含まれる塩水は、酸・アルカリの接触熱傷から除く。
- 硫酸1杯（1000 mB）を木材へ直接使うか、硫酸の液源を隣接させると、木材1個の炭化が始まる。液源は1個を消費し、隣接した別の木材へ二重に作用させない。流水だけでは炭化させない。
- 原木・板材のタグを対象にし、竹やネザー材も含める。斧で剥いだ原木も原木として扱う。
- 新しい炭化木材ブロックは600tick（稼働中のゲーム内時間30秒）で段階的に黒くなる。完成後もワールドに残る。
- 完成品を壊すと原木由来は木炭4個、板材由来は木炭1個になる。未完成の破壊は元の木材を返し、硫酸は戻さない。
- 進捗と元材は保存する。未ロードのチャンクを強制ロードせず、再ロードから続行する。
- 新しい装置は追加しない。操作、材質制限、炭化、接触の危険をPonderで説明する。

## 実装上の境界

登録IDと既存液体・バケツのIDは維持する。従来バケツがなかった液体には容器と液体ブロックを追加する。既存の処理レシピや原子炉の物理は変更しない。

耐食合金はニッケル・クロム・モリブデン系の実在耐食材料を参考にしたゲーム用区分であり、実機のあらゆる濃度・温度に対する材質保証ではない。全液体の設置を優先し、屋外の相変化、酸の濃度、専用防護装備、周囲の建材を広範囲に溶かす機能は今回の対象に含めない。
