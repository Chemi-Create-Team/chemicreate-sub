# 設計：ふた付き槽の役割を専用装置へ分ける

2026-11-16にユーザーと合意した方針と、それに基づく具体設計です。

> **取り下げ（2026-11-16）**：ユーザーの指示で、撹拌反応槽と触媒反応器は元のふた付き槽＋内部部品の方式に戻しました。吸収塔だけを独立した装置として残し、2つの大きさにしています。現行の仕様は[反応プラント](../reaction-plant.md#吸収塔)と[吸収塔の完了レポート](../reports/absorption-tower-sizes.md)を参照してください。

## 背景

今のふた付き槽は、見た目が同じ槽に内部部品（撹拌翼・触媒充填バスケット・反応／吸収棚段）を入れ替えて、撹拌反応・触媒反応・吸収と気固反応・貯蔵に使い分けています。外から役割が見分けられず、「3×3に積み、各段に部品を入れ、底の中央を回し、下から加熱する」という手順もわかりにくい状態です。

| 役割 | 内部部品 | レシピ |
| --- | --- | --- |
| 撹拌反応 | 撹拌翼 | 撹拌反応のJSON（`pressure_reaction`）62件＋Createのミキサーのレシピ |
| 触媒反応 | 触媒充填バスケット | `ProcessRecipe`の`REACTION_VESSEL`10件＋アンモニア合成（`CATALYST_UNIT`） |
| 吸収・気固反応 | 反応・吸収棚段 | 硝酸の吸収1件＋ウランの気固反応4件（`module: absorber`） |
| 貯蔵 | なし | なし |

## 合意した方針

- 役割ごとに、見た目と名前の違う装置へ分ける。内部部品を入れて役割を変える仕組みはやめる。
- 撹拌反応の回転は、ふたの上の撹拌機から入れる。
- 吸収は塔の形で残し、硫酸（三酸化硫黄＋水）と塩酸（塩化水素＋水）の吸収もそこへ移す。
- 触媒反応器は、3×3の八角の縦型円筒にする。
- 仕組みはClaudeが実装し、モデルとテクスチャはFableへ依頼する。

## 1. 撹拌反応槽＝ふた付き槽＋撹拌機

Createの「鉢の上にミキサー」を大きくした関係にする。

- **撹拌機（`agitator_drive`）**：新しいブロック。3×3のふた付き槽の最上段の中央の上に置くと、その槽が撹拌反応槽になる。外すと貯蔵槽に戻る。
  - 回転はCreateのメカニカルミキサーと同じく、上面のシャフトか、側面の歯車（小歯車として噛み合う）から入れる。32 RPM以上で運転し、速さは`回転数÷32`倍（最大4倍、今と同じ）。
  - 応力は今と同じ16 SU/RPM×段数で、撹拌機が負う。
  - 見た目はモーターと減速機。運転中は、点検窓から見える撹拌軸と羽根が回る。
- **槽**：1〜4段のふた付き槽をそのまま使う。各段の撹拌翼の装荷はなくなり、撹拌翼（`reactor_impeller`）は撹拌機の材料に回す。
- **ハッチ**：撹拌機が載っている間は中央のハッチが開かない。汚れは今ある洗浄水で落とすか、レンチで撹拌機を外してからブラシをかける。
- **レシピ**：今の撹拌反応すべてと、Createのミキサーのレシピ。棚段で行っていたウランの気固反応4件（ペレット焼結、二酸化ウランへの還元、六フッ化ウランへのフッ素化、小型炉用の二酸化ウラン）もここへ移す。加熱条件は変えない。
- **入出力**：今の撹拌反応と同じ（液体は側面、気体は上面、アイテムはファンネル、底面は汚れの排出）。

## 2. 触媒反応器（3×3の八角の縦型円筒）

触媒を詰めた縦長の円筒に上から原料を流し、下から製品を取り出す。撹拌しない。

- **組み立て**：メカニカルクラフターで作る「触媒反応器の胴」を2〜4段積む。1個で3×3の八角形の段を置く（パルス抽出塔の段と同じ置き方）。最下段の中心が制御部を兼ねる。
- **触媒**：最上段の天面から、ファンネルか素手で入れる。最下段をしゃがんで素手で右クリックすると取り出せる。触媒の種類で反応が決まる。
- **回転は不要**。処理速度は一定で2倍（今の64 RPM相当）。段数が並列バッチ数になる（今と同じ、1段1バッチ）。
- **熱**：最下段の下の3×3に置いた熱源（ブレイズバーナー、電熱ヒーター）。条件は今と同じ。
- **入出力**：

| 面 | 動作 |
| --- | --- |
| 最上段の天面 | 原料の搬入（気体・液体）、触媒の搬入 |
| 最下段の側面 | 製品の搬出 |
| それ以外 | 何も公開しない |

- **レシピ**：`REACTION_VESSEL`の10件と、アンモニア合成。原料・製品・時間・触媒の消耗は変えない。

## 3. 吸収塔（1×1の細長い塔）

気体を下から、水を上から流し、塔の中で向かい合わせに接触させる（向流）。

- **組み立て**：「吸収塔の段」を縦に4〜8段積む。直径14ピクセルの円筒で、段ごとに棚の帯とのぞき窓を描く。最下段が制御部。
- **回転・熱は不要**。速さは`段数÷4`倍。
- **入出力**：

| 位置 | 搬入 | 搬出 |
| --- | --- | --- |
| 最下段の側面 | 気体の原料 | 液体の製品（酸） |
| 最上段の側面・天面 | 水 | 吸収しきれなかった気体（硝酸の一酸化窒素） |

- **レシピ**（`ProcessRecipe`の`ABSORPTION_TRAYS`に集め、JSONから移す）：
  - 硝酸：二酸化窒素300 mB＋水100 mB → 硝酸200 mB＋一酸化窒素100 mB（今のまま）
  - 硫酸：三酸化硫黄250 mB＋水250 mB → 硫酸250 mB（今の`pressure_reaction/sulfuric_acid`の量）
  - 塩酸：塩化水素500 mB＋水500 mB → 塩酸1,000 mB（今の`pressure_reaction/hydrochloric_acid`の量）

## 4. 貯蔵槽

ふた付き槽は、撹拌機を載せなければ今の貯蔵槽として使う（1×1〜3×3、1〜4段、ハッチ、汚れ、加熱）。

## 削除するもの

- 内部部品の登録と仕組み：`reactor_catalyst_basket`、`reactor_separator_core`（撹拌翼は撹拌機の材料として残す）、各段の装荷、`ReactorModule.VESSEL`と`ABSORBER`の槽側の処理、触媒バスケットの処理（`CatalystBasketProcess`は触媒反応器へ移す）。
- 底面の回転入力（`DRIVE`の状態と、底からの動力選択）。
- 関係するPonder・JEIの表示・ガイド・テスト・生成元・翻訳。

## 決めていないこと（実装時に判断してレポートに書く）

- 触媒反応器の一定速度（2倍）と、吸収塔の段数による速度が、今の運用と釣り合うか。
- ウランの気固反応を撹拌反応槽へ移したとき、同じ原料を使う別のレシピとぶつからないか。
