# 指示書：転炉の炉体を超粘着剤で組むからくりにし、素材と転炉ガスの量を直す

この文書は、Codexへの作業依頼です。作業の前に `AGENTS.md` と `DESIGN.md` を読み、その規約に従ってください。今の転炉（`f689d48`、9×9×11の鉄骨の架台）を作り直す作業です。

## 背景と決定事項

ユーザーの決定（2026-11-06）は次の3つです。

1. **炉体の素材**
   - 今の可動の炉体は銅を使っていますが、銅の融点（約1,085 °C）は溶鋼（約1,650 °C）より低いので、合いません。
   - 実在の転炉と同じく、**外殻を鋼**（Createの鋼材ブロック `create:industrial_iron_block`）、**内張りと炉口を耐火物**にします。耐火物は新しいブロック「ジルコニア耐火レンガ」です。
2. **炉体をCreateのからくりとして動かす**
   - CDGのポンプジャックと同じ方式にします。プレイヤーが炉体を本物のブロックで組み、**超粘着剤で接着**します。専用の軸受（ベアリング）が、その炉体をCreateのからくり（コントラプション）として傾けます。
   - 今の「描画だけで炉体を傾ける」方式（`ConverterRenderer` の可動部）は廃止します。
3. **転炉ガスの量**
   - 今の8,000 mBでは、工業用加熱器を約5 tickしか動かせず、燃料として役に立ちません。
   - 炉内では、酸素1体積から一酸化炭素がおよそ2体積できます（2C＋O₂ → 2CO）。そこで、酸素64,000 mBに合わせて、**転炉ガスを128,000 mB**にします。

## 1. 参考にするCDGの実装

CDG 1.3.15の `com.jesz.createdieselgenerators.content.pumpjack` を読んでから設計してください。

- `PumpjackBearingBlockEntity` は、Createの `MechanicalBearingBlockEntity` を継承しています。`assemble()` で `BearingContraption` を作り、`attach()` で `ControlledContraptionEntity` を受け取り、`assembleNextTick` で組み立てを次のtickに回しています。
- 炉体の接着には、Create 6の超粘着剤（`SuperGlueEntity`）をそのまま使います。接着されていないブロックは、からくりに入りません。

## 2. 新しい作りの構成

### 据え付け部分（動かない）

- 今の9×9の鉄骨の架台、支柱、桁は残します。ただし、架台にある銅ブロックは鋼か耐火物に置き換えます。
- **転炉のトラニオン軸受**（新しいブロック、例：`converter_trunnion_bearing`）
  - 炉体の片側の軸に置きます。Createの `MechanicalBearingBlockEntity` を継承し、シャフトの回転で炉体を傾けます。
  - 反対側の軸は、回転しない軸受（今の従動軸受の役目）にします。
- **在庫（原料・製品・気体・転炉ガス）は据え付け部分に置きます。** 今の所有ブロック（左トラニオン）か、新しい軸受のブロックエンティティです。
  - 炉体をからくりにしても、在庫はからくりの中に入りません。そのため、移動・保存・チャンクのアンロードで中身が消えたり増えたりしないようにできます。
- 入出力の口（酸素ランス、原料の口、転炉ガスの口、出鋼口）も、据え付け部分に置きます。今のCreateの流体パイプ・シュートとのつなぎ方は残してください。

### 動く部分（プレイヤーが組んで接着する炉体）

- 炉体の形は、今の5×5の段付きの炉体を基準にします。外殻と内張りの区別ができる形にしてください。
  - 外殻のマス：Createの鋼材ブロック。
  - 内張り・炉口のマス：ジルコニア耐火レンガ。
  - どのマスに何を置くかを `ConverterStructure` に定義し、Ponderで示します。
- プレイヤーは、炉体を組んでから超粘着剤で全体を接着します。
- 炉体の中に、ブロックエンティティを持つブロックは要りません（在庫は据え付け部分にあるため）。

### 動き

1. 直立（0°）では、炉体は普通のブロックとしてワールドにあります。このときだけ、炉体の形と素材を確かめ、吹錬します。
2. シャフトを正転させると、軸受が接着された炉体を組み立て、60°まで傾けて止まります。
   - 組み立てる前に、接着されたブロックの集まりが、決められた炉体の形・素材とちょうど一致することを確かめます（足りない・余計なブロックが付いている・素材が違う、はすべて不可）。
   - 一致しなければ組み立てません。理由をCreateの組み立てエラー（`AssemblyException`）の形で、翻訳キーを使って出します。
3. 60°で止まっている間だけ、出鋼口から製品を取り出せます。
4. 逆転させると0°へ戻り、元の位置で炉体を普通のブロックに戻します（分解）。
5. 吹錬の途中で傾けようとしたら、今と同じく吹錬を止めて進み具合を保ちます。
6. 傾いている間に保存・再読み込みしても、炉体はからくりのまま戻り、軸受とつながり直すこと。

## 3. ジルコニア耐火レンガ

- 新しいブロックです（例：`zirconia_refractory_bricks`）。
- 作業台レシピの例：ジルコニア4＋レンガ（`minecraft:brick`）4＋粘土玉1 → 4個。釣り合いが悪ければ変えてよいですが、理由をレポートに書いてください。
- テクスチャは、ジルコニアの白っぽいレンガにし、ほかのレンガと見分けられるようにします（`validate_visual_identity.py` に従う）。
- ツルハシで掘れ、鉄のツール以上を要求します。
- 炉体の外でも、建材として使えます。
- 炉殻（`converter_shell`）のレシピに使っていたジルコニアの量は、炉体の耐火レンガに移す形で見直してください。全体として、材料が重くなりすぎないようにします。

## 4. 転炉ガスの量

- 酸素製鋼の1チャージの転炉ガスを、8,000 mBから**128,000 mB**にします（レシピJSON・生成スクリプト・JEI）。
- 転炉ガスの槽の容量を、1チャージ分以上にします。出口が詰まっているときに始めない動きは、今と同じです。
- 1チャージ分の熱量（約1.5 MJ）と、工業用加熱器を何tick動かせるかを、文書とレポートに書いてください。

## 5. Ponder と文書

- Ponder「転炉で鋼を作る」を作り直します。手順は8つまでで、収まらなければ2本に分けます。示す内容は次のとおりです。
  - 架台と軸受を組む。
  - 炉体を鋼材ブロックと耐火レンガで組む。
  - **超粘着剤で接着する**（CDGのポンプジャックの「接着を忘れずに」の手順に当たる）。
  - 原料と酸素を入れて吹錬する。
  - シャフトで傾けて出鋼する。
  - 転炉ガスを工業用加熱器へ送る。
  - アルゴンでAOD精錬をする。
- 文書：`docs/converter.md` を作り直します。`docs/metals.md` の耐火レンガ（ジルコニアの使い道）、`docs/thermal-equipment.md` の転炉ガスの熱量、`PONDER_GUIDE.md` も直します。

## 確認と完了

GameTestで、少なくとも次を確かめてください。CreateのからくりはGameTestでも組み立てられます。超粘着剤は `SuperGlueEntity` を置いて再現してください。

- **組み立て：** 正しい炉体を接着すると組み立てられ、0→60°で止まり、0°に戻すと元のブロックに戻る。
- **組み立てを拒否する場合：** 接着していない、ブロックが足りない、素材が違う（銅など）、余計なブロックが付いている。いずれも組み立てない。
- **入出力の制限：** 直立している間だけ吹錬・搬入でき、60°の間だけ出鋼できる。
- **量：** 酸素製鋼で鋼材ブロック64個と転炉ガス128,000 mB、AODでステンレス鋼192個ができる。
- **途中の操作：** 吹錬の途中で傾けても、中身と進み具合が保たれる。傾けたまま保存・再読み込みしても、中身・角度・からくりが保たれる。
- **壊したとき：** 軸受を壊すと炉体がワールドに戻り、在庫は消えも増えもしない。所有ブロックを壊すと中身が一度だけ出て、転炉ガスは雲が1つになる。
- **既存の試験：** 全レシピの読み込み（`everyRecipeFileOfTheModLoads`）と、鉢のレシピが気体を要求しないこと（`noBasinRecipeAsksForAGas`）も合格する。
