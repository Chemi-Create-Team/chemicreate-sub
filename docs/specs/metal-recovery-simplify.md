# 方針メモ：金属回収ラインの簡素化（実装済み）

2026-11-16にユーザーと合意した方向性です。最新の設備削除依頼に従い実装しました。対象は`3f75c37`で追加された金属回収ライン（[完了レポート](../reports/metal-recovery.md)）です。

## 決めたこと

- 流れを**撹拌槽で浸出 → 電解セルで採取（3倍、希硫酸が戻る）**にまとめる。
- **沈降分離槽（5×3×3）は削除する。** 判断の余地がない待つだけの関門で、専用マルチブロックに見合う遊びがない。浸出した撹拌槽が、精製溶液と廃泥（鉱滓スラッジ）を直接出す。
- **冷却晶析槽（3×3×4）も削除する。** 硫酸を作るには電解セルの酸素が必要なので、浸出できる時点で電解セルはすでにある。晶析（2倍、酸を再生しない）は電解（3倍）に常に劣り、選ぶ理由がない。結晶が育つ表現を残すなら、別の用途（例：肥料・染料の原料になる硫酸塩）を持たせてから検討する。
- 錫石鉱石・錫、希硫酸の調製と循環、濁った浸出液を経ない精製溶液、電解セルの金属在庫と陰極・陽極からの搬出は残す。

## 実装時の注意

- 削除する登録・アセット・翻訳・Ponder・JEIカテゴリ・GameTest・生成元（`tools/generate_metal_recovery*.py`）を同じ作業で片付ける。
- 浸出レシピの出力が変わるので、Ponder「鉱石回収：3倍と2倍のライン」と手引書・実績の説明を3倍のラインに合わせる。
- 濁った浸出液の流体が不要になるかを確認し、不要なら削除する。
