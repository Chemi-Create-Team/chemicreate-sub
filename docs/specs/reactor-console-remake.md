# 原子炉制御盤のリメイク（承認・実装済み）

2026-11-12時点の`reactor_control_console`を見直した記録です。見た目・大きさと組み方・操作方法・表示する情報のすべてを対象にしました。2026-11-12にユーザーが下記「決めること」をすべて承認し、追加で「原子炉の温度を壁面に、Createのニキシー管を縮小したモデルで表示する」と指定しました。Javaの変更（構造判定・操作・表示）は実装済みで、仕上げのモデルとテクスチャは[Fable向け指示書](modeling-brief-reactor-console.md)で依頼します。操作と表示の正本は[原子炉](../rbmk-reactor.md#物理制御卓)です。

## 案からの変更点

| 項目 | 案 | 実装 | 理由 |
| --- | --- | --- | --- |
| 壁の高さ | 卓と同じ高さ | 卓の1マス上 | 同じ高さでは壁の最下段（ニキシー管）が卓に隠れる |
| 数値窓 | 平均挿入率・キセノン・黒鉛温度 | Createのニキシー管を縮小した4桁表示で、最高燃料温度・黒鉛温度・平均挿入率 | ユーザー指定（原子炉の温度をニキシー管で壁に表示） |
| 計器 | 最高燃料温度を含む6個 | 最高燃料温度をニキシー管へ移し、キセノンを計器へ | 温度をニキシー管にまとめるため |
| AZ-5のカバー | 1回目で開く | 1回目で開き、RESETで閉じる | カバー専用ボタンをなくしたため |
| 壁の一部欠け | 記載なし | 卓は運転を続け、壁の表示と炉心図での選択だけが止まる | 卓だけの簡易構成と同じ扱い |

## 現状の問題

現状の画像：`docs/quality/plant-console/reactor-console-overview.png`、`reactor-console-buttons.png`。

| 分野 | 問題 |
| --- | --- |
| 大きさ | 同じユニット62個（卓6×2＝12、壁10×5＝50）。最小の5×5炉でも同じ62個が必要 |
| 操作 | 実物ボタンが25個。−1/＋1/−5/＋5/−10/＋10/0%/100%など似たボタンが並び、文字が小さく読めない |
| 表示 | 計器10個の題名と目盛が小さく読めない。チャネルごとの流量計（5×3区画）は、炉が小さいと大半が空き区画になる |
| 見た目 | 卓の文字札・ボタン名が縮小された文字で、Createの部品と比べて情報が細かすぎる |

## 方針

- 1種類のユニットを並べて組む方式は維持する（専用GUIは作らない）。
- ボタンは「よく使う操作だけを大きく」。細かい刻みはしゃがみ操作に寄せる。電解セルコントローラーの稼働率ダイヤル（右半分で＋、左半分で−、しゃがみで10倍）と同じ操作に揃える。
- 壁には運転中に見続ける値だけを置き、詳細はCreate標準のDisplay Linkへ出す（DESIGN.mdの「ゴーグルは概要、詳細はディスプレイリンク」に沿う）。

## 1. 大きさと組み方

同じユニット32個（現状の約半分）。

```
壁（7×4＝28個）
┌───────────────┬──────────┐
│               │ 警報窓 3 │
│   炉心図      ├──────────┤
│   4×4         │ 計器 3×2 │
│               │          │
│               ├──────────┤
│               │ 数値窓 3 │
└───────────────┴──────────┘
卓（4×1＝4個）
[AZ-5] [個別棒] [一括・モード] [記録紙・警報]
```

- 卓は壁の正面1マス手前、壁の下端と同じ高さに置く。卓と壁は同じ向き（操作者側を向く）。
- 炉心図を5×5から4×4へ縮める。最大13 m炉心の26×26区画は1区画あたり約2.5ピクセルで表示できる。
- 任意構成として、卓4個だけでも運転できる（制御棒の選択はPREV/NEXT、表示はゴーグルとDisplay Link）。小型炉の序盤向け。

## 2. 操作方法

ボタン25個を、操作部品10個にまとめる。

| 卓 | 操作部品 | 操作 |
| --- | --- | --- |
| 1. AZ-5 | カバー付きAZ-5 | 1回目でカバーを開き、2回目で緊急全挿入（現状どおり） |
| | RESET | 制御卓のAZ-5ラッチを解除（現状どおり） |
| 2. 個別棒 | PREV・NEXT | 選択棒の切り替え。炉心図の白いランプを押しても選べる（現状どおり） |
| | 個別棒ダイヤル | 右半分で＋5%、左半分で−5%。しゃがみで1%刻み。ダイヤルを押し込む操作はない |
| | 解除 | 選択棒の個別指定を解除。しゃがみで全棒を解除（現状の LOCAL と ALL LOC） |
| 3. 一括・モード | モード切替スイッチ | 押すたびに LOCAL → MAN → AUTO の順で切り替わる3位置スイッチ。位置が見た目で分かる |
| | 一括ダイヤル | MANのとき有効。右半分で＋5%、左半分で−5%、しゃがみで1% |
| 4. 記録紙・警報 | ACK | 警報の確認。しゃがみでランプ試験（現状の TEST） |
| | 記録紙 | 記録紙そのものを押すと消去（現状の PAPER） |

- 0%・100%への一気の変更は廃止する。全挿入はAZ-5、全引抜は誤操作の危険が大きいため、ダイヤルで行う。
- 優先順（AZ-5 → 個別目標 → 一括 → キャップ・制御棒リンク）、所有権の制約、保存形式の意味は変えない。

## 3. 表示する情報

| 場所 | 表示 |
| --- | --- |
| 炉心図（4×4） | 燃料チャネルを温度で緑〜赤の8段階。低流量のチャネルは点滅。選択棒は黄色枠、制御棒は挿入率に応じて白〜灰 |
| 警報窓（3×1） | 文字入りの警報窓5枚：AZ-5、燃料高温、出口高温、低流量、所有権競合。点灯・点滅で示す |
| 計器（3×2） | 熱出力、反応度、最高燃料温度、最高出口水温、総冷却水流量、ボイド率 |
| 数値窓（3×1） | 平均挿入率、キセノン平衡比、黒鉛温度を数字で表示 |
| 卓4 | 記録紙2本（出口水温・黒鉛温度、現状どおり） |
| ゴーグル（4行） | 接続状態、モード、選択棒の実深度／目標、AZ-5 |
| Display Link | 現状の測定値をすべて維持（平均冷却水温度、最高燃料棒表面温度、チャネルごとの流量など） |

- チャネルごとの流量計（壁の5×3区画）は廃止し、炉心図の点滅とDisplay Linkに移す。
- 計器の題名は短い文字札（例：「出力 MW」「反応度」）にし、16×16の画素で読める大きさにする。

## 4. 見た目

- 16×16のピクセルアート、1面24色以下、光源は左上（DESIGN.mdの外装面の規則）。
- 本体は鋼の灰色。差し色の真鍮は縁の一部に限る。銅色は使わない。
- 操作部品は大きく、形で役割が分かるようにする（ダイヤルは丸、モード切替は棒状のレバー、AZ-5は赤いカバー付き）。
- 文字はボタンに直接書かず、部品の上の札にまとめる。

## 影響と移行

- 旧62個構成は新構成として形成されない。既存ワールドでは、旧制御盤を壊して32個で組み直す必要がある（ユニットはそのまま再利用できる）。自動変換は行わない。
- ボタン定義`nuclear/ReactorConsoleButton.java`、構造判定`nuclear/ReactorConsoleStructure.java`、ブロックエンティティ、描画、生成スクリプト`tools/generate_reactor_console.py`、Ponder「原子炉制御卓の操作」、`docs/rbmk-reactor.md`、DESIGN.mdの該当節を更新する。
- AUTOの冷態起動の不具合は、この作業とは別に直す（[改善方針](improvement-policy.md)）。

## 決めたこと（2026-11-12承認）

1. 32個構成（壁7×4＋卓4）にする。
2. 卓4個だけの簡易構成を認める。
3. 0%・100%ボタンを廃止する。
4. チャネルごとの流量計を炉心図の点滅に置き換える。
5. 原子炉の温度は、Createのニキシー管を縮小したモデルで壁に表示する。
