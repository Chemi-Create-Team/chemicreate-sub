# テクスチャ指示書：鉱石ブロック

この作業では、この文書と「読むファイル」に挙げたものだけを読んでください。リポジトリの探索、`docs/`・`src/main/java/`・ほかの`tools/`の読み込み、ビルドは不要です。ゲーム内確認・Ponder・文書は別の担当が行います。

## 目的

8種の鉱石ブロック（石と深層岩の2種ずつ、計16ブロック）の鉱石部分を、バニラの鉄鉱石・金鉱石と同じ描き方に作り直す。現在は全鉱石が「ひし形の点を5〜6個置いただけ」の同じ描き方で、石版と深層岩版も同じ画像を使っており、バニラの鉱石と並べると浮いている。

## 読むファイル

- `tools/generate_metal_ores.py`：ボーキサイト・ペントランド鉱・チタン鉄鉱・ジルコン・クロム鉄鉱・輝水鉛鉱（`textures()`と`blocks()`）
- `tools/generate_uranium_assets.py`：ウラン鉱石（`uranium_ore_overlay`を描く部分と`ores()`）
- `tools/generate_chlor_alkali.py`：岩塩（`textures()`と`ores()`）
- `src/main/resources/assets/create_refinery_n_reactors/textures/block/*_ore_overlay.png`（現在の8枚）

上の3つの生成スクリプトは鉱石以外も大量に生成するので、実行しないでください。

## 作るもの

1. 新しい生成スクリプト`tools/generate_ore_textures.py`を作り、鉱石の上絵（overlay）16枚をここだけで生成する。
   - 出力：`textures/block/<鉱石>_ore_overlay.png`（石用）と`textures/block/deepslate_<鉱石>_ore_overlay.png`（深層岩用）。
   - 鉱石：`bauxite`、`pentlandite`、`ilmenite`、`zircon`、`chromite`、`molybdenite`、`uranium`、`halite`。
2. 3つの生成スクリプトから上絵を描く処理を削除し、深層岩版のモデルが`deepslate_<鉱石>_ore_overlay`を参照するように、モデルを書く行の`overlay`だけを変える。
3. 同じ変更を、既にあるモデルJSON（`models/block/deepslate_<鉱石>_ore.json`の8枚）にも手で反映する。`overlay`の値以外は変えない。

モデルは今と同じ「バニラの`minecraft:block/stone`または`deepslate`の上に上絵を重ねる」2層構造のまま。下地の石は描かない（バニラ画像を複製しない。リソースパックの石にも合う）。

## 描き方（バニラの鉄鉱石・金鉱石に合わせる）

バニラの鉱石は、石の上に「塊」を4〜6個散らした形をしている。

| 項目 | バニラの特徴 | この作業での規則 |
| --- | --- | --- |
| 塊の形 | 3〜12ピクセルの不規則な塊。ひし形や正方形ではない | 塊ごとに形を変える。大1〜2個、中2〜3個、小1〜2個 |
| 鉱石部分の量 | 石版で約120〜140ピクセル、深層岩版で約100〜110ピクセル（灰色の縁を含む） | 同程度。鉱石ごとに±20%の範囲で変えてよい |
| 色の段階 | 鉱石色が暗・中・明・最明の4段階前後。左上が明るく、右下が暗い | 鉱石ごとに4〜5段階。最明は各塊に1〜2ピクセルだけ |
| 縁 | 塊の周りの石を1段暗い灰色や明るい灰色に変えて、石に埋まって見せている | 塊の周りに灰色の縁を描く。石用は`#686868`・`#747474`・`#7F7F7F`・`#8F8F8F`、深層岩用は`#2F2F37`・`#3D3D43`・`#515151`・`#646464`から選ぶ |
| 深層岩版 | 石版と違う配置で、塊がやや小さく暗い | 石版と別の配置にする。鉱石色は石版と同じ |
| 鉱石ごとの配置 | 鉄と金で配置が違う | 8種すべて別の配置にする。バニラの配置を1ピクセルずつ写さない |

## 配色の目安（暗→最明）

実際の鉱物の見た目に合わせた初期案。ほかの鉱石と区別できれば調整してよい。

| 鉱石 | 見た目 | 色 |
| --- | --- | --- |
| ボーキサイト | 赤褐色の土状の粒 | `#5A2A1C` `#7E3B24` `#9C5030` `#BF7346` `#D9A070` |
| ペントランド鉱 | 青銅色の金属光沢 | `#5E4A22` `#8A6E32` `#B0904A` `#CFB26A` `#EDDDA0` |
| チタン鉄鉱 | 鉄黒色、わずかに褐色 | `#18181C` `#26262B` `#36353A` `#55504C` `#8A8580` |
| ジルコン | 赤褐色〜桃橙色の小さな結晶 | `#5C2A20` `#8A4434` `#B4644C` `#D89878` `#F4D0BC` |
| クロム鉄鉱 | 褐黒色の塊に緑の縁取り | `#1C1A1A` `#2C2828` `#403A38` `#5E7A52` `#8FB07E` |
| 輝水鉛鉱 | 鉛灰色で青みのある薄片 | `#3E4450` `#5A6272` `#7A8496` `#9EA8BA` `#CCD4E2` |
| ウラン鉱石 | 黒い瀝青ウラン鉱に黄緑の二次鉱物 | `#141410` `#2A2A22` `#3E3C30` `#9AA840` `#D4E070` |
| 岩塩 | 白〜淡桃の立方体の結晶 | `#9E8E92` `#C4B4B6` `#DCD0D0` `#EEE6E4` `#FFFFFF` |

- チタン鉄鉱とクロム鉄鉱はどちらも黒いので、クロム鉄鉱は緑の縁取り、チタン鉄鉱は褐色の最明部で見分けられるようにする。
- 岩塩だけは不規則な塊ではなく、2〜4ピクセルの角ばった立方体の結晶にする。
- ウラン鉱石は黒い塊の縁や割れ目に黄緑の点を置く。光らせない。

## テクスチャの規則

- 1枚16×16、上絵は鉱石と縁以外を完全な透明（アルファ0）にする。半透明のピクセルを作らない。
- 1枚あたり、灰色の縁を含めて12色以下。
- 写真、写真から作った画像、画像生成AIの出力、なめらかなグラデーションは使わない。1ピクセルのランダムなノイズで埋めない。
- 生成は固定の配置データから行い、実行のたびに同じ画像になるようにする（乱数を使う場合は固定の種）。
- 鉱石のアイテム（`textures/item/<鉱物>.png`）は今回変えない。

## 完了時に確認すること

1. `python3 tools/generate_ore_textures.py`がエラーなく終わり、16枚が出力される。
2. 次のコマンドで、すべて16×16、12色以下、アルファが0か255だけである。

```bash
python3 -c "from PIL import Image;import glob
for f in sorted(glob.glob('src/main/resources/assets/create_refinery_n_reactors/textures/block/*_ore_overlay.png')):
    i=Image.open(f).convert('RGBA');d=list(i.getdata());print(f.split('/')[-1],i.size,len(set(p for p in d if p[3])),sorted(set(p[3] for p in d)))"
```

3. `grep -h overlay src/main/resources/assets/create_refinery_n_reactors/models/block/deepslate_*_ore.json`で、8つの深層岩版がそれぞれ`deepslate_<鉱石>_ore_overlay`を参照している。
4. `git status`で、変更が`tools/generate_ore_textures.py`、上記3つの生成スクリプト、`textures/block/*_ore_overlay.png`、`models/block/deepslate_*_ore.json`の範囲に収まっている。

変更したファイル、各鉱石の配色と塊の数、確認結果、気になった点を短く報告してください。
