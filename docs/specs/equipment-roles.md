# たたき台：同じ役割の装置の整理

2026-11-17作成。1は決定・実装済み、ほかは方針が決まっていません。「現状」は実装とレシピから確かめた事実、「提案」は私の案、「決めること」はユーザーに判断してほしい点です。

## 進行段階の目安

判断の軸として、クラフトの段（`tools/generate_crafting_recipes.py`）と必要な設備から、次の3段階で考えます。

| 段階 | 手に入るもの | 例 |
| --- | --- | --- |
| 序盤 | 鉄板・銅板・Createの基本部品（作業台）、鉢で作るステンレス鋼 | 撹拌翼。ふた付き槽・吸収塔・電解セルは2026-11-18からステンレス鋼板を使う（[装置の材質](../../DESIGN.md#装置の材質)） |
| 中盤 | ステンレス板・モリブデンなど精錬金属（基本段以降のレシピ） | 反応塔、アンモニア分離器、分留塔、往復式圧縮機、各種触媒 |
| 終盤 | 機械式クラフトの部品 | タービン翼、大型フライホイール |

## 1. 触媒反応：反応塔に統合（決定済み）

2026-11-17にユーザーの指示で決定し、実装しました。ふた付き槽の触媒バスケットの使い方を削除し、`REACTION_VESSEL`と`CATALYST_UNIT`の反応（触媒の要らない一酸化窒素の酸化を含む）をすべて反応塔で行います。

| | 反応塔 |
| --- | --- |
| 段階 | 中盤（ステンレス板・かまど・ガラス板・モリブデン） |
| 規模 | 3×3、3～12段、働いている段ごとに1バッチ |
| 回転 | 不要 |
| 触媒 | 段ごとに1個（段ごとに減る）。天板中央の22 pxハッチを素手で開けて入れる |
| 入出力 | 最下段の側面から原料、最下段の側面か底面中央から製品 |

残った課題：序盤（鉄板・銅板の段階）には触媒反応の手段がなくなりました。序盤の希硫酸は鉄触媒の液相酸化（撹拌槽）で作れます。ほかの触媒反応を序盤に置くかは未定です。

## 2. 気液分離：アンモニア分離器 と 反応棚段なしの反応塔

| | アンモニア分離器 | 反応塔（反応棚段なし） |
| --- | --- | --- |
| 段階 | 中盤（ステンレス板・配管・タンク） | 中盤 |
| 処理量 | 段数のバッチを同時に（1×1・2～6段） | 段数のバッチを同時に（3×3でも1段1バッチ） |
| レシピ | `GAS_LIQUID_SEPARATOR`の2つ | 同じ2つ |
| 表示 | 正面の液面計・ゴーグル | のぞき窓から液面が見える |

分離器は幅1の専用ドラムで、反応塔とは用途と設置面積が異なります。どちらも1段につき1バッチを同時処理します。

提案（推奨）：今のまま「兼用の補助」と位置づけ、説明書とPonderでそう伝えます。重なりを減らしたいなら、塔の分離機能を削除する案もあります（のぞき窓もなくなります）。

## 3. 硫酸：3つの経路

| 経路 | 段階 | 装置 | 製品 | 特徴 |
| --- | --- | --- | --- | --- |
| 接触法 | 中盤 | 加熱した撹拌槽 → 酸化触媒の反応塔 → 吸収塔 | 硫酸 | 大量・正規の経路 |
| 鉄触媒の液相酸化 | 序盤 | 撹拌槽（加熱不要） | 希硫酸のみ | 鉄を毎回消費 |
| 亜硫酸の電解 | 中盤 | 吸収塔 → 電解セル | 硫酸＋水素 | 電力が要る。水素も得られる |

現状：生成物と必要なもので差がはっきりしていて、重なりは小さいです。

提案：このまま、序盤は液相酸化（金属の浸出に使う希硫酸）、量産は接触法、電力に余裕があって水素も欲しいときは電解、と説明書に段階として書きます。

決めること
- [ ] この位置づけでよいか

## 7. 反応棚段：反応塔に統合（実装済み）

2026-11-22にユーザーの指示で決定し（案A）、同日に実装しました。あわせて触媒充填バスケットを反応棚段に統合し、撹拌は専用の撹拌機に変えました（現行の取付位置は下記）。

現状：
- ステンレスタンク（旧ふた付き槽）の反応棚段は、ウラン燃料の4レシピ（`pressure_reaction`の`module: absorber`）だけに使われています。
  - 還元：焙焼したウラン＋水素→二酸化ウラン（加熱）
  - ガス化：四フッ化ウラン＋フッ素→六フッ化ウラン（超加熱）
  - ペレット焼成：通常・小型炉用の2つ（加熱）。かまどと、燃焼中のブレイズバーナーを通したファンでも焼成できます。
- 反応棚段でしかできないのは、還元とガス化です。
- 反応塔には固体の材料を入れる口がなく、触媒の差し込み口しかありません。そのため、今は代わりになりません。

決めた方針：
- 反応塔の最下段の側面から、アイテムの材料も入れられるようにします。触媒の入っていない段で、固体＋気体の加熱反応（還元・ガス化・焼成）を行います。
- 反応棚段は廃止します。既存ワールドの反応棚段（`reactor_separator_core`）と、それを入れた槽は、旧IDの対応で消失しないように置き換えます。
- 理由：触媒反応を反応塔へまとめた「1.」と同じく、「反応は反応塔」にそろえて装置を減らすためです。

実装するときに確認すること：
- 反応塔の熱（下からの加熱・超加熱）と、段ごとのバッチ処理が、この4レシピの条件を満たすか。
- 生成物の出口：アイテムは最下段の側面から出し、六フッ化ウランの気体は既存の製品ポートから出す。
- 撹拌翼の工程（グリーンソルト化など）は、ステンレスタンクに残す。
- 更新するもの：JEI（加熱棚段反応の表示）、Ponder（ウラン燃料の手順2・4、反応塔）、サバイバル到達性のテスト、`docs/reports/uranium-fuel-route.md`の工程の説明。
- 序盤から中盤の進行：ウラン燃料が、反応塔（3×3・3段以上、中盤）を前提にすることになる。

## 8. 撹拌槽：撹拌機（実装済み）

2026-11-22にユーザーの指示で決定し、実装しました。
- 撹拌翼をステンレスタンクに右クリックで入れる方式をやめ、タンクの天面中央に撹拌機（`vessel_stirrer`）を載せると撹拌槽になります（0.4.9から）。
- 撹拌機はCreateのメカニカルミキサーと同じく、中ほどの歯車にかみ合う歯車で回します。32 RPM以上が必要で、負荷は1 RPMあたり32 SUです。
- タンクは3×3・2～4段。天面から伸びる軸で底近くのタービンを回し、2バッチを同時に処理します。
- 撹拌翼のアイテムは撹拌機の材料になりました。既存ワールドでタンクに入っていた撹拌翼・反応棚段はアイテムとして落ちます。
- 遠心ロータ柱（1×1）は変えていません。
