# テクスチャ指示書：鉱物アイテム

この作業では、この文書と「読むファイル」に挙げたものだけを読んでください。リポジトリの探索、`docs/`・`src/main/java/`・ほかの`tools/`の読み込み、ビルドは不要です。ゲーム内確認・文書は別の担当が行います。

## 目的

鉱石を掘ったときに出る鉱物アイテム8種の絵を作り直す。

- バニラの「鉄の原石」（`raw_iron`）と同じ描き方にするもの（6種）：ウラン原石`uraninite`、ボーキサイト`bauxite`、ペントランド鉱`pentlandite`、チタン鉄鉱`ilmenite`、ジルコン`zircon`、クロム鉄鉱`chromite`
- 実物の標本の見た目を元に、マイクラ風に描き直すもの（2種）：輝水鉛鉱`molybdenite`、蛍石`fluorite`

現在はすべて同じ丸い塊の形（`LUMP`）に色を付けただけで、バニラの原石と並べると平板に見える。

## 読むファイル

- `tools/generate_metal_ores.py`：`textures()`の中で`icon(ore, LUMP, ...)`を呼ぶ1行（6種の鉱物の絵）
- `tools/generate_uranium_assets.py`：`shade`・`icon`・`LUMP`・`lump`の定義と、`textures()`の`out['uraninite']`と`out['fluorite']`の行
- `src/main/resources/assets/create_refinery_n_reactors/textures/item/`の、上記8種のPNG

上の2つの生成スクリプトはほかのものも大量に生成するので、実行しないでください。

## 作るもの

1. 新しい生成スクリプト`tools/generate_mineral_items.py`を作り、8枚の`textures/item/<名前>.png`をここだけで生成する。
2. 2つの生成スクリプトから、この8種の絵を描く処理だけを削除する（ほかの鉱物・酸化物・ペレットなどの絵とモデルの出力は残す）。
3. アイテムモデル（`models/item/<名前>.json`）は今のまま使う。変更しない。

## 原石6種の描き方（バニラの鉄の原石に合わせる）

バニラの鉄の原石は次のような作りになっている。

| 項目 | 鉄の原石の特徴 | この作業での規則 |
| --- | --- | --- |
| 形 | 左上の大きな塊と、右下に重なる小さな塊の2つでできた、ごつごつした輪郭。不透明部分は約170ピクセル | 同じ「大小2つの塊」の構成で、大きさも同程度。6種それぞれ輪郭を少しずつ変え、鉄の原石を1ピクセルずつ写さない |
| 色の段階 | 暗い縁から最明部まで8段階 | 鉱物ごとに8段階（下の表）＋必要なら差し色1〜2色 |
| 光 | 左上が明るく、下辺と右辺に1ピクセルの最暗の縁 | 同じ。最明部は大きな塊の左上に数ピクセルだけ |
| 陰影 | 塊の内側に、くぼみや割れ目の暗い筋が入る | 各塊に1〜2本の暗い筋やくぼみを入れて立体感を出す |

| 鉱物 | 見た目 | 8段階（暗→明） | 差し色 |
| --- | --- | --- | --- |
| ウラン原石 | 黒く脂ぎった光沢の瀝青ウラン鉱 | `#16140F` `#22201A` `#302D25` `#3F3B31` `#524D40` `#6A6452` `#8A8370` `#B2AA92` | 割れ目に黄緑の二次鉱物`#9AA840` `#D4E070`を数ピクセル |
| ボーキサイト | 赤褐色で土っぽく、丸い粒（豆石）が見える | `#3A1A10` `#522417` `#6E3020` `#8A3E28` `#A55334` `#BF7346` `#D59466` `#E8B88E` | 明るい丸い粒を2〜4個 |
| ペントランド鉱 | 青銅色の金属光沢 | `#3A2E14` `#54431E` `#6E5828` `#8A7034` `#A88A44` `#C4A65C` `#DCC27E` `#F0E0AE` | なし |
| チタン鉄鉱 | 鉄黒色、わずかに褐色を帯びた鈍い金属光沢 | `#0E0E10` `#18181C` `#222226` `#2E2D31` `#3C3A3C` `#4E4A48` `#6A6460` `#948C84` | なし |
| ジルコン | 赤褐色〜桃橙色、ガラス光沢の小さな結晶の集まり | `#3E1A14` `#58261C` `#743426` `#904534` `#AC5C46` `#C47A60` `#DA9C82` `#F0C4AE` | 結晶の面の照り返しを1〜2ピクセル白寄りに |
| クロム鉄鉱 | 褐黒色で粒状、ところどころ緑の縁取り | `#0F0E0E` `#1A1818` `#252222` `#322D2C` `#403938` `#504745` `#665A56` `#80706A` | 緑`#5E7A52` `#8FB07E`を縁や筋に数ピクセル |

- チタン鉄鉱とクロム鉄鉱はどちらも黒いので、クロム鉄鉱の緑と、チタン鉄鉱の褐色寄りの明部で見分けられるようにする。

## 輝水鉛鉱と蛍石（実物の標本を元にマイクラ風で）

写真をそのまま縮小したり、写真から色を拾ったりはしない。実物の特徴を、バニラのアイテム（ダイヤモンド、アメジストの欠片、石英など）と同じ密度のドット絵で表す。

| 鉱物 | 実物の特徴 | 描き方 |
| --- | --- | --- |
| 輝水鉛鉱 | 柔らかい鉛灰色〜青みがかった銀色。強い金属光沢。六角形の薄い板状結晶が何枚も重なり、端がめくれた薄片になる。白い石英の母岩に付いていることが多い | 六角形の板が2〜3枚斜めに重なった形。板の上面は青みのある明るい銀、縁は暗い鉛灰色。薄片の層を示す細い横の段を数本。左下に白い石英の母岩を少し入れてよい。8〜10色 |
| 蛍石 | ガラス光沢で半透明の立方体の結晶。紫が代表的で、緑や無色の層（色帯）を持つことが多い。立方体が組み合わさった形や、角が欠けた形 | 斜めから見た立方体1つ、または2つの立方体の組み合わせ。3面を明・中・暗の3段階で塗り分け、紫を主に、中心や一部の層に緑を入れる。辺の明るい線と、面の照り返しを1〜2ピクセル。10〜12色 |

## テクスチャの規則

- 1枚16×16、アルファは0か255だけ（半透明を作らない）。
- 原石6種は差し色を含めて10色以下、輝水鉛鉱は10色以下、蛍石は12色以下。
- 写真、写真から作った画像、画像生成AIの出力、なめらかなグラデーションは使わない。1ピクセルのランダムなノイズで埋めない。
- 固定の配置データから生成し、実行のたびに同じ画像になるようにする。
- 8枚すべてが互いに別の画像であること。

## 完了時に確認すること

1. `python3 tools/generate_mineral_items.py`がエラーなく終わり、8枚が出力される。
2. 次のコマンドで、すべて16×16、色数が規則以内、アルファが0か255だけである。

```bash
python3 -c "from PIL import Image
for n in 'uraninite bauxite pentlandite ilmenite zircon chromite molybdenite fluorite'.split():
    i=Image.open(f'src/main/resources/assets/create_refinery_n_reactors/textures/item/{n}.png').convert('RGBA');d=list(i.getdata())
    print(n,i.size,len(set(p for p in d if p[3])),sorted(set(p[3] for p in d)),sum(1 for p in d if p[3]))"
```

3. `git status`で、変更が`tools/generate_mineral_items.py`、上記2つの生成スクリプト、8枚のPNGの範囲に収まっている。

変更したファイル、各鉱物の色数と不透明ピクセル数、確認結果、気になった点を短く報告してください。
