# 放射線と汚染

放射線は炉心、使用済み部品、廃液、保管容器、落下アイテム、プレイヤーの所持品、汚染面に共通の処理を使う。評価はサーバー側で1秒ごと。積算値と現在値は個人線量計、周囲のγ線・β線はサーベイメーターで確認する。

## 運用

使用済み燃料を遮蔽せず手で持たない。クレーン、デプロイヤー、ファンネルで移し、燃料プールの水と壁を間に置く。防護服はβ線と皮膚への付着を減らすが、γ線・中性子は止めない。ガスマスクの有効なフィルターは吸入を98%減らし、汚染場所で使うと消耗する。

個人線量計を持つと、生涯積算mSvと現在のmSv/hを表示する。サーベイメーターは右クリックでγ窓とβ+γ窓を切り替え、強い場ではクリックが増える。サーベイメーターは中性子計ではない。個人線量計の現在値には中性子と体内からの線量も含む。初回測定前は「未測定」と表示する。

汚染を踏むと皮膚・靴へ移り、別の場所に足跡として移る。防護服へ付いた物質は脱いでも残る。石けんは皮膚・衣服・対象の面から90%、水中では毎秒20%を除去する。除去した物質は直下の排水面へ移すので、その場所も隔離する。受けた線量と預託線量は洗い流せない。個人線量計やサーベイメーターのPonderに手順を追加した。

## 線源と保存

`RadiationSources` の登録表は、アイテム・流体・設置ブロックの実効的なγ線量率、β線量率、放射能量、核種群の割合を持つ。外部の追加登録も同じAPIを使える。

| 線源 | 初期γ線量率、1 m | 初期β線量率、1 m（空気による減衰前） |
| --- | ---: | ---: |
| 使用済み燃料棒 | 5,000 Sv/h | 500 Sv/h |
| 使用済み制御棒・ブランケット・ダイバータ | 50 Sv/h | 5 Sv/h |
| 照射済みターゲット | 5 Sv/h | 0.5 Sv/h |
| 切断済み使用済み燃料 | 500 Sv/h | 50 Sv/h |
| 使用済み被覆管 | 5 Sv/h | 0.5 Sv/h |
| ガラス固化体 | 100 Sv/h | 0 |
| 高レベル廃液、1,000 mB | 500 Sv/h | 50 Sv/h |
| 使用済み燃料溶解液、1,000 mB | 5,000 Sv/h | 500 Sv/h |
| 新燃料・イエローケーキ・ウラン鉱石等 | 0 | 0 |

新燃料等は弱い長寿命α汚染源。封じ込められた新燃料から外部α被ばくは起こさず、ばらのイエローケーキ等は微量の粉じんを周囲へ移す。

`Radionuclides` は短寿命、Cs-137相当、長寿命α群の量と基準tickを保存する。半減期は8.02日、30.05年、24,110年。`N(t)=N(0)×2^(-t/T)` を使い、γ・βは短寿命群とCs群、α汚染は長寿命群から計算する。1秒は20 tick、日・年はその物理秒を基準にし、Minecraftの昼夜周期とは連動しない。基準時計は各次元で共通のoverworld game timeで、`/time set` の昼夜変更では巻き戻らない。`RadiationPhysics.TIME_MULTIPLIER` の初期値は1で、変更すると放射性物質の減衰時間だけが変わる。

物質データはアイテム・流体のData Componentとして保存する。炉からの取り出し、実インベントリへの投入、タンクへの充填で基準を持たせ、燃料プールは各スロットの物質データも保存する。SIMULATEで保管量・保管データは変えない。冷却履歴の異なる使用済みアイテムは別スタックになる。未使用の密封燃料にはこの履歴を付けず、従来どおり積める。冷却期間の違う廃液は、各群の量をmBで加重して混ぜる。設置した液体の汲み取り、ガラス固化体の設置・回収でも基準を保持する。旧セーブで履歴のない物質は、最初のロード・認識時を基準にする。

ブロックの線源は標準のアイテム・流体ハンドラーを読み、Createタンク、横置きタンク、Vault、ふた付き槽は所有者へ集約する。Basinは入力・出力の両方を読む。落下アイテムと所持品も評価し、液体バケツや通常形式の携帯容器の保存内容も対象にする。

RBMKは同じ線源表へ登録される。運転出力に比例するγ・中性子と、過去の運転出力および既存`DECAY_SHARE=0.002`を使う停止後のγ成分を持つ。停止すると中性子成分は消える。炉心自身の内部は実効線源体積とし、そこから外の実際の壁・水を辿る。従来の6面開口率・漏れ率は廃止し、Display Linkも炉ポート位置のmSv/hへ変更した。炉心物理・定格765 MWは変更していない。

## 透過

距離による逆2乗と、経路上の物質による `2^(-厚さ/半価層)` を掛ける。1ブロックは1 m。経路はボクセルを辿り、部分ブロックは衝突形状を通った長さを使う。

| タグ | γ半価層 | 中性子の実効半価層 |
| --- | ---: | ---: |
| `radiation_shielding/water` | 0.09 m | 0.10 m |
| `radiation_shielding/concrete` | 0.05 m | 0.12 m |
| `radiation_shielding/steel` | 0.016 m | 0.30 m |
| `radiation_shielding/serpentinite` | 0.04 m | 0.09 m |

空気は透過、木材はγ半価層0.4 m、未分類の固体は0.1 mの近似。収納設備の筐体は中空なので実効壁厚1 cmとし、コンクリート・生体遮蔽タグの固体はこの薄壁扱いにしない。β線は空気中4 mまでで弱まり、物質では薄い層で止まる。燃料プールの描画水位を仮想水体として経路に重ねるため、水が減れば遮蔽も下がる。

## 汚染と線量

汚染はチャンク内の4×4×1格子に3群の量と基準時間を保存する。放射性流体の放出、容器破損、炉心爆発で生じ、放射性崩壊・足への付着・移動・洗浄を反映する。衣服、皮膚、靴への移染でも群の内訳を保持する。長寿命α群だけの粉じんからγ線は作らない。

汚染のごく一部を吸入量へ換算し、β/γ群とα群で異なる実効換算係数から預託線量を記録する。体内からの実際の付加線量は簡略化した70日半減の残存線量状態から加える。生涯積算は減らず、死亡・再接続でも保存する。急性症状は従来の1/2/4/6/8 Svの5段階を残し、低線量率では急性損傷への寄与を小さくする。従来の「1 Sv/20分」の回復は使わない。がんは名目係数5%/Svの統計表示だけで、死亡処理には使わない。

## 性能と近似

- チャンクごとの線源・落下物の索引と、インベントリの変更通知を使う。プレイヤーごとの全ブロック走査はしない。
- 20 tickごとにプレイヤーのみを評価する。半径64 m、遮蔽前の寄与が強い順に最大256候補、しきい値`1e-12 Sv/s`。範囲外・上限超過の寄与は合算しない。
- 遮蔽経路は始点・終点と通過チャンクの変更番号でキャッシュし、最大4,096件。移動、ブロック変更、チャンクのアンロードで失効する。温度だけの変化では幾何学キャッシュを捨てない。
- 線量の通信は値が変わったとき本人だけへ送る。計測値を装備アイテムへ複製せず、計器のツールチップも本人専用データを読む。クライアントは線量を計算しない。

これはゲーム用の3群・直線透過モデル。散乱線のビルドアップ、詳細な放射化計算、エネルギー別の中性子輸送、核種別の完全な生体動態は計算しない。線源の実効定数や内包量は設備のゲーム単位に合わせた代表値であり、実機・各燃料棒の実測値ではない。半径・候補上限、点線源化、粗い汚染格子、容器壁厚の近似を含む。

使用済み品の初期の危険度は指定の数千Sv/h級とし、減衰を速める調整は時間倍率だけで行う。輸送途中の他MOD独自の保管形式や、レシピによる物質変換を跨ぐ詳細な核種収支は、個別の登録・接続確認が必要。

## 数値の参照

- [NIST・光子の質量減弱係数](https://www.nist.gov/pml/x-ray-mass-attenuation-coefficients)、[水の表](https://pml.nist.gov/PhysRefData/XrayMassCoef/ComTab/water.html)：指数減衰の考え方の参照。上記のγ半価層4値は依頼文で指定された初期近似を採用。
- [IAEA TECDOC-1925](https://www-pub.iaea.org/MTCD/Publications/PDF/TE-1925web.pdf) 2.4.3：Cs-137点線源の1 mでの代表値0.08 mSv/h/GBq。汚染面のγ換算に`0.08e-3/(3600×1e9) Sv/s/Bq`を使用。
- [CDC・Radiation Safety](https://www.cdc.gov/radiation-health/safety/)：時間・距離・遮蔽、防護服がγ線を防がないこと。
- [NRC・Radioactive Waste](https://www.nrc.gov/regulations-legislation/fact-sheets-brochures/backgrounder-on-radioactive-waste)：使用済み燃料の長期にわたる強い放射線の参考。10年後の表面線量率の説明と、本MODの「1 m・取り出し直後」の設定値は同じ条件の実測値として扱わない。
