# ふた付き槽と分留塔による反応プラント

対象：Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10。温度・圧力の等級化B2適用後。

撹拌・加熱の反応はふた付き槽（天面中央に撹拌機を載せると撹拌槽）で、触媒反応と棚段での固体の加熱反応は[反応塔](#反応塔)、気体の水への吸収は[吸収塔](#吸収塔)、分留・蒸留は[分留塔](distillation-plant.md)へ送ります。槽は温度や圧力を蓄積せず、流体の種類と下面の熱源で反応条件を判定します。

## 組立と搬送

| 設備 | 槽の寸法 | 駆動 |
| --- | --- | --- |
| 撹拌槽 | 3×3、高さ2～4段。天面中央の真上に撹拌機（`vessel_stirrer`） | 撹拌機の横の歯車を32 RPM以上（Createのメカニカルミキサーと同じ回し方）。2バッチを同時処理。負荷は1 RPMあたり32 SU |
| 遠心ロータ柱 | 1×1、高さ1～4段、各段1本 | 最下段底面へ32 RPM以上 |

3×3槽の点検窓は皿底より上に付きます。撹拌槽では上から軸が伸び、底近くの4枚羽根のタービンを回します。固定邪魔板4枚は窓と窓の間の斜め方向に付きます。

撹拌機は撹拌翼・歯車・ステンレス鋼板・安山岩ケーシングで作ります。1段の槽、2×2の槽に載せても撹拌しません。槽そのものは回転を受けず、軸もつながりません。既存の設備は、底面側の撹拌機を天面中央に移すと再開できます。撹拌翼や反応棚段を槽の段に入れる方式は廃止しました。既存ワールドで槽に入っていた撹拌翼・反応棚段は、読み込み時にアイテムとして落ちます。

撹拌槽の天面には直径30 pxの丸い開口ができ、右クリックで円形のふたを開閉します。撹拌機の脇の天面から操作できます。貯蔵槽は従来の角形ハッチを使います。2×2は貯蔵専用です。側面レンチで点検窓を切り替えます。アイテムは標準ファンネル、液体・気体はCreateの配管・ポンプで搬送します。原料不足、出口満杯、ハッチ開放、レッドストーン信号では材料を消費しません。

## 熱源と反応条件

Createの加熱バーナー（KINDLED以上）と超加熱バーナー（SEETHING）を使います。電熱ヒーターも同じ段階を出します。槽の予熱待ちはありません。熱源を失うと途中のバッチは止まり、原料は消費しません。撹拌槽では途中の進捗が0に戻り、反応塔では進捗を保ったまま再開します。電熱源の熱供給は支払済みの電力で制限されます。

| 工程 | 熱源・原料条件 |
| --- | --- |
| ナフサ分解（反応塔） | 超加熱、通常のナフサ |
| エチレン・プロピレン重合（反応塔） | 加熱、通常の気体 |
| エチレン酸化（反応塔） | 加熱、通常のエチレンと酸素 |
| 軽油の水素化脱硫（反応塔） | 加熱、高圧水素 |
| 重油の水素化分解（反応塔） | 超加熱、高圧水素 |
| 原油予熱 | 加熱した撹拌槽またはBasinで原油を予熱した原油へ変換し、分留塔へ搬送 |
| 水の凍結 | 撹拌槽へ水と液体窒素を投入する固定レシピ |

高圧水素は通常水素を往復式圧縮機で2段階圧縮して作ります。通常水素の量を増やしても代用できません。加熱ナフサなどの別名流体や、スタックの連続温度による別名扱いはありません。

## 鉄触媒によるアンモニア合成

1. 撹拌槽で水素と窒素を混ぜ、合成ガスを作ります。
2. 往復式圧縮機で加圧合成原料へ変換します。
3. 鉄触媒を入れた[反応塔](#反応塔)の最下段の側面へ送り、下面を加熱します。1段につき1バッチ100 tick、原料10,000 mBから高温合成混合ガス9,000 mBを生成し、その段の触媒耐久を1消費します。
4. ファン付きラジエーターなどで冷えた合成混合ガスへ変換します。
5. 気液分離器を1×1で2～6段に積み、最上段の側面へ供給します。60 tickごとに1段につき1バッチを同時処理し、1バッチ9,000 mBから液体アンモニア1 mBと加圧循環原料8,000 mBを生成します。最上段の上面から循環原料、最下段の底面から液体を回収します。正面のガラス管で液量を確認できます。横の列とは連結せず、7段目からは別のドラムになります。
6. 液体アンモニアを加熱した撹拌槽またはBasinへ入れると、1 mBからアンモニアガス934 mBを作れます。

乾き度が付いた流体も最上段の側面から供給できます。その流体の気体分は上面、液体分は底面へ分けます。発熱・冷却装置から配管で送る場合の乾き度の扱いは[気液二相の流れ](two-phase-flow.md)を参照してください。

各段で並列処理でき、原料・製品は有限の専用バッファへ保管します。どちらの分離製品も搬出しなければ次の処理は停止します。モル平衡、反応熱、冷却ジャケット、過熱損傷の旧計算は使いません。比率はゲーム用の固定レシピで、実機の収率を表しません。

### 反応塔

触媒反応と、反応棚段に固体を載せる加熱反応（ウランの還元・ガス化・ペレット焼成。レシピの`module: absorber`）は反応塔で行います（[下の表](#反応塔で使える触媒)）。触媒充填バスケットは廃止して反応棚段に統合し、既存ワールドのバスケットは反応棚段として読み込みます。反応棚段を入れなければ手順5の高圧気液分離タンクになります。

| 部分 | 内容 |
| --- | --- |
| 構造 | 反応塔（`reaction_tower`）を3×3で3～12段積む。Createのタンクと同じように1層ずつまとめて置ける。Createの窓は付けられない |
| 外観 | 厚さ6 pxの壁の内側は空洞で、最下段に2 pxの床、最上段に2 pxの天板がある閉じたタンク。天板の中央に、3×3のふた付き槽と同じ22 px角のハッチがある。形成した塔では各面の中央のブロックに、ボルト留めの鋼製フランジと厚いガラスののぞき窓があり、中の反応棚段とその上の触媒・固体、気液分離中の液面と気体が見える |
| ハッチ | 天板の中央を素手で右クリックすると開閉する。開いている間は運転せず、開けると中の気体を外へ放出する |
| 反応棚段 | 開いたハッチに反応棚段を使うと、下の段から1段に1個入る。触媒は開いたハッチから手で、または上面のファンネルで、下の棚段から1個ずつ入れる。全段で同じ触媒にそろえる |
| 固体原料 | 触媒のない棚段には、最下段の外側面のファンネル・シュートから棚段の反応の固体を入れられる。空きのある一番下の棚段に16個まで、満ちると上の棚段にたまり、棚段の上に見える。固体と触媒は同時に使えない（固体があると触媒を、触媒があると固体を入れられない） |
| 処理 | 触媒と原料で`ProcessRecipe`の反応（`REACTION_VESSEL`と`CATALYST_UNIT`）が1つに決まる。触媒の要らない反応（一酸化窒素の酸化）は、触媒の有無にかかわらず棚段のある段で行う。棚段に固体があるときは`module: absorber`の加圧反応を行い、固体の載った棚段ごとに1バッチ（既定100 tick）。固体の生成物は棚段に残り、最下段の外側面のファンネルで取り出す。気体・液体の生成物は製品の槽へ入る。働いている段ごとに1バッチを同時に処理し、触媒反応ではその段の触媒が1減る。回転は不要。熱が必要な反応は、底面の下の3×3にブレイズバーナー（ふた付き槽と同じ段階） |
| 入出力 | 反応器では、原料は最下段の外側面から入り、外筒に沿って上がって触媒層を上から下へ流れる（実機の合成塔と同じ流れ）。製品は最下段の外側面か、底面の中央ブロックの下面から出る。原料2種は同じ配管でよい。気液分離では、原料は最下段から入り、液体は最下段（側面と底面中央）、気体は最上段の外側面から出る。中間の段・底面のほかのブロック・天面は液体をつながない |
| 計器 | Createのボイラーと同じ計器（外筒と同じ鋼色）が正面だけに付く。正面は最下段の中央ブロックを置いたプレイヤーの側。反応棚段の入った段ごとに、正面の左側のブロックに半分の大きさの温度計（0～600 ℃）。下から2段目の右側のブロックに針の赤い圧力計（合成ループ、0～30 MPa）。計器の前にブロックがあるときは付かない |
| 在庫 | 原料2つ・製品2つの槽。1段あたり液体2,000 mB、気体はその64倍 |
| 取り出し | 使い切った触媒だけ上面のファンネルで出る。開いたハッチにレンチを使うと、いちばん上の触媒、次にいちばん上の棚段の生成物と固体、最後にその棚段を取り出す。壊した段の中身は落ちる |
| 気液分離 | 反応棚段がない塔は高圧気液分離タンク。気液分離器と同じレシピ（冷えた合成混合ガス、高温の原子炉冷却材）を1段につき1バッチ同時に処理する。熱は不要。中に流体がある間は最初の棚段を入れられず、反応器として流体が残っている間は最後の棚段を取り出せない |
| 停止 | 未成立・ハッチ開放・触媒の種類違い・原料不足・熱不足・製品の出口満杯では原料を消費しない。バッチは完了時にだけ確定する |

計器の読み：

- 圧力は塔内の気体の量で決まり、原料の緩衝槽が満杯で25 MPa（上限30 MPa）。ループを15～25 MPaに保つには、緩衝槽を6～10割に保つ。
- 各段の温度は、熱源の温度（加熱で380 ℃、超加熱で450 ℃、なしで20 ℃）に、その段での反応熱を足したもの（塔の高さの3分の1で全反応150 ℃分、上限600 ℃）。ガスは上の段から順に触媒に触れ、各段は「残りの平衡までの量」のうち、触媒の活性（残り寿命の割合）に応じた分を反応させる。
- 新しい触媒では反応の大半が上の段で起き、上段がいちばん熱い。触媒が劣化すると上の段で反応しきれなくなり、上段の温度が上がらなくなって、反応と熱が下の段へ移る。寿命の終わりが近づくと全段が熱源の温度へ下がる。
- 生産量は固定レシピのまま（働いている触媒の段ごとに1バッチ）で、計器は運転状態の表示。針は数秒かけて新しい値へ動く。

最下段の中央を壊すと、中の気体は大気へ放出されます。ゴーグルで状態、働いている触媒と反応棚段の数（固体があるときは固体と生成物の数）、原料・製品の量とバッチの進捗を確認できます。

## 硫黄の燃焼

硫黄粉と空気を密閉したステンレスタンクに入れ、底面から超加熱すると二酸化硫黄ができます。撹拌槽では加熱と撹拌で処理できます。吸気にはノズルとポンプを使います。二酸化硫黄は下側の出口、反応後に残る混合気体は上側の出口から搬出できます。

| 酸化剤 | 1バッチ |
| --- | --- |
| 酸素 | 硫黄粉1＋酸素500 mB → 二酸化硫黄500 mB |
| 空気 | 硫黄粉1＋空気2400 mB → 二酸化硫黄500 mB＋残りの混合気体1900 mB |

空気で燃やした二酸化硫黄を、次の液相酸化でも空気と一緒に使えば、電気を使わずに希硫酸まで作れます。酸の配管には粘土を焼いたセラミック管を使えます（[温度・圧力等級](thermal-grades.md)）。

## 鉄触媒による二酸化硫黄の液相酸化

触媒床や吸収塔を使わずに希硫酸を作る方法です。撹拌槽（撹拌機の横の歯車へ32 RPM以上）の水に、鉄ナゲットか酸化鉄（赤）を入れて二酸化硫黄と酸素を吹き込みます。溶けた鉄イオンが酸素を運び、加熱なしで 2SO₂＋O₂＋2H₂O → 2H₂SO₄ が進みます。

| 酸化剤 | 1バッチ（200 tick） |
| --- | --- |
| 酸素 | 水1000 mB＋二酸化硫黄250 mB＋酸素125 mB＋鉄1個 → 希硫酸1000 mB |
| 空気 | 水1000 mB＋二酸化硫黄250 mB＋空気600 mB＋鉄1個 → 希硫酸1000 mB＋残りの混合気体475 mB |

鉄は硫酸鉄として酸に溶けるので、1バッチに1個使います。希硫酸は硫酸250 mBを水で薄めたものと同じ量です。

## 吸収塔

気体を下から、水を上から流し、塔の中で向かい合わせに接触させます。同じ大きさの段を4～8段積み、1段につき1バッチを同時に処理します。回転も熱も要りません。

段は3×3の八角形が外周ごとまとめて置かれます。段の天面をクリックすると、次の段が中心の真上に積まれます。外殻はふた付き槽と同じ銀色の板です。

配管は中心と平らな4辺（各辺の中央）のブロックだけにつながり、斜めの角のブロックにはつながりません。レンチかホースを持つと、使える面だけに入口（青）・出口（橙）の枠が表示されます。

| 位置 | 搬入 | 搬出 |
| --- | --- | --- |
| 最下段の平らな4辺の外側面 | 気体の原料 | 酸などの液体 |
| 最下段の底面（中心と4辺、角を除く5面） | なし | 酸などの液体 |
| 最上段の平らな4辺の外側面 | なし | 吸収しきれなかった気体 |
| 最上段の天面（中心と4辺、角を除く5面） | 水・洗浄液 | なし |
| 角・中間の段・中心の側面 | なし | なし |

ゴーグルでは、どの段・どの外周ブロックを見ても最下段が持つ塔全体の段数・工程・在庫を表示します。

| レシピ | 原料 | 製品 |
| --- | --- | --- |
| 硝酸 | 二酸化窒素300 mB＋水100 mB | 硝酸200 mB＋一酸化窒素100 mB（酸化工程へ戻す） |
| 硫酸 | 三酸化硫黄250 mB＋水250 mB | 硫酸250 mB |
| 亜硫酸 | 二酸化硫黄250 mB＋水250 mB | 亜硫酸250 mB（電解セルで水素と硫酸に分ける） |
| 塩酸 | 塩化水素500 mB＋水500 mB | 塩酸1,000 mB |

酸の出口が満杯なら、次の原料を消費しません。最下段が工程在庫と進捗を持ち、上の段に在庫が残っている列は形成しません。

## 硝酸とメンテナンス

アンモニアと酸素を酸化触媒入りの反応塔で反応させ、高温一酸化窒素混合物を冷却・分留します。回収した一酸化窒素を反応塔で酸素で酸化し（触媒は不要）、吸収塔で水に吸収させて硝酸にします。

汚れ・清掃・ドレンは維持します。槽のハッチを開けると、実在庫の気体のうち常圧を超える分と空気より軽いものを放出し、空気より重い気体は常圧分まで残します。水の自然沸騰・凍結、過圧破裂、安全弁による圧力調整はありません。バーナーなどの火気へ可燃性ガスを放出する危険は残ります。

## 保存と構造変更

ふた付き槽の工程在庫・進捗は最下段北西のコントローラーが所有します。在庫がある所有元の移動は拒否し、構造変更・再読込で古い搬送ハンドラーを無効にします。途中保存、満杯、再形成で二重処理は行いません。旧モル数・温度・相割合の保存データは移行しません。

専用Ponderは反応塔（触媒、棚段の固体、気液分離）、気液分離器、撹拌機（ステンレスタンクの撹拌）、吸収塔（2つの大きさ）から開けます。レシピの原料・熱源・製品はJEIで確認できます。

## 1×1のガス遠心分離機

ふた付き槽1個へ遠心ロータ柱を持って右クリックすると装荷する。槽内の円筒は1本で、外装は四角いまま。側面をCreateレンチで右クリックすると点検窓になり、実際のシャフト速度に従う回転をガラス越しに見られる。1×1槽の上面は固定ふたで、素手で開くハッチはない。

最下段の底面だけへ32 RPM以上の回転を入れる。側面と上面は回転を受けない。応力は1段につき24 SU/RPM、処理速度は従来どおり最大4倍。各段へローターを1本ずつ装荷して最大4段まで積める。隣接する装荷済み1×1列は横に結合しない。3×3遠心分離機は廃止し、3×3・2×2槽へローターを挿入できない。旧保存データに残るローターは上面レンチで回収できるが、旧寸法では運転しない。

| 面 | 標準Create配管／ポンプの役割 |
| --- | --- |
| 側面 | 原料を搬入。別の搬出配管で劣化物などの副製品を回収。原料を吸い戻さず、濃縮物も出さない |
| 最上段の上面 | 濃縮物などの主製品のみ搬出。原料は受け付けない |

遠心分離の全既存レシピ・量・時間を維持する。標準のゲーム内ウラン濃縮は原料1,000 mBを主製品125 mBと劣化物875 mBへ分ける。重水・ヘリウム同位体・小型炉用燃料の追加濃縮も同じ設備で処理する。上面はレシピの第1製品、側面は第2製品以降を取り出すため、液体原料の既存レシピも使える。どちらかの製品が満杯の場合は次のバッチを消費しない。停止・再読込でも原料・製品と進捗を保持する。

遠心ロータ柱またはふた付き槽のPonder「1×1槽のガス遠心分離機」で最小構成と4段の拡張を説明する。ゴーグルで状態・主要値を、標準Display Linkで各工程値を確認する。
