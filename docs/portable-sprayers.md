# 消火器・火炎放射器・液体噴射器

右クリックを長押しすると噴射し、離すと止まります。中身がないと使えません。アイテムの説明欄と残量バーで内容物・残量を確認します。

| 器具 | 容量 | 射程 | 用途 |
| --- | ---: | ---: | --- |
| 消火器 | 2,000 mB | 6マス | 水または二酸化炭素で消火 |
| 火炎放射器 | 4,000 mB | 8マス | 軽油・ガソリン・ナフサなどで着火 |
| 液体噴射器 | 4,000 mB | 10マス | 水や硫酸・硝酸・塩酸などの液体を噴射 |

4 tickごとに20 mBを使います。水や消火器は炎・燃えている生物・焚き火・ろうそく・フレアの種火を消します。腐食性の液体は命中した相手へ腐食ダメージを与えます。塩水は腐食ダメージの対象外です。火炎放射器は相手を燃やし、既存の可燃ガス雲にも着火します。壁を越えて直接攻撃しません。

## 補充

- 器具を持ってShift＋右クリックすると、狙ったタンクから補充します。
- 逆の手に中身入りのバケツを持ち、Shift＋右クリックしても補充できます。
- Createの注液口から、デポやベルトに載せた器具へ補充できます。
- 別の流体へ変える前に、使い切るかCreateのアイテム排液口などで抜き取ります。種類や成分の違う中身は混ぜられません。

火炎放射器の燃料は流体タグ `create_refinery_n_reactors:spray_fuels` で指定します。液体噴射器は液体用で、溶岩・気体・極低温・超高温の流体は受け入れません。消火器の二酸化炭素は専用の受入対象です。容器内で温度や圧力を計算する装置ではありません。

## 製作と見た目

消火器は通常の作業台、火炎放射器と液体噴射器はメカニカルクラフターで製作します。材料はJEIを参照してください。クリエイティブタブの設備カテゴリからも取り出せます。3種類に専用Ponderがあります。

消火器は赤いボンベ、黒いホース、ノズル、レバー、安全ピン、計器を備えます。火炎放射器と液体噴射器は二連ボンベを本体にまとめ、前者は燃焼口と種火、後者は細い噴射ノズルと銅のポンプ部で区別します。16pxの既存素材を使った立体アイテムモデルです。使用中はレバーが動きます。計器は外観上の部品で、実残量は残量バーと説明欄に表示します。
