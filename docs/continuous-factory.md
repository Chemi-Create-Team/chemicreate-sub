# 大型連続加工設備

入口ブロックを材料が進む方向に向け、搬出口も同じ向きに置きます。図表の座標は入口を `(0, 0, 0)`、進行方向を `+Z`、進行方向が南の場合の東を `+X` とします。各設備の加工レシピはJEIに、組立と動力の接続例はPonderにあります。

原料は入口の上面か背面にCreateのファンネル・シュートで供給できます。上面には手で置くか落とすこともできます。巻線の鉄心などの副材料はブレーキと反対側の入口側面から入れます。搬出口は入口に面する側以外から、Createのファンネルなどで取り出せます。搬出口を素手で右クリックしても回収できます。

## 大型ロータリーキルン

- 搬出口は入口から8〜16マス先。ドラムの全長は7〜15マスです。床のフレームを入口から1マス、搬出口の手前2マス、中間の3か所に設置します。中間は入口から搬出口までの距離の半分を切り捨てます。
- 搬出口の上に排気筒、下にブレイズバーナーを置きます。排気筒は最大3段まで、上端から煙が出ます。入口の下から回転を入力し、96 SU/RPMを消費します。
- 2.7°傾いたドラムのガースギアを小歯車が回し、両端は支えローラーが受けます。中空部と内側の突起もからくりに含まれます。複数の材料が時間差で入り、内部で転がりながら出口へ進みます。
- 7マス、通常加熱なら16 RPMから調整できます。15マスなら36 RPM前後。過加熱時は1 tickの焼成量が1.6倍です。同じ材料は回転を速めるほど早く出ますが、焼成量が足りなければ元の材料で搬出し、過多なら固着します。
- 方解石を石灰石原料として生石灰を作れます。鉄の原石・ペントランド鉱の焙焼と、超過熱による劣化した鉄・酸化触媒の再生にも対応します。反応塔で使用した耐久の減った触媒を入れると、未使用の触媒に戻ります。

## 多段連続圧延ライン

入口の下にはバーナーを置きます。各スタンドに次の部品を組み、最初を入口の2マス先、以降は3マスごとに並べます。2〜5段に対応し、搬出口は最終スタンドの2マス先です。

| スタンド内の位置 `(X, Y)` | 部品 |
| --- | --- |
| `X=-2`、Y=0〜3 | フレーム4個 |
| `X=+2`、Y=0、2、3 | フレーム3個 |
| `X=+2`、Y=1 | 圧延スタンド駆動部。シャフト面を外側へ |
| `X=-1,0,+1`、Y=3 | 上の横梁のフレーム3個 |

各スタンドの外側から回転を入れます。負荷は1段あたり32 SU/RPMです。各段で厚さが前の段の75%になり、体積が同じになるように長さが伸びます。目安は27 → 36 → 48 → 64 → 85 RPMです。前段から求めた必要回転数との差が±10%を超えると、後段が遅い場合は座屈で詰まり、速い場合は破断して変形した加工材を排出します。加熱した材料から極厚鋼板、H形鋼、レール材、銅箔、アルミ箔を作れます。転炉から出した溶鋼は[鋳造鋼スラブ](steelworks.md)にすれば、極厚鋼板の圧延にそのまま投入できます。

## 大型巻線・撚線機

- 搬出口は入口の6マス先。2マス先の `X=-2, Y=0〜1` と `X=+2, Y=0`、4マス先の `X=0, Y=0` にフレームを置きます。ブレーキは2マス先の `X=+2, Y=1` に置き、軸を外へ向けます。
- 本体は入口の下から48 SU/RPM、ブレーキは外側から12 SU/RPMを受けます。本体32 RPM、ブレーキ16 RPMが初期調整の目安です。4個のボビンが自転しながら公転し、繰り出し位置から巻き取り面までワイヤーが張られます。巻き取り径が大きくなるにつれて張力も変わります。
- ブレーキが強すぎると断線で停止し、弱すぎると巻きが緩んだ製品が出ます。トロイダル磁場コイルとポロイダル磁場用中央ソレノイド、鋼心アルミ撚線、極太ワイヤーロープを作れます。

## 停止・復旧と表示

ゴーグルで形成状態、進捗、回転数、キルン火力、巻線張力を確認できます。Createのディスプレイリンクでは状態、形成、進捗に対応します。回転動力を切るか入口にレッドストーン信号を入れて停止してから、入口をレンチで右クリックすると詰まりや断線を解除できます。破損した材料は変形した加工材として回収します。

加工中の材料と完成品は入口ブロックに保存されます。可動部のからくりは形成された設備から再生成されます。`F3+B` を有効にすると、オレンジ色の線で可動部の衝突形状を確認できます。Minecraft標準の外接枠も同時に表示されます。
