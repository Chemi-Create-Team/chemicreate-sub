# 工業製品の受注と出荷

工業製品の出荷票をCreateのアイテム保管庫の側面に取り付けます。単独の出荷票では注文処理できません。保管庫への搬入は通常のファンネル、開梱機、ベルト・列車の物流で行います。専用の輸送網やGUIはありません。

出荷票を素手で右クリックすると次の注文、スニーク右クリックすると前の注文へ切り替わります。ゴーグルは注文、状態、累計出荷件数を4行以内で表示します。Display Linkは現在の注文、状態、進捗、累計出荷、液体在庫、報酬数を標準ディスプレイへ出せます。注文は切替時と出荷完了時に進みます。レッドストーン信号で停止できます。

| 製品 | 注文量 | 報酬 |
| --- | --- | --- |
| ステンレス鋼インゴット | 64個 | エメラルド5個 |
| 工場用コンクリート | 128個 | エメラルド2個 |
| 硝酸アンモニウム肥料 | 128個 | エメラルド4個 |
| 樹脂（ポリエチレン） | 128個 | エメラルド4個 |
| 合成ゴム | 64個 | エメラルド3個 |
| CDG共通軽油 | 8,000 mB | エメラルド4個 |

数量と報酬はゲーム用の交易設定です。液体注文は出荷票の標準流体能力へCreateパイプ・ポンプで供給します。16,000 mBの荷受けバッファに保持し、注文を変えても液体を失いません。液体は同じパイプから取り戻せます。報酬は出荷票のアイテム能力からファンネル等で搬出します。製品自体は保管庫から取り出しません。

材料全量、流体全量、報酬の空きが揃った状態で200 tick検品します。報酬満杯では荷を消費せず停止し、空きができれば再開します。完成時に製品を一度だけ消費し、報酬を生成します。出荷印の位置が変わり完了を示します。注文切替は進捗だけをリセットします。

保管庫の全構造がロードされていることを確認してから処理し、チャンクを強制ロードしません。保管庫の撤去・分割に追従し、有効な保管庫がなければ停止します。出荷票には注文ID・進捗・累計・報酬・液体を保存します。撤去時には報酬をドロップし、残液をドロップした出荷票のBlockEntityDataに保持します。設置し直すと残液を復元します。

注文は`industrial_delivery`型のデータパックレシピで追加できます。現在の付属注文は単一製品の大量納品です。多種類の入力を定義した場合も、処理はレシピにある全量を要求します。各工程の入出力はJEI、搬送・切替・停止は出荷票のPonderから確認できます。
