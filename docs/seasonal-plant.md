# 季節による熱交換と表示の整理

Serene Seasons 10.1系を任意で導入すると、対象ディメンションの暦の季節に応じて次の処理速度が変わります。未導入時、およびSerene Seasonsの対象外ディメンションでは従来の100%です。連携確認にはSerene Seasons 10.1.0.8とGlitchCore 2.1.0.2を使用しました。通常の配布Jarには両Modを同梱しません。

| 季節 | 加温 | 冷却 |
| --- | ---: | ---: |
| 春 | 100% | 100% |
| 夏 | 120% | 80% |
| 秋 | 95% | 105% |
| 冬 | 80% | 120% |

加温はブレイズバーナーによるふた付き槽・槽系構造・Createタンクの温度等級の上昇に適用します。冷却は自然通風冷却塔の温排水処理量、ラジエーターの空冷処理量に適用します。液体のバッチ量・生成数・電力台帳・密閉熱交換器の収支は変えません。気候帯やバイオーム別の補正は行わず、同じディメンションの季節で揃えます。季節の取得は20tick以内のキャッシュを共有し、加温の小数進捗を保存します。

冷却塔では形成済みで実際に温排水を冷却している間、塔頂から白い凝結雲が上がります。停止すると新しい雲が止まり、既存の雲は約5〜7秒で消えます。描画は塔頂から128ブロック以内、2tickごとに塔サイズに応じて2〜5粒子、寿命100〜139tickに制限します。パーティクル設定「少なめ」で半減、「最少」で省略します。雲はクライアントだけで生成し、粒子ごとのサーバー通信や液体の生成は行いません。既存の自然通風冷却塔のPonderに加え、冷却塔・ラジエーター・ふた付き槽から季節と蒸気を説明するPonderを開けます。

JEIの取得方法がなかった6品は、既存の運転・保守・鍛造によって得られる副産物でした。使用済み燃料棒・使用済み制御棒・照射済みリチウム標的棒は炉の運転、照射済みカートリッジ・使用済みダイバータカセットは核融合炉の運転と保守、製鋼スラグは銑鉄の鍛造工程として表示します。スラグは完了時25%であることを明記し、新しい代替クラフトや生成経路は追加しません。制作途中の順序組立品を除く全自Modアイテムについて、実際のJEI出力検索とサバイバル到達性を確認しています。

鋼材と未加工鋼材のアイコンは他の金属インゴットと同じ輪郭に揃えました。自ModのクリエイティブタブからCDG製ガソリン・軽油バケツの重複掲載を除き、CDG本来の登録と用途を維持します。自Modの流体名をFluidTypeの共通翻訳キーへ統一し、CDGの燃料・植物油・色付き液状コンクリートも日本語で表示します。翻訳の正本は既存生成器と `tools/generate_seasonal_plant.py` です。
