# エンジニアゴーグルのツールチップ

実装：`client/GoggleSpec.java`（呼び出しは `client/ProcessGoggles.java`）。検査：`GoggleSpecGameTests`。

## 構成
1. 1行目：`稼働中: 反応式 (進行度%)`（緑）または `⚠ 停止中: 理由`（オレンジ）。貯蔵専用のタンクには付けない。
2. 貯蔵量（1か所だけ）：`貯蔵量: 8 / 144 B (H₂SO₄)`。混合物は成分を割合の降順で最大5行、超えた分は `他 X 成分...`。
3. 環境：`環境: 常温 / 常圧 | 動力: 64 RPM`。
4. 設備：`設備: ハッチ 閉 | 排水 閉 | 汚れ 0%`。Shift で `| 構造: 3×2` を足す。

停止理由は優先度順に1つだけ出す：ハッチ開放 → 排水開放 → メンテナンス必要 → 出力満杯 → 原料不足 → レシピ未成立 → 動力不足 → 温度不足 → 圧力不足。原因になっている値（`0 RPM`、`ハッチ 開`など）はオレンジにする。

## 表記
- 通常は化学式のみ。Shift で `硫酸 (H₂SO₄)`、mB 表記、割合つきの内訳、構造サイズを出す。
- 量は 1,000 mB 未満は mB、1,000〜9,999 mB は小数1位の B（`.0` は省く）、10,000 mB 以上は3桁区切りの整数 B。
- 割合は小数1位。0.1% 未満は `<0.1%`。
- 色：ラベルと区切りは GRAY、化学式・値は WHITE（AQUA は使わない）。
- 字下げ：Create のゴーグル枠が最初の4桁を使うので、1階層目は6桁、内訳は8桁。

## 対応範囲
- 蓋つき容器（反応槽・貯蔵槽）：全面的にこの構成。
- 吸収塔などの積み重ね型の反応機、反応塔、ガス化炉、分留塔：同じ構成（`GoggleSpec.machine`）。反応式は化学式で出し、レシピのIDは出さない。翻訳のない状態語は、IDをそのまま出さずに下線を空白に直して出す。
  - 反応塔・反応機：貯蔵は区画ごとに1行（最初が「貯蔵量」）。環境は加熱と圧力の等級。塔は触媒の棚数を設備に出す。
  - 分留塔：段ごとの入口・出口の行はそのまま残す。
- 液体タンクなど貯蔵量だけが分かる装置：貯蔵量の行を共通の形式にし、停止なら `⚠ 停止中: 理由` を最上段に出す。
- 電解セル、蒸気タービン、核融合炉、RBMK の制御卓：最上段を `稼働中: 状態` または `⚠ 停止中: 状態の文` にし、元の行をその下に字下げして並べる（`GoggleSpec.status`）。配管の計器は名前の行を省き、計測値をそのまま最上段に出す。
- 未対応（従来の表示のまま）：RBMK の燃料チャンネル・制御棒などの部品、核燃料サイクルの機械、ガスタンク以外の貯蔵（ガスホルダー等）の細部。
