# 電動ポンプ

電熱線ヒーターは撤去済みです。加熱はCreateのブレイズバーナーを使用します。


`create_refinery_n_reactors:electric_pump` の両端にCreateのパイプをつなぎます。上面の矢印が吐出方向です。レンチで向きを反転でき、横向き・上向き・下向きで使えます。

約400 Vでは理想入力5 kW、電線損失を含む今回の実測は約4.98 kW・124 RPMです。入力電力から内部回転数を4 RPM刻みで求め、上限は128 RPMです。250 W未満では始動しません。電気をつないだままなら、流体がないときや配管が詰まったときも電力を消費するため、停止にはレッドストーンを使います。

Createのポンプ・流体搬送処理を使い、MOD既存の材質等級・配管抵抗・流量制限を維持します。内部の仕事用バッファは最大512 Jで、確定した搬送だけが圧送仕事を使います。シミュレーションの照会では消費しません。内蔵モーターから軸・歯車へ回転動力を取り出すことはできません。

このMODの密閉タンクは上面が蒸気・気体の取り出し口です。タンクから液体を上向きに吸い上げたい場合は、タンク側面からパイプを出して電動ポンプの吸込側へ曲げます。

## 製作と確認

製作には鋼鉄インゴット・銅・ニッケルを使い、ヒーターにはレンガ、電動ポンプにはCreateのメカニカルポンプも必要です。両方とも設備タブにあります。専用Ponderで配置・2本の電線・運転・停止を確認できます。

ゴーグルは状態・入力電力・主要値を表示します。Display Linkでは状態、電力（kW）、蓄積エネルギー（J）を取り出せます。ポンプでは内部回転数も選択できます。保存・再ロードでは有限の仕事用エネルギーを保ち、以前の電圧や回転数だけでは再始動しません。
