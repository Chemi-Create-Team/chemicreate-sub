# 横型タンクのボイラー

横型タンク（XまたはZ方向に寝かせたCreateのタンク、断面1×1・2×2・3×3、長さは自由）に水を入れ、下にブレイズバーナーを置くと、蒸気を作るボイラーになります。下段の各列の最後の区間（X・Zの正の向きの端）が、その列の下にあるバーナーの熱を集計して水を沸かします。2026-11-18に、別ブロックだった横置き管束ボイラー（`tubular_boiler`）をこの仕組みにまとめました。

| 接続 | 用途 |
| --- | --- |
| 沸騰している端の区間の上面・外向き端面 | 蒸気の搬出（沸騰していないときは普通のタンクの面） |
| ほかの面 | タンクとしての給水・排水 |

末端の下のバーナーが加熱なら高圧蒸気、超加熱なら過熱蒸気です。水1 mBから蒸気1 mBを作り、固定の熱量を消費します。高圧蒸気は2,508 J/mB、過熱蒸気は3,008 J/mBです。流体ごとの温度・圧力計算や予熱待ちはありません。沸かすのは水と温排水だけで、ほかの液体はこれまでどおり加熱（温度等級の上昇）だけです。

各熱源のCreate加熱段階1あたり4,000 J/tを使用します。丸め残りの熱は最大400 kJまで保存します。

給水不足・未形成・熱源なし・出力満杯なら止まります。満杯のときは新しい水や熱を消費しません。蒸気は気体なので、どの配管でもタービンへ接続できます。過熱蒸気を貯めるタンクはないため、直接タービンへ送るか冷却装置で変換します。

タンクにCreateの蒸気エンジンを付けると、Createのボイラー（蒸気エンジンで回転を取り出す）として働き、配管へ出す蒸気は作りません。同じバーナーで二重に動力を作らないためです。

Create標準の結合・分割で水を共有し、蒸気と丸め熱は各末端の区間が保存します。分割すると、各部分は自分の蒸気を保ち、分けられた水で沸騰を続けます。端の区間を壊すと、残っていた蒸気は外へ出ます。

配管はほかの流体と同じく、ボイラーに接して通しても構いません。配管がボイラーの出口や蒸気エンジンとして数えられることはありません（2026-11-19に修正）。

既存ワールドの横置き管束ボイラーは、読み込むと横型タンクになります（登録IDの対応付け、`registry/CELegacyIds.java`）。中の水と蒸気は保たれます。Ponderは「横型タンクで蒸気を作る」（断面1×1・2×2・3×3）です。

## 立てたCreateの液体タンク

Createの液体タンク（縦置き）も、水か温排水を入れて点火したブレイズバーナーの上に置き、蒸気エンジンと汽笛を付けなければ、通常蒸気（100 °C・常圧）を作るボイラーになります。底面の下にある各熱源の加熱段階1あたり4,000 J/tを使い、通常蒸気1 mBに2,008 J、水1 mBから蒸気1 mBです。丸め残りの熱は最大400 kJまで保存します。蒸気は制御ブロックが最大16,000 mB保存し、沸騰中は最上段の天面から出ます。ほかの面と、沸騰していないときの天面は普通のタンクの面です。上にポンプを置いて取り出し、どの配管でもタービンや気体タンクへ送れます。出力が満杯なら新しい水と熱を消費しません。熱源がないタンクは1秒に1回だけ下を確かめます。結合したタンクでは蒸気を新しい制御ブロックへ移します。Ponderは「Createのタンクで蒸気を作る」です。

以前の、Createのボイラーに接する配管がタービンまでの経路をたどって蒸気を直接渡す処理（`BoilerSteamOutput`）は廃止しました。古いワールドで配管の内部にたまっていた未送出の蒸気は引き継がれません。
