# 横型タンクのボイラー

横型タンク（XまたはZ方向に寝かせたCreateのタンク、断面1×1・2×2・3×3、長さは自由）に水を入れ、下にブレイズバーナーを置くと、蒸気を作るボイラーになります。下段の各列の最後の区間（X・Zの正の向きの端）が、その列の下にあるバーナーの熱を集計して水を沸かします。2026-11-18に、別ブロックだった横置き管束ボイラー（`tubular_boiler`）をこの仕組みにまとめました。

| 接続 | 用途 |
| --- | --- |
| 上面と長さ方向の両端面 | 接続した列の蒸気を搬出 |
| 長辺の側面 | 給水 |
| 底面 | 給水・排水 |

末端の下にバーナーが付いたボイラーでは、蒸気がまだないときや燃料切れでも、蒸気口から給水は流れ出ません。バーナーを外し、残った蒸気を取り出すと、各面は通常タンクの接続に戻ります。

ボイラーに切り替わると、空いている側面と端面の中央にCreate標準の計器が現れます。配管に蒸気を出す場合の針は、各列の蒸気バッファー全体の充填率を示します。蒸気エンジンを取り付けた場合は、針もCreate標準ボイラーの値を表示します。ゴーグルでは横型タンクとステンレスボイラーの両方にCreate標準のボイラー表示を使います。最下段には配管出力時の現在／最大蒸気流量、または蒸気エンジン接続時の給水流量をmB/sで表示します。

横型流体タンクは高温・常圧の蒸気、ステンレスボイラーは高温・高圧の蒸気を出します。どちらも水1 mBから蒸気1 mBを作り、常圧蒸気は2,258 J/mB、高圧蒸気は2,508 J/mBの熱を使います。沸かすのは水と温排水です。ほかの液体は従来どおり温度等級が上がります。

底面のバーナー1台あたり、通常加熱で65.536 mB/s、超加熱で131.072 mB/sです。断面3×3・長さ9で底面27台分を使い、すべての蒸気を高圧タービン段へ送ると、通常加熱のステンレスボイラーは約884,736 SU、横型流体タンクは約442,368 SUです。超加熱ではどちらも流量とSUが2倍になります。流量とSUは底面の列数と長さに比例し、蒸気が1 mB単位で流れるため瞬間値は前後します。

最大流量の表示は、底面すべてを超加熱したときの値です。丸め残りの熱は最大400 kJまで保存します。ゴーグルとディスプレイリンクは全列を見て運転状態を表示し、一部の出口が詰まった場合は搬出の改善を案内します。

給水不足・未形成・熱源なし・出力満杯なら止まります。蒸気は、その温度・圧力に合う配管でタービンへ送ります（高圧蒸気・過熱蒸気はステンレス鋼管など）。既設ボイラー内に旧等級の蒸気がある場合は、先にその在庫を搬出すると新しい等級の生成が始まります。

タンクにCreateの蒸気エンジンを付けると、Createのボイラー（蒸気エンジンで回転を取り出す）として働き、配管へ出す蒸気は作りません。同じバーナーで二重に動力を作らないためです。

Create標準の結合・分割で水を共有し、蒸気と丸め熱は各末端の区間が保存します。分割すると、各部分は自分の蒸気を保ち、分けられた水で沸騰を続けます。端の区間を壊すと、残っていた蒸気は外へ出ます。

配管はほかの流体と同じく、ボイラーに接して通しても構いません。配管がボイラーの出口や蒸気エンジンとして数えられることはありません（2026-11-19に修正）。

既存ワールドの横置き管束ボイラーは、読み込むと横型タンクになります（登録IDの対応付け、`registry/CELegacyIds.java`）。中の水と蒸気は保たれます。Ponderは「横型タンクで蒸気を作る」（断面1×1・2×2・3×3）です。

## 立てたCreateの液体タンク

Createの液体タンク（縦置き）も、水か温排水を入れて点火したブレイズバーナーの上に置き、蒸気エンジンと汽笛を付けなければ、高温・常圧の蒸気を作るボイラーになります。熱源1台の通常加熱で約39.84 mB/s、水1 mBから蒸気1 mBです。丸め残りの熱は最大400 kJまで保存します。蒸気は制御ブロックが最大16,000 mB保存し、沸騰中は最上段の天面から出ます。ほかの面と、沸騰していないときの天面は普通のタンクの面です。上にポンプを置いて取り出し、どの配管でもタービンや気体タンクへ送れます。出力が満杯なら新しい水と熱を消費しません。熱源がないタンクは1秒に1回だけ下を確かめます。結合したタンクでは蒸気を新しい制御ブロックへ移します。Ponderは「Createのタンクで蒸気を作る」です。

以前の、Createのボイラーに接する配管がタービンまでの経路をたどって蒸気を直接渡す処理（`BoilerSteamOutput`）は廃止しました。古いワールドで配管の内部にたまっていた未送出の蒸気は引き継がれません。
