# 産業用アームと組立ジグ

Createのメカニカルアームと同じ関節計算・モデル・テクスチャ（色もCreateのアームのまま）で動く産業用アームが、組立ジグの上で段階的な3D組立を行う。操作は右クリック、レンチ、ホッパーやファンネルへの搬入だけで、独自GUIはない。

## 部品

| 部品 | 役割 |
| --- | --- |
| 組立ジグ `assembly_jig` | アームが作業する台。作業範囲は上の最大3×3×3マス。レシピと各工程の状態・進捗を持つ。1000 mBの液体タンク（パイプで充填、スプレー用） |
| 産業用アーム `industrial_arm` | 回転で動く。下面から軸を受ける。応力4 SU。工具スロット1個と1000 mBの液体タンク |
| グリッパー `gripper` | ブロックを置く |
| 溶接トーチ `welding_torch` | 継ぎ目の溶接 |
| レーザーカッター `laser_cutter` | 外周・対角の切断 |
| スプレーノズル `spray_nozzle` | 全面の吹き付け（液体を消費） |
| 精密配線ヘッド `wiring_head` | フェライトコアを並べ、X・Y・センス線を通す |

工具はスタック1。工具を持って右クリックで装着（付いている工具とは交換）、素手の右クリックで外す。ホッパー、ファンネル、シュート、ベルトから工具スロットへ出し入れできる。ジグは自動で作るものを選ぶ（下の「レシピの自動選択」）。レンチを使うと読み込み済みのレシピを順に固定し、最後の次は自動に戻る（工程が始まった後は不可）。素手で右クリックすると進捗を表示する。

## 動き

アームはCreateのメカニカルアームの2本の腕の長さだけを2倍にしたもの（`ArmPose.SCALE`）で、太さ・関節・爪はCreateのまま。関節角はCreateの `ArmAngleTarget` と同じ計算を腕の長さを変えて行う（`ArmPose.angles`、元の長さではCreateと同じ角度になることをGameTestで確認）。届く距離は肩（ブロック中心の0.375上）から手首まで約3.6マス、手首は狙う点の0.5上。Createの長さのままでは1.8マスしか届かず、3×3のジグを覆えないため。通る点のどれかに届かない工程は予約しない。

1. 回転を受けたアームは5マス以内のジグを探す（10 tickごと）。停止中は新しい工程の予約や材料の取り出しを行わない。
2. ジグの現在のステージで、自分の工具でできる工程のうち、自分に最も近い未着手のものを予約する。1つの工程は1台にだけ割り当てる。同じステージの工程は複数台で並列に進み、次のステージは前のステージがすべて終わってから始まる。
3. 工程の材料（置くブロック、消費する線材・部品）を、上面に爪が届くアイテムを持つブロック（チェスト、デポ、ベルトなど）から1個取る。届かない入れ物からは取らない。アームはまずそこへ腕を伸ばし（12 tick）、それから作業位置へ動く。スプレーの液体はアームのタンクを先に、足りなければジグのタンクから、工程の開始時に引き落とす。スプレーは材料を取る前に液体が足りるかを確かめる。材料か液体が無ければ予約を戻し、3秒待つ。その間もほかのジグやベルト・デポ加工は続ける。中断したときは、持っていた材料を取得した入れ物へ戻し（入らなければ落とす）、引き落とした液体をアームのタンク（あふれた分はジグのタンク）へ戻す。
4. 作業位置へ動き、作業する。作業時間はレシピの `time` tickを16 RPMで基準にし、回転が速いほど短い。回転が0なら止まる。
5. グリッパーは空気のマスにだけブロックを置く。マスが埋まっていれば、空くまでブロックを持って待つ。同じブロックがすでに立っていれば、その工程を済みにして材料を入れ物へ戻す。

回転が止まったアームは、つかんでいたベルト・デポのアイテムを放す。

工具の取り外し、アームの破壊、ジグの変更で予約は戻る。アームとジグは作業中の予約と進捗を保存する。ワールドを開き直すと、アームが保持していた材料で工程を再開する。ジグの進捗は、読み込んだレシピが保存時と完全に同じときだけ引き継ぐ（id と工程数が同じでも中身が変わったら最初から）。ジグは20 tickごとに、読み込み済みのアームが持っていない予約を戻す。

### レシピの自動選択

新しいジグは自動。工程が1つも始まっていない間、1秒ごとに周りのアーム（5マス以内）の工具と、それらのアームが材料を取る入れ物（取得する場所、選んでいないアームは届く範囲の入れ物）の中身を調べ、全工程の工具と材料がそろうレシピを選ぶ。複数あれば材料の種類が多いもの、同じなら総数が多いものを選ぶので、鉄板・フェライトコア144個・エナメル線25本があれば磁気コアメモリ、鉄ブロックだけなら溶接された鉄骨を作る。工程ごとに、その工具を持ち作業位置に届くアームがいることも条件にする（届かないアームのチェストの材料では選ばない）。材料は入れ物ごとに1回だけ数える（大きいチェストの両半分を選んでも二重に数えない）。完成したら選び直す。そろうレシピが無ければ待つ。液体は選択の条件に入れない。レンチで固定したジグは選び直さない。以前のワールドでレシピが設定されていたジグは固定として読み込む。

### 取得する場所と置く場所

Createのメカニカルアームと同じく、設置する前にアームを手に持って、チェストなどの入れ物・ベルト・デポを右クリックして選ぶ。1回で取得する場所（青の枠）、2回で置く場所（橙の枠）、3回で解除。スニークしながらの右クリックは選択せず普通に設置する。アームを置くと選んだ場所がそのアームに記録され（選択のパケットはブロックの設置より先に届くので、サーバーは設置まで預かってから適用する）、範囲（5マス）外や爪が届かない場所は外して知らせる（最大16か所ずつ）。ゴーグルで取得・置く場所の数が見える。

- ジグ組立の材料: 取得する場所があればそこからだけ取る。1か所も選んでいないアームは、従来どおり範囲内の入れ物を自動で探す。
- ベルト・デポ加工: 取得する場所に選んだベルトとデポの上だけで行う。選んでいなければ行わない。

### ベルトとデポの上のアイテム

ジグに自分の工具でできる工程がなければ、アームは取得する場所に選んだベルトとデポを調べ、中央付近にある、ベルト用レシピの `input` に合うアイテムを1個取る。Createのメカニカルアームと同じく、毎tick `lockedExternally` を立ててアイテムをその場に止める。工具の既定の軌道を0.45マスに縮めてアイテムの上でなぞり、`time` が終わると1個を `result` に変える（残りはそのまま流れる）。置く場所があれば完成品をベルトから取り、工具の下に提げて最初に全部入る置く場所へ運ぶ（どれも満杯なら待って再試行）。置く場所がなければ完成品はその場に残る。同じアイテムは1台だけが扱う。グリッパーはベルト作業をしない。ベルト作業は保存しない（開き直すと最初から探し直す）が、運搬中の完成品は保存する。スプレーの液体は開始時に足りるかだけを確かめ、加工が終わった時に引き落とすので、途中で保存しても液体は失われない。

置いたブロックが壊されたり取り除かれたりすると、その配置工程は未着手に戻り、それより後のステージの作業もやり直しになる（作業中のアームは手を止め、持っていた材料を落とす）。壊れた枠から完成品は出ない。後のステージで置いたブロックがまだ立っていれば、その工程はやり直さず、壊れた工程だけを作り直して再開する。

全工程が終わって40 tick後、ジグが置いたブロックを消し（ジグが置いたものと同じブロックだけ）、完成品を上に出し、蒸気と音を出す。

## 描画

ジグの描画が、サーバーが同期した進捗から、アームと同じ軌道（`arm/Trajectory`）で描く。

- 溶接: 継ぎ目に沿ったビード。熱は白→黄→橙→暗赤→銀へ、トーチからの距離と時間で冷める。アークの閃光、火花、煙、音。
- 配線: 実際のコアメモリの作り方に合わせ、上面中央の4分の1（0.5×0.5マス）に、ほこりほどの大きさ（半径0.007マス）の12×12のフェライトコアを1列ずつ置き（全部45°傾けて立てる、線の太さは0.0025マス）、次に銅のX線、赤いエナメル線のY線を全コアに通し、最後に金のセンス線を対角線に沿ってジグザグに全コアへ通す。ヘッドはコアごとに輪の中まで沈み、コアの間で持ち上がる。各線が全コアをちょうど1回通ることをGameTest（`everyWireThreadsEveryCore`）で確認。
- レーザー: ビームと、通った後の暗い溝、煙。
- スプレー: ジグザグの吹き付けと、流体の色の半透明の膜、滴。

## データパック

レシピは `data/<名前空間>/assembly/<名前>.json`。表示名は翻訳キー `assembly.<名前空間>.<名前>`。

```json
{
  "size": [3, 1, 3],
  "stages": [
    [ { "pos": [1, 0, 1], "action": "place", "tool": "gripper", "block": "minecraft:iron_block" } ],
    [ { "pos": [1, 0, 1], "action": "process", "tool": "wiring_head", "pattern": "grid_wire", "consume": "minecraft:copper_ingot", "time": 120 } ]
  ],
  "result": { "id": "create_refinery_n_reactors:magnetic_core_memory", "count": 1 }
}
```

- `size`は各軸1〜3。`pos`はジグの真上のマスを原点にした相対座標で、範囲内。
- `action`は `place`（グリッパーだけ。`block`が必要）、`lay`（グリッパーだけ。`item` のアイテムをブロックにせず、マスの床に平らに置く。後の工程はその上で作業し、完成時に消費される）か `process`。グリッパーは置くことしかしない。
- `pattern`: `seam_weld`、`perimeter_cut`、`diagonal_cut`、`grid_wire`、`core_set`、`wire_thread`、`full_spray`。省略時は工具の既定。`seam_weld`は水平に隣接する `place` のマスとの境を溶接する。
- `full_spray`は `"fluid": {"id": "minecraft:water", "amount": 100}` が必要。`consume`は材料として取るアイテムで、`"consume": {"id": "...", "count": 144}` と書くと1工程で複数個（最大1024）取る。アームは届く入れ物を合わせて数がそろったときだけ取り出す。
- `core_set` はコアを並べるだけ、`wire_thread` は並んだコアに線を通すだけの `grid_wire` の前半・後半。
- 不正なレシピは読み込み時に警告を出して無視する。

ベルト用レシピは同じ `assembly/` に置き、`input` を持つものがベルト用になる。

```json
{ "tool": "welding_torch", "input": "minecraft:damaged_anvil", "result": { "id": "minecraft:chipped_anvil" }, "time": 80 }
```

- `tool` はグリッパー以外。`spray_nozzle` は `fluid` が必要で、アームのタンクから引き落とす。`time` の既定は40。
- サンプル: 溶接で欠けた金床→少し欠けた金床→金床、レーザーで石レンガ→模様入り石レンガ、水スプレーで白のコンクリートパウダー→白のコンクリート。

サンプル: `welded_iron_beam`（鉄ブロック2個を置き、継ぎ目を溶接）と `magnetic_core_memory`（鉄板を敷く、フェライトコア144個を並べる、エナメル線25本を通す、縁のはんだ付け。専用のPonderあり。`docs/quality/industrial-arm/memory-ponder.png`）。

### 磁気コアメモリの部品

コアの数は配線面の実際のコアの数（12×12＝144個）と同じ。エナメル線はX線12本、Y線12本、センス線1本の計25本。

| 部品 | 作り方 |
| --- | --- |
| フェライト粉 ×2 | 加熱ミキサー: 酸化鉄（赤）×2、酸化ニッケル、亜鉛ナゲット（ニッケル亜鉛フェライト） |
| 未焼成のフェライトリング ×16 | プレス: フェライト粉 |
| フェライトコア | かまど（ファンの溶鉱でまとめて焼ける）: 未焼成のフェライトリング |
| エナメル線 ×4 | 加熱ミキサー: 銅線（Electro Energetics）×4、工業用樹脂 |

1台分でフェライト粉9個（酸化鉄18、酸化ニッケル9、亜鉛ナゲット9を2回分に分けて）、エナメル線は7回分（銅線28、樹脂7）。

## 実装

- `arm/`: レシピ（`ArmRecipe`、`ArmRecipes`）、工具（`ArmTool`）、軌道（`Trajectory`、サーバーとクライアントで共有する純粋な計算）、Createの関節角の取得（`ArmPose`）、先端の粒子（`ArmEffects`）。
- `block/AssemblyJigBlock`、`block/entity/AssemblyJigBlockEntity`: 予約・進捗・完成。更新タグで同期し、進捗の変化は2 tickごと。クライアントは進捗を補間して描く。
- `block/IndustrialArmBlock`、`block/entity/IndustrialArmBlockEntity`: 探索・材料の取得・作業。サーバーは狙う先端の位置だけを同期し、クライアントがCreateの `ArmAngleTarget` で関節角を求めて動かす。
- `client/IndustrialArmRenderer`、`client/AssemblyJigRenderer`: 描画。Flywheelのインスタンス描画は使わない。持った物と工具は、Createのアームと同じく関節の変換の後に爪の座標系で置く。工具は爪の狙う点で終わる大きさで描く。
- 関節角はCreateの `ArmAngleTarget` の計算を `ArmPose.angles` に移植し、腕の長さだけを変えて解く（Mixin・Access Transformer・リフレクションは使わない）。Createの元の長さでは同じ角度になることをGameTestで確認している。
- ゴーグル: アームは状態・工具・ジグの位置と工程・タンク、ジグはレシピ・ステージ・工程数・タンクを表示する。
- Ponder: `plant/industrial_arm`（`ponder/ArmPonderScenes`）。
