# 産業用アーム

Createのメカニカルアームと同じ関節計算・モデル・テクスチャ（色もCreateのアームのまま）で動く産業用アームが、デポやベルトの上のアイテムを、Createのシーケンス組立のように工程を重ねて組み立てる。操作は右クリックとホッパーやファンネルへの搬入だけで、独自GUIはない。レシピはJEIの「産業用アームの組立」で見られる。

## 部品

| 部品 | 役割 |
| --- | --- |
| 産業用アーム `industrial_arm` | 回転で動く。下面から軸を受ける。応力4 SU。工具スロット1個。何も付けなければ（素のアーム）Createと同じ爪で、部品を置く、コアを並べる、線を通す、線を押さえる |
| 溶接トーチ `welding_torch` | 唯一の工具。溶接の工程 |
| 未完成の磁気コアメモリ `incomplete_magnetic_core_memory` | 磁気コアメモリの途中の品。次の工程を覚えている |

トーチはスタック1。持って右クリックで装着（付いている工具とは交換）、素手の右クリックで外す。ホッパー、ファンネル、シュート、ベルトから工具スロットへ出し入れできる。

2026-11-26に組立ジグ `assembly_jig` を廃止した（古いワールドのジグは消える）。それ以前にグリッパー・レーザーカッター・スプレーノズル・精密配線ヘッドも廃止している。

## 使い方

1. アームを手に持ち、設置する前に、作業させるデポ（またはベルト）と、部品を入れたチェストや部品供給用デポを右クリックして取得する場所（青の枠）にする。完成品の置き先は2回右クリックで置く場所（橙の枠）。3回で解除。スニークしながらの右クリックは選択せず普通に設置する。
2. アームを置いて回転を与える。待機中の先端（クロー）は、置いたときにプレイヤーが見ていた方向を向く（blockstate `facing`）。
3. レシピの最初のアイテム（磁気コアメモリなら鉄板）を、そのデポに置く。

アームを置くと選んだ場所がそのアームに記録され、範囲（5マス）外や爪が届かない場所は外して知らせる（最大16か所ずつ）。選択のパケットはブロックの設置より先に届くので、サーバーは設置まで預かってから適用する。ゴーグルで状態・工具・作業中の工程・取得と置く場所の数が見える。

## 動き

アームはCreateのメカニカルアームの2本の腕の長さだけを2倍にしたもの（`ArmPose.SCALE`）で、太さ・関節・爪はCreateのまま。関節角はCreateの `ArmAngleTarget` と同じ計算を腕の長さを変えて行う（`ArmPose.angles`、元の長さではCreateと同じ角度になることをGameTestで確認）。届く距離は肩（ブロック中心の0.375上）から手首まで約3.6マス、手首は狙う点の0.5上。Createの長さのままでは1.8マスしか届かず、周りのデポやベルトに届かないため。通る点のどれかに届かない工程は行わない。

1. 回転しているアームは、取得する場所に選んだデポとベルトの上で、中央付近のアイテムを調べる（10 tickごと）。アイテムの次の工程が自分の工具（素のアームか溶接トーチ）の工程で、その軌道に届けば、それを行う。新しいアイテムはレシピの `input` に合えば最初の工程から、途中の品は覚えている工程から。
2. 工程の部品を、取得先に選んだチェストや部品供給用デポから、必要な数がそろったときだけまとめて取る。作業中のデポは組立品を保持する。大きいチェストの両半分を選んでも中身は1回だけ数える。アームはまず供給側へ腕を伸ばし（12 tick）、それからアイテムの上へ動く。
3. Createのメカニカルアームと同じく毎tick `lockedExternally` を立ててアイテムをその場に止め、軌道をなぞって作業する。作業時間はレシピの `time` tickを16 RPMで基準にし、回転が速いほど短い。回転が0なら止まる。
4. 工程が終わると、スタックのうち1個が次の段階（`transitional` のアイテム、なければ元のアイテムのまま、次の工程を `custom_data` に記録）になり、残りはそのまま。最後の工程なら製品になり、置く場所があればアームが下に提げて最初に全部入る置く場所へ運ぶ（どれも満杯なら待って再試行）。なければデポに残る。
5. 部品（または線通しの補助のアーム）が無ければ3秒待つ。同じアイテムは1台だけが扱う。

回転が止まったアーム、工具の付け外し、アームの破壊では作業をやめ、持っていた部品を空きのある取得先へ戻す（入らなければ落とす）。アイテムは終わった工程までを覚えているので、次のアームが続きから行う。作業中の工程は保存しない（開き直すと部品を戻して最初から探し直す）が、運搬中の製品は保存する。

### 2台で行う作業（線通し）

`"helpers": 1` の工程（磁気コアメモリの線通し）は素のアーム2台で行う。工程を取るアームは、部品を取る前に、アイテムの5マス以内で手が空いていて回転していて軌道に届く素のアームを探し、いなければ待つ（線は取らない）。見つかれば線を取って通し、もう1台（補助、状態「ほかのアームの線を押さえています」）は通している線の先（面の端、`Trajectory.runEnd`）を爪で押さえて、線と一緒に動く。補助のアームは取得する場所を選ばなくてよい。進む速さは2台の遅い方の回転で決まる。補助が壊されたり工具を付けられたりすると、線を通していたアームは線を入れ物へ返す。

## 描画

アームの描画が、サーバーが同期したアイテムの位置・レシピ・工程・進捗から、アームと同じ軌道（`arm/Trajectory`）でアイテムの上に描く。前の工程は完成した形で、作業中の工程は進捗まで描く。工程の間はアイテムのテクスチャ（未完成の磁気コアメモリ）で見える。

- 先端は幅1.3ピクセルのピンセット状の爪と細い手首を使う。ブロックをつかむときは広く開き、コアを並べる間は小さく開閉する。コアを並べる間と配線中は手首を最大0.44マス持ち上げ、細い軸だけを作業面へ伸ばす。部品の束は爪から外し、先端の動きが見えるようにする。
- 溶接: 細いトーチの先から継ぎ目に沿ったビードを引く。熱は白→黄→橙→暗赤→銀へ、トーチからの距離と時間で冷める。アークの閃光、火花、煙、音。
- 配線: 0.5×0.5マスの作業面に12×12のフェライトコアを1列ずつ置く。明暗を付けた半径0.009マスの輪に、銅のX線、赤いY線、斜めのセンス線を通す。線は描画上で0.005マスの太さ。先端と補助アームの爪まで伸びた線で、どこを通しているか見える。各線が全コアをちょうど1回通ることをGameTest（`everyWireThreadsEveryCore`）で確認。
- 未完成品と完成品はどちらも16×16のドット絵。未完成品は露出したフェライトの輪と治具、完成品は銅線格子、斜めのセンス線、縁の端子を描く。[実物の磁気コアメモリ面](https://www.si.edu/object/mainframe-computer-component-whirlwind-magnetic-core-memory-plane%3Anmah_334413)

## レシピ

種類 `create_refinery_n_reactors:arm_assembly`。`data/<名前空間>/recipe/` に置き、ほかのレシピと同じくクライアントへ同期され、JEIに出る。

```json
{
  "type": "create_refinery_n_reactors:arm_assembly",
  "input": "create:iron_sheet",
  "transitional": "create_refinery_n_reactors:incomplete_magnetic_core_memory",
  "steps": [
    { "pattern": "core_set", "consume": { "id": "create_refinery_n_reactors:ferrite_core", "count": 144 }, "time": 60 },
    { "pattern": "wire_thread", "helpers": 1, "consume": { "id": "create_refinery_n_reactors:enamelled_copper_wire", "count": 25 }, "time": 120 },
    { "tool": "welding_torch", "time": 50 }
  ],
  "result": { "id": "create_refinery_n_reactors:magnetic_core_memory" }
}
```

- `input`: デポに置く最初のアイテム。`transitional`（省略可）: 工程の間のアイテム。省略すると `input` のまま進み具合だけを記録する。
- `steps`: 順に行う工程。`tool` は `hand`（素のアーム、省略時）か `welding_torch`。`pattern` は素のアームなら `place`（部品を置く、省略時）、`core_set`（コアを並べる）、`wire_thread`（線を通す）、トーチは `seam_weld`（溶接、省略時）だけ。`consume`（省略可）は工程で使い切る部品で、`count` は1〜1024。`helpers` は0か1。`time` は16 RPMでのtick数（既定40）。
- サンプル: `arm_assembly/magnetic_core_memory`（鉄板→コア144個→素のアーム2台で線25本→はんだ付け）、`arm_assembly/welded_iron_beam`（鉄ブロックの上に鉄ブロックを置いて溶接）、`arm_assembly/repair_damaged_anvil`・`repair_chipped_anvil`（溶接で金床を1段直す）。

### 磁気コアメモリの部品

コアの数は配線面の実際のコアの数（12×12＝144個）と同じ。エナメル線はX線12本、Y線12本、センス線1本の計25本。

デポだけで部品を供給する場合は、コアを64個、64個、16個に分けて3台のデポに置き、エナメル線25本を4台目に置く。部品を取る素のアームには、作業デポと部品供給デポ4台をすべて青で登録する。[そのまま動かせるテストワールド](playtests/magnetic-core-memory-line.md)

| 部品 | 作り方 |
| --- | --- |
| フェライト粉 ×2 | 加熱ミキサー: 酸化鉄（赤）×2、酸化ニッケル、亜鉛ナゲット（ニッケル亜鉛フェライト） |
| 未焼成のフェライトリング ×16 | プレス: フェライト粉 |
| フェライトコア | かまど（ファンの溶鉱でまとめて焼ける）: 未焼成のフェライトリング |
| エナメル線 ×4 | 加熱ミキサー: 銅線（Electro Energetics）×4、工業用樹脂 |

1台分でフェライト粉9個（酸化鉄18、酸化ニッケル9、亜鉛ナゲット9を2回分に分けて）、エナメル線は7回分（銅線28、樹脂7）。

## 実装

- `arm/`: レシピ（`ArmRecipe`、`CERecipeTypes.ARM_ASSEMBLY`）、工具（`ArmTool`）、軌道（`Trajectory`、サーバーとクライアントで共有する純粋な計算）、Createの関節角の取得（`ArmPose`）、先端の粒子（`ArmEffects`）、取得・置く場所の選択（`ArmPoints`、`client/ArmPointSelection`）。
- `block/IndustrialArmBlock`、`block/entity/IndustrialArmBlockEntity`: 探索・部品の取得・作業・運搬。サーバーは狙う先端の位置と作業中のアイテムを同期し、クライアントがCreateの `ArmAngleTarget` と同じ計算で関節角を求めて動かす。
- `client/IndustrialArmRenderer`、`client/ArmWorkDraw`: 描画。Flywheelのインスタンス描画は使わない。持った物と工具は、Createのアームと同じく関節の変換の後に爪の座標系で置く。
- JEI: `compat/jei/CreatePlantJeiPlugin` の `arm_assembly`。入力（最初のアイテムと各工程の部品）、溶接トーチ（使うレシピだけ）、製品、工程の順。
- Ponder: `plant/industrial_arm` の `arm`（鉄骨）と `memory`（磁気コアメモリ）（`ponder/ArmPonderScenes`）。
