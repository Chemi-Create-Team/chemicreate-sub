# セメントと工業建材

セメントを既存のCreate設備で作り、工場用コンクリート、階段、ハーフブロック、樹脂張り防食床へ使う工程です。新しい加工機は追加しません。ミキサー、鉢、ブレイズバーナー、破砕ホイール、デプロイヤー、カッターと標準搬送を組み合わせます。

## 工程

| 設備 | 入力 | 出力・条件 |
| --- | --- | --- |
| 鉢＋ミキサー＋超加熱バーナー | 方解石4、粘土玉1、砂1、鉄塊1 | セメントクリンカー4。通常加熱では処理できない |
| 同じ超加熱設備 | 上記原料＋水処理の一般洗浄汚泥1 | クリンカー5。原料の一部を代替する増収経路 |
| 破砕ホイール | クリンカー1 | 粉砕クリンカー1 |
| 鉢＋ミキサー | 粉砕クリンカー8、既存の石膏1 | ポルトランドセメント8。加熱不要 |
| 鉢＋ミキサー＋通常の水配管 | セメント1、砂4、砂利4、水1,000 mB | 工場用コンクリート8。加熱不要 |
| デプロイヤー | 工場用コンクリート1、樹脂板1 | 樹脂張り防食床1。樹脂板は消費する |
| カッターまたは作業台 | 工場用コンクリート | 階段、ハーフブロック |
| カッターまたは作業台 | 樹脂張り防食床 | ハーフブロック |

水処理は[排水処理](water-treatment.md)の中和・沈殿・ろ過工程へ接続します。汚泥は一般の槽洗浄排水の固体残渣であり、高レベル廃液やガラス固化物をセメントに変える工程ではありません。石膏は既存のリン酸製造から供給します。

方解石を炭酸カルシウム源に使い、クリンカー焼成、粉砕、石膏添加、骨材・水との混合を分けています。[American Cement Associationの工程説明](https://www.cement.org/cement-concrete/how-cement-is-made/)と[メーカーの工程説明](https://www.heidelbergmaterials.com/en/products-and-services/cement/how-cement-is-made)を参考にしました。実際のクリンカーは高温炉で焼成し、少量の石膏と粉砕してセメントにします。超加熱鉢はその工程のゲーム内表現です。アイテムの配合量・収率・時間は建築用のゲーム設定で、実機の質量配合や焼成炉設計を表しません。か焼で生じる二酸化炭素は開放鉢から逃げる扱いで、回収用ガスは生成しません。

## 接続と操作

材料は鉢側面のファンネル等、水はCreate標準パイプとメカニカルポンプで搬入します。ミキサーは上面への直結軸を持たないため、隣接する歯車から回転を入れます。生成物は鉢の標準出力から取り出します。Create本来の照合と確定処理を使い、照会だけでは材料を消費せず、出力満杯時には材料と水を保持します。ゴーグルとDisplay Linkは既存の鉢・Create設備の表示を使います。


コンクリートのハーフブロック2個は作業台で1ブロックへ戻せます。重ねたハーフブロックを壊すと2個を落とし、体積が失われません。建材にBlockEntityやtick処理はなく、保存やチャンクの境界はバニラの建材と同じです。樹脂張り床は耐薬品仕上げを表現する建材で、現時点で床による流体の無害化・封じ込め能力は付与しません。

## 外観とPonder

新しいコンクリートは灰色の型枠目地と粗骨材、防食床は抑えた緑灰色の樹脂面と継ぎ目で描き分けています。基本密度は16×16で、既存設備の画像は変更しません。粉砕クリンカーとセメント粉は、既存粉体と同じバニラ火薬の輪郭・7階調を使います。焼成前の粉と誤認しないよう、クリンカー自体は粒の大きい塊です。

各新製品から「セメントを作って工場を建てる」Ponderを開けます。超加熱焼成、逆回転する破砕ホイール、石膏との混合、水配管によるコンクリート製造、建材の配置を順に示します。処理中だけミキサーを動かし、クリンカー粉砕の後は破砕ホイールを停止します。

## 実装と確認

- 登録：`CEBuildingMaterials`。`MATERIALS`に中間材3種、`BUILDING_ITEMS`に建材5種をまとめています。
- 生成：`tools/generate_building_materials.py`。新規画像、モデル、レシピ、loot、Ponder構造、統合用翻訳fragmentを再生成できます。
- 自動確認：`BuildingMaterialsGameTests`。実際のCreate鉢を使い、加熱条件、無消費の照合、出力満杯時の保持、水の搬入と消費、生成量、ハーフブロックのdropを確認します。
- ビルド・GameTest・実クライアントでの最終結果は、この作業全体の完了レポートに記録します。
