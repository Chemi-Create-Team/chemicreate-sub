# 冷却・液化と冷媒循環

温度・圧力等級化B3以降の仕様。流体の状態は種類で決まり、保管中の自然蒸発・凍結、圧力によるフラッシュは行わない。

- ラジエーターはファンで高温工程流体を冷却後の種類へ変換する。温排水を水へ戻したり、通常の蒸気を水へ凝縮したり、アンモニアなどの気体冷媒を液化できる。ファン停止中は原料を保つ。
- 熱交換器は高温流体と冷媒を同時に変換する。水は温排水へ、液体冷媒は登録された比率の気体へ変わる。詳しくは[熱交換器と対向流](counterflow-heat-exchanger.md)。
- 窒素・酸素・ヘリウムはコールドボックスで液化する。ファンだけでは液化できない。3×3×3の本体、中央の再生器、外付け駆動部を組み、32 RPM以上の動力を与える。

コールドボックスの上面は気体入口、下面は液体出口。正面から見て左が水入口、右が温排水出口で、前後は流体口ではない。最初のヘリウム充填や予冷待ちは不要。各バッチに固定の回転仕事と冷却水を払い、液体・温排水の両方に空きがある場合だけ処理する。回転仕事は液化量で決まり、伝動網の容量不足では処理しない。

窒素・酸素の液体1 mBには水50 mB、ヘリウムの液体1 mBには水200 mBを使い、同量の温排水を出す。1 mBの液体に必要な気体量は共通の気液ペア表で決まる。JEIで実際の原料・製品を確認できる。

液体アンモニアを冷媒として循環させる場合、熱交換器で高温流体を冷やしながらアンモニアガスへ変換し、ファン付きラジエーターで同じ液体量へ戻す。液体窒素などの極低温冷媒を使い切った場合は、回収した気体を動力式コールドボックスへ戻す。

配管・タンクは等級と耐食性で選ぶ。極低温の液体は保冷配管と対応タンクへ送る。対応しない容器は受け付けず、沸騰・圧力上昇・破裂による置き換えはない。気体量、液体量、出力待ちの在庫は保存・再読込で保持する。

水の製氷は、液体窒素と水をふた付き撹拌槽へ入れる固定レシピを使う。氷を熱交換器の底から自動生成する旧方式は廃止した。
