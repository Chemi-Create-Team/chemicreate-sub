# 洗浄排水を工業用水へ戻す

ふた付き槽の清掃ドレンから出る既存の洗浄排水を、既存の撹拌槽3基で通常の `minecraft:water` へ戻す工程です。専用装置や画面は追加しません。核燃料工程の廃液を処理する設備ではありません。

各槽は2×2または3×3で組み、撹拌羽根を装着して32 RPM以上を供給します。各段の原料は60 ℃以下に冷却してください。Blaze Burnerは不要です。固体はCreate標準ファンネル、液体は標準ポンプと配管で搬送できます。槽の内容物・窓・実際の撹拌運動は既存の表示を使います。凝集剤・ろ材・汚泥からPonderを開くと、3槽の配置と配管を確認できます。

| 工程 | 1バッチの原料 | 生成物 | 所要時間（32 RPM） |
| --- | --- | --- | --- |
| 中和 | 洗浄排水1000 mB、方解石1個 | 中和処理水1000 mB | 80 tick |
| 凝集・化学沈殿 | 中和処理水1000 mB、水処理凝集剤1個 | 澄明水1000 mB | 160 tick |
| ろ過 | 澄明水1000 mB、水処理ろ材1個 | 通常の水1000 mB、洗浄汚泥3個 | 80 tick |

水処理凝集剤は、既存の赤色酸化鉄・アルミナ・粘土玉を各1個混合すると4個できます。ろ材は砂・木炭・羊毛を各1個クラフトすると4個できます。

各槽の**出口へ直接スマート液体パイプを付け、次の段に送る生成物をフィルターで指定**してください。撹拌槽の側面は原料の回収も許可しているため、無指定の配管では未処理の液体も搬出できます。フィルター見本には通常の流体バケツを使えます。最後の槽は水バケツを指定し、固体の汚泥をファンネルで別に取り出します。

回収した水は清掃・冷却や、通常の水を要求する既存工程に再利用できます。一般洗浄汚泥は[セメント工程](industrial-building-materials.md)の `mixing/cement_clinker_with_sludge` へ送れます。放射性廃棄物をセメント原料へ変える仕組みではありません。

## 難燃樹脂ペレットの製造と水の循環

1. 3×3の撹拌槽を32 RPM以上で回し、底面の隅をブレイズバーナーで加熱します。ポリプロピレン2個、ネザークォーツ1個、方解石1個、水250 mBで、難燃樹脂ペレット4個と樹脂加工蒸気250 mBができます。ペレットはファンネルで取り出し、蒸気はハッチを閉じた槽の上面からポンプで回収します。
2. 4～8段の大型吸収塔の最下段の側面へ蒸気250 mB、最上段へ水750 mBを送ります。最下段の別の面から中和処理水1000 mBを回収します。樹脂加工蒸気は、この工程用に追加した架空の流体です。
3. 中和処理水を上記の凝集・ろ過に通します。戻った水1000 mBをペレット製造側へ250 mB、吸収塔へ750 mB配分すると、最初の水を次のバッチに使えます。凝集剤とろ材は毎回必要です。汚泥は別に取り出します。
4. メカニカルプレスでペレット1個を耐熱パッキン2個に成形します。高圧ケーブル導体・往復式シリンダー・往復式コンプレッサーのレシピは、どちらのパッキンでもクラフトできます。

ペレット、耐熱パッキン、樹脂加工蒸気入りバケツから製造Ponderを開けます。投入量と生成物はJEIでも確認できます。

## 保存量と停止条件

中間の2流体は水系キャリアとして密度1 kg/L、比熱4180 J/(kg·K)です。各段はキャリア液量を1000 mBから1000 mBへ保ち、消費した流体の熱量を生成流体へ引き継ぎます。異なる温度の既存在庫へ合流すると、既存の熱量合成を使います。実配管やタンクを通す間の外気との熱交換は通常どおり発生します。

`pressure_reaction` の省略可能な `conserve_heat: true` をこの3レシピで指定します。既存レシピは省略時の挙動を維持します。熱量の計算は生成物の既定の相エネルギーも考慮し、必要な出力温度が物性の範囲外なら処理を開始しません。アイテムの顕熱・反応熱は現行のレシピ模型に含めません。

原料・固体生成物・液体生成物を一括で確認してからバッチを確定します。水または汚泥を入れる空間が不足していれば、原料やろ材を先に消費しません。回転停止・過温・構造不成立でも消費しません。保存と再読込は既存槽の在庫・進捗の保存を使います。

方解石の中和剤、鉄・アルミナ・粘土の凝集剤、砂・木炭・羊毛のろ材は工程を遊ぶための近似です。個々のアイテムにSI単位の質量を割り当てておらず、3種類の投入資材と捕集した汚れを最終的な汚泥3個にまとめます。実際のpH、溶存成分、沈降時間、飲用水の水質保証を再現する模型ではありません。沈殿段は化学的な凝集・沈殿をレシピで表し、静置沈降を時間・重力から解いてはいません。

## 根拠と実装

中和・凝集・化学沈殿・清澄化・ろ過を組み合わせる構成は、米国EPAの[産業排水処理技術一覧](https://watersgeo.epa.gov/iwtt/treatment-technologies)と[集中排水処理の技術文書](https://www.epa.gov/sites/default/files/2015-06/documents/cwt_dd_2000.pdf)を参考にしています。工業用水への再利用はEPAの[水再利用ガイドライン](https://www.epa.gov/sites/default/files/2019-08/documents/2004-guidelines-water-reuse.pdf)を参考にしたゲーム上の目的です。上記の投入比率・処理時間・60 ℃上限・アイテム換算はゲーム設計です。

主要な実装は `registry/CEWaterTreatment.java`、`recipe/PressureReactionRecipe.java`、`block/entity/ReactorMachineBlockEntity.java`、`ponder/ManufacturingPonderScenes.java`、`gametest/WaterTreatmentGameTests.java` です。製造Ponderで排水処理を解説し、中間素材からも同じ工程を開けます。

新しいレシピ・粉とろ材の画像・バケツ・Ponder構造・統合fragmentは次のコマンドで再生成できます。既存設備の画像や中央の翻訳ファイルは書き換えません。

```sh
python3 tools/generate_water_treatment.py
```

`tools/data/water_treatment_{integration,lang,powders}.json` は中央の登録・タブ・Ponder・翻訳・粉の棚卸しへ統合するfragmentです。新規流体は `CEWorldFluids` の登録より先に初期化します。
