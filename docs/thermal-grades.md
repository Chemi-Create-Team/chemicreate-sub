# 温度・圧力の等級と流体ライン

現在の流体・温度・圧力・熱交換の仕様は[流体の状態](fluid-states.md)を参照。以下は旧仕様の記録。

流体の初期等級は種類で決まります。タンクの下でブレイズバーナーを燃やすと、内容物の温度等級を上げられます。種類・圧力・相を変える工程には引き続きレシピや変換装置を使います。数値の温度・圧力を調整する操作はありません。RBMKと核融合炉の内部温度・核反応計算は例外です。

## 配管と貯蔵

温度は「極低温（-123℃未満）・低温（-123～10℃）・常温（10～100℃）・高温（100～500℃）・超高温（500℃以上）」、圧力は「常圧（2 bar未満）・加圧（2～20 bar）・高圧（20 bar以上）」。ゴーグル・配管計器・バケツの説明では、等級名にこの範囲を添えて「温度 常温（10～100℃）／圧力 常圧（2 bar未満）」のように表示します。配管・ポンプは「運べる液体の温度・圧力」、タンクは「入れられる温度・圧力」を同じ形で表示するので、流体の等級がその範囲に入っているかを比べます。槽・塔・電解セルなどの装置は基本的にステンレス鋼製という設定です（[装置の材質](../DESIGN.md#装置の材質)）。配管の自然放熱・凍結・熱傷はありません。

定格に合わない流体も拒否せずに受け入れます。その流体が入っている間、配管・材質別ポンプ・タンクにはブロックを掘るときと同じひびが入り、約60秒（1200 tick）で壊れて中身を放出します（有毒・可燃ガスは雲になります）。ゴーグルと照準の横に「⚠ 気体に非対応：損傷 35%」のような警告が出ます。合わない流体を抜けば同じ速さでひびが消えます。タンクは結合した全ブロックにひびが入り、まとめて壊れます。材質別ポンプは同じ材質の配管と同じ定格（気体・大型気体ポンプは強化管、Createのメカニカルポンプは銅管）で、電動ポンプと高圧ポンプには定格がありません。可燃ガスの放出・着火、有毒ガス、放射線、炉内事故は別の仕組みとして残ります。

配管の材質条件は液体に適用します。気体・蒸気は等級や材質を問わず、Create標準の銅管などどの配管にも通せます。

| 強化 | 低温～超高温 | 加圧 | なし |
| ステンレス鋼 | 低温～超高温 | 高圧 | 酸 |
| ニッケル合金 | 低温～超高温 | 高圧 | 酸・フッ化物 |
| ジルコニウム | 低温～超高温 | 高圧 | 酸・熱い酸 |
| 保冷 | 極低温～常温 | 加圧 | 酸 |
| PVC | 低温～常温 | 加圧 | 酸 |
| セラミック（粘土を焼いた管） | 低温～高温 | 常圧 | 酸・熱い酸 |

| タンク | 温度範囲 | 最大圧力 | 対象・耐食 |
| --- | --- | --- | --- |
| Createの通常タンク・横置き | 低温～高温 | 加圧 | 液体、腐食性不可 |
| Createのクリエイティブタンク | 全等級 | 全等級 | 液体・気体。バケツで無限供給を設定 |

液体専用タンクには気体も入りますが、定格外として損傷します。ガスタンク・ガス受け・ガスホルダーには液体自体を入れられません。

一般貯蔵の気体容量はタンクの定格で常圧×1・加圧×16・高圧×64。空気は実際の圧力等級も反映し、常圧では容積と同量、加圧時は容積の16倍の常圧換算量を貯蔵できます。液体容量は通常どおりです。結合・分割・保存でも総量を保ちます。炉・タービン・ボイラーの専用水換算バッファには、この倍率を重ねません。

気体もCreateのポンプで送ります。クリエイティブタンクはガス入りバケツで右クリックして供給する気体を選べます。配管内の移送で等級は変化せず、受け取り側のタンクや装置は各自の受入条件に従います。往復式圧縮機は対応表の流体を一段圧縮し、減圧弁は一段戻します。例として水素は加圧水素を経て高圧水素になります。計器の針と比較器は等級に従い、PIDと発信器は液位・流量を扱います。

## 加熱と冷却

Create標準タンク、縦置き・横置きの各タンク、ガスタンクコンテナ、伸縮式ガスホルダー、開放槽、ふた付き槽は、底面直下の燃焼中のブレイズバーナーで加熱できます。底面のどこか1か所が燃焼していれば、200 tick（10秒）ごとに内容物の温度等級が1段階上がり、超高温で止まります。確認間隔は20 tickなので、初回には最大1秒の待ちがあります。液体と気体の両方が対象です。

量・種類・圧力・相は変えません。等級は流体スタックへ保存し、搬出・保存・再読込後も保持します。空、消火、内容物の種類・等級変更で加熱待ちをリセットします。同じ流体の量だけが変わってもリセットしません。異なる等級の同じ流体をタンク内で混ぜると、低い方の等級にそろえます。異種流体やその他の異なる成分を混ぜられるようにする変更ではありません。

タンクの受入条件は内部加熱の上限を決めません。加熱した液体の搬出先は配管とタンクの等級を確認し、加熱した気体の受け取り側はタンクの等級を確認します。蒸気や高圧水への変換には専用の工程を使います。電熱線ヒーターは撤去済みです。

ふた付き槽は固有の連続温度を持ちません。下のブレイズバーナーが「加熱」「超加熱」を満たすとレシピが進みます。レシピ固有の加熱条件と、内容物の等級上昇は別の処理です。必要な材料・触媒・出口容量がそろわない場合は消費しません。ハッチを開くと実在庫の気体を放出します。

| 操作 | 使う設備・流れ |
| --- | --- |
| 原油を分留へ | 加熱した槽で原油→予熱した原油、2×2・5段の分留塔へ |
| ナフサ分解 | 通常のナフサ・水・分解触媒、超加熱 |
| 軽油脱硫 | 通常の軽油・高圧水素・触媒、加熱 |
| 重油分解 | 通常の重油・高圧水素・触媒、超加熱 |
| 合成アンモニア | 加圧合成原料と鉄触媒を加熱→高温混合ガス→冷却→気液分離器 |
| 固定冷却 | ファン駆動ラジエーターで、高温生成ガス→冷えた生成ガス、蒸気→水、アンモニアガス→液体アンモニア |
| 熱交換 | 冷やす流れと水／液体冷媒を別系統へ。2系統を同時変換。長さ×断面で処理量が増え、対向流は×1.5 |
| アンモニア冷媒循環 | 液体アンモニア→熱交換器→アンモニアガス→ラジエーター→液体アンモニア |
| 極低温液化 | コールドボックスへ窒素・酸素・ヘリウム、回転動力、水。液化ガスと温排水を搬出。予冷・ヘリウム初期充填なし |
| 製氷 | 槽で水と液体窒素→氷と窒素ガス |

レシピと変換比はJEIを参照してください。熱交換器は両方の出口容量を確保してから変換するため、一方が詰まると両方停止します。

## 発電と炉の境界

| 蒸気 | 等級 | 生産 |
| --- | --- | --- |
| 通常蒸気 | 高温・常圧 | バーナーの上のCreateの液体タンク（蒸気エンジン・汽笛なし、天面からポンプで搬出） |
| 高圧蒸気 | 高温・高圧 | 加熱したバーナーの上の横型タンク、RBMK、核融合冷却材の分離 |
| 過熱蒸気 | 超高温・高圧 | 超加熱したバーナーの上の横型タンク |

高い蒸気等級ほどタービンの仕事量と摩耗が大きくなります。高圧段の排気は通常蒸気としてポンプで低圧段へ送り、低圧段から普通の水を取り出します。整備は停止・排出後にレンチ。低圧段の有限の排熱は復水器冷却水箱で水→温排水として回収し、冷却塔で温排水→水へ戻します。冷却水が止まるとタービンも停止します。

RBMKは加圧給水を炉内の公称給水条件として受け、高圧蒸気と残液を別の種類で出します。核融合炉は加圧給水→高温炉冷却材。気液分離器で高温炉冷却材12,000 mB→加圧給水11,000 mB＋高圧蒸気1,000 mB。普通の戻り水は加熱レシピで加圧給水へ変えてから炉へ送ります。配管へ数値の温度・相分率を運ぶ仕組みはありません。

蒸気をラジエーターなどで凝縮すると普通の水になります。薬品・塩水・不凍液の製造にも通常の水を使い、水質による区別や不良品への分岐はありません。

溶融塩電解炉は5 kW以上、ガラス固化炉は100 kW以上で、固定の電気仕事を使って処理します。浴の昇温や放熱計算はありません。
