# 溶銑輸送と転炉製鋼

| 工程 | 設備と入出力 |
| --- | --- |
| けい石レンガ | 鉢の上にメカニカルプレス、下にブレイズバーナーを置きます。砂2個と生石灰1個を超過熱でプレスすると、けい石レンガ4個ができます。 |
| 溶解 | メカニカルミキサーと超過熱した鉢で銑鉄1個を溶銑100 mBにします。 |
| 鉄道輸送 | 横型流体タンクの両側にけい石レンガを置くクラフトで耐火内張り横型タンクを作ります。台車とタンクの全ブロック、移動側のポータブル流体インターフェースを超粘着剤でつなぎ、駅から列車を組み立てます。 |
| 予備処理 | 加熱したミキサーで溶銑800 mBと生石灰1個を混ぜると、脱硫溶銑800 mBとスラグ1個ができます。 |
| 酸素吹錬 | [転炉](converter.md)に脱硫溶銑6,400 mB、鉄インゴット8個、生石灰4個と酸素64,000 mBを入れます。800 tickで溶鋼6,400 mB、スラグ8個、転炉ガス128,000 mBができます。 |
| 鋳造 | 転炉を傾けて溶鋼を抜き、鉢とメカニカルプレスで溶鋼800 mBを鋳造鋼スラブ1個にします。鋳造の鉢には追加のバーナーは不要です。 |
| 圧延 | 鋳造鋼スラブを加熱した[多段連続圧延ライン](continuous-factory.md)へ送り、極厚鋼板3枚にします。スラブは鋼鉄インゴット8個へのクラフトにも使えます。 |

## 停車中の積み下ろし

1. 耐火内張り横型タンクを、通常の横型タンクと同じ要領で同じ軸に並べます。運ぶ範囲をすべて接着してから列車にします。
2. 駅側と列車側のポータブル流体インターフェースを向かい合わせ、1〜2ブロック空けます。列車を接続できる位置で停車させます。
3. 高温の金属はステンレス製パイプとステンレス製ポンプで送ります。積み込みでは列車へ向け、積み下ろしでは設備へ向けます。車両内に複数の流体槽がある場合、Createの流体インターフェースは共有の積荷を扱います。

このタンクは常圧の溶銑・脱硫溶銑・溶鋼を1種類ずつ保持します。走行中の冷却と凝固はゲーム内では計算しません。タンクの一部だけが車体の組立範囲に入っている場合、Createの組立画面に接着範囲のエラーが出ます。

ゲーム内の製鋼経路は、溶銑の輸送と予備処理、酸素吹錬、鋳造、熱間圧延の順を採用しています。けい石レンガは指定されたゲーム内建材です。現代の酸素転炉では塩基性スラグに適したマグネシア系・ドロマイト系の耐火材が用いられます。 [日本製鉄の製鋼技報](https://www.nipponsteel.com/en/tech/report/pdf/124-03.pdf) · [ArcelorMittalの製鋼・圧延解説](https://constructalia.arcelormittal.com/en/sica-steel-academy/properties-of-steel/manufacturing-and-forming-processes)
