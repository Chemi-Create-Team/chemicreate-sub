# 説明書と進行の実績

テストプレイで「部品が多すぎて何を作ればいいかわからない」という声があったため、ゲーム内の説明書と、進む順番を示す実績を追加した。

## 説明書

- バニラの記入済みの本（`minecraft:written_book`）で、ページの文はすべて翻訳キー（`book.create_refinery_n_reactors.manual.page_0`〜`page_21`）。プレイヤーの言語で表示され、専用の画面は使わない。
- 入手方法
  - ワールドに初めて入ると、実績「Refinery 'n' Reactors」の報酬として1冊もらえる。報酬は`loot_table/gameplay/manual.json`。
  - 本と鉄インゴットでも作れる（`recipe/manual.json`）。
- 全24ページ。設備の作り方の順ではなく、遊ぶ目的の順に並べている：調べ方、最初に（鋼鉄と槽）、鉱石から金属を増やす（水素と硫酸を含む）、回転力を増やす（タービン・RBMK・核融合）、農業を速くする、発破で掘る、製品を出荷する、よい素材を作る、等級と配管、止まったとき。
- 目的の章は、最初の1文で「この章を進めると何ができるようになるか」（例：粉砕済み鉱石1個から2倍の金属）を書き、必要な設備と該当するPonderの題名を続ける。

## 進行の実績

- 実績画面（Lキー）にタブ「Refinery 'n' Reactors」を追加した（`advancement/guide/`）。
- 2026-11-24：圧縮・反応・配管・計器・安全・発電・原子力・採掘などの各設備と製品に、実績を38個追加した。各実績は、その分類で最初に作る設備か製品で達成する（`tools/generate_manual.py` の `STEPS`）。
- 同日、「産業革命」（低圧タービン）、「空気からパンを」（硝酸アンモニウム）、「連鎖反応」（RBMKの燃料チャネル）など、逸話や名言風の題をつけた実績を13個追加した。毒ガス・酸・気絶の状態異常を受けると達成する3つも含む（`effects_changed`）。
- 同日、すべての流体と気体のバケツに実績を追加した（118個。`advancement/fluids/`、生成は `tools/generate_fluid_advancements.py`）。「液体の図鑑」「気体の図鑑」の2つを入口にして、バケツ1種類ごとに1つ。題は流体の名前、説明文は共通の1文。状態違いの旧ID（蒸気・液体窒素など）は物質のバケツに含める。
- 同日、マルチブロック施設を完成させると達成する実績を25個追加した（`advancement/facilities/`、生成は `tools/generate_facility_advancements.py`）。入口は「プラントマネージャー」。条件は `minecraft:impossible` で、`event/FacilityAchievements` が各コントローラーの完成判定（`formed()` など）を2秒ごとに調べ、半径24ブロック以内にいるプレイヤーに与える。施設を足すときはこの表と生成スクリプトの両方に1行足す（食い違うとスクリプトが止まる）。
- 2026-11-27：本筋と寄り道を分け直した。本筋は太い枠（`goal`、最後の核融合だけ`challenge`）の一本道で、題に1〜12の番号をつける。寄り道はすべて`task`（状態異常の3つと錬金術は従来どおり）。
- 説明文は「まだ取っていない実績にカーソルを合わせたときに読む文」として、作り方（機械と主な材料）と、Wキーで開くPonderのアイテム名を書く。「次：〜」のような取った後の文は使わない。
- 本筋：
  1. 鋼鉄 → 2. ニッケル → 3. フェロクロム → 4. 圧延ライン → 5. ステンレス鋼 → 6. 工場の心臓（ステンレスタンク）→ 7. 水を分ける（電解セル）→ 8. 硫酸 → 9. 金属が増える（浸出液のバケツ）→ 10. 回転力が増える（タービンか燃料電池）→ 11. 燃料棒 → 12. 最後の工場（核融合炉の磁石給電盤）
- 寄り道は、関係する本筋の実績から枝分かれする（例：出荷票と施設建設機は最初から、プラスチック・配管・タンク・ガスの安全はステンレス鋼から、発電の設備は10から）。
- 各実績は、そのアイテムを手に入れたときに達成する。浸出は流体なので、浸出液を耐食合金バケツに汲んだときに達成する。

## 生成元

`tools/generate_manual.py`が、本・レシピ・報酬・実績・翻訳を書く正本。ほかの生成元が作る`guide/`の実績（工業肥料など）の翻訳は消さない。ページは本の1ページ（幅114ピクセル・14行）に収まるかを、英語は単語単位の折り返しで、日本語・中国語は文字単位の折り返しで見積もって確認する。
