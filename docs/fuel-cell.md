# 燃料電池

対象は Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10 / Create: Electro Energetics（CEE）1.1.4 です。水素と酸素から、CEE の回路の電力と温水を作ります。電極にニッケル、電解質膜に工業用樹脂を使う燃料電池です。

## 置き方とつなぎ方

- 1ブロックで1つのスタック（ニッケルの電極板とガスケットを、ステンレスの端板と4本のタイロッドで締めたもの）。正面に真鍮の銘板が付く。
- 上面の2本の端子に CEE の電線をつなぐ。
  - 赤い碍子の端子（正面から見て左）が＋（ノード0）、黒い碍子の端子（右）が－（ノード1）。
  - 端子に向けると「正極（＋）」「負極（－）」と表示される。
- 水素と酸素は、どの面からでも配管で入れる（別々の配管で）。それぞれ4,000 mBまで入る。
- 水は、どの面からでも配管で抜ける。4,000 mBまで入る。
- たくさん置けば、そのぶん電力が増える（並列なら電流、直列なら電圧が増える）。

## 計算

| 値 | 内容 |
| --- | --- |
| 開放電圧 | 400 V |
| 内部抵抗 | 20 Ω |
| 最大出力 | 2 kW（20 Ωの負荷のとき。端子電圧200 V・10 A） |
| 電流 | （400 V － 端子電圧）÷ 20 Ω |
| 水素の消費 | 400 V × 電流 × 1 tick（1/20秒）÷ 15 J/mB |
| 酸素の消費 | 水素の半分 |
| 水の生成 | 水素の1.5倍（普通の水） |

- 水素1 mBのエネルギーを、開放電圧で15 Jとした。フィルタープレス型電解槽が水素1 mBを作るのに使う25 J（極板1枚・1 tickに50 Jで水素2 mB）の6割で、実在の電解槽と燃料電池の電圧の比に近い。
- 負荷に届くのは、そのうち 端子電圧 ÷ 400 V の割合。残りはスタックの中で熱になる。
  - 20 Ωの負荷（最大出力）：負荷へ2 kW、水素は1 tickに13.3 mB。電解で使った電力の3割が返る。
  - 160 Ωの負荷（電解槽の極板1枚）：端子電圧356 V・2.2 A・790 W、水素は1 tickに3.0 mB。電解で使った電力の5割強が返る。
- 水素と酸素・水は1 mB単位で出し入れし、端数は次の tick に持ち越す。
- 水の比率は電解槽の逆（電解槽は水3 mB → 水素2 mB・酸素1 mB）。

## 止まる条件

| ゴーグルの表示 | 条件 |
| --- | --- |
| 発電中 | 電流が流れている |
| 待機 | 燃料はあるが、端子に負荷がつながっていない |
| 水素がありません／酸素がありません | どちらかが空。回路から外れる |
| 水の出口が満杯です | 水が4,000 mB近くたまった。回路から外れる |
| 切り離し中 | 回路の電圧が400 Vを超えて、燃料電池に電流が逆に流れ込もうとした。1秒（20 tick）回路から外れ、また試す |
| 回路につながっていません | CEE の回路計算から呼ばれていない（ワールドに電線が1本もないなど） |

ゴーグルでは、出力（kW・V・A）と、水素・酸素・水の量も見える。

## 作り方（作業台）

```
S C S
N P N
S R S
```

S＝ステンレス鋼板、C＝銅板、N＝ニッケルインゴット、P＝液体パイプ（Create）、R＝工業用樹脂（電解質膜）。ニッケル電極は3個から2個になり、樹脂膜1個を追加した。

## 実装

| ファイル | 内容 |
| --- | --- |
| `block/FuelCellBlock.java` | 向き、端子の位置と名前、形 |
| `block/entity/FuelCellBlockEntity.java` | 水素・酸素・水のタンク、消費の計算、ゴーグル、保存 |
| `compat/electro/FuelCellDevice.java` | CEE の回路で、内部抵抗付きの電圧源になる |
| `registry/CEFuelCell.java` | 登録 |
| `tools/generate_fuel_cell.py` | テクスチャ・モデル・レシピ・翻訳 |
| `tools/generate_fuel_cell_ponder.py` | Ponder「燃料電池で発電する」 |

- CEE の `voltageSourceWithResistance(a, b, 抵抗, 電圧)` は、引数の順が抵抗・電圧で、2つ目のノードの電位を上げる。そのため（ノード1, ノード0）の順で渡して、ノード0を＋にしている。

## 確認

- GameTest `CircuitGameTests.aFuelCellDrivesTheHeaterElementAndLetsGoOfAHigherVoltage`：燃料電池と工業用加熱器の発熱体（10 Ω）を銅線でつなぐと、端子電圧＋133 V・約1.78 kWで加熱器に電力が入り、水素が減って水ができる。
- GameTest `FuelCellGameTests.fuelCellBurnsHydrogenAndOxygenIntoWaterWithTheCurrent`：
  - 水素・酸素は入り、水は入らない。電線なしでは水素を使わない。
  - 端子電圧200 Vで3 tick：2 kW、水素40 mB・酸素20 mBを使い、普通の水60 mB。水だけが出る。
  - 450 Vで逆に流れ込もうとすると切り離し、20 tick後にまた試す。
