# 送電鉄塔と長距離高圧ケーブル

送電鉄塔を1ブロック置くと、鋼製の格子塔が立ちます。塔の正面には保守足場と黄色い注意板があります。当たり判定と設置・撤去の位置は中央の基部1マスです。脚と腕金の範囲に建物のない場所へ設置します。

| 地上高 | 寸法 |
| --- | --- |
| Y=1 | 根開き約5×5ブロック |
| Y=6 | 塔体約3.5×3.5ブロック、保守足場を含め約4×4ブロック |
| Y=14〜24 | 主塔体は約1.1×1.1ブロック |
| Y=17、Y=23 | 下段・上段の腕金は全幅約7ブロック |
| Y=20 | 中段の腕金は全幅約9ブロック |

## 設置と配線

1. 長距離高圧ケーブルリールを持ち、基部の上にある番号付き端子を右クリックします。1〜3は左側の上・中・下段、4〜6は右側の上・中・下段に対応します。
2. 次の鉄塔で同じ端子を右クリックします。基部間の距離が最大128ブロックで、線は両端の碍子をたるみなしで直線につなぎます。接続を取り消すときはリールを持ったままスニーク右クリックします。
3. 回路の行きと戻りを別の端子へつなぎます。6端子はそれぞれ独立しています。鉄塔のほか、Create: Electro Energeticsの接続端子にもつなげます。ゲーム内でのケーブルの絶縁上限は35 kVです。
4. ケーブルはCreate: Electro Energeticsの工具で取り外せます。鉄塔の基部を撤去すると、その鉄塔の配線が外れます。

## 材料とモデル

送電鉄塔はステンレス鋼板3枚、鉄格子2個、滑らかな石2個、精密機構とガラス碍子の部品を使います。ケーブル導体は重被覆電線、アルミニウム、ゴムパッキンから作り、導体4個と空リールで長距離高圧ケーブルリールを作ります。クラフトの配置はJEI、配線はPonderで見られます。

[ワールド用モデルJSON](../src/main/resources/assets/create_refinery_n_reactors/models/block/transmission_tower.json)は、1ブロックを単位とする `beams` の端点、断面寸法、テクスチャを記録したものです。このModの `lattice_beams` モデルローダーで読み込みます。インベントリ用とワールド用は同じ生成スクリプトから作ります。
