# クァーリー駆動部

駆動部を掘削範囲の角へ置き、外側の2面で長さと幅を設定します。範囲マーカーは使いません。

## 範囲の設定

1. レッドストーン信号を切ります。
2. 外側の面の上端へレンチを合わせ、Create標準のスクロール操作、または長押しの値設定で変更します。
3. それぞれの面に表示する数値は、**その面の反対方向へ掘るマス数**です。

長さは5～64、幅は3～64マス、初期値は16×16です。駆動部と外周の部材は掘削範囲に含めません。駆動部の上面または下面をレンチで右クリックすると、向きを90度ずつ変えられます。

南向きに置いた場合は、西面で東方向の長さ、北面で南方向の幅を設定します。回転入力は南面です。ほかの向きでは、この配置全体が回転します。

## 自動建設と補給

ゴーグルで駆動部を見ると、設置済み部材と在庫を差し引いた不足数が分かります。チェストからシュート、ファンネルなど通常のCreate搬送で補給してください。

採掘中は、駆動部のゴーグル表示で採掘完了までのおおよその時間を確認できます。残りの区画数と直近の進み方から推定し、地層の硬さ・空洞・サーバーの負荷で変動します。Shiftを押しながら見ると、吊り下げ位置と在庫を表示します。

| 資材 | 新設時の必要数 |
| --- | ---: |
| メタルガーダー | 4本の脚の高さの合計（レールから地面まで）＋掘削長×2 |
| メカニカルドリル | 1 |
| ベルトコネクター | ベルト区間ごとに1 |
| 通常のシャフト | ベルト区間ごとに2 |
| ケース入りチェーンドライブ | 掘削長＋1 |

掘削場の内側から回転を入れ、レッドストーン信号を入れると建設・採掘します。ドリルは在庫から自動装着され、手に持って駆動部を右クリックしても装着できます。

側面の搬出路は、Createの最大ベルト長に収まる複数の通常ベルトで作ります。各区間の回転は、その外側に並ぶケース入りチェーンドライブで伝えます。Create全体の最大長設定は変更しません。

最大ベルト長が既定の20の場合、掘削長32にはコネクター2個・通常シャフト4個・チェーンドライブ33個、長さ64にはそれぞれ4個・8個・65個を使います。既設部材は不足数から差し引きます。

搬出路の外側にはチェーンドライブ1列分の空間を確保し、駆動部に近いベルト終端から回収します。終端から落ちる荷物をシュートやホッパーなどで収納先へ回収してください。地面に放置された荷物は通常のアイテムと同様に消滅します。搬出先が詰まると荷を保持し、ドリルヘッドが満杯になると採掘を止めます。

枠や搬出路の建設時に取り除いたブロックのドロップは、採掘中のベルト搬送とは別に駆動部の在庫へ入ります。そちらは駆動部からファンネルなどで取り出してください。鉱石のドロップは幸運・シルクタッチのない鉄のツルハシ相当です。

クァーリーが取り除けないブロックで枠や搬出路の建設が止まると、現在の障害物を赤い枠で表示します。取り除くと建設が再開し、ほかに障害物があれば赤枠が次の位置に移ります。

## 水・溶岩の排水

稼働中は、各列を掘る前に水と溶岩の源・流れを自動で抜きます。更新前に掘った区画に残っていた液体も、稼働時に確認します。抜いた液体はその場で消え、水没したブロックとその内容物は保持します。範囲外に源があると、掘削跡へ再び流れ込むことがあります。

## 設定を変えるとき

信号を切ってから範囲や向きを変更します。既設の枠やベルトは自動解体されません。新しい範囲に合わない部材があると停止理由を表示するので、回収してから再建設してください。

駆動部は設定した方向・寸法のレールを確認するので、隣に別の枠を設置できます。

レッドストーン信号を入れると、駆動部・掘削範囲・側面ベルトとその出口付近のチャンクを読み込みます。プレイヤーが離れても作業を続け、採掘後に荷物が側面ベルトを出切ると解放します。動力源や回収装置は作業範囲内か出口付近に設置してください。

信号を切ると採掘を一時停止し、クァーリーが読み込んでいたチャンクを解放します。回転も止めると搬送も止まります。駆動部のPonderでも配置と操作を確認できます。

## 速度とSU

移動・採掘・自動建設・内部搬送は、1ワールドtickにつき最大8ステップ進みます。直前の4ステップから2倍にしました。外側の通常Createベルトは入力RPMに従います。内部搬送と橋のベルト表面は動力停止中に止まり、停止時間の分を再開時に飛ばしません。

クァーリー駆動部の応力影響値は16で、必要SUは **16×絶対回転数** です。64 RPMで1,024 SU、128 RPMで2,048 SU、256 RPMで4,096 SU。範囲の広さによる増減はありません。未形成時は0で、形成済みの軸が回転していれば、資材待ちやレッドストーンによる採掘停止中もこの負荷が掛かります。今回の2倍速化ではSU設定を変えていません。
