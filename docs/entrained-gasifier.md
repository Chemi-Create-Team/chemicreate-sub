# 水蒸気ガス化炉

炭素粉と水蒸気を反応させ、**一酸化炭素・水素混合気体**を作る3×3×6の設備です。石炭や木炭を粉砕して炭素粉を用意し、炉の底面中央の真下に燃料を入れたブレイズバーナーを置きます。JEIの「水蒸気ガス化」で配合を、炉の部品のPonderで組立と接続を確認できます。

| 下から数えた段 | 中央 | 外周 |
| --- | --- | --- |
| 6 | ケーシング。上面から混合気体を搬出 | ケーシング |
| 5 | 空洞 | 耐火炉壁。観察窓も設置可能 |
| 4 | 空洞 | 四隅は耐火炉壁。辺の中央に外向きの供給ノズル1〜4基を置き、残りは耐火炉壁 |
| 3 | 耐火炉床 | ケーシング |
| 2 | 空洞 | ケーシングまたは観察窓 |
| 1 | ケーシング。真下に熱源を設置 | ケーシング |

1. 供給ノズルの外向きの面にファンネルで炭素粉を送り、ポンプで水蒸気を供給します。ノズルが複数ある場合は別々に接続できます。在庫は炉全体で共有します。
2. ブレイズバーナーに、石炭などの燃料を入れます。外部加熱で炉内が1300℃に達すると反応が始まります。途中で火が消えると進捗を保持して停止し、燃料を補給して炉が十分に温まると再開します。
3. 最上段の中央からステンレス鋼管とポンプで搬出します。出口は常圧・超高温です。気体タンクへ送る場合は、冷却ファン付きラジエーターか熱交換器で常温に下げます。冷却後も気体の種類と量は同じです。

ノズル1基では40 tickごとに炭素粉1個と水蒸気250 mBを使い、COとH₂を1:1で含む混合気体500 mBを作ります。入力は通常蒸気、高圧蒸気、過熱蒸気に対応します。ゴーグルでは加熱や供給の待ち状態、ノズル数、速度倍率、炉温の等級、生成気体と水蒸気の残量を確認できます。蒸気バッファは8000 mB、生成気体バッファは16000 mBです。

| ノズル配置 | 速度 |
| --- | --- |
| 1基 | 1.0倍 |
| 隣接2基 | 1.6倍 |
| 対向2基 | 2.4倍 |
| 3基 | 3.0倍 |
| 4基 | 4.5倍 |

## ブレイズバーナーの燃料

一酸化炭素・水素混合気体入りバケツでブレイズバーナーを右クリックすると、空バケツが戻り、800 tick（通常速度で40秒）の超過熱燃料が入ります。

自動で供給するには、ポンプを使ってバーナーの側面に混合気体を送ります。受け入れた気体を1000 mB分ためると、バケツ1杯と同じ燃焼時間が追加されます。燃焼時間が十分に残っている間は、Create標準の補給条件に従って供給を待ちます。超高温のまま炉から直送する場合は、ステンレス鋼管とステンレス鋼ポンプを使います。

## 既存ワールドの炉

以前の炉は同じ構造で使えます。底面中央の下に熱源を取り付け、供給配管を水蒸気に切り替えてください。旧合成ガスが残っている場合は、先に上面中央から抜くと新しい混合気体を作り始めます。残った酸化剤は供給ノズルから、冷却水・温水・急冷水は底面の西・東・南から、それぞれ搬出できます。旧スラグを回収する場合は底面北側か、熱源を外した底面中央の下を使います。底面中央のケーシングを回収する場合は、そのブロックアイテムに炉の在庫が入ります。

データパックのレシピ型は `create_refinery_n_reactors:entrained_gasification` です。フィールドは `ingredient`、`steam`、`duration`、`gas_result` です。既定の配合は `data/create_refinery_n_reactors/recipe/entrained_gasification/carbon_steam.json` にあります。
