# 湿式浸出と円形沈殿池

浸出は既存のふた付き槽に攪拌羽根を入れ、下から加熱して行います。専用の大型浸出攪拌槽とその部品は削除しました。[当初の依頼仕様](specs/wet-leaching-and-clarification.md)からの変更点です。登録IDは `create_refinery_n_reactors:` です。

## 組立と入出力

施設建設機の「円形タンク（タンク構成）」で通常の貯蔵タンクを建設できます。「円形沈殿池」は同じ外壁と床に中央の2部品も組み込みます。どちらも直径7〜29の奇数を＋／−で2ブロックずつ選び、高さは床込みで3・4ブロックから選べます。

構成ブロックは通常の円形タンクと同じです。変換するには、床の中央1ブロックを下向きの底面流入口に交換し、その真上の縁と同じ高さにセンタードライブを置きます。ドライブの上面へCreate回転動力をつなぎます。推奨は1〜4 RPM、負荷は8×RPM SUです。

以下は直径7・高さ3、底面中央を(0,0,0)、正面を+Zとした構成です。

| ポート | 位置 | 接続面・用途 |
| --- | --- | --- |
| 中央駆動 | (0,2,0) | 上：Create回転動力 |
| センターフィード | (0,0,0) | 下：地下配管からスラリーを搬入 |
| 上澄み液の出口 | (0,2,+3) | 正面：上澄み液または未分離スラリーを搬出 |
| 汚泥の排出口 | (0,0,−3) | 背面・下：尾鉱泥を搬出、別スロットへ凝集剤を搬入 |

正面の外周最上段のタンク構成ブロックは上澄み液の出口になり、背面の外周最下段は汚泥の排出口になります。これらは既存の越流堰・汚泥排出口に交換することもできます。Create標準のパイプ・ポンプ・ファンネルに対応します。

ふた付き槽の側面へファンネルで鉱石を投入し、処理用の流体ポートから希硫酸と圧搾空気または酸素を供給します。Ponderでは液体を下段、気体を上段に接続した例を示します。気体は反応の投入材であり、液体保管タンクへの気体搬入制限を緩和しません。通常のふた付き槽の温度・動力・保守条件が適用されます。

## レシピと回収量

鉄・銅・亜鉛・錫に対応し、金の化学倍化は追加しません。

1. Createの破砕ホイールで原石を砕きます。錫は既存の錫石ルートを使います。
2. `pressure_reaction/<metal>_leaching.json`：攪拌羽根を入れたふた付き槽を加熱し、砕いた鉱石3個＋希硫酸750 mB＋圧搾空気または酸素250 mB → スラリー4000 mB。基準処理時間200 tick。
3. `clarifying/<metal>.json`：スラリー1000 mB → 精製液750 mB＋尾鉱泥2個。基準200 tick。凝集剤1個で1バッチ100 tickに短縮します。
4. 既存の電解採取で精製液1000 mB → インゴット3個＋希硫酸250 mB。

鉱石3個から合計インゴット9個、尾鉱泥8個、再生希硫酸750 mBが得られます。

ふた付き槽では廃水1000 mB＋粘土玉1個＋酸化用気体125 mBから凝集懸濁廃水1000 mBを作れます。これは加熱不要の撹拌反応です。同じ沈殿池で水750 mBと尾鉱泥2個へ分離します。尾鉱泥はプレスで粘土と確率で砂、加熱ミキサーで乾燥するとさらに確率で石英を回収できます。凝集剤はポリエチレン・スライムボール・水から作ります。

## 停止と回転数

| 沈殿池の回転数 | 結果 |
| --- | --- |
| 0 RPM | 沈降は継続。汚泥の搬出は停止し、64個で次バッチも停止 |
| 1〜4 RPM | 清澄な精製液と尾鉱泥へ完全分離 |
| 4 RPM超〜17 RPM未満 | 回転数に応じて上澄みに不純物が残る |
| 17 RPM以上 | 元のスラリー1000 mBがそのまま越流。泥と精製液は生成しない |

不純物は `suspended_impurity`（0〜1000）で保存・同期します。4〜17 RPMの間で線形に増え、精製液を混ぜると体積の加重平均になります。電解採取の必要仕事は通常×(1＋不純物/1000)、最大2倍。金属・酸の量は変わりません。

スラリーは密度1400、粘度3500、流動更新20 tick、拡散距離2で、中のエンティティに移動抵抗を与えます。全種類にバケツがあります。

## 保存・構造・表示

在庫は駆動部1個が所有します。各流体バンクの容量は従来どおり `min(64000, (直径−2)²×(高さ−2)×4000)` mB、泥は64個です。大型化で処理速度や上限容量は増えません。構造の変更で在庫が失われたり増えたりしないよう、容量超過時は形成を止めます。

形成後は変更位置の索引で壁と内部を監視し、毎tickの全探索を行いません。未形成の再確認は20 tickごと。寸法候補は床の入口と外周の壁で絞り込み、必要なチャンクを勝手にロードしません。構造や向きが変わると古いハンドラーを無効にし、配管へ再通知します。

壁を壊しても在庫は駆動部に残ります。駆動部の通常回収では在庫・高さ・進捗をドロップした駆動部に保持し、BlockItemの配置で復元します。ゴーグルは寸法・状態・回転と応力・分離効率の4行です。詳細はディスプレイリンクで確認できます。

JEIの浸出レシピは既存の撹拌反応カテゴリへ移しました。固液分離は円形沈殿池のカテゴリで表示します。Ponderも、ふた付き槽での浸出と直径15・高さ4のブロック円形槽を使う説明へ更新しました。

## 今回の配管・保管変更

吸収塔（小）、超耐圧パイプ、超耐圧ポンプは登録・アイテム・レシピ・アセットから削除しました。大型吸収塔は残します。発電設備で使う主管と関連Ponderは既存のステンレス鋼管へ置き換え、主管の既存流量係数512を引き継ぎます。

Create標準銅管の等級は常温〜高温・常圧です。他の材質別配管の等級は変更しません。保管タンクの気体制限はユーザー確認どおり保管用途へ適用し、専用の工程用気体入口は維持します。ステンレス・耐圧・保冷・横置き・Create標準タンクには気体を入れられません。クリエイティブ液体タンクも、配管からの搬入とバケツでの内容選択で気体を拒否します。気体の保管は脈動抑制管・ガスコンテナ・ガスホルダーを使い、それぞれの温度・圧力・耐食等級にも従います。

撤去したブロックは既存ワールドから失われるため、更新前に回収してください。互換用の旧登録は残していません。

既存の液体タンクに保存済みの気体は勝手に消去せず、搬入を止めて取り出せる状態にします。専用の気体保管へ移してください。
