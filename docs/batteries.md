# 鉛蓄電池とリチウムイオン電池

対象は Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10 / Create: Electro Energetics（CEE）1.1.4 です。**この文書の数値と挙動は、ビルドとゲーム内での確認をしていません。**

## 素材

| 素材 | 入手 |
| --- | --- |
| 方鉛鉱（方鉛鉱石） | Y -32〜48。粉砕ホイールで1〜2個。かまどでは精錬できず、下の乾式製錬で鉛にする |
| リチア輝石（リチア輝石鉱石） | Y -16〜64。粉砕ホイールで1〜2個 |
| 炭酸リチウム | 圧力反応：リチア輝石2個＋炭酸ナトリウム1個＋硫酸250 mB（超加熱）→ 炭酸リチウム2個＋砂1個 |
| 鉛の焼結鉱 | 焙焼・焼結（下記）。酸化鉛の塊 |
| 鉛インゴット | 下記の乾式製錬。タグは `c:ingots/lead` |

## 鉛の乾式製錬

どれも既存の圧力反応槽（ブレイズバーナーで加熱）で行う。新しい専用設備はない。

| 工程 | 入力 | 加熱 | 出力 |
| --- | --- | --- | --- |
| 焙焼・焼結（2 PbS ＋ 3 O₂ → 2 PbO ＋ 2 SO₂） | 方鉛鉱2個＋酸素1,500 mB | 加熱 | 鉛の焼結鉱2個＋二酸化硫黄1,000 mB |
| 還元溶錬（PbO ＋ CO → Pb ＋ CO₂） | 焼結鉱2個＋一酸化炭素1,000 mB | 超加熱 | 鉛インゴット2個＋二酸化炭素1,000 mB |
| 直接製錬（PbS ＋ O₂ → Pb ＋ SO₂） | 方鉛鉱2個＋酸素1,000 mB | 加熱 | 鉛インゴット2個＋二酸化硫黄1,000 mB |

- 直接製錬は、硫化鉱の酸化熱を使うため、焼結と還元の2段階より低い加熱で1回で済む。
- 二酸化硫黄は、硫酸の製造ラインへ回せる。
- 溶剤（石灰石）と、亜鉛混在鉱のISP法は再現していない。

## 鉛の湿式製錬

鉄・銅・亜鉛・錫と同じ流れ（[排水処理と湿式処理](wet-processing.md)の浸出と沈降、電解セルの電解採取）に、鉛を加えた。硫酸鉛は水に溶けにくいため、浸出には塩酸を使う。ゲーム内の簡略化で、実際の塩化第二鉄溶液やフルオロケイ酸溶液の化学は再現しない。

| 工程 | 設備 | 入力 | 出力 |
| --- | --- | --- | --- |
| 浸出 | 攪拌羽根と加熱付きのふた付き槽 | 方鉛鉱3個＋塩酸750 mB＋酸化用気体（圧搾空気か酸素）250 mB | 鉛浸出スラリー4,000 mB |
| 沈降 | 沈降槽（低速で回す） | スラリー1,000 mB | 精製鉛溶液750 mB＋尾鉱泥2個 |
| 電解採取 | 電解セル | 精製鉛溶液1,000 mB | 鉛インゴット3個＋塩酸250 mB |

- 排ガス（二酸化硫黄）や鉛の蒸気が出ず、低品位鉱の処理に向く。電解で塩酸が戻るので、次の浸出に使える。
- 方鉛鉱は粉砕済みの精鉱として、そのまま投入する。

## 組み立て

1. 同じ種類のケーシングを、各辺2ブロック以上の中身の詰まった直方体に積む。上限は4,096個。
2. 直方体の上面に、同じ種類の端子を置く。端子は直方体の真上のどこでもよい。
3. 端子へ電解液を入れる。配管・ポンプ・バケツなどCreateの標準の液体搬送が使える。ケーシング1個につき250 mBで、満杯になるまで回路に入らない。
4. 端子の2本の柱をCEEの電線へつなぐ。赤が＋、黒が－。

| | 鉛蓄電池 | リチウムイオン電池 |
| --- | --- | --- |
| 電解液 | 希硫酸 | アセトン |
| 満充電の電圧 | 200 V | 300 V |
| 空に近づくときの電圧低下 | 12% | 30% |
| ケーシング1個の抵抗 | 40 Ω | 24 Ω |
| ケーシング1個の容量 | 100 kJ | 300 kJ |
| 充電効率 | 90% | 96% |

- 電池は、電圧が充電量で変わる電源と、全ケーシングを並列にした抵抗（1個の抵抗 ÷ 個数）として回路に入る。ケーシングが多いほど、容量が増え抵抗が下がる。
- 回路の電圧が電池の電圧より高いと、電流が流れ込んで充電される。満充電になると回路から切れ、1秒後に再び確かめる。
- 空になると電圧が0 Vになり、放電は止まるが、充電は受け付ける。
- 箱を壊す、穴をあける、電解液が減るなどで条件を欠くと、回路から外れる。構造は2秒ごとに確認する。
- ゴーグルで、状態・充電率・電力・電解液の量を見られる。ディスプレイリンクの対応は未実装。
- 鉛蓄電池とリチウムイオン電池の電解液は、ゲーム内の簡略化であり、実際の電池の化学を再現するものではない。

## 確認していないこと

- ケーシング側の面から配管をつなぐ入口。現状は端子だけが電解液の入口。
