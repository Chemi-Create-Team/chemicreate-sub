# 大型フライホイールのテストワールド

[テストワールドのZIP](large-flywheel-test-world.zip)

Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10 と、大型フライホイールの蓄勢修正 `5424df5` を含む Create: Refinery 'n' Reactors を使用します。依存Modは Create Diesel Generators 1.21.1-1.3.15 と Create: Electro Energetics 1.21.1-1.1.4 です。

## 開き方と操作

1. ZIPを展開して `Large-Flywheel-Test` フォルダーを Minecraft の `saves` に入れ、「大型フライホイール試験場」を開きます。ゴーグルを装備した状態で足場の手前に出ます。樽にも予備のゴーグルがあります。
2. 階段を上がって、クラッチの上のレバーを右クリックで **OFF** にします。回転計と送風機が64 RPMで回り、フライホイール3台が蓄勢を始めます。
3. 12秒ほど待ち、いずれかのフライホイールの中心を見ます。ゴーグルにローター64 RPM、蓄積エネルギー約6.2 MJ（3台合計）が表示されます。
4. レバーを **ON** にするとモーターとの接続が切れます。回転計と送風機は回り続け、ゴーグルに放出電力が現れます。蓄積エネルギーとローターの回転数は徐々に下がります。
5. レバーを再び **OFF** にすると蓄勢が再開します。エネルギー0から試し直す場合は、ZIPを別の場所に展開して初期セーブを使ってください。

| 設備 | 座標 |
| --- | --- |
| クラッチのレバー | `-5 -54 0` |
| フライホイール3台 | `-4 -55 0` ～ `-2 -55 0` |
| 回転計 | `-1 -55 0` |
| 送風機 | `0 -55 0` |
