# 気液分離プラント

Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10 のクリエイティブ用ワールドです。気液分離の修正を含む Create: Refinery 'n' Reactors と、通常の依存Modを入れてください。検証環境には Create Diesel Generators 1.21.1-1.3.15 と Create: Electro Energetics 1.21.1-1.1.4 も入っています。

[テストワールドのZIP](gas-liquid-separation-plant-world.zip)

## 操作

1. ZIPを展開し、`Gas-Liquid-Separation-Plant` フォルダーを Minecraft の `saves` に入れます。
2. ワールドを開くと、ゴーグル装備済みで南側の通路に出ます。蒸気と冷却水は各4,800 mB入っています。
3. 左側の足場を登り、蒸気供給のレバーを右クリックして消灯します。蒸気ポンプが回り始めると、熱交換器の出口から気液分離器へ二相流が送られます。
4. 右端の上段タンクに蒸気、下段タンクに凝縮水がたまります。手前の冷却水タンクもゴーグルで確認できます。開始直後から約7秒が目安です。
5. 同じ条件で最初から試すときは、ZIPから新しく展開したワールドを使ってください。

| 設備 | 座標 |
| --- | --- |
| 蒸気供給タンク | `-7 -56 0` |
| 蒸気供給レバー | `-4 -54 0` |
| 冷却水供給タンク | `0 -54 -6` |
| 熱交換器 | `0 -56 0` |
| 気液分離器の土台 | `8 -57 0` |
| 蒸気回収タンク | `15 -54 0` |
| 凝縮水回収タンク | `15 -58 0` |
| 冷却水回収タンク | `1 -54 6` |

## 確認した量

| 回収先 | 量 |
| --- | ---: |
| 分離器の上面から蒸気 | 4,200 mB |
| 分離器の下面から凝縮水 | 600 mB |
| 冷却水の別回路 | 4,800 mB |

熱交換器へ常圧162.5 ℃の蒸気と6.25 ℃の冷却水を供給しました。熱交換器の流体ハンドラーで蒸気7/8の二相流を観測しました。出力タンクでは両方とも単相で、蒸気と凝縮水の合計は投入量と同じ4,800 mBです。
