# 溶融ステンレス製造ライン

[テストワールド ZIP](stainless-casting-line-world.zip) · [検証に使用したMod JAR](create-refinery-n-reactors-0.3.4-stainless-playtest.jar)

Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10、Create Diesel Generators 1.21.1-1.3.15、Create: Electro Energetics 1.21.1-1.1.4、Create: Refinery 'n' Reactors 0.3.4で検証しました。

検証用JARを使う場合は、Minecraftの `mods` にある既存の Create: Refinery 'n' Reactors のJARを入れ替えます。

## 遊び方

1. ZIPを解凍し、`Stainless-Casting-Line` フォルダーを Minecraft の `saves` に入れて開きます。
2. 左奥の「始動レバー」を右クリックします。鉄インゴット24個、フェロクロム8個、ニッケルインゴット4個は原料チェストに入っています。
3. 超過熱した鉢とミキサーが溶融ステンレスを計2,400 mB作ります。ステンレス管とポンプが溶湯を鋳造側へ送り、鉢とプレスでスラブ3個を作ります。
4. スラブはホッパーから2段の圧延ラインに入り、ステンレス鋼インゴット24個が右端の回収チェストにたまります。再試験には、手前左の樽にある予備原料を原料チェストに補給します。

| 場所 | 座標 |
| --- | --- |
| 始動レバー | `-1 -55 -1` |
| 原料チェスト | `0 -54 -1` |
| ミキサーの鉢 | `0 -55 0` |
| 鋳造プレスの鉢 | `6 -55 0` |
| 連続圧延ラインの入口 | `7 -56 0` |
| 製品チェスト | `14 -58 0` |
| 予備原料とゴーグル | `-3 -60 5` |

ワールドには動力と加熱を設定済みのクリエイティブモーター、ブレイズバーナーを配置しています。1回分は鉄6・フェロクロム2・ニッケル1から溶融ステンレス600 mBです。800 mBでスラブ1個、圧延するとスラブ1個につきインゴット8個になります。鋳造の鉢に追加加熱は不要です。

ZIPを解凍して専用サーバーで読み直した試験では、レバーを押してから約36秒でインゴット24個を回収できました。鋳造側の鉢で溶湯を確認し、配管の損耗はありませんでした。
