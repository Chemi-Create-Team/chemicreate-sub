# 最小RBMK・CEE発電

[テストワールドのZIP](compact-rbmk-cee-world.zip)

Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10 用のクリエイティブワールドです。Create: Refinery 'n' Reactors、Create Diesel Generators 1.21.1-1.3.15、Create: Electro Energetics 1.21.1-1.1.4 を入れてください。ZIPを展開し、`Compact-RBMK-CEE` フォルダーを `saves` に入れて開きます。

## 起動と停止

1. スポーンしたら振り返り、北側の操作卓へ行きます。右側の樽にゴーグルとレンチがあります。空のホットバースロットを選び、空手でボタンを右クリックします。
2. 卓の左端で灰色の **RESET** を押し、左から3台目の **MODE** を2回押して **AUTO** にします。
3. 冷態からの発電には20 TPSで約6分かかります。待ち時間を短縮するなら、起動後に `/tick sprint 7400t` を使い、その後は通常速度で電圧計を確認できます。
4. 操作卓の右奥にある **CEE発電** の看板の先で、電圧計と電力量計を見ます。ゴーグルで電圧を確認でき、電力量計の値は抵抗負荷へ送った電力で増えていきます。
5. 停止するときは左端のカバーを開けてから、赤い **AZ-5** を押します。余熱で蒸気はしばらく出続けます。AUTOのまま再起動するときは **RESET** を押します。カバーは左側に立ち上がった部分を押すと手動で閉じられます。

## 見どころ

| 設備 | 座標 |
| --- | --- |
| 操作卓と表示盤 | `0 -60 9` |
| 炉心中央 | `2 -51 2` |
| 給水タンク | `2 -57 -4` |
| 気液分離器 | `11 -48 2` |
| 高圧タービン | `16 -45 2` |
| CEE電力量計 | `20 -58 4` |
| CEE電圧計 | `23 -58 5` |

炉心は直径5×高さ3ブロックで、遮蔽と上下の構造を含む炉体は幅9×奥行9×高さ11ブロックです。小型炉用燃料棒44本と制御棒8本を装荷済みです。給水はクリエイティブタンクの加圧水を使い、分離した水とタービン排気は別々の回収用タンクで処理します。補機のポンプと制御棒にはクリエイティブモーターを使い、発電軸は高圧タービンにつないでいます。炉の蒸気 → タービン → CEE交流発電機 → 電力量計 → 抵抗負荷の順に追えます。

制御盤の左側の炉心図では、外周から1区画以上内側にある白い制御棒が、4分の1回転ごとに同じ配置を作ります。[52チャンネルの配置図](../rbmk-reactor.md#52チャンネルの初期配置)
