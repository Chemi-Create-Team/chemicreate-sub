# 52チャンネル炉心の左右・上下対称配置

[確認ワールドZIP](compact-rbmk-cee-mirror-world.zip) · [制御盤のスクリーンショット](compact-rbmk-mirror-control-map.jpg)

Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10 と、この変更を含む Create: Refinery 'n' Reactors を使います。元のワールドと同じく、Create Diesel Generators と Create: Electro Energetics を入れてください。ZIPの `Compact-RBMK-Mirror-Layout` を `saves` に展開します。

スポーン地点で振り返り、操作卓の左側の炉心図を見ます。白い制御棒8本は上下・左右の両方で鏡映対称です。炉に燃料44本と制御棒8本を装荷し、停止状態で保存しています。

このワールドは配置確認用です。鏡映配置でのAUTO起動試験では給水が不安定で、安定発電に到達しませんでした。
