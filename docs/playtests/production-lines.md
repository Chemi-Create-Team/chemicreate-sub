# 生産ラインと発電のテストワールド

Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10 用のクリエイティブワールドです。現行の Create: Refinery 'n' Reactors、Create Diesel Generators 1.21.1-1.3.15、Create: Electro Energetics 1.21.1-1.1.4 を入れてください。

ZIP を展開し、中のワールドフォルダーを `saves` に入れてシングルプレイで開きます。各 ZIP に投入口、回収先、座標を記載した `README-ja.md` が入っています。

- **核燃料生成ライン**。ウラン鉱石を投入口に入れると、粉砕から焼成ペレットの搬出まで進みます。燃料棒は末端の作業台で組み立てます。[核燃料生成ラインのZIP](uranium-fuel-line-world.zip)
- **アルミ生産ライン**。ボーキサイトを投入してから溶解槽のレバーを消灯します。抽出、アルミナの析出、ホッパー搬送、電解、インゴットの搬出がつながっています。[アルミ生産ラインのZIP](aluminum-production-line-world.zip)
- **最小RBMK・CEE発電**。炉心が直径5×高さ3ブロックの小型炉を操作卓で起動・停止し、タービンでCEEの負荷に送電できます。[操作ガイド](compact-rbmk-cee.md) · [発電テストワールドのZIP](compact-rbmk-cee-world.zip)
