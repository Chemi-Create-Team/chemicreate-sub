# RBMKの燃料交換を試す

[練習用ワールドのZIP](rbmk-refuelling-practice-world.zip)

Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10用のクリエイティブワールドです。今回の修正を含む Create: Refinery 'n' Reactors と通常の依存Modを入れてください。ワールドには小型RBMKの燃料チャネル、冷却水92,000 mB入りの2×2プール、回転動力付きの門型クレーンを配置しています。

## まず1本交換する

1. ZIPを展開し、`RBMK-Refuelling-Practice` フォルダーを Minecraft の `saves` に入れます。
2. ゴーグルを装備した状態で操作台に出ます。空手で正面のレバーを右クリックして点灯させます。
3. クレーンが炉から使用済み燃料棒を引き抜き、プールへ降ろします。続けてプールから小型炉用新燃料棒を取り、炉の空き区画へ装荷します。初回の実機試験では約14秒で1往復しました。
4. ゴーグルで駆動部を見ると、作業内容と吊り具にある棒が分かります。運転後はプールに使用済み燃料棒1本、炉に新燃料棒1本が残ります。余った炉の空き区画について「新燃料棒がありません」と表示されることがあります。
5. 同じ交換を繰り返す場合は、ZIPから新しく展開したワールドを使います。

このワールドの開始時点で使用済み燃料棒1本と小型炉用の新燃料棒1本が入っています。炉の発電運転は不要です。

| 場所 | 座標 |
| --- | --- |
| 操作台のレバー | `1 -18 1` |
| クレーン駆動部 | `1 -18 2` |
| 原子炉の上部キャップ | `5 -33 5` |
| 燃料プールのラック | `13 -55 5` |
| 新燃料用の上向きドロッパー | `13 -56 5` |
| ドロッパーの押しボタン | `13 -56 4` |

## 自分の設備で同じように動かす

- プールの壁上端と炉のキャップを同じ高さにし、その15マス上へ共通レールを組みます。キャップとラックの四隅まで届くよう、レールの端や左右に余裕を取ります。
- 鋼鉄外壁を備えたプールへ、ラック下面から1枚につき22,000 mB以上の水を送り、90 ℃未満にします。最小の2×2では88,000 mB以上です。
- ラックの真下へ上向きドロッパーを置いて、炉に合う新燃料棒を1本ずつ入れます。使用済み燃料用に、クレーンが届く空き枠を残します。
- 駆動部へ回転とレッドストーンを与えます。制御盤にリンク済みの場合は、空手で橙色のクレーンボタンを2回押し、停止から手動を経て「自動」にします。通常運転中の燃料を交換したい場合は、使用済みになるまで待つと自動交換の対象になります。
