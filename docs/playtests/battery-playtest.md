# 電池・鉛・リチウム・アルミニウム・肥料の連続プラント（テストプレイワールド）

`-Dcreateplant.batteryPlaytest=true ./gradlew runClient` で作る、創造モードの平坦ワールドです。生成コードは `client/BatteryPlaytestWorld.java`。燃料・肥料のワールド（[報告書](../reports/fuel-and-fertilizer-playtests-2026-11-23.md)）と同じ `PlaytestPlant` の配管・ポンプを使います。**作成者は一度も実行しておらず、最初の実行が検証です。** セーブ（zip）は未提出で、実行して保存したものを `docs/playtests/` へ置いてください。

- 作り終えるとワールドを保存し（肥料プラントは保存後も動き続けます）、チャットに結果（作れなかった設備）を出して、**開いたまま**にします。自動で閉じたいときは `-Dcreateplant.batteryPlaytestClose=true` を足します。
- 結果は `run/battery-playtest-result.json`、ログは `BATTERY PLAYTEST` で検索できます。
- `-Dcreateplant.*` が `runClient` に渡らない環境では、`./gradlew -I docs/playtests/battery-playtest.gradle runClient` を使います。

## 一続きの流れ

原料だけが外から入ります（クリエイティブタンク：酸素・水・一酸化炭素・塩酸・電解液。チェスト：鉱石・石炭・炭酸ナトリウム・閃緑岩）。各段のあいだは実物の配管・ポンプ・ホッパーでつないでいます。

1. **鉛（乾式）**: 方鉛鉱＋酸素 →（焙焼槽）→ 焼結鉱 → ホッパー → 還元槽（＋一酸化炭素）→ 鉛インゴット（チェスト）。
2. **硫黄サイクル**: 焙焼槽の二酸化硫黄 → 吸収塔（頂上から水）→ 亜硫酸 → 電解セル（400 V）→ 硫酸。水素は受槽へ。硫酸は母管のタンクへ。
3. **硫酸の分配**（母管から2本）
   - リチウム：リチア輝石＋炭酸ナトリウム＋硫酸 → 炭酸リチウム（チェスト）。
   - 酸の槽：ハッチを開けた槽に硫酸が溜まる。入ると死ぬまで続く火傷。
4. **鉛（湿式）**: 方鉛鉱＋塩酸＋酸素 → 浸出スラリー →（配管）→ 沈降槽 → 精製鉛溶液 →（配管）→ 電解採取セル（400 V）→ 鉛インゴット。
5. **合成肥料プラント（東へ70ブロック）**: `FertilizerPlaytestWorld` の全体をそのまま同じワールドに建てます。木炭のガス化・空気分離・水の電解・硫黄の燃焼と亜硫酸の電解（肥料側の硫酸）→ リン酸・リン酸肥料、合成ガス → アンモニア合成塔 → 液体アンモニア、方解石の焼成 → 尿素、乾燥昆布 → カリ、混合器 → NPK肥料のチェスト。肥料側は電解セル・ポンプ・加熱を自前で持ち、独立して動きます（鉛側の硫酸とはつないでいません）。NPKができるか、止まるとチャットに知らせます。**肥料側は単独ワールドの時点で未完成**（尿素以降が未確認。[報告書](../reports/fuel-and-fertilizer-playtests-2026-11-23.md)）で、ここでも同じところで止まる見込みです。
6. **単独の設備**: 苛性ソーダの槽・水の槽（火傷の対照）、鉛蓄電池・リチウムイオン電池（電解液の創造タンクを配管、CEEのクリエイティブ電池で充電）、方解石（ファン＋魂の焚き火＋石臼）。
7. **アルミニウム**。ボーキサイトと供給タンクの苛性ソーダ4,000 mBからアルミン酸ナトリウム溶液を作り、次の槽でアルミナと苛性ソーダに分離します。アルミナはホッパーで溶融塩電解炉（200 V）へ送り、石炭とともに電解します。鉄塊とアルミニウムはそれぞれのチェストに入り、回収した苛性ソーダは貯槽へ送ります。

## 割り切り

- 電解採取セルの鉛インゴットは電極ヘッドに溜まる。ヘッドの上面か側面から取り出す。回収した塩酸は、セルの出口から手で戻す。
- 鉛蓄電池の電解液（希硫酸）は、母管ではなく創造タンクから入れる（希釈の鉢を置いていない）。
- 沈降槽の泥の排出は付けていない。長く回すと泥で止まる。
- 沈降槽の駆動は、駆動の上のクリエイティブモーター（4 RPM）。向きや入力面が違う場合は置き直す。
- 作れなかった設備があっても、ほかは作られる。下流が作れていないと、その先は動かない。
