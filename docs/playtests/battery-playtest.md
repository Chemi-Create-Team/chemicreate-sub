# 電池・鉛・リチウム・アルミニウムの試験ワールド

2026-11-22のユーザー指定で追加した、`-Dcreateplant.batteryPlaytest=true` で作る創造モードの平坦ワールドです。**作成者は一度も実行しておらず、最初の実行が検証です。**

## 作り方

```
./gradlew -I docs/playtests/battery-playtest.gradle runClient
```

- ゲームが自動でワールドを作り、配線と供給を済ませ、保存して終了します。
- ワールドは `run/saves/createplant-battery-<時刻>/`、結果は `run/battery-playtest-result.json` に出ます。
- 作れなかった駅は結果の `failedStations` に、ログの `BATTERY PLAYTEST station ... failed` に理由が残ります。ほかの駅は作られます。
- 配布するときは、`saves` の下のフォルダを `docs/playtests/` へzipにして追加します（`synthetic-fuel-world.zip` と同じ形）。

## 駅（床のサインで確認できます）

| 列 | 駅 | 内容 |
| --- | --- | --- |
| z=0 | 方解石 | 閃緑岩を台に置くと、魂の焚き火を通したファンで方解石になる。石臼で方解石→蛍石（50%）。材料のチェスト付き |
| z=0 | 硫酸・苛性ソーダ・水の槽 | ハッチを開けたステンレスの槽。酸・塩基の槽に入ると死ぬまで続く火傷、水の槽は燃えない（対照） |
| z=0 | 鉛蓄電池・リチウムイオン電池 | 4×2×3のケーシングに端子。電解液は入れ済み、CEEのクリエイティブ電池（230 V・330 V）と配線済みで、空から充電される |
| z=40 | 鉛の焙焼・還元・直接製錬 | 撹拌付きのふた付き槽。ブレイズバーナー・モーター・原料ガスの供給（創造タンクとポンプ）・材料のチェスト付き |
| z=40 | 鉛の浸出 | 方鉛鉱＋塩酸（北）＋酸素（東）から鉛スラリー |
| z=80 | 沈降槽・電解セル | 鉛スラリーを沈降槽で精製鉛溶液にし、電解セル（400 V、配線・START済み）で鉛インゴット |
| z=80 | 炭酸リチウム | リチア輝石＋炭酸ナトリウム＋硫酸（北） |
| z=120 | アルミニウム | 硫酸塩法（浸出→アルミナ焼成）、バイヤー法（浸出→アルミナ析出）、溶融塩電解炉（200 V、アルミナと石炭の入ったチェスト→ホッパー、製品は炉の下のチェスト） |

## 割り切り

- 各駅は独立で、前の駅の製品を次の駅へつなぐ配管は付けていない。中間の液体は各駅の創造タンクから入る。つなぐ試験は、プレイヤーが配管でつなぐ。
- 槽の製品は、槽が公開するポートから取り出す。ポートの位置は[反応プラント](../reaction-plant.md)を参照。
- 電池の放電は、電池の電圧が充電量を上回る間は起きない。放電を見るには、クリエイティブ電池の配線を外し、負荷（電解セルなど）につなぐ。
- 沈降槽の回転（4 RPM）は、駆動の上に置いたクリエイティブモーターで与える。向きが合わないときは、モーターを置き直す。
