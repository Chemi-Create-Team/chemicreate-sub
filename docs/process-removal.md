# 旧加熱・分離設備の撤去と流体バケツ

電熱線ヒーター、沈降槽、晶析槽は、登録・部品・描画・レシピ・アセット・翻訳・Ponder・生成元から撤去しました。既存のブレイズバーナー、電動ポンプ、ふた付き槽の内部部品、吸収塔は引き続き使います。削除した登録を置いた開発用ワールドでは、該当ブロックや中間素材が失われます。

鉄・銅・亜鉛・錫の鉱石回収は、破砕ホイール → 加熱した撹拌反応槽 → 電解セルの順です。撹拌槽は粉砕済み鉱石1個と希硫酸250 mBから、精製金属溶液1000 mBと鉱滓スラッジ1個を直接作ります。精製溶液を電解セルへ送り、インゴット3個と希硫酸250 mBを回収します。原料・生成数・電解の消費仕事は維持し、酸を浸出へ循環できます。濁った浸出液4種・金属塩結晶4種と2倍回収分岐は廃止しました。金は対象外です。

自Modの流体は液体55種・気体44種の計99種です。以前バケツがなかった気体28種に、既存と同じ気体バケツを追加しました。バニラの容器部分を維持し、気体の色で中身を表現します。全99種について、FlowingFluidとFluidTypeの両方からバケツを取得でき、クリエイティブタブに表示されることを検査します。気体バケツはCreate/NeoForgeの標準流体ハンドラーから充填・排出でき、ワールドで使うと既存の気体バケツと同じく放出します。

温度等級や汚染混合ガスの付加情報は既存の `bucket_contents` コンポーネントで保持します。アイテムの保存・再ロードと流体のシミュレーション・排出で、1000 mBの中身と情報を維持します。汚染混合ガスは以前から登録されているものの、現行のサバイバル生成経路がないため、その新しいバケツもクリエイティブ用途です。生成経路を作る変更は行っていません。

CDGの既存ガソリン・軽油バケツは、前回の指定どおり自Modタブへ重複掲載しません。CDG本来の登録・タブを利用します。

生成元は `tools/generate_metal_recovery.py`、`tools/generate_metal_recovery_ponder.py`、`tools/generate_electric_utilities.py`、`tools/generate_process_gas_buckets.py` です。通常の液体・気体の一覧取得は `tools/generate_world_liquids.py` を共有します。ゲーム内の金属工程と手引書も更新しています。
