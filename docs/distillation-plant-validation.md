## 追加した7件のGameTest

1. Createの公開接続機構による1×1・2×2・3×3の形成、各最小高さ、面別の配管接続・拒否、留分出口の制限。原料待ちで処理200回を実行しても構造走査回数が増えないこと。
2. 各断面の最大高さ6・12・18段、過剰な段を追加した場合の停止と古いポートの無効化、過剰部分を取り除いた後の再形成。
3. 搬入・搬出シミュレーションで在庫が変わらないこと、未加熱原油・未冷却留分の拒否、蒸発と分離の実行、既存5留分の正確な生成量、照会結果から内部在庫を変更できないこと。
4. 高さ3・4・5段で、それぞれ3・4・5種類の留分を得られ、総量1,000 mBを保持すること。
5. 出力満杯時の原料保持、空きができた後の再開、レッドストーン停止、無回転停止。停止した有効な塔の応力負荷が安定していること。
6. NBT保存・読み込みによる原料・進捗保持、1×1から2×2への増設、古いポートの無効化、1×1×3への縮小、残留した潤滑油・ガソリンの保守用出口からの回収。
7. **実際のCreateポンプ・配管・回転動力による精製ライン**。標準Fluid Tankから原油2,000 mBを供給し、既存マルチブロック予熱器 → 新規蒸留塔 → 既存フィンファン式工業用冷却器 → 蒸留塔への戻り配管 → 5本の留分配管 → 5基の標準Fluid Tankを稼働。温冷の配管を接続しない状態を遠隔転送で代用していない。

7件目では重油タンクを先に満杯にし、重油400 mBを塔内に保持したまま他の4製品をそれぞれのタンクへ搬出できることを確認。その後タンクに空きを作り、重油も搬出されることを確認。最終量は重油400 mB、潤滑油200 mB、軽油600 mB、ガソリン400 mB、ナフサ400 mB。原油・加熱原料・高温留分・戻り留分・塔内製品の残量は0。2,000 mBの収支が一致する。
