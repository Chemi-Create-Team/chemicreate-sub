# ウラン鉱石から燃料棒まで

Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10のゲーム内工程。設備は既存のCreate搬送・ファン・プレスと、ふた付き槽の内部部品を組み合わせる。新しい専用装置やGUIは追加しない。

| 工程 | 設備・条件 | 1バッチのゲーム内レシピ |
| --- | --- | --- |
| 粉砕 | Createクラッシングホイール | ウラン鉱石 → ウラン原石。既存の副産物・追加ドロップ率を維持 |
| 焙焼 | 溶岩を通したファンの風。デポやベルト上で処理 | ウラン原石1個 → イエローケーキ1個 |
| 還元 | 反応棚段入り槽＋通常加熱 | 焙焼物1個＋水素250 mB → 二酸化ウラン1個 |
| グリーンソルト化 | 撹拌翼入り槽＋通常加熱、底面中央32 RPM以上 | 二酸化ウラン1個＋フッ化水素500 mB → 四フッ化ウラン1個 |
| ガス化 | 反応棚段入り槽＋超加熱 | 四フッ化ウラン1個＋フッ素250 mB → 六フッ化ウラン250 mB |
| 濃縮 | 専用ガス遠心分離機を4台横に接続、各台の底面へ32 RPM以上 | 既存レシピのまま。濃縮気体を上面、劣化気体を側面へ取り出す |
| 粉末化 | 別の撹拌翼入り槽、底面中央32 RPM以上。バーナー不要 | 濃縮六フッ化ウラン250 mB＋液体の水250 mB＋水素250 mB → 濃縮二酸化ウラン粉末1個＋回収フッ化水素750 mB |
| 成形 | Createメカニカルプレス | 粉末1個 → 未焼結ペレット2個 |
| 焼成 | 燃焼中のブレイズバーナーを通したファン、通常のかまど、または通常加熱した棚段入り槽 | 未焼結ペレット1個 → 完成ペレット1個。追加の水素は不要 |
| 組立 | 既存のクラフト | 完成ペレット7個＋ジルカロイ被覆管2個 → 燃料棒1本 |

「通常加熱」「超加熱」はCreateの`heated` / `superheated`条件。超加熱は青い炎のブレイズバーナーを使う。実機の製造条件を表す温度設定は追加していない。

## 配置と搬送

棚段の槽は3×3・高さ2〜4段、各段に反応棚段を1個入れる。回転動力は不要で、各段が1バッチを並列処理する。撹拌槽は3×3・高さ1〜4段、各段に撹拌翼を1個入れ、最下段の底面中央だけに回転動力を接続する。両方ともハッチを閉じて運転する。硝酸の吸収は棚段ではなく[吸収塔](reaction-plant.md#吸収塔)で行う。

アイテムはCreateのファンネル・ベルト、流体はパイプ・ポンプで搬送する。ガスは側面から搬入でき、搬出は上面のハッチ以外へつなぐ。液体は側面・下面から搬出する。フッ化物にはニッケル合金管を使う。流体の等級に合わない設備は搬入を拒否し、安全弁による圧力調整は行わない。構造・加熱・回転・原料・搬出の不足はゴーグルで、詳細は標準ディスプレイリンクで確認する。

粉末化には3つの独立した原料バッファを使える。濃縮気体、水、水素の投入順は自由で、全材料と生成物の空きがそろうまで消費しない。粉末化槽にバーナーは置かず、水を液体のまま供給する。回収フッ化水素はグリーンソルト化などへ戻せる。

## 小型炉用の分岐

小型炉用燃料は、既存の濃縮気体をもう一段、別の8台カスケードで処理する。小型炉用濃縮気体を上記の水・水素による粉末化へ送り、小型炉用粉末、未焼結ペレット、完成ペレット、短い燃料棒へ加工する。通常系列と同じ設備・加熱条件を使う。既存の濃縮レシピ、燃料棒性能、装荷できる炉の高さは維持する。

## 再処理との接続と更新時の扱い

使用済み燃料の再処理で得られる硝酸ウラニルは、既存の三酸化ウラン化を経て棚段の還元へ戻せる。還元原料タグ`uranium_reduction_feed`はイエローケーキと三酸化ウランを受け入れる。既存の地質由来ヘリウム回収から出る三酸化ウランも同じ入口を使う。

置き換えた湿式鉱石処理の硫酸ウラニル溶液と、通常・小型炉用フッ化ウラニルの中間アイテムは廃止した。既存ワールド内の該当在庫は更新前に処理・回収する。自動変換は追加しない。通常の槽の既存原料0・1と生成物2〜6の保存番号は維持し、3番目の撹拌原料を`Tank7`として追加した。

Ponder「ウラン鉱石から濃縮前の気体を作る」「濃縮気体を燃料ペレットにする」を日英中で追加。JEIでは加熱棚段反応と撹拌反応を別カテゴリに表示する。小型RBMKの既存Ponderも新しい製造工程に更新した。


遠心分離機は各台32 SU/RPMを消費し、必要段数に対する稼働段数の比率で最大4倍に加速します。原料は下半分の側面、濃縮気体は上半分の天面、劣化気体は上半分の側面です。各台の原料・製品タンクは独立して保存され、カスケードを分けても残る台の内容物は保持されます。詳細は[新装置の仕様](specs/centrifuge-cascade-and-cubic-press.md)を参照してください。
