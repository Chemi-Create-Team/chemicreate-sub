# 1×1・2×2蒸留塔の動作確認

2026-10-24、外装改修後の作業ツリーで専用サーバーGameTestを実行。Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10-281。

`./gradlew build runGameTestServer`に成功。新たな2件を含む必須117件すべて成功。

| 断面 | 今回処理を確認した高さ | 1回に投入・処理した量 | 最小高さで得られる留分 |
| --- | --- | --- | --- |
| 1×1 | 3・5・6段 | 1,000 mB | 重油・軽油・ナフサ |
| 2×2 | 4・5・12段 | 4,000 mB（4バッチ並列） | 重油・軽油・ガソリン・ナフサ |

各構成で加熱済み原油の投入、塔頂高温留分の生成・搬出、冷却済み留分の戻し、各段からの留分搬出を確認。各流体の種類と量を確認し、総搬出量が投入量と一致した。高さ5段以上では両断面とも重油・潤滑油・軽油・ガソリン・ナフサの5種類を生成した。

上記の容量・高さを組み合わせた試験は標準流体ハンドラーで各工程を直接確認している。これに加えて、1×1×5と2×2×5では、実際のCreateの配管・ポンプ・回転動力、既存予熱器、既存工業用冷却器、標準Fluid Tankを使った全工程を確認した。

各ラインで原油2,000 mBを投入し、最終的に重油400 mB、潤滑油200 mB、軽油600 mB、ガソリン400 mB、ナフサ400 mBをそれぞれ別の標準タンクへ搬出。重油タンクを満杯にした場合の塔内保持と、空きを作った後の搬出再開も成功した。

稼働には制御部1台、32 RPM以上、既存予熱器からの加熱済み原油、外部冷却器との往復配管が必要。高さの許容範囲は1×1が3～6段、2×2が4～12段。今回追加した変更は回帰テストとその配管配置ヘルパーであり、装置の動作コードは修正していない。
