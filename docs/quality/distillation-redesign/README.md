# 蒸留塔の外装改修

2026-10-24。`1d1cbf8`の外装を基準に、参考画像の「蒸留塔制御部」に合わせて改修。

## 外装

- 塔全体の寸法で組み立てたモデルをセルごとに切り分ける方式へ変更。
- ブロックごとの囲み模様・上蓋・点検ハッチの繰り返しを解消。上蓋と屋上ハッチは全体で一組。
- 四隅の柱、中央の縦補強、全幅に続く棚段の補強帯、奥へ引いた鋼板を組み合わせ、各段を立体化。
- 閉じた点検蓋、保守用はしご、屋上の金属床と手すりを追加。
- 暗い鋼板と明るい鋼材のエッジを16×16テクスチャで描画。
- 当たり判定は同じ形状データから生成。留分の出口も生成済みの形状を利用。

Createの配管へ接続する面・中心位置、登録ID、BlockStateの既存プロパティ、流体の保存形式、レシピ、処理能力は維持している。はしごは保守設備の外観であり、新しい登攀機能は追加していない。構造物は各セルの範囲内に収まり、周囲の配管へ張り出さない。毎tickの装置処理は追加していない。

## 検証

1×1・2×2を追加で確認した結果は[断面サイズ別の動作確認](small-medium-verification.md)を参照。追加後の必須GameTestは117件すべて成功。

- Gradle `build runGameTestServer`に成功。必須115件すべて成功。実際のCreateポンプを使った原油から5種の製品タンクまでの既存回帰試験も含む。
- 既存のリソース検証スクリプト10本が成功。
- 全セルのモデルと当たり判定、セル範囲、テクスチャ参照、16×16画像を確認。
- 各幅で屋上ハッチが一組だけあり、中央の内部セルに余分な枠がないことを確認。
- 蒸留塔以外の既存モデル・テクスチャ892ファイルをSHA-256で比較し、変更0件。
- 実クライアントで3サイズを描画。日本語Ponderの実行時翻訳50シーンを確認。
- `git diff --check`に成功。

今回の変更は外装とその形状、Ponderの表示範囲に限定。多MOD環境での長時間運転や大規模設備の性能測定は追加していない。画像撮影はソフトウェア描画のため、FPSの評価には使用していない。
