# 表面・配管の品質改善

Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10-281 を維持。
既存のレジストリID、レシピ、機械の保存形式と流体量は変更しない。
新しい化学製造プロセスは追加しない。

## アセット

- 改修前の調査は `texture-audit-before.json`。砂糖・鉄塊・ブレイズパウダーの直接流用、蒸気の水バケツ表示、3種類の羽根と2種類のケーシングの同一表示を修正。
- 16種類のバケツはバニラ1.21.1の金属部分と輪郭を共有し、内容物のピクセルだけを変更。気体も既存の有限mB容器として扱い、常温の無色気体を液化した設定には変更しない。
- 機械は銀灰色の鋼・鋳鉄、金色の真鍮、明るい褐色の銅を基本とし、前面・側面・上面を差別化。16×16の加工痕、リベット、継ぎ目に加え、材質に合う明るい反射色と暗い折り目を使用する。粒状模様は方向性のある細い加工痕に重ね、鋳鉄は粗め、真鍮・銅は控えめ。
- 材質や共通規格の部品は共有可能。完成品100種の同一モデル・テクスチャの組み合わせは検証で禁止する。比較結果は `texture-audit-after.json`。

### 金属色の明度調整

暗い青緑の本体色を、彩度の低い銀灰色へ変更した。真鍮は金色、銅は明るい褐色とし、反射の明暗によって材質を表現する。既存の `paint_blue`・`paint_green`・`teal_enamel` などの参照パスは維持し、画像を鋼材色へ更新する。
鋼材の中間色は RGB(200, 208, 211)、真鍮は(199, 158, 61)、銅は(192, 119, 79)。それぞれに別の影色・反射色を持たせ、表面全体を一様に明るくする処理は使わない。

`metal-gallery-comparison.png` は左が前回の `c09123d`、右が今回の実クライアント画像。
照明・背景・カメラ・モデル形状・表示倍率は同じで、テクスチャだけを変更している。
`metal-textures.png` は上段が前回、下段が今回の16×16画像を最近傍で拡大した比較。

再生成順序（Python標準ライブラリのみ）：

```sh
python tools/generate_rotating_models.py
python tools/generate_transport_assets.py
python tools/generate_plant_tutorials.py
```

最後の配管生成は `generate_quality_assets.py` の表面仕上げも実行する。
`vanilla_bucket_template.json` はバニラの金属ピクセルと内容物マスクを記録している。
独立した画像編集ソフトやPillowは再生成に不要。

## Createとの接続

普通の水・原油・燃料・常温気体はCreateの液体パイプ、メカニカルポンプ、液体タンクで扱う。
スマート液体パイプのバケツフィルター、回転で開閉する流体バルブも使用できる。
工程設備の軸面は回転用、残りの4面が流体用。原料へのfillと製品からのdrainは分離したまま。
気体はNeoForgeのFluidStackとして輸送し、質量保存は液体と同じ有限mB単位。

既存樹脂管と新しい2種類の管はすべてCreateのFluidPipeBlock / FluidPipeBlockEntityを使用。
別の流体ネットワークや輸送ループは実装しない。
既存の蒸気管は従来のボイラー・タービン用として維持し、通常の流体輸送へ要求しない。

| 材質 | 温度上限 | 圧力上限 | 硝酸・二酸化窒素 | 用途 |
| --- | --- | --- | --- | --- |
| Create銅管 | 450 K | 2 bar | 不適合 | 通常の水・油・燃料・常温気体 |
| 既存樹脂管 | 400 K | 2 bar | 適合 | 常温の腐食性薬品 |
| 耐圧鋼管 | 800 K | 16 bar | 不適合（[配管とタンク](../pipes-and-tanks.md)で変更） | 12 barの合成原料・反応混合物 |

これはゲーム用の簡略分類。FluidHazardsの明示リストだけに適用する。
未知の他MOD流体やバニラ流体を温度・名前から危険と推測しない。
タンク・ポンプ・バルブ・フィルター自体には劣化を適用しない。

## 劣化と設定

Createの公開 `BlockEntityBehaviourEvent` から既存の流体Behaviourを残したまま監視用Behaviourを追加する。
対象はCreateの銅管・被覆管・ガラス管と自MODの材質管だけ。他MODブロックには追加しない。
各BEが1秒に一度、自分の6面の実際の流れと圧力を読む。チャンク探索・強制ロード・独自の流体移動はない。

1. 不適合な流体に接触すると警告・パーティクル。
2. 初期設定60秒後に劣化し、材質と原因に応じた表面の腐食・焦げ・軟化模様。
3. 公開のPipeConnection圧力APIで接続部の圧力を60%、重度では35%へ低減。搬出元の接続部では実流量も低下し、中間部では流れの伝播が遅くなる。ネットワーク全体の流量を一律に下げる仕組みではない。
4. 追加240秒の接触後、破損を設定で許可した場合だけ、その配管を削除。周辺破壊・爆発・薬液源の設置は行わない。元のCreateブロックの削除処理でネットワークを更新する。

警告・劣化中に停止し、バルブを閉じて適合する管へ交換する。
曝露時間は既存BEのNBTに独立した `CreatePlantPipeWear` タグで保存する。
Createの圧力再計算を検出して過剰な重ね掛けを防ぎ、無効化時は自身が低減した圧力だけを復元する。

NeoForge 21.1.219では共通設定を `config/create_heavy_indusstry-server.toml` に生成する。
ワールド別に変える場合は `serverconfig/create_heavy_indusstry-server.toml` へ同名の上書き設定を置く：

```toml
[chemical_transport]
enabled = true
affectCreatePipes = true
allowPipeBreakage = false
warningSeconds = 60
failureSeconds = 240
```

既存ラインの意図しない破損を避けるため、初期状態では破損しない。
`enabled = false` なら劣化・圧力低減・破損を停止し、通常のCreate輸送を継続する。
ゴーグル・アイテムツールチップ・追加3本のPonderで条件と対処を確認できる。Ponderは合計41本。

クライアントの劣化模様は近傍32ブロック、最大128本を描画し、1フレームの確認対象も512本まで。
シングルプレイと専用サーバーで共通のサーバー処理を使い、クライアント専用クラスをサーバーから参照しない。

## 検証

`tools/validate_visual_identity.py` を含む10本のリソース検証。
サーバーGameTestは従来86件と追加9件の95件。
追加試験では実際のCreateモーターとポンプを使い、通常配管から自MOD設備への輸送、バケツフィルターの拒否・許可、バルブの閉鎖・開放、各材質の保存・輸送を確認する。
硝酸の実際の流れを観測した上で曝露時間だけを加速し、警告、実流量低下、圧力の復元、単体破損、削除後の流体保存とネットワーク更新を確認する。
任意JEIの有無の両構成を検証する。

日本語・英語それぞれで実クライアントを起動し、41本の翻訳実値を検証、7種類の設備・配管のPonderを撮影した。
`metal-textures.png` は実際の16×16画像の最近傍拡大、`metal-gallery.png` はMinecraftで焼き込んだ3Dモデルを表示した実画面。
言語リソース再読み込み直後にPonderのフォント画像解放エラーを再現したため、この自動検証は言語別起動にしている。言語のホットリロードの問題は未解決。

多数の他MODを入れた環境、巨大工場の長時間TPS、遠隔クライアントによる複数人同時プレイは未検証。
