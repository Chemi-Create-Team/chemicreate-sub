# ソーダ工業（塩・塩素・苛性ソーダ）

対象は Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10 / Create: Electro Energetics（CEE）1.1.4 です。塩から塩水を作って電気分解し、塩素・水素・苛性ソーダを得ます。それぞれを塩酸・塩化ビニル樹脂・アルミナ（バイヤー法）に使います。

## 塩

### 岩塩鉱石

| 鉱石 | 高さ（台形分布） | 1か所の大きさ | チャンクあたり | 必要な道具 |
| --- | --- | ---: | ---: | --- |
| 岩塩鉱石・深層岩塩鉱石 | −16～96 | 20 | 3 | 石のツルハシ以上 |

- 採掘すると塩が2～4個出る（幸運で増える。シルクタッチなら鉱石ブロック）。
- Createのクラッシャーでは、塩4個と、50%の確率で塩2個・経験値が出る。
- 実在の岩塩は、蒸発した海の跡（蒸発岩）に大きな層を作る。そのため、数は少なく1か所を大きくした。

### 天日塩（開放円筒タンク）

- 海（`#minecraft:is_ocean`）か砂浜（`#minecraft:is_beach`）のバイオームにある開放円筒タンクに水を入れると、日光で蒸発して塩が残る。
- 条件：
  - タンクが成立している。
  - 中身が水。
  - 昼で、雨が降っていない。
  - タンクの上面の中央（壁の高さ＋1）から空が見える。
- 1秒ごとに、床1マスあたり1 mBの水が蒸発する（直径4なら12マスで毎秒12 mB）。
- 蒸発した水1,000 mBごとに塩が1個たまる。タンクにためられるのは64個まで。
- 塩は、どの構成ブロックからでも取り出せる（ファンネル・シュート・ホッパー）。外から入れることはできない。
- 空手で構成ブロックを右クリックすると、たまった塩の数も出る。
- 中央の床（タンクの持ち主）を壊すと、たまった塩がその場に落ちる。
- 保存：NBTの`Salt`（塩の数）と`Evaporated`（次の塩までに蒸発した量）。

## 塩水の電気分解

[フィルタープレス型電解槽](filter-press-electrolysis.md)で行う。1列のセルに電極ヘッドと端面の2段の制御盤を付け、上がったヘッドに極板を入れ、底面か奥の端面から塩水を送る。

- 通常極板1回50 Jで、塩水2 mBから水素1 mB・塩素1 mB・苛性ソーダ液2 mBを作る。ニッケル極板では35 J。
- 陰極ガス（水素）と陽極ガス（塩素）は長い両側面から別々に回収する。苛性ソーダ液は奥の端面からポンプで抜く。
- 給液と各製品は専用のバッファで保持し、別の種類へ切り替える前に残量を抜く。原料の優先順や異種ガスの混合バッファはない。
- 出口が満杯なら材料を消費せず、電気負荷を切って待つ。
- 実在の対応：隔膜法・イオン交換膜法の食塩電解（2NaCl＋2H₂O → Cl₂＋H₂＋2NaOH）。

### 石綿隔膜

- 電解セルの開いた上面ハッチから石綿を入れると、塩水電解だけで隔膜として働く。
- 水素・塩素・電力消費は変えず、苛性ソーダ液を1.25倍にする。塩水10,000 mBを処理するごとに石綿1個を消費する。
- 途中の処理量は、石綿そのもの（アイテムのデータ `diaphragm_wear`）に記録する。電解槽を組み直しても、別のセルへ移しても、使いかけの量は変わらない。複数のセルにあるときは構造の走査順に使う。
- 水とフッ化水素の電解には作用しない。石綿を粉砕したときの粉じんは、この実装には含めていない。

## 塩素・水素・苛性ソーダの使い道

すべて撹拌反応槽で行う（熱はBlaze Burner）。

| 工程 | 入力 | 出力 | 熱 |
| --- | --- | --- | --- |
| 塩化水素の合成 | 水素250 mB、塩素250 mB | 塩化水素500 mB | なし |
| 塩酸の吸収 | 塩化水素500 mB、水500 mB | 塩酸1,000 mB | なし |
| 二塩化エチレンの合成 | エチレン250 mB、塩素250 mB | 二塩化エチレン250 mB | なし |
| 塩化ビニルへの熱分解 | 二塩化エチレン250 mB | 塩化ビニル250 mB、塩化水素250 mB | 強く加熱 |
| 塩化ビニルの重合 | 塩化ビニル250 mB | 塩化ビニル樹脂2 | 加熱 |
| バイヤー法の溶解 | ボーキサイト2、苛性ソーダ液500 mB | アルミン酸ナトリウム溶液500 mB、鉄塊3 | 加熱 |
| バイヤー法の析出・焼成 | アルミン酸ナトリウム溶液500 mB | アルミナ1、苛性ソーダ液500 mB | 強く加熱 |
| 合成ルチル法 | チタン鉄鉱3、塩酸500 mB | 二酸化チタン1、鉄塊5 | 加熱 |
| 次亜塩素酸ナトリウム（漂白剤） | 塩素250 mB、苛性ソーダ液500 mB | 次亜塩素酸ナトリウム溶液500 mB | なし |

- 塩化ビニルの熱分解で出る塩化水素は、塩酸にできる。
- バイヤー法の苛性ソーダ液は戻ってくるので、最初の分を用意すれば、あとはボーキサイトと熱だけでアルミナが取れる。鉄塊は赤泥（鉄分）にあたる。
- 硫酸でボーキサイトを浸出する従来の方法も残している（[金属の鉱石と精錬](metals.md)）。
- 合成ルチル法は、硫酸法より1工程短い代わりに、二酸化チタン1個に要るチタン鉄鉱が3個になる（硫酸法は2個）。塩酸は回収されない。

### 排ガス洗浄

除害装置の底面へ有毒ガスを直接ポンプで送り、側面へ苛性ソーダ液を補給します。上面は排気用に空けます。安全弁は使いません。実在庫と中和材がある分だけ処理します。

### 酸洗い（Createのミキサー）

| 入力 | 出力 |
| --- | --- |
| 少し錆びた銅、塩酸50 mB | 銅ブロック |
| 錆びた銅、塩酸100 mB | 銅ブロック |
| 酸化した銅、塩酸150 mB | 銅ブロック |
| 錆びた鋼材ブロック、塩酸100 mB | 鋼材ブロック |

- 錆びた鋼材ブロックはCreateの鋼材ブロックを水で洗って作るものなので、酸洗いで装飾材が増えることはない。鋼鉄インゴット・鋼鉄ブロックへの変換は行わない。

### 製品の使い道

| 製品 | 作り方 | 使い道 |
| --- | --- | --- |
| 漂白剤（次亜塩素酸ナトリウム溶液） | 上の表（撹拌反応槽。塩素は気体なので鉢では作れない） | Createのミキサーで、色の付いた羊毛（25 mB）・カーペット（10 mB）・ベッド（50 mB）を白に戻す |
| 石けん | 加熱した鉢で、CDGの植物油250 mBと苛性ソーダ液250 mBから2個 | 右クリックで使うと、牛乳と同じように状態異常を消す（有毒ガスも消える）。状態異常がないときは減らない |
| 塩（融雪） | 岩塩鉱石・天日塩 | 氷に使うと水に、雪（雪・雪ブロック・粉雪）に使うと消える。1回につき1個。氷塊・青氷は冷たすぎて溶けない。ネザーでは氷が水にならず消える |

- Ponder「ソーダ工業の製品を使う」（石けん・塩から開く）。

## 流体・配管

塩水・塩素・苛性ソーダ・塩化水素・塩酸は等級と耐酸性に合う設備で扱います。アルミン酸ナトリウム溶液は高温なので、樹脂やPVCへ送れません。

塩素などの液化はラジエーターか、液体冷媒を別系統へ流す熱交換器で行います。液体を冷媒側へ入れると対応する気体に戻ります。外気・飽和圧・沸点で状態が自然変化することはありません。液化／気化の比は共通のPhaseChange表にあります。

PVC管は低温～常温・加圧まで・耐酸。熱い酸や高温の流体を拒否し、軟化・劣化はしません。一覧は[等級ガイド](thermal-grades.md)を参照してください。

## 確認

- GameTest `ChlorAlkaliGameTests`：
  - 塩水300 mBを100回電解すると、水素100 mB・塩素100 mB・苛性ソーダ液200 mBができ、塩水100 mBが残る。陽極から塩素が出る。
  - 塩水10,000 mBでは隔膜なしの苛性ソーダ液10,000 mBに対し、隔膜ありは12,500 mBになる。水素・塩素は各5,000 mBのままで、石綿1個を使い切る。
  - 砂浜のバイオームに置いた直径16の開放円筒タンクで、晴れた昼に水が蒸発し、蒸発量1,000 mBごとに塩が1個たまる。構成ブロックから取り出せ、入れられない。
  - 塩ビ管：塩酸は通し、熱いアルミン酸ナトリウム溶液で軟化する。塩水・酸洗いのレシピが読み込まれる。
- GameTest `ReactorGameTests.everyStirredReactionRunsWithItsHeat`：新しい撹拌反応槽の7工程を含め、すべての反応が指定の熱で進む。
