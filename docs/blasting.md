# ANFO爆薬と発破薬

対象は Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10 です。硝酸アンモニウムと軽油から産業用爆薬（ANFO、硝安油剤爆薬）を作り、発破薬にして岩を砕いて採掘します。

## 作り方

| 物 | 設備 | 材料 | できるもの |
| --- | --- | --- | --- |
| ANFO爆薬 | Createのミキサー（鉢） | 硝酸アンモニウム3、軽油25 mB（流体タグ `c:diesel`。CDGの軽油と低硫黄軽油） | ANFO爆薬3 |
| 発破薬 | 作業台 | ANFO爆薬4、紙4、レッドストーンダスト1 | 発破薬1 |

- 実在のANFOは、硝酸アンモニウム94%と燃料油6%の混合物で、鉱山や採石場の発破に最も多く使われている。
- 硝酸アンモニウムは撹拌反応槽でアンモニアと硝酸から作る（[DEVELOPMENT_CHEMISTRY.md](../DEVELOPMENT_CHEMISTRY.md)）。

```
発破薬（作業台）
P A P
A R A
P A P
```

P＝紙、A＝ANFO爆薬、R＝レッドストーンダスト。

## 使い方

- 発破薬を岩に置き、レッドストーン信号を与えると導火線に火がつく（煙が出て、雷管の先が光る）。
  - 置いたときにすでに信号があれば、すぐに火がつく。
- 2秒（40 tick）後に起爆する。
- 半径3ブロック（中心からの距離が3以下）のブロックのうち、次のものを壊し、道具なしで掘ったときのアイテムをすべて落とす（シルクタッチ・幸運なし）。
  - ツルハシかシャベルで掘るブロック（石・深層岩・鉱石・土・砂利など）。
  - 爆発耐性が9以下（石・深層岩は6、黒曜石は1,200）。
  - ブロックエンティティを持たない（機械・チェスト・タンクなどは壊さない）。
  - 岩盤など、壊せないブロックは壊さない。
- 爆風（強さ3）は生き物を傷つける。落ちたアイテムは爆風で壊れない。
- 半径3ブロック以内のほかの発破薬は、4 tick後に続けて起爆する。

## 実装

| ファイル | 内容 |
| --- | --- |
| `block/BlastingChargeBlock.java` | 点火（`LIT`）、導火線、起爆、連鎖 |
| `registry/CEBlasting.java` | ANFO爆薬と発破薬の登録 |
| `tools/generate_blasting.py` | テクスチャ・モデル・レシピ・翻訳 |
| `tools/generate_blasting_ponder.py` | Ponder「ANFOで発破採掘する」 |

- 起爆は、ブロックを先に壊して落とし、そのあとに `ExplosionInteraction.NONE`（ブロックを壊さない爆発）で音・煙・生き物へのダメージを出す。爆発の計算（`ExplosionDamageCalculator`）で、落ちたアイテムを対象から外している。

## 確認

- GameTest `BlastingGameTests.aChargeBreaksTheRockInReachIntoItemsAndSetsOffTheNext`：
  - レッドストーンブロックで点火し、導火線が燃えきる前には起爆しない。
  - 半径内の石と鉄鉱石がなくなり、丸石と鉄の原石が落ちる。
  - 半径内のもう1つの発破薬が続けて起爆し、その周りの石もなくなる。
  - チェスト・黒曜石・半径外の石は残る。
  - ANFOの混合レシピが読み込まれる。
