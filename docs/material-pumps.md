# 配管に合わせたポンプ

耐圧鋼・ニッケル合金・超耐圧・ジルコニウム・ステンレス鋼・保冷・塩ビ・樹脂・気体・大型気体の10種類です。各配管の既存テクスチャを本体へ使い、回転歯車はCreate標準の色に揃えています。アイコンも同じ配色です。CreateのMechanical Pumpの形状・接続・回転駆動を再利用します。ガラス付き・ケース入りのステンレス鋼管にもステンレス鋼ポンプを使えます。鉄パイプ素材や被覆材のJacketed Pipeは独立した搬送管ではないため、別のポンプを追加しません。

作業台でCreateのメカニカルポンプ1個と対応するパイプ1個を組み合わせます。両端が配管接続面で、隣の歯車から回転を入れます。配置・レンチによる流向の反転・回転速度による流量・停止時の動作・応力・搬送距離はCreate標準ポンプと同じです。専用の設定画面や別の搬送網はありません。標準ポンプも引き続き使用できます。流体の温度・圧力・耐食性による制限は通過する配管の材質で判定し、ポンプの色で新しい制限を追加しません。

エアフィルターは廃止しました。気体パイプまたは大型気体パイプの端を空気ブロックへ開放し、ポンプで吸引すると常温の空気を取り込めます。圧縮機の上面入口へ送り、一段圧縮して空気分離へ使います。吸気口が塞がれた場合や水没した場合は大気を吸いません。大気の吸入は気体パイプの開放端だけで行い、Create標準の銅管などは従来どおりです。取り込んだ空気を開放端へ排出すると大気へ戻り、液体の水源ブロックは生成しません。

吸気はCreateの開放端ハンドラーを使い、1回の要求量を最大1,000 mBまで返します。シミュレーションでは状態を変更せず、異なる流体を指定する排出要求は拒否します。独自のtick搬送や別の配管内インベントリを作らず、Createのネットワークが流れと停止を管理します。各ポンプのPonderで両端の接続、歯車駆動、レンチでの逆送、停止を示し、気体用の2種類には大気吸入も追加しています。

配管架台も登録・レシピ・モデル・翻訳・Ponderの対象一覧から削除しました。既存ワールド内の削除された2ブロック・対応アイテムは引き継ぎません。

2026-11-17：超耐圧パイプと超耐圧ポンプを撤去しました。現行の材質別ポンプは9種類です。歯車の色とCreate標準の搬送動作は維持します。
