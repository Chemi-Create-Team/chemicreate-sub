# 配管に合わせたポンプ

ニッケル合金・ジルコニウム・ステンレス鋼の3種類です（2026-11-21に耐圧鋼・保冷・塩ビ・樹脂・気体・大型気体のポンプを廃止し、既存ワールドのものはステンレス鋼ポンプへ読み替え）。各配管の既存テクスチャを本体へ使い、回転歯車はCreate標準の色に揃えています。アイコンも同じ配色です。CreateのMechanical Pumpの形状・接続・回転駆動を再利用します。ガラス付き・ケース入りのステンレス鋼管にもステンレス鋼ポンプを使えます。鉄パイプ素材や被覆材のJacketed Pipeは独立した搬送管ではないため、別のポンプを追加しません。

作業台でCreateのメカニカルポンプ1個と対応するパイプ1個を組み合わせます。両端が配管接続面で、隣の歯車から回転を入れます。配置・レンチによる流向の反転・回転速度による流量・停止時の動作・応力・搬送距離はCreate標準ポンプと同じです。専用の設定画面や別の搬送網はありません。標準ポンプも引き続き使用できます。各ポンプは同じ材質の配管と同じ流体の定格を持ちます（気体・大型気体ポンプは強化管、Createのメカニカルポンプは銅管と同じ）。定格外の流体を通すと配管と同じくひびが入り、約60秒で壊れます（[温度・圧力の等級](thermal-grades.md)）。フランジ側面には、Create標準ポンプと同じ形の矢印を各材質の色で描いており、流れる向きを指します（`tools/generate_material_pump_textures.py`で生成）。

吸気するには、Create標準のノズルをポンプの吸い込み側か配管の先に取り付けます。ノズルの正面を空気に向けてポンプを回します。吸気を圧縮機の上面入口へ送ると空気分離に使えます。配管やポンプの開放端は排気に使えます。

ノズルの背面が流体の搬出面で、1回の要求に最大1,000 mBの空気を返します。正面が塞がれると吸気が止まります。旧エアフィルターはワールドを読み込むとノズルになり、隣の配管またはポンプの接続方向に合わせます。気体ポンプのPonderでノズルの接続を確認できます。

配管架台は削除済みです。

2026-11-17：超耐圧パイプと超耐圧ポンプを撤去しました。現行の材質別ポンプは9種類です。歯車の色とCreate標準の搬送動作は維持します。
