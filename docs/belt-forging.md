# ベルト鍛造と蛍石の追加製法

## 小規模な鋼鉄鍛造

1. 加熱したCreateの鉢に鉄インゴット1個と木炭1個を入れ、メカニカルミキサーで銑鉄1個を作る。
2. 銑鉄をベルトへ送り、メカニカルプレス → 溶岩を通したファン → もう1台のメカニカルプレス、の順に加工する。
3. 同じ3工程を3周、合計9工程行う。3組を直列に並べても、未完成品を入口へ戻してもよい。
4. 最後に鋼鉄インゴット1個が必ず完成する。完成時だけ、25%の確率で製鋼スラグ1個が別に出る。スラグが鋼鉄の代わりになる抽選ではない。

溶岩は鉄格子で囲む。鉄格子は風を通し、溶岩の流出を止める。送風時間を確保できる速さにベルトを落とす。標準のファン加工時間に合わせた試験では1 RPMのベルトを使用している。サーバー設定でファン加工時間を変えた場合は速度や送風区間を調整する。

入力と出力にはCreateのファンネルとチェストを使える。完成品とスラグを分けるときは、Createのフィルター付き搬送を組む。スラグの二次利用レシピは今回追加していない。

未完成鋼の進捗はCreate標準のシーケンストアセンブリ用Data Componentに保存する。保管・再ロードしても工程は戻らない。順番が違う機械では進まない。赤熱は工程を示す外観で、放置時間で冷える温度シミュレーションではない。

銑鉄を入口にしているのは、通常の鉄インゴットを最初のプレスに指定するとCreateの鉄板製造と競合するため。既存の炭素粉を使う5回プレスと転炉による鋼鉄製造は残る。JEIには通常のCreateシーケンストアセンブリとして表示し、再加熱にファン・溶岩、折り返しに完成時のスラグ確率を示す。

銑鉄・赤熱した未完成鋼・鋼鉄・スラグのPonderから組立例を確認できる。

## 蛍石

蛍石は次の2製法で得られる。霊魂洗浄の出力は方解石で、蛍石は方解石の粉砕から得る。

| 操作 | 入力 | 出力 |
| --- | --- | --- |
| 霊魂洗浄 | 閃緑岩1個。魂の炎か魂の焚き火を通したファンの風を当てる | 方解石1個 |
| 鉢で混合 | 骨粉1個＋砂利1個＋水250 mB。メカニカルミキサーで混ぜる | 蛍石1個 |

混合に加熱は不要。水はCreateの配管、アイテムは通常の搬送から入れる。蛍石のPonderで両方の構成を確認できる。方解石は粉砕ホイールまたは石臼で250 tick加工すると、50%で蛍石1個と副産物の骨粉（75%）が出る。

これらは工場づくりのためのゲーム内製法であり、実際の蛍石合成反応や製鋼の全工程を化学量論・熱収支まで再現するものではない。
