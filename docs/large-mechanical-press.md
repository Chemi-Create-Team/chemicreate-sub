# 大型メカニカルプレス

大型メカニカルプレスと大型デポは、どちらも1個のアイテムで3×3の正方形に設置できます。通常のメカニカルプレスやデポを材料にし、作業台でそれぞれクラフトします。大きな鉄の板のレシピはJEIの「大型プレス加工」に出ます。

## 組立と操作

1. 床の3×3を空けて大型デポを設置します。中央に載せた材料を9マスの作業台で受けます。
2. 大型メカニカルプレスを手に持ち、デポの上面をスニーク右クリックします。プレスはデポの中央にそろい、その間に空気1段分の作業空間ができます。
3. プレス上面の軸にCreateの回転動力をつなぎます。回転方向はどちらでもよく、負荷は72 SU/RPMです。
4. 鉄ブロックをデポの上面へ右クリックで載せるか、外周の外向きの面からファンネルで搬入します。1ストロークで鉄ブロック1個を大きな鉄の板1枚に加工します。完成した板はデポから回収できます。自動化するときは、搬出ファンネルを完成品でフィルターします。

プレスのゴーグル表示で、フレーム、大型デポの位置、作業空間、動力を確認できます。不足があると材料を消費せずに停止します。ディスプレイリンクには状態・回転数・ストロークの進捗を出せます。デポだけでも使用でき、中央ブロックはCreateのデポの在庫・比較器出力を共有します。上面のどこを右クリックしても同じ在庫を操作します。

## 保存と実装

在庫は大型デポの中央にあります。プレスはCreateのプレス用アニメーションとデポの加工処理を再利用し、ストロークの途中でレシピを確認して変換します。同じ材料が複数ある場合、先にできた板の搬出を待ってから、次の鉄ブロックを加工します。中央または外周を壊すと、9マスの設備が外れ、デポの内容物も回収できます。動くからくりへの組み込みは対象外です。

プレスの金型は3×3で上下し、中央のピストンが伸縮します。各マスの表面は16×16の鋼板テクスチャ、外縁には真鍮の縁取りを使います。レシピは `large_pressing` 型で定義します。モデル・テクスチャ・Ponder構造の生成元は `tools/generate_large_press_assets.py` です。
