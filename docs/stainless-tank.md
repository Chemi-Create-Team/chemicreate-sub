# ステンレスタンクとステンレスボイラー

ステンレスタンクは従来のふた付き槽です。以前のタンク型気液分離機の外装を使い、開閉するふたと点検窓を組み合わせています。既設の槽と在庫は引き継ぎます。

中央ハッチは反応塔と同じ形状で、内側と外側を外装に合う鋼色で仕上げています。点検窓の枠もステンレス色です。正面から見て左の側面、その面を外から見たときの左端にはしごがあります。

作業台でステンレスタンク1個をステンレスボイラー1個に組み替えられます。横置きしたボイラーは断面1×1〜3×3でつながります。長辺から給水し、列の末端の下にブレイズバーナーを置きます。上面か両端から蒸気を取り出し、露出した面の計器で蒸気の残量を確認できます。組み替えの逆レシピでステンレスタンクへ戻せます。稼働条件と蒸気量は[横型タンクのボイラー](horizontal-tank-boiler.md)を参照してください。

2026-11-21のユーザー指定により、ステンレスボイラーは定格外の流体による損傷（ひび割れ・破裂）を受けない。自身が作る高圧蒸気でも壊れない。損傷するボイラーは銅（Create標準の流体タンクと横型流体タンク）だけ。

ステンレスタンクへファンネルで硫黄を入れ、上面の配管から酸素を供給します。閉じた槽の下をブレイズバーナーで超加熱すると、上面から二酸化硫黄をポンプで回収できます。撹拌羽根と回転入力は任意です。JEIの槽反応カテゴリで、二酸化硫黄の最初のレシピに酸素と硫黄を使う経路を表示します。
