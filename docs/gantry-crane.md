# 門型クレーン（RBMK燃料交換・核融合炉保守）

Createのメタルガーダーで組んだ門型クレーン。駆動部が自分の範囲の脚とレールをメタルガーダーで自動で建て、レッドストーン信号と回転がある間、自動で巡回する。[原子炉制御盤](rbmk-reactor.md#crane-console)に接続すると、制御盤から自動運転・停止・手動移動を指示できる。採掘は別ブロックの[クァーリー駆動部](quarry.md)が受け持つ。

[施設建設機](facility-constructor.md)で核分裂炉または核融合炉を選ぶと、炉の寸法に合わせた鉄骨枠と保守クレーン駆動部も建設される。

## 外観と構造

| 部品 | 役割 |
| --- | --- |
| RBMK燃料交換クレーン駆動部 `crane_drive` | RBMK炉の燃料交換・制御棒交換。27スロットの格納庫 |
| 核融合炉保守クレーン駆動部 `fusion_crane_drive` | 核融合炉のブランケット・ダイバータ交換。27スロットの格納庫 |
| 脚 | 縦向きの `create:metal_girder`。レール端から地面（最初の固いブロック）まで |
| 走行レール | 横向きの `create:metal_girder` 2列 |

桁・トロリー・燃料取扱いマスト・吊り具はブロックとして置かず、駆動部から描画する。原子炉保守用マストは太い下部10マス＋細い上部5マス、合計15マスの固定長である。

- 駆動部は置いた向き（`facing`）に手前のレールが延び、奥のレールは右側に建つ。回転は駆動部の軸を通る（レールは回転を伝えない）。
- 長さ5～64、レール間隔4～65。外幅5～66なので外径17 m炉体を覆える。
- 4つのレール端は、地面まで届く縦向きガーダーの脚（最大64段）か、固いブロックの上に直接載せる。脚の高さは角ごとに違ってよい。
- 原子炉保守では、レールのY座標を上部キャップおよびプール壁の最上段のY座標より正確に15マス上へそろえる。キャップとラックは各ブロックの四隅に作業位置がある。四隅すべてに届かせるには、レールの端と両側から余裕を取る。
- 40 tickごとと未形成時に再走査し、不足箇所はゴーグルへ表示する。

## 範囲の設定と自動建設

- **範囲**：Create標準レンチのValue Settingsで、駆動部の左側の面に「レールの長さ（正面方向）」（5～64）、右側の面に「スパン（右側へ）」（3～64）を設定する。既定は16×16。レッドストーン信号がある間は変更できない。
- **材料**：メタルガーダーを、ファンネルやシュートで駆動部へ入れる。必要数は、4本の脚の高さの合計＋レール長×2。
- **建設**：レッドストーン信号がある間、1 tickに1部材ずつ、四隅の脚（レールの下から地面へ）、手前のレール、奥のレールの順に設置する。脚を先に置くので、全部材が揃ってから構造が形成される。回転は不要。
- **障害物**：枠組みの位置にブロックがあると、位置をゴーグルに表示して止まる（クレーンは掘らない）。
- **材料不足・修理**：不足するガーダー数を表示し、材料が入ると続きを建てる。脚やレールが壊れたときも、在庫のガーダーで建て直す。
- 手で組んだ枠も、設定した範囲と一致すれば使える。

## 駆動

- 駆動部にレッドストーン信号と回転がある間だけ動く。
- 原子炉保守ではマストの長さを変えず、橋の走行とトロリーの横行、つまり前後左右だけで位置を合わせる。燃料集合体そのものは固定マスト先端からチャネル／プール内を上下する。
- 原子炉保守の水平速度は1 tickあたり `min(0.49, |RPM|/256)` ブロック。応力は8 SU/RPM。
- 核融合炉保守では、吊具を炉の上面（ブランケットのどの位置でも、届く範囲で吊具に一番近い位置）へ下ろす。
- 作業途中で止めても掴んだ燃料と進行を保存し、再開時に取り出し元を二重消費しない。

## 原子炉保守

形成済み炉心と[燃料プール](fuel-pool.md)を同じレール範囲に収める。炉とプールの対象面は同じ高さにそろえる。

組立済みの設備で操作を試せる。[燃料交換の練習用ワールド](playtests/rbmk-refuelling-practice.md)

1. ラック1枚につき22,000 mB以上、90 ℃未満の水を確保する。最小の2×2プールなら88,000 mB以上。ゴーグルで水量と水温を確認する。
2. ラックの真下に上向きのドロッパーを置く。炉に合う新燃料棒を入れ、ドロッパーを1回作動させると1本入る。使用済み燃料を受け取るため、クレーンが届く位置を1枠以上空けておく。
3. 駆動部を回してレッドストーン信号を入れる。制御盤と連携している場合は、橙色のクレーンボタンを空手で押して「自動」にする。停止からは手動を経て2回で自動になる。[制御盤の操作](rbmk-reactor.md#crane-console)
4. クレーンは燃え切った棒を1本ずつ見つけてプールへ戻し、新燃料を炉の空き区画に装荷する。駆動部のゴーグル表示で作業内容と吊り具の中身が見える。残量のある燃料棒は炉に残る。

- **燃料交換**：2×2＝4区画の正確な中心へ水平移動し、21 m燃料集合体を1本ずつ60 tickで引き抜く／挿入する。外周の無効区画と制御棒区画は飛ばす。
- **プールとの搬送**：空きラックを確認してから使用済み燃料を引き抜き、プールへ運ぶ。新燃料はプールから空の燃料区画へ運ぶ。
- **待機**：プール満杯、水位不足、90 ℃以上、構造破損、新燃料不足、高さ不一致、対象炉なしを状態表示で区別する。搬送中に条件が崩れた燃料は吊り具に保持する。
- **プールなし**：駆動部へ補給した新燃料を使い、使用済み燃料を格納庫へ戻す。
- **照射済みリチウム標的**：燃料キャップの既存アイテム出力から回収する。燃料交換中も標的とその照射結果は燃料区画に保持される。
- **制御棒交換**：全引抜で消耗25%以上の棒を2×2区画で交換し、使用済み制御棒を格納する。

## 入出力、観測、保存

- 駆動部の全面に27スロットを公開する。外から入るのはメタルガーダーと、その駆動部が扱う部品（RBMK用は新燃料棒・制御棒、核融合炉用は新品ブランケット・ダイバータ・照射カートリッジ）。外へ出るのはそれ以外（使用済み燃料棒・使用済み制御棒・使用済み部品）である。
- ゴーグルは状態、構造寸法、吊り具の中身、補給品と搬出待ちを表示する。自動建設中は状態、建設済み部材数／全部材数、不足するガーダー数、障害の位置を表示する。Display Linkで固定マストの深度も確認できる。
- 位置、格納庫、搬送中の燃料、範囲の設定を保存する。位置は移動中4 tickごとに同期し、クライアント側で補間する。

生成元は `tools/generate_crane_assets.py`。燃料搬送Ponderは駆動部・プール・炉上部キャップから開ける。
