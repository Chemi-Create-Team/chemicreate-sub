# 反応プラントの検証記録

対象：Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10-281 / Java 21。`d510251`を基準にした作業ツリー。

## 実施した確認

- Gradle `build`：成功。
- 専用サーバーGameTest：108件成功。既存102件と新規6件。
- JEIなし（`-PwithJei=false`）の専用サーバーGameTest：108件成功。
- 既存のアセット・化学・Ponder関連バリデーター10本：成功。
- 実クライアントの日本語Ponder：47シーンのタイトル・本文を検証。予熱器、反応槽、分離塔を実際に描画し、反応槽は最終外観も撮影。
- 既存のモデル・テクスチャ：変更0件。既存の圧縮機・工業用冷却器のコードも維持。

## 新しい6件のGameTest

1. 最小構造、ジャケットや脚の欠損、再形成、Createのパイプが接続する面、据付設備の移動制限。入力がない状態の処理200回で構造走査回数が増えないこと。
2. シミュレーションと実行、未加熱原料の拒否、触媒条件、2段の並列処理、照会結果のコピー、入口／出口の制限、レッドストーンと無回転での停止。
3. 保存と読み込みで流体・触媒・進捗を保持すること、解体直後に古いハンドラーが停止すること、再形成後も古いハンドラーが復活しないこと、再開後に一度だけ生成すること。
4. 4段の処理能力と応力、出力満杯時の原料保持、空きができた後の再開、5段目の拒否。
5. バーナーなしの予熱停止、実バーナーでの予熱、分離塔の最小2段、未冷却流体の拒否、既存の分離レシピと各生成量。
6. 連結ガス貯槽からCreateの実ポンプで供給し、予熱器 → 反応槽 → 完成済みフィンファン式工業用冷却器 → 分離塔を実際の配管で接続。各設備・ポンプ・冷却ファンを実Createモーターで駆動。途中の配管を鉄ブロックで閉止して搬送停止を確認し、配管を戻して再開。圧縮合成原料2,400 mBから、アンモニア800 mB、水素600 mB、窒素200 mBを確認。開放配管によるCreate本来の流体放出と混同しないよう、切断時には配管端を閉止する。

## 未検証

多数の他MODを同時に導入した環境での長時間運転、実プレイヤーが参加するマルチプレイ、数百台規模のTPS・MSPT・メモリ・FPSは未測定。GameTestの終了時間を性能測定値として扱っていない。チャンク未ロード判定は実装しているが、今回の新規GameTestでは実際のチャンクアンロードを伴う往復試験を追加していない。

既存のレガシー1ブロック装置やGUIは今回の全面改修対象に含めていない。新しい3設備は独自GUIを使用せず、ゴーグル、ワールド内計器、Ponderで操作・状態を説明する。
