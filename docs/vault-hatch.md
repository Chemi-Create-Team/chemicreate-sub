# アイテム保管庫ハッチ

Createのアイテム保管庫に取り付け、右クリックするとチェスト形式で中身を確認・出し入れできる部品です。標準のファンネル・シュートは自動搬送を担えますが、保管庫をチェスト形式で開く操作は提供しないため、この接続部品を追加します。

- 登録ID：`create_refinery_n_reactors:vault_hatch`
- 構造：Createのアイテム保管庫の6面に配置。裏面の保管庫が必要で、単独では使えません。
- 操作：右クリックで開く。54スロットずつ、左右の矢印で全ページを確認。カーソルのスタックを置いてからページを切り替えます。Shiftクリック、通常の出し入れに対応します。
- 外観：鋼板のふた・蝶番・取っ手を16×16の密度で表現。誰かが表示している間は開き、最後の閲覧者が閉じるとふたも閉じます。
- 搬送：Createの保管庫へ既存の搬送部品を接続します。ハッチには追加の在庫や搬送ポートを持たせません。搬送による変化は表示中のページに同期されます。
- 保存：アイテムの所有・保存はCreateの保管庫に任せます。ハッチを取り外しても中身を移動・複製しません。保管庫を破壊した場合の中身はCreate標準の挙動です。
- 構造変更：表示中の接続先ハンドラーが変わった場合、保管庫全体がロードされていない場合、ハッチから8ブロックを超えて離れた場合は操作を拒否し、標準のメニュー更新で閉じます。再度右クリックすると現在の構造で開きます。チャンクの強制ロードは行いません。
- 負荷：閉じているハッチは継続tick処理を行いません。表示中は54スロットとプレイヤー在庫の差分を標準メニュー同期で送り、ページ切替時だけ表示分を全送信します。ふたの閲覧者はバニラの5tick間隔の再確認を使います。
- クラフト：中央に鉄のトラップドア、上にアンデサイト合金、左右と下に鋼鉄インゴット。
- 学習：ハッチとCreateのアイテム保管庫からPonderを開けます。取付、開閉、ページ、標準搬送、取り外しを説明します。

2026-11-15の「保管庫へ取り付けてチェストのように一覧を見るハッチ」というユーザー指定を、この部品に限った在庫画面の例外として扱います。表示にはMinecraftの標準チェスト画像・スロット操作を再利用し、ページ切替だけを追加します。他の設備の操作画面へ例外を広げません。

開発時の実機確認用フィクスチャは`-Dcreateplant.vaultHatchClientCheck=true`で起動します。平坦ワールドに6方向のハッチと2ページ分の在庫を用意し、実際の右クリック経路で画面を開きます。通常起動では無効です。
