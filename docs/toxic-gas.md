# 有毒ガスとガスマスク

対象は Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10 です。有毒な流体が外に漏れると雲になって広がり、中の生き物を傷つけます。ガスマスクで防げます。

## 有毒な流体

| 強さ | 毎秒のダメージ | 流体 |
| --- | --- | --- |
| 刺激性（0） | 1 | アンモニア（気体・液体）、二酸化硫黄、塩化水素、塩化ビニル、酸化エチレン、一酸化窒素（高温・冷えた混合物を含む）、二酸化炭素 |
| 有毒（1） | 2 | 硫化水素、塩素、転炉ガス（一酸化炭素）、二酸化窒素、三酸化硫黄、フッ化水素、六フッ化ウラン（濃縮・小型炉用の濃縮・劣化を含む） |
| 最も強い（2） | 3 | フッ素 |

- ダメージは防具を通る（ダメージタイプ `create_refinery_n_reactors:toxic_gas`、タグ `minecraft:bypasses_armor`）。
- 目の位置が雲の範囲に入っている間、1秒ごとにステータス効果「有毒ガス」が3秒ずつかかり直す。雲から出ても3秒は続く。

## 漏れる場面

| 場面 | 漏れる量 |
| --- | --- |
| ハッチ・パージ・未着火フレアから放出したとき | 実際の放出量 |
| 内容物を持つ設備を撤去・解体したとき | 実際に放出した在庫 |
| 転炉トラニオン軸受を、転炉ガスを保持したまま壊したとき | 保持していた転炉ガスすべて（雲1個） |

- 漏れた位置がすでにある雲の範囲（またはその隣）に入っていて、同じ流体なら、新しい雲を作らずにその雲の量を増やす。違う流体は別の雲になる。
- 燃えるガス（水素・一酸化炭素・合成ガス・エチレンなど）も同じ雲になる。毒があって燃えるガスは、1つの雲が両方の性質を持つ。
- フレアで燃やしたあとに残る有毒ガスは、燃えない雲になる。

## 雲の広がりと消え方

- 放出元の雲は検知・回収・従来の毒と引火の判定に使う。8 ＋ 量 ÷ 20（最大512マス）を、水平±8、上4、下12（軽いガスは下4）まで埋める。重いガスの濃度と窒息は、下記の時間で広がる範囲を使う。
- 壁、閉じたドア・トラップドア、つながった板ガラス・鉄格子、液体は通らない。開いたドア、柵、ハーフブロックの横などは通る。
- 重いガスは床側から、軽いガスは天井側から埋める。

| | 色付きのもやとして見える | 見えない |
| --- | --- | --- |
| 床側から | 塩素（黄緑）、二酸化窒素（赤茶）、フッ素（淡黄）、三酸化硫黄・六フッ化ウラン（白） | 硫化水素、二酸化硫黄、塩化水素、塩化ビニル、酸化エチレン、一酸化窒素、二酸化炭素、エチレン・プロピレン・オレフィン、汚染された排ガス |
| 天井側から | 水蒸気（白、毒も引火もない） | アンモニア、一酸化炭素、転炉ガス、混合気体、合成ガス、水素（加圧・圧縮を含む）、重水素、三重水素、フッ化水素 |

- 見えないガスでも、毒・引火・ガス検知器はそのまま働く。
- 空気・酸素・窒素・アルゴン・ヘリウムは、毒も引火もないので雲を作らない。汚染された排ガスは、含む成分で毒と引火が決まる。
- 長さ：20秒 ＋ 5 mBごとに1 tick。最大2分。空が見える屋外では3分の1（水蒸気は6分の1）。範囲は100 tickごとに作り直し、ブロックの変化と屋外かどうかを反映する。
- 時間とともに量が減り、床側の雲の一番上の層は薄くなる。立っている人の目の高さより低く溜まった重いガスは吸わない。
- 重いガスの濃度は座標ごとに変わる。ガスは下り道を優先し、低い所で横に広がる。小さな筒やくぼみでは、今の段を満たし、次の段へ進める放出量（上に空いている1マスあたり1,000 mB）に達すると、もやが一段上がる。その高さに開口部があると縁から外へ流れる。時間とともに薄まり、洞窟や屋内では長く残る。
- 重いガスの濃度は目の高さで判定する。濃い場所では息が減り、息が尽きると窒息ダメージを受ける。ガスマスクの役割は毒のろ過。
- 色のある軽いガスのもやの中にカメラが入ると、画面がガスの色の霧で覆われる。
- 床側のもやと上昇する蒸気は、Minecraft標準の半透明エンティティレイヤーで描く。床側のもやは専用の描画バッファを持ち、パーティクルの直後に描画する。濃さの模様は `gas_mist.png`（32ブロックで繰り返す）に焼き込み、ゆっくり横へ流す。壁際・天井際・床からの高さによる濃さの変化は頂点ごとに計算する。

## 燃えるガスの雲

- 燃えるガスの雲は1秒ごとに、範囲の中とその隣の着火源（火、松明、溶岩、火の付いた焚き火、くすぶり以上のブレイズバーナー、パイロットの点いたフレアの先端）と、範囲の中で燃えている生き物を探す。
- 見つかると雲は消え、範囲の重心で爆発する。半径は2 × ∛（量 ÷ 1,000 mB）、1〜12ブロック。サーバー設定 `flammableGasExplosions` を無効にすると、爆発せずに炎を出して消える。
- 壁の向こうの火では着火しない。

## 苛性ソーダの排ガススクラバー

- 除害装置の底面へ、有毒ガスを直接配管とポンプで送ります。側面へ苛性ソーダを補給します。安全弁はありません。
- 上面は排気用に空けます。塞がれている間は処理せず停止します。
- 塩素・塩化水素・硫化水素・二酸化硫黄・三酸化硫黄・二酸化窒素・フッ化水素・フッ素を、ガス1 mBにつき苛性ソーダ液1 mBで中和する。中和したガスと廃液は残らない。
- 苛性ソーダ液が不足すると、残ったガスだけがスクラバーの上へ雲として出る。アンモニアは塩基性なので中和せず、苛性ソーダ液を消費しない。
- 中和中は上面の排気蓋が持ち上がる。ゴーグルは接続状態・洗浄状態・苛性ソーダ残量を2行で示す。ディスプレイリンクでは「状態」と「流体1」を別々に選べる。
- 破壊時は内部の苛性ソーダ液をブロックアイテムへ保存し、再設置時に全量を戻す。

作業台では、ステンレス鋼板4、工業用ガラス2、Createの流体パイプ・流体タンク・流体バルブ各1から1台を作る。

## ガスマスク

- 頭に着ける。雲の中でガスを受けるたびに（1秒に1回）、吸収缶を1秒分使い、ガスを通さない。
- 吸収缶は1,200秒分（耐久値のバー）。使い切ると防げない（マスクは壊れずに残る）。
- 木炭2個と紙で活性炭フィルターを作る。消耗したマスクを新品のフィルターと作業台で組み合わせると残量が満タンになる。残量はアイテムのツールチップに表示される。

## 工場内の排ガス処理と監視

- 吸収塔の最下段の平らな面へ排ガス、最上段の天面（角を除く）へ苛性ソーダ液を接続する。最下段の別の平らな面から洗浄後の液を取り出す。洗浄は上部へ排ガスを放出せず、液の出口が満杯になると材料を保持したまま停止する。
- 二酸化硫黄と硫化水素の洗浄で得た硫黄系洗浄液は、Createの鉢とミキサーで方解石と混ぜると石膏になる。塩化水素、塩素、フッ化水素の洗浄液は中和済み廃水として既存の水処理へ送れる。各レシピはJEIで確認できる。
- ガス検知器は周囲4ブロックの、ガスが通れる範囲にある雲を読み取り、最も近いマスとの距離と雲の濃さから警報用のレッドストーン信号を出す。壁の向こうの雲には反応しない。警報ランプなどをつなげて、雲が消えたことも確認できる。
- 保護コート・ズボン・シューズカバーを同時に装備すると腐食性液体による接触ダメージを防ぐ。吸入対策には頭にガスマスクも装備する。
- 不活性ガスボンベは窒素・アルゴン・ヘリウムを最大4,000 mB運べる。接続できるタンクの面を空のボンベで右クリックして充填し、受け取り側を右クリックして移送する。

```
ガスマスク（作業台）
  R
G R G
I C I
```

R＝合成ゴム、G＝板ガラス、I＝鉄板、C＝木炭。

## パイプとポンプの開放端

ポンプで気体を送ると、吐出側のパイプやポンプの先が空気ブロックのとき、その位置に気体が出ます。回収するには対応するタンクをつなぎます。屋外の蒸気は続けて空へ昇り、重いガスのもやは段差を下って低い場所へ広がります。

## 水蒸気のもやと回収ダクト

1. 高圧蒸気管の破損、フレアの排気、ポンプで送った蒸気の開放端からの放出で白いもやが出ます。もやは天井側の空間に広がり、壁や閉じたドアで止まります。屋外では早く薄まります。
2. ガス検知器は、4ブロック以内で空気の通り道がある水蒸気のもやを読み取り、残量と距離に応じてコンパレーターに0〜15の信号を出します。警報ランプや、信号を受けると止まる電動ポンプに接続できます。
3. ガス回収ダクトの格子面を空け、真上に下向きのCreateのケース入りファンを置いて32 RPM以上で回します。ダクトは空気の通り道がある近くのもやから蒸気を回収します。ゴーグルで流体の名前と残量を確認できます。
4. 丸いノズルにCreateの液体パイプとメカニカルポンプをつなぎます。ダクトに入るのは同じ種類・同じ成分の蒸気が4,000 mBまでです。搬出して空になれば別の等級も回収できます。

作業台でガス回収ダクトを1台作るのに、鉄の板2、鉄格子1、安山岩ケーシング1、液体パイプ1が必要です。ダクトと検知器からPonder「水蒸気のもやの検知と回収」を開けます。

既存ワールドに保管された未処理プロセスガスは、引き続きダクトから搬出でき、吸収塔の最上段の天面（角を除く）に水を供給して洗浄できます。

## 確認

- GameTest `ToxicGasGameTests`：
  - 水は雲を作らない。塩素1,000 mBと、その隣の4,000 mBで1つの雲になり、閉じた部屋を埋める。
  - 雲の中で、素顔と使い切ったマスクのハスクは傷つき、吸収缶の残るマスクのハスクは傷つかず、吸収缶が減る。
  - 閉じた部屋で、塩素は床の段から、アンモニアは天井の段から埋まる。天井近くの塩素の漏れも床に溜まる。
  - 閉じたドアの向こうには広がらず、向こう側のハスクは毒を受けない。開けると作り直しで広がる。
  - 屋外では雲の長さが3分の1になる。
  - 無色の一酸化炭素の雲に、部屋の中の検知器は反応し、壁の向こうの検知器は反応しない。
  - フレアで燃やしたあとの一酸化炭素は燃えない雲になり、松明でも着火しない。以前のバニラの雲は消える。
  - 一酸化炭素の雲は1つで、毒と着火の両方が起きる。壁の向こうの焚き火では着火しない。
  - 爆発を無効にすると、着火した雲は部屋を壊さずに消える。
  - 専用スクラバーは印のある側面から苛性ソーダ液だけを8,000 mB受け入れ、破壊・再設置でも保持する。
- GameTest `FlareGameTests`：水素の漏れの合流、保存と読み込み、時間による減少、64か所の漏れの上限。
