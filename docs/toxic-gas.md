# 有毒ガスとガスマスク

対象は Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10 です。有毒な流体が外に漏れると雲になって広がり、中の生き物を傷つけます。ガスマスクで防げます。

## 有毒な流体

| 強さ | 毎秒のダメージ | 流体 |
| --- | --- | --- |
| 刺激性（0） | 1 | アンモニア（気体・液体）、二酸化硫黄、塩化水素、塩化ビニル、酸化エチレン、一酸化窒素（高温・冷えた混合物を含む） |
| 有毒（1） | 2 | 硫化水素、塩素、転炉ガス（一酸化炭素）、二酸化窒素、三酸化硫黄、フッ化水素、六フッ化ウラン（濃縮・劣化を含む） |
| 最も強い（2） | 3 | フッ素 |

- ダメージは防具を通る（ダメージタイプ `create_refinery_n_reactors:toxic_gas`、タグ `minecraft:bypasses_armor`）。
- 雲の中にいる間、ステータス効果「有毒ガス」が3秒ずつかかり直す。雲から出ても3秒は続く。

## 漏れる場面

| 場面 | 漏れる量 |
| --- | --- |
| ハッチ・パージ・未着火フレアから放出したとき | 実際の放出量 |
| 内容物を持つ設備を撤去・解体したとき | 実際に放出した在庫 |
| 転炉トラニオン軸受を、転炉ガスを保持したまま壊したとき | 保持していた転炉ガスすべて（雲1個） |

- 近く（1.5ブロック以内）にすでに雲があれば、新しい雲を作らずにその雲を広げ、長くする。

## 雲の広がりと消え方

- 広さ：1.5ブロック ＋ 1.5 × √（量 ÷ 1,000 mB）。最大6ブロック。
- 長さ：20秒 ＋ 5 mBごとに1 tick。最大2分。
- 空が見える屋外では、長さが3分の1になる（換気は時間と屋外だけ）。
- 消えるまでに、広さは半分まで縮む。
- 色はガスで変わる（塩素は黄緑、二酸化窒素は赤茶など）。

## 苛性ソーダの排ガススクラバー

- 除害装置の底面へ、有毒ガスを直接配管とポンプで送ります。側面へ苛性ソーダを補給します。安全弁はありません。
- 上面は排気用に空けます。塞がれている間は処理せず停止します。
- 塩素・塩化水素・硫化水素・二酸化硫黄・三酸化硫黄・二酸化窒素・フッ化水素・フッ素を、ガス1 mBにつき苛性ソーダ液1 mBで中和する。中和したガスと廃液は残らない。
- 苛性ソーダ液が不足すると、残ったガスだけがスクラバーの上へ雲として出る。アンモニアは塩基性なので中和せず、苛性ソーダ液を消費しない。
- 中和中は上面の排気蓋が持ち上がる。ゴーグルは接続状態・洗浄状態・苛性ソーダ残量を2行で示す。ディスプレイリンクでは「状態」と「流体1」を別々に選べる。
- 破壊時は内部の苛性ソーダ液をブロックアイテムへ保存し、再設置時に全量を戻す。

作業台では、ステンレス鋼板4、工業用ガラス2、Createの流体パイプ・流体タンク・流体バルブ各1から1台を作る。

## ガスマスク

- 頭に着ける。雲の中でガスを受けるたびに（1秒に1回）、吸収缶を1秒分使い、ガスを通さない。
- 吸収缶は1,200秒分（耐久値のバー）。使い切ると防げない（マスクは壊れずに残る）。
- 作業台でガスマスク＋木炭2 → 新しい吸収缶。2つを合わせる修理はできない。

```
ガスマスク（作業台）
  R
G R G
I C I
```

R＝合成ゴム、G＝板ガラス、I＝鉄板、C＝木炭。

## 確認

- GameTest `ToxicGasGameTests`：
  - 水は雲を作らない。塩素1,000 mBと、その隣の4,000 mBで、1つの雲になり、広さ4.5ブロック、長さは屋内と屋外で変わる。
  - 雲の中で、素顔と使い切ったマスクのハスクは傷つき、吸収缶の残るマスクのハスクは傷つかず、吸収缶が減る。
  - 塩素を入れたCreateのタンクが壊れると、その場所に雲ができる。
  - 専用スクラバーは印のある側面から苛性ソーダ液だけを8,000 mB受け入れ、破壊・再設置でも保持する。
  - 除害装置へ送った塩素は苛性ソーダ液を同量消費して雲を作らず、不足時だけ残量が雲になる。アンモニアは中和されない。
  - 普通の流体タンクはスクラバーとして働かない。
