# ChatGPT引き継ぎ：ウラン鉱石からウランペレットまで

## 実装内容
ウラン鉱石から焼結ウランペレットまでの工程と、そこで使う硫酸・フッ化水素・フッ素を追加した。DESIGN.mdの「既存ブロックを優先」に従い、新しい機械は、反応プラント（駆動部・圧力容器のジャケット・鏡板で組むマルチブロック）のモジュールとして追加したガス遠心分離機と撹拌反応槽だけにした。ほかの工程はCreateの粉砕ホイール・メカニカルミキサー・メカニカルプレスと、既存の触媒反応槽・ベイスン電解槽で行う。数量はゲーム用の値で、実在設備の運転条件ではない。

気体と他の物質の反応は、すべて撹拌反応槽で行う（レシピ型`create_heavy_indusstry:pressure_reaction`）。Createのベイスン（鉢）は気体を受け付けない。

| 工程 | 設備 | 入力 → 出力 |
| --- | --- | --- |
| 鉱石 | 採掘・粉砕ホイール | ウラン鉱石（石・深層岩、Y-48～32に1チャンク4回・最大6個の鉱脈）→ 閃ウラン鉱（幸運対応）。粉砕は閃ウラン鉱1＋75%で1＋経験値ナゲット＋丸石類。方解石の粉砕 → 骨粉（75%）＋蛍石（25%） |
| 二酸化硫黄 | 撹拌反応槽（加熱） | 硫黄の粉＋酸素250 → 二酸化硫黄500 |
| 三酸化硫黄 | 触媒反応槽＋酸化触媒 | 二酸化硫黄100＋酸素50 → 三酸化硫黄100（100 tick） |
| 硫酸 | 撹拌反応槽 | 三酸化硫黄250＋水250 → 硫酸250 |
| フッ化水素 | 撹拌反応槽（加熱） | 蛍石＋硫酸250 → フッ化水素1000 |
| フッ素 | ベイスン電解槽 | 水が無いとき、フッ化水素2 mB → 水素1 mB＋フッ素1 mB（1極板・1 tick、32 FE） |
| 浸出 | 撹拌反応槽 | 閃ウラン鉱＋硫酸250＋酸素100 → 硫酸ウラニル溶液500 |
| 沈殿 | 撹拌反応槽 | 硫酸ウラニル溶液250＋アンモニア250 → イエローケーキ |
| 精製 | ミキサー | イエローケーキ＋硝酸250 → 硝酸ウラニル溶液250 |
| 脱硝 | 撹拌反応槽（加熱） | 硝酸ウラニル溶液250 → 三酸化ウラン＋二酸化窒素100（硝酸吸収塔へ戻せる） |
| 還元 | 撹拌反応槽（加熱） | 三酸化ウラン＋水素250 → 二酸化ウラン |
| フッ化 | 撹拌反応槽（加熱） | 二酸化ウラン＋フッ化水素500 → 四フッ化ウラン |
| 六フッ化 | 撹拌反応槽（加熱） | 四フッ化ウラン＋フッ素250 → 六フッ化ウラン250 |
| 濃縮 | **ガス遠心分離機** | 六フッ化ウラン1000 → 濃縮125＋劣化875（200 tick） |
| 加水分解 | 撹拌反応槽 | 濃縮六フッ化ウラン250＋水250 → 濃縮フッ化ウラニル＋フッ化水素500 |
| 還元 | 撹拌反応槽（加熱） | 濃縮フッ化ウラニル＋水素250 → 濃縮二酸化ウラン＋フッ化水素250 |
| 成形 | メカニカルプレス | 濃縮二酸化ウラン → 未焼結ウランペレット2個 |
| 焼結 | 撹拌反応槽（超加熱） | 未焼結ペレット＋水素100 → ウランペレット |

| 使用済み制御棒の再処理 | 撹拌反応槽（加熱） | 使用済み制御棒＋硝酸500 → 原子炉用黒鉛1 |

濃縮比は、天然0.7%を4%へ、劣化側0.25%とした物質収支から1/8とした。Createの混合は液体入力が2種までなので、再転換を加水分解と水素還元の2段に分けた。ペレット1個あたりの原料は閃ウラン鉱2個（天然二酸化ウラン4個）。

再処理の硝酸ウラニル溶液3,500 mBは、脱硝で三酸化ウラン14個になり、その後の濃縮比とペレット工程を通すと新燃料棒1本に必要な7ペレットのおよそ半分に相当する。新燃料棒のジルカロイ被覆管2本に対して戻すジルコニウムも1個だけであり、循環だけで燃料や被覆材を増やせない。

## 撹拌反応槽（設計項目）
| 項目 | 内容 |
| --- | --- |
| 工程と追加理由 | 開いた鉢で気体を反応させるのは不自然なため、気体と物質の反応は圧力容器のジャケットで囲んだ反応プラントのマルチブロックで行う。Createの部品だけでは閉じた撹拌容器を表せないため、反応プラントに撹拌反応槽モジュール（`ReactorModule.STIRRED`）を追加した |
| 構造 | 触媒反応槽と同じ枠：下に駆動部、その上に撹拌翼の段（1～4段）とその周囲8か所の圧力容器のジャケット、最上部に鏡板9。加熱が必要な反応は駆動部の真下にブレイズバーナーを置く（予熱器と同じ約束） |
| 入出力 | 気体・液体は駆動部の入口面（軸がzなら西）から入れ、出口面から生成物を出す（入力2槽・出力5槽、各8,000 mB、気体は256倍まで）。アイテムは駆動部の下面以外の面からファンネル等で、原料9枠へ反応の材料だけ入り、生成物4枠から取り出せる。生成物の空きが足りないバッチは始めない |
| 駆動と条件 | 32 RPM以上で撹拌し、速度倍率は最大4倍。1段ごとに並列1バッチ、応力16 SU/RPM。レシピの熱条件はバーナーの熱の段階で判定し、段階が変わると反応を探し直す |
| レシピ | Createの処理レシピと同じJSON（材料・液体・結果・`heat_requirement`・`processing_time`）。材料9・液体入力2・結果4・液体結果2まで。気体を使うレシピはすべてこの型にした（ウラン工程11件、ペレット焼結、合成ガス、硝酸アンモニウム、合成ゴム）。気体を使わない硝酸ウラニル溶液はCreateの混合のまま |
| 操作と観測 | 既存反応容器と同じゴーグル表示に、原料・生成物のアイテム行を追加。レッドストーン停止 |
| 外観と動き | 触媒反応槽と同じ形状を、空気分離塔のテクスチャをわずかに暖色にしてボルトを足した派生テクスチャ（`textures/block/reactor/stirred/`）で描く。撹拌翼は軸と羽根の形。駆動部のシャフト回転と稼働ランプ |
| 保存と構造変更 | 既存の保存・構造再検証・ポート世代管理を使い、原料・生成物の枠は`Charge`として保存。駆動部を壊すと枠の中身を落とす |

前回までの「密閉反応槽の蓋」と1ブロックの「圧力反応容器」は、この撹拌反応槽に置き換えて、登録・アセット・レシピ・翻訳・Ponderごと削除した。Createのレシピ照合を変えていたMixin（`BasinRecipeMixin`）も不要になったので削除した。

## JEI
`compat/jei`に汎用カテゴリ（入力グリッド・矢印・消費しない触媒・出力・条件の注記）を作り、次の12種を登録した：撹拌反応槽、触媒反応槽、反応生成物分離塔、ガス遠心分離機、ベイスン電解槽、ガス圧縮機、中間冷却器、ハーバー・ボッシュ塔、アンモニア分離器、空気分離塔、工程加熱、工程冷却。撹拌反応槽のカテゴリには`pressure_reaction`型のレシピをすべて表示する。作業台・Createの通常レシピはJEIとCreateの既存カテゴリで表示される。

ハーバー・ボッシュ塔・アンモニア分離器・冷却・加熱は温度や圧力で量が変わる物理計算なので、量は目安であることを注記に書いた。

## 選択枠・全面の搬入出・Create風テクスチャ・ウランの粉
- **選択枠**：当たり判定は軸に沿った箱しか扱えないため形はそのままにし、反応プラントのジャケット・鏡板にカーソルを合わせたときの選択枠を独自に描く（`client/ReactorOutlineRenderer.java`）。モデルと同じ八角形をそのブロックの範囲で切り取った多角柱で、斜めの辺はまっすぐ。
- **全面の搬入出**：触媒反応槽・分離塔・撹拌反応槽・遠心分離機は、駆動部・ジャケット・鏡板・内部部品のどの面からでも、流体（液体・気体）とアイテムを出し入れできる。部品には中身を持たない中継用ブロックエンティティ（`ReactorPartBlockEntity`、Createの配管は接続先にブロックエンティティを要求するため）を置き、所属する駆動部のポートを返す。入れた流体は原料槽にだけ入り、抜けるのは生成物槽だけ。形成・解体時は全部品のcapabilityを無効化し、隣の配管の形を更新する。ゴーグルの入出力口の行も「どの面にもつながる」に変えた。予熱器（横型）は対象外で従来どおり。
- **テクスチャ**：反応プラント共通の鉄・鋳鉄・真鍮・銅・格子と、撹拌反応槽用の4枚を、Createのケーシング風（1pxの暗い縁、内側の明暗の面取り、角のリベット、低彩度）に描き直した。同じテクスチャを使う工業用加熱器の制御部と熱交換器の上部フレームの見た目も同様に変わる。
- **ウランの粉**：三酸化ウラン・二酸化ウラン・四フッ化ウラン・濃縮二酸化ウランは、バニラの火薬の絵（`minecraft:item/gunpowder`）を参照し、クライアントで色を掛けて表示する（`ElectrolysisClient.tintPowders`）。絵を写していないので、Mojangの素材を同梱しない。火薬は暗い灰色なので、どの色も暗めになる。
- `build`と必須212件のGameTestは成功（テストは全面共通ポートに合わせ、ジャケットからのアイテム・鏡板からの気体の搬入を追加）。未検証：ゲーム内での選択枠・テクスチャ・アイテムの色・配管の接続の見た目。

## 駆動部を底の段に・Ponderの作り直し・銀色テクスチャ
- **底の段**：触媒反応槽・分離塔・撹拌反応槽・遠心分離機とも、最下段は「中央の駆動部＋周囲8か所のジャケット」で、そろわないと成立しない（`ReactorStructure.scan`、組立ガイドも同じ）。容器は地面に載り、浮かない。駆動部は縦軸で、シャフトは下から入れる。遠心分離機の上部駆動（`ReactorModule.topDrive`）は廃止し、ロータは駆動部の上の段に描く。
- **入出力**：駆動部はcapabilityを公開しない（予熱器などの横型は従来どおり）。ジャケット・鏡板・内部部品の面から行う。
- **撹拌反応槽の加熱**：最下段のジャケットの下にあるブレイズバーナーのうち最も熱いもの（駆動部の下はシャフトの位置）。
- **Ponder**：反応プラント6本（触媒反応槽3本・分離塔・撹拌反応槽・遠心分離機）と、硝酸アンモニウム・合成ゴムの組立図を、ケーシングの台座の上に「ギアボックス＋モーターで下から駆動、駆動部をジャケットで囲む」形で作り直し、説明文も書き直した。これらは今後`generate_uranium_assets.py`で生成する（古い`generate_reactor_tutorials.py`の該当分は使わない）。JEIの立体図も同じ組立図を使う。
- **テクスチャ**：4装置の全モデル（駆動部・内部部品・ジャケット・鏡板・ロータ）を、気液分離機（アンモニア分離器）の側面テクスチャを元にした銀色系（`textures/block/reactor/silver/`）に変えた。胴体は分離器の側面、枠はそれを暗くしたもの、帯・飾り・格子は分離器の縁・溝・地の色で描いた。撹拌反応槽専用だった4枚は削除。工業用加熱器・熱交換器が共有する`reactor/`のテクスチャは変えていない。
- `build`と必須212件のGameTestは成功（底の段のジャケット、下に置くバーナー、駆動部の真下のレッドストーンに合わせてテストを修正）。未検証：ゲーム内での見た目・Ponder・JEIの立体図。

## 気液分離機の質感の再現
- 前回は分離器の側面テクスチャを1枚の模様として扱い、モデルの面ごとにブロック内の座標ぶんだけ切り出していたため、細かく分かれた胴体には縁の明るさ・溝の影・面の反射がほとんど出なかった。
- 4装置のモデルは、6px以上の面に分離器のパネルを1面1枚で丸ごと貼る（分離器自身のモデルと同じ貼り方、`panel`）。上下を向く胴体の面は分離器の天板（`silver/top`）。斜めの板も1枚ごとにパネル全体を貼る。
- 段ごとの帯リング（枠・真鍮・銅）を外し、触媒反応槽・分離塔・撹拌反応槽のジャケットは1段1枚の胴体だけにした。分離器のパネル自体に上下の明るい縁があるため、重ねると帯が二重になって見た目が崩れていた。触媒反応槽の側面の点検口も外した。
- 細い部品用の`silver/band`・`silver/trim`は、どの2pxを切り出しても「上が明るい縁・下が暗い溝」になる縞にした。
- `build`と必須212件のGameTestは成功。テクスチャを貼った簡易描画で確認。ゲーム内は未確認。
