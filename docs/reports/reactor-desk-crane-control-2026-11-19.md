# 原子炉制御盤から保守クレーンを操作

実装コミットは `b98b5d05c08a3e30a9722b37e4f8ffa729fa703a`。操作手順は[原子炉制御盤](../rbmk-reactor.md#crane-console)を参照。

- 共通の `CraneDriveBlock` を使う核分裂炉用と核融合炉用の保守クレーンを、制御盤ユニットの右クリックで接続できる。アイテムには駆動部の位置とディメンションを記憶し、設置済みの双方に相手の座標を保存する。1台のクレーンを同時に操作できる制御盤は1台。
- `ReactorControlConsoleBlockEntity` に停止・手動・自動の切替と2方向の右クリック操作を追加した。`CraneDriveBlockEntity` は手動操作の片側1クリックにつき1ブロックの目標を設定し、レールの範囲に収める。移動速度は既存の `min(0.49, abs(RPM) / 256)` ブロック/tick を使う。自動では既存の交換作業を使用し、停止では保持物とその時点の進捗を維持する。
- 接続時と再読込後は停止から始まる。接続中は制御盤が始動・停止を決める。接続解除で駆動部のレッドストーン入力へ戻る。相手が未読込の場合は既存チャンクだけを参照し、強制ロードしない。
- 実機と同じ盤面モデルにボタン3個とモード表示を追加し、日本語・英語・中国語のPonderへ接続と操作を追加した。ゴーグルを付けてスニークするとクレーンの状態を表示する。
- 専用サーバーの関連GameTest 36件、Gradleビルド、翻訳とPonderの検証が通過。テストは実際のアイテム接続、両軸の正逆移動、RBMKの燃料搬送の途中停止と再開、保持物の保存、接続解除を確認した。RTX 4060のMinecraftクライアントで日本語Ponderと盤面を表示した。
- 核融合駆動部は同じ操作経路を使う。核融合炉の消耗部品を制御盤から交換完了まで運ぶ試験は今回未実施。マルチプレイヤーによる同時操作は個別に試していない。
