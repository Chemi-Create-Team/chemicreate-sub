# 顔料から染料（白・緑） レポート

## 基準と実装コミット

- 作業ブランチ：`main`
- 作業開始時の基準コミット：`b541fd5`
- 実装コミット：`31df0af`

## 依頼

- 金属の使い道の案Cのうち、C1（白の顔料）とC2（緑の顔料）の染料を作る。
- 現状の素材でほかの色も作れないか検討する（検討結果はユーザーへ報告し、実装は未着手）。

## 実装内容

- 新規アイテム`chromium_oxide`（酸化クロム（クロムグリーン））。`registry/CEMetals.java`に登録し、クリエイティブタブに追加した。
- 撹拌反応槽の反応：クロム鉄鉱2・酸素500 mB（強く加熱）→ 酸化クロム1・鉄塊2。
  - 実在の製法（ソーダ灰とのアルカリ焙焼と還元）を、酸素での焙焼に簡略化した。
- Createの石臼の加工：
  - 二酸化チタン1 → 白の染料4
  - 酸化クロム1 → 緑の染料4
- 生成スクリプト：`tools/generate_metal_ores.py`（テクスチャ・モデル・翻訳・反応・加工）。
- Ponder「鉱石から金属を作る」に、石臼と顔料の手順を追加した。二酸化チタン・酸化クロムからも開ける。
- 文書：`docs/metals.md`。

## 追加：黒・赤・黄・青

- 実装コミット：`83dd5d0`
- 新規アイテム：`iron_oxide_red`（ベンガラ）、`nickel_titanium_yellow`（ニッケルチタンイエロー）、`molybdenum_blue`（モリブデンブルー）。
- 撹拌反応槽の反応：
  - 四三酸化鉄の山1・酸素250 mB（加熱）→ ベンガラ1。
  - 二酸化チタン2・酸化ニッケル1（強く加熱）→ ニッケルチタンイエロー3。
  - 三酸化モリブデン1・二酸化硫黄250 mB・水250 mB（加熱）→ モリブデンブルー1・硫酸250 mB。
    - 撹拌反応槽は、材料のそろった最初のレシピを選ぶ。モリブデンを作る水素還元と材料が重ならないように、還元剤を二酸化硫黄にした。
- 石臼：四三酸化鉄の山・ベンガラ・ニッケルチタンイエロー・モリブデンブルーから、黒・赤・黄・青の染料を4個ずつ。
- Ponder「鉱石から金属を作る」の顔料の手順を、6色すべての説明にした。各顔料からも開ける。
- 確認：`bash gradlew build runGameTestServer` 281件すべて合格。`PigmentGameTests`は6種の顔料すべてを確かめる。撹拌反応槽の全反応のGameTestに、新しい3反応も含まれる。
- 未検証：ゲーム内で実際に挽く操作。Ponderの撮影。
