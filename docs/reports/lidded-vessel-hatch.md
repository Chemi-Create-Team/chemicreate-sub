# ふた付き槽のハッチ化と2×2反応装置 完了レポート（ChatGPT引き継ぎ用）

## 実装内容

### ハッチ
- ふたが丸ごと開く仕組みをやめ、上面の真ん中に1マス分のハッチを付けた。上面の残りは固定の板になる。
  - 3×3：中央のブロックの上。
  - 2×2：4ブロックの内側の角にまたがる、中央の16 px。
  - 1×1：壁の内側全体。
- ブロック状態`hatch`（`none`／`full`／`nw`／`ne`／`sw`／`se`）で、そのブロックの上にハッチのどの部分があるかを表す。連結のたびに、最上段だけに付け直す。
- 開け閉めは、何も持たずに右クリックする（どの面でもよい）。レンチでは開閉しない。
- 開いているときに中空になるのは、ハッチの下だけ。
  - 3×3の中央：床だけが残る。
  - 2×2の各ブロック：内側の角の8×8 pxだけがくり抜かれる。
  - ほかのブロックと下の段は、普通のブロックの当たり判定のまま。
- 上面のパイプが外れるのは、開いたハッチの下のブロックだけ。ハッチの横の上面パイプはつながったまま。
- 噴き出し・放出・バケツの出し入れ・反応装置の「ハッチを閉じて」の停止は、従来のふたの開閉と同じ扱い。

### 内部部品の出し入れ
- 2×2か3×3の槽のどこを内部部品で右クリックしても、下の段から順に入る。ハッチの開閉は問わない。
- 各段の内部部品は、その段のうちコントローラーの真上にあるブロック（スロット）が持つ。
  - 連結し直してスロット以外のブロックに残った内部部品は、その段のスロットへ移す。スロットがふさがっていればドロップする。
  - 1×1に分かれたブロックは内部部品を持ったままにし、レンチで取り出せる（槽が分かれても、内部部品が無言で消えないようにするため）。
- レンチで右クリックすると、上の段から順に1つずつ外れてプレイヤーに渡る。
- スニークしてレンチで右クリックしたときも、内部部品が残っていればまず外す。全部外れてから、Create標準のブロック回収になる。
- 素手でスニークして右クリックして取り出す操作は廃止した。

### 2×2の反応装置
- 駆動部は、2×2か3×3の槽の最下段の、どのブロックの真下に置いてもよい。
- 1つの槽の下に駆動部が2つ以上あると、形成しない（状態`drive`）。同じ槽を二重に処理しないため。
- 八角形になるのは3×3の撹拌反応槽・ガス遠心分離機だけ。2×2は四角のまま。
- 内部部品とロータは槽の中心に描く。
  - 遠心ロータの4本の軸の位置：3×3では中心から±10 px、2×2では±8 px。
  - 分離棚段の板は28 pxに縮めて、2×2の壁の内側にちょうど収まるようにした。3×3ではまわりに隙間ができる。
- 回転角は、槽の下にある駆動部から取る。

### Ponder・字幕
- Ponder構造15件を変換した。
  - 槽のブロックに`hatch`の状態を付けた。
  - 内部部品を各段のスロット（コントローラーの真上）へ移した。
- 生成スクリプトの`Structure.reactor`も同じ出力にした。
- ふた付き槽のPonderの変更点：
  - ハッチは素手で開ける。
  - 内部部品の出し入れの字幕を追加した。
  - 上面パイプを、ハッチの横に移した。
- 反応装置・ふた付き槽の字幕（英語・日本語）は、2×2・3×3とハッチの説明に直した。生成スクリプトの中の文字列も同じにした。

## 未検証・制約

- 通常のワールドで手で操作する確認はしていない：素手での開閉、レンチ・スニークレンチでの取り出し順、2×2の反応装置、Createのレンチの回収との兼ね合い。
- 2×2の反応装置と、そのハッチ・内部部品は、画面で確認していない（Ponderに2×2の例はない）。
- 内部部品は、ハッチを閉じていても出し入れできる（指示どおり「どこをめがけても」）。
- 建築ガイド（`ReactorGuide`）は、今も3×3を駆動部の中心に置く形だけを示す。
