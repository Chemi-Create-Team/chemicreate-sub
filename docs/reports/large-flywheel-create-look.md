# 大型フライホイールの標準の見た目をCreateのフライホイールにした

2026-11-25のユーザー指定：「大型フライホイールのテクスチャをデフォルトではサイズの大きいCreateのフライホイールの見た目にしてください。染料で色を変えられる」。

- 標準の `large_flywheel.png` を、Createの `create:block/flywheel` のテクスチャ（真鍮・灰色の軸受・茶色の胴）に差し替えた。モデルは以前と同じ大きいもの（約5.5ブロック幅）のまま。
- 染料の15色（黄色は標準）は、Createのテクスチャの真鍮の部分だけを染料の色相・彩度・明るさに変えて作り直した。灰色の軸受と暗い土台は色を保つ。黒と灰色だけは軸受も暗くした。染料で色を変える動作（`LargeFlywheelBlock`）は元からあり、変えていない。
- 生成は `python3 tools/generate_large_flywheel_textures.py <Createのjar>`。色相と明るさの表はスクリプトの中にある。
- 確認したのはテクスチャの見た目（標準と8色の並べた画像）と、GameTestの通過まで。ゲーム内の描画は見ていない。
