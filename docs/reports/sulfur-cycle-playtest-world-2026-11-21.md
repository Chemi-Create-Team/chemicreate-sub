# 硫黄サイクルのテストワールド

2026-11-21。ユーザーの「二酸化窒素を吸収塔に通して亜硫酸を作り、電解して硫酸を作る流れのテストワールドを作ってテストして」という依頼に対応。亜硫酸になるのは二酸化硫黄（SO₂）なので、二酸化硫黄で組んだ。

実装コミット：`905cb1d`（ワールド生成）、本レポートと同じコミット

## 実装

`-Dcreateplant.sulfurCyclePlaytest=true`を指定したときだけ動く開発用のワールド生成（`client/SulfurCyclePlaytestWorld.java`）。新しいクリエイティブ・スーパーフラット・ピースフルのワールドに実ブロックで組み、自動で運転して確認したあと保存する。通常のゲーム起動には影響しない。

| 部分 | 構成 |
| --- | --- |
| 吸収塔 | 3×3・4段（最下段の中心が(0, -58, 0)） |
| 二酸化硫黄 | クリエイティブタンク → ステンレスポンプ → 最下段の西の直線面 |
| 水 | クリエイティブタンク → ステンレスポンプ → 最上段の中心の天面 |
| 未吸収ガス | 最上段の北の直線面 → ステンレスポンプ → ステンレスタンク |
| 亜硫酸 | 最下段の中心の底面 → ステンレス配管・ポンプ → 電解セルの下面 |
| 電解セル | 1セル（(0, -58, 8)、Z軸、制御盤は北）。ニッケル電極板1枚 |
| 電力 | クリエイティブモーター（256 RPM）→ 発電機のブラシ・ローター・ステーター4個 → 銅線で制御盤へ |
| 生成物 | 水素：陰極側（西）→ ポンプ → ガスレシーバー。硫酸：奥の端面（南）→ ポンプ → ステンレスタンク |

すべての受け渡しは配管とポンプで行い、プログラムから流体を移す操作はしない。起動時の操作は、電極板の装着、銅線の接続、STARTボタンだけ（プレイヤーと同じ操作）。各ポンプは歯車とモーターで駆動する。

## 検証

Linuxのコンテナで、Xvfb上の実クライアントを使って実行した（`JAVA_TOOL_OPTIONS=-Dcreateplant.sulfurCyclePlaytest=true ./gradlew runClient`）。合格。

| 項目 | 結果 |
| --- | --- |
| 亜硫酸の生成 | tick 125 |
| 電解セルへの到達 | tick 134 |
| 水素・硫酸の生成 | tick 139 |
| 硫酸1,000 mBに到達 | tick 1,135（水素も1,000 mB） |
| 電圧・電力量 | 最大1,473 V、53,986 J |
| 未吸収ガス | 0 mB |
| 配管・ポンプ20か所の損耗 | すべて0 |
| 吸収塔・電解セルの状態 | どちらも運転中 |

運転中の様子：電解セルの入力バッファは約4,000 mBで満杯になり、その後は亜硫酸が吸収塔に溜まっていく（tick 1,000で3,272 mB）。処理速度は電解セル1台が上限になっている。

保存したワールド：`run/saves/createplant-sulfur-cycle-1795272430602`（Git管理外）。結果は`run/sulfur-cycle-playtest-result.json`。

## 未検証・制約

- 画面での見た目（配管の向き、ポンプの矢印、ゴーグル表示）は確認していない。ワールドの自動運転と数値だけを確認した。
- 発電機の出力電圧は約1,470 Vで、電解セルのGameTestの400 Vより高い。セルは正常に運転しているが、電圧の適正範囲の確認はしていない。
- 電解セルが1台なので、流れを続けると亜硫酸が吸収塔に溜まり、やがて吸収塔が止まる。
- 二酸化硫黄と水はクリエイティブタンクから無限に供給される。
