# 組立基準：RBMK炉・核融合炉・冷却塔を概略図砲で組み立てる：完了レポート

この方式は2026-11-15の追加指定で[施設建設機](../facility-constructor.md)へ置き換えました。以下は旧実装時の記録です。

## 実装内容

- **基準ブロック3種**（`AssemblyBaseBlock`、`registry/CEAssembly`）：RBMK炉組立基準、核融合炉組立基準、冷却塔組立基準。
  - インベントリは持たない。
  - 機械は、基準の向いている方向に、基準を中央にして、基礎を基準と同じ高さにして建つ。冷却塔は、ポートの向きが決まっているので常に南側に建つ。
  - RBMK炉は、上面のつまみで炉心の直径（5・7・9・11・13 m）を選ぶ。
- **完成形の定義**（`assembly/AssemblyPlan`）：
  - 核融合炉は`FusionStructure.cells`、冷却塔は`CoolingTowerStructure.cells`をそのまま使う。
  - RBMK炉は、試験用ワールドの組み立てと同じ構成：下部の給水束、炉心、上部の管、上蓋、生体遮蔽、遮蔽の出口と駆動部。
  - 空けておくべきマスは空気として含める。
- **概略図砲への受け渡し**（`assembly/AssemblySchematic`、`AssemblyBaseBlockEntity.lazyTick`）：
  - 20 tickごとに、水平方向の隣の概略図砲を調べる。
  - 設計図のスロットが空で、機械がまだ完成していなければ、完成形をCreateの概略図の形式で書き出す。保存先は`schematics/uploaded/create_refinery_n_reactors/`。
  - 書き出したものを、設置済み（deployed）・基点つきの設計図として渡す。
  - 停止中の概略図砲に古い大きさの設計図が入っていれば、入れ替える。
  - 材料・火薬・不足素材リスト（右上のスロットにクリップボードか本）は、概略図砲の仕組みをそのまま使う。
- **完成形の表示**（`AssemblyPreviewRenderer`）：
  - 64マス以内で、まだ置かれていないマスを、そのブロックの地図色の半透明の箱で描く。邪魔なブロックは赤。
  - 冷却塔の制御部の表示と、描画処理を`MultiblockPreview`に共通化した。
- **見た目・レシピ・翻訳**（生成元`tools/generate_assembly_bases.py`）：
  - 上面は、向きの矢印と機械の印を描いた設計図の板。側面は真鍮ケーシング、底面は安山岩ケーシング（Createのテクスチャを参照）。
  - レシピは、空の概略図・真鍮板2枚・真鍮ケーシング・機械の部品1つ。
- **Ponder**（`plant/assembly_base`、3種の基準で共通）：基準を置く → 完成形の表示 → 概略図砲 → クリップボード → 組み上げ。

## 確認

- `AssemblyGameTests`（2件）：合格。
  - 3種の完成形を置くと、核融合炉・RBMK炉（炉心13 m）・冷却塔のどれも形成される。
  - 基準が横の概略図砲に設計図を渡す。基点が完成形の端に合い、書き出した概略図の大きさが機械全体と一致する。
  - Createの印刷処理（`SchematicPrinter`）が、エラーなく読み込む。
  - 完成後は、設計図を渡さない。
- 全ブロック点検・クリエイティブタブ・レシピ・Ponder・サバイバル到達性・発電所のGameTest：失敗は既知の採掘Ponderの1件だけ（クァーリーの作り直しで対応予定）。
- 画面での確認（Ponder）：完成形の半透明表示と、組み上がったトカマク。
