# 蒸気ハンマー

実装コミットは `9273aa5efcc6888195a205a87b3c78e336eb6f88`。

## 操作と調整値

| 操作 | ゲーム内の挙動 |
| --- | --- |
| しゃがみながら蒸気入りの脈動抑制管の端面を右クリック | 最大2,000 mBまで充填する。通常蒸気、高圧蒸気、過熱蒸気に対応 |
| メインハンドに持って左クリック | 250 mBを使い、蒸気で前へ踏み込みながら振り下ろす。基礎ダメージ45。攻撃速度は1.25 |
| 命中 | ノックバック、14 tickのめまい、80 tickの移動速度低下V。めまい中は移動・ジャンプ・攻撃・アイテム使用が止まり、解除後は移動速度が通常の約4分の1になる |
| 右クリック長押し | バニラの盾と同様に正面をガードする。蒸気消費なし |

振り始めの3～6 tickに、現在位置から通常の近接リーチで最初の対象を一度だけ判定する。ガード、持ち替え、スタンは判定中の振りを中断する。ブロックで遮蔽されるか外れた場合も、振り始めに使った蒸気は消費される。既存のPvP設定、チームの同士討ち設定、ダメージ軽減、ノックバック耐性を尊重する。

## 主要ファイル

- `item/SteamHammerItem.java` と `item/SteamHammerAction.java` がサーバー側の充填残量、振り、踏み込み、命中とガードを管理する。既存の携帯器具の流体処理・保存を使う。
- `safety/DazedEffect.java` がめまいの属性修正と行動制限を実装する。蒸気銃の攻撃もめまい中は止める。
- `client/SteamHammerClient.java` と `mixin/SteamHammerSwingMixin.java` がガード姿勢と振り下ろしを描画する。見た目は真鍮ボイラー、銅の排気管と計器、鋼の打撃面、革を巻いた柄を組み合わせた。
- `tools/generate_steam_hammer.py` で立体モデル、ピクセルシート、めまいアイコン、メカニカルクラフターのレシピとPonder構造を再生成できる。

## 初回実装の検証

- Java 21、Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10でGradleビルドに成功した。専用サーバーGameTestの32件が合格した。新規試験は打撃のタイミング、有限の蒸気消費、壁、ガード、スタン中の攻撃拒否、ノックバック、スタン解除後の速度上昇を確認する。
- Ponderと3言語の翻訳の静的検証が合格した。全体外観監査は変更前からある硫黄スクラバー液バケツ画像の参照で失敗する。
- RTX 4060の日本語クライアントから通常の攻撃キーを入力し、開始時点で近接射程外の相手へ蒸気で踏み込んで命中させた。サーバー側で移動、ダメージ4、蒸気250 mB消費、めまいと速度上昇を確認し、クライアントで振りのアニメーションを受信した。同じワールドで使用キーによるガード、Ponderおよびモデルの描画を確認した。
- 音声デバイスのない検証環境のため、効果音の実際の再生は未確認。配布用JARは圧縮のみ変更し、Gradle出力と全エントリーの内容が一致することを確認した。
