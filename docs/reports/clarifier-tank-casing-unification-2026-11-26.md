# 沈殿池のライニング槽壁をタンク構成へ統一

実装コミットは 。円形沈殿池の外壁と床は通常の円形タンクと同じタンク構成ブロックを使う。センタードライブと底面流入口で沈殿池として形成する。[現行の組立と入出力](../wet-processing.md)

- [古い登録IDの変換](../../src/main/java/net/createplant/registry/CELegacyIds.java)で、設置済みのライニング槽壁とアイテムをタンク構成ブロックに読み替える。現在と以前の名前空間の両方を扱う。
- [壁の保存データ読み込み](../../src/main/java/net/createplant/mixin/ClarifierWallLoadMixin.java)では、壁と稼働中の各ポートが旧ブロックエンティティの型を共有しているため、変換先のブロックがタンク構成の場合に限って型を切り替える。在庫と工程進捗はセンタードライブのデータに含まれる。
- 旧壁の専用レシピ、モデル、採掘タグ、戦利品、3言語の名前と自動生成元を削除した。施設建設機とPonderの既存データはタンク構成ブロックを使用している。
- Java 21 / NeoForge 21.1.219でGradleビルド成功。湿式処理、施設建設、クリエイティブタブ、旧ID読み込みの関連GameTest 26件が通過した。旧壁のブロック・アイテムと共有型の読み込みを旧NBTで確認した。配布JARとPonder構造データも確認した。
