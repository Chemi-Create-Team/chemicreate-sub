# JEIでアンモニア合成の原料をたどれるようにした完了レポート

- 日付：2026-11-18
- 実装コミット：このレポートと同じコミット（`git log -1 -- docs/reports/jei-haber-bosch-feed.md`で確認）

## 指示

JEIでハーバー・ボッシュ反応（アンモニア合成）の原料が「圧縮合成原料」になっていて、水素と窒素が見えない。直す（ユーザーの選択：仕組みは変えず、JEIの表示だけ補う）。

## 原因

原料は「水素750 mB＋窒素250 mB → 合成ガス（撹拌槽）→ 往復式圧縮機で圧縮合成原料 → 反応塔」の3段。JEIには撹拌槽の合成ガスのページと反応塔のページはあったが、圧縮機のページがなく、圧縮合成原料からさかのぼれなかった。反応塔のページの注記は熱の条件だけで、しかもCreateの翻訳キーに`create.`を付けていなかったため「recipe.heat_requirement.heated」とそのまま表示されていた。

## 実装

| 部分 | 内容 |
| --- | --- |
| JEI「ガスの圧縮」（新カテゴリ） | 往復式圧縮機（シリンダーも触媒欄に表示）。圧縮機が実際に使う変換表（`thermal/Compression.java`の`steps()`）から作る4件：空気 → 圧縮空気、合成ガス → 圧縮合成原料、水素 → 加圧水素 → 圧縮水素。注記「往復式圧縮機で圧力を1段上げる。16 RPM以上。量は変わらない。」。これで反応塔の原料 → 圧縮 → 合成ガス → 撹拌槽（水素・窒素）とたどれる |
| JEI「アンモニア合成」の注記 | 「原料＝水素3：窒素1の合成ガスを1段圧縮。熱：加熱が必要」。JEIの注記は2行までしか表示されないので短くした |
| 熱の表示の不具合 | Createの熱の条件の翻訳キーに`create.`を付けた。同じ不具合が、反応塔・撹拌槽・吸収棚段のJEIの注記と、ふた付き槽のゴーグル表示にもあったので、まとめて直した |
| JEIの確認処理 | `verifyRecipeTrace`（`createplant.recipeTraceCheck`で実行）を、圧縮合成原料 → 反応塔、合成ガス → 圧縮機、水素＋窒素 → 合成ガスの順に確かめる内容に直した（以前は合成ガスが反応塔に直接入るという、今の仕組みと合わない確認だった） |
| 翻訳 | `tools/generate_reaction_tower.py`に3言語で追加。使われていなかった古い`note.haber_bosch`の定義を`tools/generate_uranium_assets.py`から削除 |

## 確認

- `compileJava`成功。`validate_translations.py`合格。
- 実画面（日本語、JEIの確認処理を有効にして起動）：「RECIPE TRACE PASSED」。`docs/quality/jei-haber-bosch/haber-bosch.png`（注記が2行に収まり、熱が「加熱が必要」と表示）、`docs/quality/jei-haber-bosch/gas-compression.png`（ガスの圧縮のページ、1/4）。
- 未確認：撹拌槽・吸収棚段のJEIページとふた付き槽のゴーグルでの熱の表示は、画面では見ていない（撹拌槽の撮影は別のJEIページが開いた）。同じ修正なので表示されるはずだが未確認。
