# 塩水の銅管腐食を修正

実装コミットは `a43f8ba`。

- `FluidHazards` の塩水を腐食区分「なし」に修正した。常温・常圧の塩水をCreate標準の銅管・ポンプ・流体タンクで搬送できる。機材の温度・圧力定格は引き続き適用する。
- 通常バケツと耐食合金バケツで塩水を汲める。耐食合金バケツで汲んだ既存の塩水も、空にすると元の材質のバケツが返る。
- 配管仕様書と塩水を製造するPonderの日英中字幕を更新した。
- Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10でJARをビルドした。配管、液体バケツ、腐食接触、ソーダ工業のGameTest 31件が成功した。銅の流体タンク間で塩水が移動し、途中の銅管とポンプの摩耗がゼロであることを確認した。字幕はファイルを検証し、クライアントでの目視確認は省略した。
