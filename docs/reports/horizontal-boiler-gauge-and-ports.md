# 横型流体タンクのボイラー計器と蒸気の配管

実装コミット `0646937e7dc38e8f6caaec6cf5ec2e8ff1ece4f9`

## ゲーム内の変更

- 水か温排水を入れる横型タンクをボイラーとして組むと、Create標準の計器と針が、空いている側面と端面の中央に現れる。蒸気エンジンを付けた場合、針はCreate標準のボイラー値を示す。
- 上面と長さ方向の両端面に付けたCreateの配管から、対応する列に貯まった蒸気を取り出せる。給水は長辺の側面、給排水は底面で行う。蒸気の生成前、蒸気切れ、設置したバーナーの燃料切れでも、蒸気口から水は出ない。バーナーを外して残った蒸気を取り出すと、通常のタンクに戻る。
- 「横型流体タンク」と「横型タンクで蒸気を作る」のPonderで接続面を更新した。後者は断面1×1、2×2、3×3の全シーンを更新した。

## 実装と計算

- `HorizontalTankBlockEntity` は都度マルチブロックの制御部品を参照する流体ハンドラーを公開する。蒸気面は同じ列の下段の末端に接続する。各列の蒸気バッファーは従来どおり最大16,000 mBで、各末端が保存する。共有の給水タンクと各列の沸騰条件を維持した。
- 制御部品は各列の蒸気量の合計を `16,000 mB × 断面幅` で割り、1%単位で針の位置を同期する。稼働状態の変化は即時に反映し、稼働中は5 tickごとに充填率を確認する。クライアントでは針の位置を補間する。
- `HorizontalTankRenderer` は Create の `BOILER_GAUGE` と `BOILER_GAUGE_DIAL` を使用し、X・Zの実寸でモデルの中心と突出量を決める。`ProcessPorts` は配管ガイドに蒸気出口を表示する。

## 検証

- Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10。Gradle `build` 成功。炉の制御テストと物理テスト1,668件のチェックも成功。
- 専用サーバーの対象GameTestは26件すべて成功。実ポンプでの中央上面と端面の搬出、停止と再始動、燃料切れ、ボイラー解除、X・Z両方向の断面2×2・3×3での入出力、保存と分割、水・蒸気の総量を確認した。
- RTX 4060のMinecraftクライアントで、長さ5・断面2×2の加熱した実タンクの長辺と端面に計器と針が表示されることを撮影した。Ponderは構造NBT内のポンプの位置と向き、3言語の字幕キーを検査した。Ponderのクライアント再生と実ワールドでの蒸気エンジンの針の動きは未確認。
