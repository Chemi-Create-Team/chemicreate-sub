# 核燃料とアルミの生産ラインのテストワールド

実装コミット `0eda463fdad6542c41d4a73cb6c28cd5f2dfc263`

## 配布物と構成

- [核燃料生成ライン](../playtests/uranium-fuel-line-world.zip)。ゲーム内のウラン鉱石を実物のクラッシングホイールで粉砕し、焙焼、反応棚段、攪拌槽、遠心分離機4台、粉末化、プレス、かまどを経て焼成ペレットをチェストへ出す。通常燃料棒を最後に手作業で組み立てられるよう、作業台と被覆管を置いた。
- [アルミ生産ライン](../playtests/aluminum-production-line-world.zip)。ボーキサイトと充填済みの苛性ソーダを溶解槽に入れ、液を超過熱の析出槽へ送り、アルミナをホッパーで溶融塩電解炉へ送る。電源は配線済みの Create: Electro Energetics のクリエイティブバッテリー。溶解槽は原料を投入するまでレバーで停止する。
- どちらもクリエイティブから開始し、原料は投入口と分けて格納した。設備間の物資はゲーム標準のホッパー、シュート、ファンネル、ポンプ、配管で運ぶ。試験用の原料の用意と電源にクリエイティブ設備を使用する。

## 修正

- Create の砕いたウラン原石が出ると焙焼できなかった。`blasting/roast_raw_uranium.json` の入力を両方の原石が含まれる `uranium_roasting_feed` タグに変更した。ワールドの仕分けも両対応にして、還元塔のファンネル真下でホッパーが生成物を受け取る構成にした。
- `ReactorMachineBlockEntity` の候補レシピ順を、材料の種類数が並ぶ場合は強い加熱条件を優先するよう変更した。通常加熱ではアルミン酸ナトリウムの結晶が生成され、超過熱では溶液500 mBからアルミナ1個と苛性ソーダ400 mBを得る。

## 検証

- 配布ZIPを展開したセーブで両ラインを再運転した。アルミはボーキサイト16個から1,900 tickでインゴット8個を搬出し、苛性ソーダ3,200 mBと鉄塊24個を回収した。核燃料は鉱石32個から3,740 tickで焼成ペレット8個を搬出し、作業台のレシピで通常燃料棒1本に組み立てられることを確認した。
- GameTest は49件中46件が成功した。残る3件は以前から失敗する熱交換器の温度2件と、ホウ砂の反応選択1件。溶解槽と析出槽、Createの粉砕結果の焙焼、遠心分離機と電解炉の関連テストは成功した。
- JARをビルドし、焙焼用タグが収録されていることを確認した。配布ワールドの確認にはNeoForge専用サーバーを使用した。クライアントでの外観と、小型炉用燃料の分岐は今回の確認範囲外。
