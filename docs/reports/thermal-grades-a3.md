# 温度・圧力等級化 A3：弁と計器

2026-11-14。仕様書4.2に基づく段階別記録。実装コミット：`2029590c`。

## 変更

安全弁・信号式逃がし弁・背圧弁を登録、実装、レシピ、モデル、タグ、翻訳、Ponder部品から削除。生成元も削除済みの設備を出力しない。旧連続圧力の弁専用試験を、等級と実搬入口の試験に置き換えた。

減圧弁は向きのある搬入口・搬出口を持ち、対応表で一段低い等級の流体へ変換する。対応のない流体は同量で通す。出口を塞ぐと保持し、SIMULATE・保存・再読込で量は変わらない。出口へは別のポンプを接続する。

圧縮の共通表 `Compression` に合成ガス→圧縮合成ガス、水素→加圧水素→高圧水素を登録。圧縮機での生産は次のA4で接続する。水素を常圧から高圧にするには2段必要。

配管の温度計・圧力計は種類から等級を読む。針・警報設定・比較器出力も等級を使用し、圧力計の信号は常圧0・加圧8・高圧15。圧力の実数しきい値とPID発信器の圧力モードを廃止した。流量計・液位のPIDを維持。

除害装置は下面から直接ガスを受け、苛性ソーダと同量だけ中和する。薬液不足・閉塞・不適合ガスは拒否し、SIMULATEでは消費しない。フレアは従来どおり直接配管から有限量の燃料を受ける。

## 検証

- `build` 成功。
- GradeControls・Pressure・Flare・ToxicGas：15件すべて合格。
- 減圧弁：1,300 mBの高圧水素から1,300 mBの加圧水素。保存後に取り出しても同量。
- 除害装置：苛性ソーダ700 mBで気体1,000 mBのうち700 mBだけ受入。
- フレア：容量64,000 mB。最初の排出32,000 mB、炎高14〜15ブロック、最終燃焼64,000 mBで停止。再読込でも総量を保持。
- 翻訳：日英中4,613キー一致。Ponder 140シーンの本文・96追加シーンの構造・製造27系統の検証を合格。
- NVIDIA RTX 4060でクライアント実行。全140 Ponderをコンパイルし、タンク材質・減圧弁・フレアの3シーンを実描画して `CLIENT QUALITY PASSED`。減圧弁の等級説明とモデルを目視確認。結果は `docs/quality/thermal-grades/a2-a3-client-result.json`。
