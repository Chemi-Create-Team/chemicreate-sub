# ふた付き槽の内面・断面の材質

- 作業ベース：`c2979e9b`。
- 実装コミット：`ac5fc53b`。
- 環境：Java 21、Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10、NVIDIA RTX 4060。
- 対象：槽の内壁・床・ふた裏、板の切り口、窓の開口部の厚み。

## 変更

内壁・床・ふた裏に使っていた `reactor/silver/frame` は、縦の帯が強い外装用のフレーム画像だった。これを、既存の `reactor/steel` に変更し、鋼板の面取り・陰影・留め具を表示する。

板の薄い切り口と窓の開口部の厚みは、粒状感のある `lidded_vessel/internal/steel` を共通の鋼肌材として使う。UVは既存の16 px/ブロックの割り当てを使用する。ハッチを開いたときの裏面にも、面全体の鋼板の模様が見える。

ふたの取っ手・蝶番・ドレンの金具には専用の参照変数を設け、内面材と分けた。3×3の連結天板・底板は、前回のCreate式の鉄灰色の素材を使用する。

## 主要ファイル

- `tools/generate_lidded_vessel.py`：槽の内面・床・縁の材質の正本。モデル生成だけを実行し、既存の画像全体は再生成していない。
- `models/block/lidded_vessel/cell_*.json` と `models/item/lidded_vessel.json`：生成元と同じ材質を参照。
- `LiddedVesselRenderer`：ふた裏、板の端、窓の厚みの材質を変更。金具用の素材参照を内面から分ける。
- `LiddedVesselWindowModel`：3×3の連結天板と重複する上端面の判定を、新しい縁の材質へ合わせる。
