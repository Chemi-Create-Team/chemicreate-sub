## 変更内容

### 構造

- 3×3×2 → 5×5×3 に拡大した。上段の中央が炭素陽極、母線は上段の側面中央の外側に付ける。
- 外殻の作成数は、1回8個に増やした。
- 機能は変えていない：CEE直結、2 Ω、熱・電解の計算、入出力の面、停止理由。

### 形の切り替え

- 外殻に `cell` 状態（0～74は位置、75は未形成）を追加した。
- 制御部が形成時に各外殻の位置を設定し、解体時に未形成の形へ戻す。
- 浴が溶けている間は、すべての部品を `lit` にする（浴の面と覗き窓が光る）。

### 各部の形（`tools/generate_electrolysis_furnace.py`）

| 部分 | 形 |
| --- | --- |
| 下段の架台 | 奥へ下げた黒鋼の板、鋳鉄の桁・脚・補強 |
| 中段の外装 | ステンレスの外装、各側面に3ピクセル奥まった覗き窓の帯（窓台とまぐさ付き） |
| 上段の縁 | 耐火レンガで笠木を付けた壁、外周を巡る白い配管と受け金具。側面中央には、母線の貫通部 |
| 角 | 4段で面取りした八角形。白い配管の柱とフランジ |
| 内側 | 電解浴の面（固まった状態／溶けて光る状態） |
| 電極ユニット | 黒鉛電極4本（締め具2段）、鋳鉄の梁、4本の案内柱、ステンレスのハブ、ハブから延びる白い配管 |
| 母線 | 黒鋼の架台、炉の縁を越えるアルミ母線（実際のアルミ精錬所と同じ材質）、白い碍子と端子。CEEの端子位置も碍子の上に合わせた |

### テクスチャ

- 新規：ステンレス、鋳鉄、黒鋼、白い配管、アルミ。いずれも、このMODの金属表現（反射の帯、面取り、リベット）で描いた。
- 新規：耐火レンガ、奥まった覗き窓（消灯・発光）、電極、締め具、碍子。
- 既存設備とは共有しない。赤と銅はやめた。

### モデル

- すべての面にテクスチャ座標（UV）を明示した。ブロックの外へ伸びる部品が、テクスチャ置き場の隣の絵を拾わないようにするため。

### Ponder

- 新しい形に合わせて構造データを作り直した。
- 母線を手前の面へ移し、下の支えをなくした。
- 字幕の寸法と説明も更新した。

## 未検証・制約

- ゲーム内でプレイヤーが組み立てたときの見え方は、Ponderの画面だけで確認した。ワールドに設置した状態は撮影していない。
- 電極ユニットと母線は、ブロックの外へ大きく張り出す。当たり判定は1ブロックのままなので、張り出した部分には触れられない。
- 外殻が増えたので、1基あたりの材料（鉄板・レンガ・石炭ブロック）は増えた。

## 追加修正：電解浴の面の色

- 指摘：上部のオレンジ色が目立ちすぎる。
- オレンジ色は溶けたアルミニウムではなく、電解浴（溶融塩）の面だった。
- 実際の電解炉では浴の上がアルミナのクラストで覆われるため、金属色に変えた。
  - 冷えている間：灰色のクラスト。
  - 溶けている間：銀色の反射の帯と、継ぎ目のかすかな暖色。
- 稼働の目印として、側面の覗き窓の光は残した。
- 確認：実クライアントでPonder全90シーンが合格。電解炉の画面を拡大して目視した。
