## 最初の実行で確認すること
1. チャットとログに出る「作れなかった設備」。配管の経路が空いていない、ポートの位置が違う、などはここに出る。
2. 焙焼槽 → 吸収塔 → 電解セル → 硫酸の母管まで、二酸化硫黄が届くか（硫黄サイクルのワールドの配置を流用している）。
3. 母管の3本（アルミニウムの浸出槽・リチウムの槽・酸の槽）に硫酸が届くか。
4. ホッパーでの受け渡し（焼結鉱 → 還元槽、アルミナ → 電解炉）。ホッパーは、受け側の最下層と同じ高さでしか横に渡せない。そのため還元槽は焙焼槽より1段低く、電解炉の殻も高さを合わせてある。
5. 沈降槽の駆動（4 RPM）と、電解セルの始動（ニッケル板・START）。

## 既知の弱点（コードを読んだ範囲）
- 沈降槽の駆動の入力面が合っているか未確認。泥の排出もない。
- 電解採取セルの金属は電極ヘッドに溜まり、自動では出ない。
- 三酸化硫黄は貯槽止まり。電池の希硫酸は創造タンク。
- 撹拌槽が原料を保持する修正（`386855f`）が入った main の上で作っている。

## 実行方法とセーブの置き場所
`./gradlew runClient -Dcreateplant.batteryPlaytest=true`（または `-I docs/playtests/battery-playtest.gradle`）。保存されたワールドを zip にして `docs/playtests/` に置く（燃料のワールドと同じ）。失敗した設備があれば `run/battery-playtest-result.json` と `run/logs/latest.log` の `BATTERY PLAYTEST` を共有する。
