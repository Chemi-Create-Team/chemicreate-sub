# ガスタンクコンテナ

## 実装内容

- 新しいブロック`gas_tank_container`を追加した。コンテナ規格のオレンジの枠に、白い八角形の横置きタンクをはめ込んだ気体タンク。
- 既存の横置き液体タンク（大きさ自由）はそのまま残し、別ブロックとして追加した。
- 仕組みはCreateのタンク（`FluidTankBlockEntity`）をそのまま使う。
  - 既存の`HorizontalTankBlockEntity`を継承する（容量、保存、どの面からでも配管できる共有在庫、ブロックを壊したときの中身の扱いはCreateのタンクと同じ）。
  - 形成できる大きさは、断面の幅に応じた長さまでに制限した：幅1は長さ2、幅2は長さ5、幅3は長さ7（`getMaxLength`）。
- 完成判定
  - Createがタンクを組み直すたびに、各ブロックが自分の幅と長さを確認する。決まった大きさのときだけ`size`（幅）と`cell`（断面の中の位置、横＋幅×上下）を状態に持つ（`shaped`）。
  - 完成していないブロックは`size=0`。配管の口を公開せず、ゴーグルに「断面N×Nは長さちょうどL個で完成」と表示する。
  - 完成判定は、ブロックエンティティが保持する状態ではなくワールドの状態から読む。ブロックを置いている途中に形を変えると、保持している状態が古いまま残るため。
- 中身は気体だけ（`CETransport.gas`のフィルター）。定格は気体レシーバーと同じ50 barで、壁の温度上限は500 °C（`EquipmentSafety`）。外気との熱のやりとりあり（`PassiveTank`）。
  - 気体レシーバーと同じく、水と蒸気はこの部品の共通処理（`PhaseTank`）で1つの相として扱われ、フィルターを通らずに入る。
- このための小さな変更：`HorizontalTankBlockEntity`に定格の差し替え（`ratingBar`）と状態の追加（`shaped`）を加えた。既存の横置きタンクの動作は変わらない。
- 見た目は3Dモデルで作った。
  - **枠**：4本の長手のレール、両端の四角い枠、角の隅金具。完成したタンクの各ブロックが、自分にかかる部分を描く。
  - **タンク**：八角柱の胴と、両端のふた。
  - **端の筋かい**：ひし形。
  - タンクと筋かいは、断面ごとに1ブロック（中央、2×2では最初の角）が丸ごと描き、隣のブロックまではみ出させる。これで2×2・3×3でも八角形が途切れない。並べただけのブロックは1個分の閉じたコンテナとして描く。
  - モデルの部品が隣のブロックにかかるため、環境光の陰（ambient occlusion）は切った。
  - 同じ作業の途中で作った「平面テクスチャのつながる表示」は、八角形の3Dモデルに置き換えたので残していない。
- レシピ：鋼鉄インゴット4・鉄板4・気体レシーバー1で4個。
- Ponder「ガスタンクコンテナ」を追加した。3つの大きさを並べて、置き方、決まった大きさ、気体専用・50 bar・どの面にも配管できることを説明する（`tools/generate_gas_tank_container.py`）。

## 主要ファイル

- `block/GasTankContainerBlock.java`、`block/entity/GasTankContainerBlockEntity.java`
- `block/entity/HorizontalTankBlockEntity.java`（定格と状態の追加用の差し替え口）
- `registry/CETransport.java`、`CreatePlant.java`（配管の口の登録）、`ponder/PlantPonderScenes.java`（完成前の表示）
- `tools/generate_gas_tank_container.py`（テクスチャ・モデル・ブロックステート・ルート・タグ・翻訳・Ponderの正本）、`tools/generate_crafting_recipes.py`

## 確認

- GameTest `GasTankContainerGameTests`
  - 3つの大きさがそれぞれ1つのタンクになり、全ブロックで配管の口が開くこと。
  - 2×2で長さ3の並びや1個だけのブロックはタンクにならず、口も開かないこと。
  - 液体（軽油）は入らず、窒素ガスは入ること。
  - 1個外すと完成が解けること。
  - 戻すと再び完成し、中身は外したブロックの分（1/20）だけ減ること。これはCreateのタンクと同じ扱い。
- 既存の`HorizontalTankGameTests`も合格した。GameTest全体を実行し、失敗は以前からある汚れの試験（`aFouledProcessStopsThenResumesAfterOneManualBrush`）1件だけだった。
- Ponderの撮影（`docs/quality/tanks/gas-tank-container.png`）で、1×1×2・2×2×5・3×3×7の八角形のタンク、枠、端のひし形の筋かいを確認した。クライアントでは140シーンすべてが開けた。
- 未確認：実際のプレイでの置き心地、からくり（Createの組み立て）での移動、多数設置時の描画負荷。

## 注意

- 完成しているかどうかで配管の口が開いたり閉じたりする。ブロックを1個壊すと、直すまでタンク全体が使えない（中身は残る）。
