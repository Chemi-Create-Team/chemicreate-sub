# ステンレス溶融・鋳造・圧延ライン

ワールドと手順は[ステンレス製造ライン](../playtests/stainless-casting-line.md)から開ける。実装コミットは `c804143d180fc972ec38a64321c5f30dbc800c2c`。検証用Modは `0.3.4`。

- `82054ba` の溶融、800 mBのスラブ鋳造、2段以上のスタンドによる圧延を使用した。4チャージで溶融ステンレス2,400 mB、鋳造スラブ3個、完成インゴット24個になる。臨時の直接鋳造レシピは追加していない。
- `gametest/StainlessCastingGameTests.java` がミキサー、ステンレス製の配管・ポンプ、プレス、2段の圧延、ホッパー、回収チェストまでの配置を作り、レバーの操作後に通常の設備処理だけで製品を回収する。圧延スタンドは30 RPMと40 RPM。
- `ponder/SteelworksPonderScenes.java` と `tools/generate_stainless_casting_ponder.py` に溶融と鋳造の説明を追加した。圧延の説明は鋳造スラブからも開ける。既存の製造ガイドの数量と説明を更新した。
- ビルドと新しい通しGameTestが成功。保存したZIPは開始前の配置とし、解凍したコピーを専用サーバーで読み直してレバーを切り替えた。759 tick目に完成品24個へ到達した。レバー操作は45 tick目、鋳造槽に入った溶湯の最大残量は1,000 mBで、完了時の残りは0 mB。配管損耗は0。
- Ponderのテンプレートと3言語の本文・見出しを照合した。全体の言語検査には、ベースのPVCレッスン `manufacturing_pvc.step_4.lesson_pages.0` の書式エラーが残る。
- 関連GameTestの全件実行は50件中49件成功。残る1件は既存の英語版蛍石ガイドの `50%` を書式指定子として扱う検査で失敗した。対象の翻訳文字列と検査は `82054ba` から変更されていない。
- 圧延機の更新 `d71bdcc` を取り込んだ0.4.1でも、ステンレス製造の通しテストと連続加工設備の関連テストが16件すべて成功した。
