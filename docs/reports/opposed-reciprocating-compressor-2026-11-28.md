# 対向式コンプレッサーの外装と駆動

対象バージョンは `0.6.2`。実装コミットは `6cb53dfff8d144e57f545e766e239784645628cf`。

- 新規設置の既存駆動部を1ブロックの中央ケースにした。左右2マス先に既存シリンダーを置き、間を1マス空けると片側ごとに角筒が現れる。背面のCreateシャフトを駆動源とし、空きマスを塞ぐとその側だけ接続が切れる。既存ワールドの旧取付方式とシリンダーの在庫に対応する。
- 上面レンチで12×12 pxの窓を切り替える。角筒は外寸10×10 px、壁厚1 px。コンロッドとピストン棒の断面は2×2 px、ピストンは直径8 pxの八角形。
- クランク半径2.5 px、コンロッド長12 px。実軸角からクランクピンの上下変位を取り、水平投影を `sqrt(12² - 上下変位²)` で求める。左と右ではクランクピンの位相が180度ずれる。クロスヘッドとピストン棒が行程5 pxを水平に往復する。
- 気体の吸入は上面、吐出は下面。両側のシリンダーで駆動部1台分の流量と軸仕事の上限を共有する。シリンダーの在庫は個別で、接続が重複しても一つの駆動部だけが処理する。
- 外装と可動部の生成元は `tools/generate_reciprocating_compressor.py`。Ponderと日・英・中の字幕を更新した。

## 検証

- 対象GameTest 9件を通過。旧取付、通常設置、Createレンチでの窓の切り替え、左右の圧縮、片側の閉塞、共有シリンダーの所有権と解体後の再接続を確認した。
- モデルのケース、窓、角筒、棒とピストンの寸法を検査し、RTX 4060の開発クライアントで実ワールドの両側駆動と日本語Ponderを確認した。
- 検証はコアModで実施した。大規模設置時の負荷測定と実際の旧プレイヤーワールドの再ロードは未実施。
