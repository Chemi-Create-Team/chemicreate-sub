# 水性ガスから合成燃料・工業樹脂まで

対象は Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10、JEI 19.27.0.343。作業基点は `5149cea0a4356814a223b06fad890e68d3f89397`。実装コミットは `50e9a2d9717d0049611ccfe863d5417a617ec653`。 骨粉のテスト修正は `37c32ed`。

## 調査結果と採用した設計

- `GasifierBlockEntity` は 3×3×6 の構造、既存の燃料・蒸気入口と屋上のガス出口を持つ。通しテストに実物を使用した。
- `AbsorptionTowerBlockEntity` は採用済みの4〜8段の塔を使用する。下側にガス、上側に洗浄液を入れ、上側から精製ガス、下側から脱硫排液を取り出す。水性ガスの脱硫と脱炭酸を1段のアルカリ洗浄として扱う。捕捉成分は既存の脱硫排液に集約し、石膏回収へ送れる。
- `ReactionTowerBlockEntity` は 3×3、3〜12段の触媒バスケット付き容器を使う。底段側面が原料入口、底段と底面が製品出口。触媒は各稼働段に同じ種類を入れ、反応を完了した段で耐久を1消費する。複数製品はフィルター付きのポンプで分けられる。
- `FractionatingColumnBlockEntity` は2×2の断面を使い、東側の入口と北側の各留分出口を持つ。新しい留分にも既存の高さ・物性順・貯蔵上限・生産計測が適用される。
- 新しい工程は固定バッチを読む共有 `ProcessRecipe` に追加し、既存のポート・貯蔵・構造・処理のロジック、バーナーの加熱判定をそのまま使った。反応塔のFTでは一酸化炭素、水素の両方に同じ加圧等級が必要。原料比は1バッチが消費する量の比率。

## 追加した工程

4種の触媒コアを追加した。各コアは4,000バッチ分の耐久を持ち、取り出したコアは素材を足すクラフトで再生できる。7種の流体とそのバケツ、パラフィンワックスを登録した。精製合成ガスと加圧一酸化炭素の漏出は既存の一酸化炭素系、軽質オレフィンガスの漏出は既存の可燃性ガスと同じ処理に接続した。

次の数量はゲーム内の1バッチあたりの mB。加熱・圧力表示はゲーム内の等級を使用する。

## JEIとゲーム内案内

- 流体と対応するバケツの双方で工程を検索できる。JEIのバケツ検索は対応する流体へ展開し、Createミキシングなど既存カテゴリーも対象にする。
- 反応塔には専用の触媒枠があり、耐久消費を枠の表示とツールチップの両方で確認できる。触媒にUを押すと対応する反応が出る。ZSM-5のUには2系統が出る。
- 反応・吸収・分留の詳細枠には、最低段数、加熱、原料の圧力等級、消費・生成量、処理時間、2つの気体を取る工程の投入比を表示する。既存の温度・圧力設計に合わせて等級を表示している。
- コア・樹脂・主要な流体とバケツにShift時の加工先を追加した。反応塔・合成原油分留のPonderを追加し、ガス化炉・吸収塔の既存Ponderに製造ラインへの分岐を追記した。
- 触媒コアの通常クラフトは作業台の既存JEI転送経路を使う。塔の原料自動投入はワールドのポンプとファンネルで行う。これらの塔にインベントリメニューがないため、JEIの「＋」から配管や塔へ自動投入するRecipeTransferは保留。

## 主なファイルと制約

- `chemistry/ProcessRecipe.java`、`chemistry/SynthesisProcesses.java`、`data/create_refinery_n_reactors/process/synthetic_fuels.json` が既存の固定レシピ表と同梱データを統合する。圧力反応・混合・クラフトは元のデータパック用RecipeTypeに登録している。塔用の同梱JSONは起動時に読み込む。サーバーの `/reload` による上書きは保留。
- アイテム・流体登録は `registry/CEItems.java`、`registry/CEProcessFluids.java`、気体の扱いと分留順は `transport/FluidHazards.java`、`thermal/FluidMaterials.java`。一酸化炭素の等級変換は `thermal/Compression.java`。
- JEIは `compat/jei/PlantProcessCategory.java`、`CreatePlantJeiPlugin.java`、`SynthesisRecipeLinks.java`。Shift案内は `client/SynthesisGuide.java`。英語、日本語、簡体字中国語を追加した。
- `gametest/SyntheticFuelsGameTests.java` は既存設備で通し工程と触媒別の反応を検証する。既存の分留テストは全レシピをテスト範囲内のグリッドで検証するよう更新した。冷却とHaber–Boschの表示テストは、現在の専用冷却と圧縮済み原料を検証する形に更新した。

- 翻訳、Ponderの字幕・構造、チュートリアル、`git diff --check` は成功した。
- 配布JARは8,382,794バイト。配布サイズに合わせてZIPの空ディレクトリエントリーを省き、Gradle JARに含まれる実ファイルをバイト単位で照合した。SHA-256は `1f02af238fa293c359d2439185191ef884a1ae98e29d4df02b726e6a1570843d`。
