## 方針（ユーザーの選択）

- 脱硫は任意の工程。今までの軽油の扱いは変えない。
- クラウス法は2段（燃焼炉と反応器）。
- ブレイズパウダー・ネザーラックからの既存の硫黄の入手方法は残す。
- 二酸化硫黄の物性を正しい値にする。

- **流体**（`CEProcessFluids`）：加熱軽油、高温／冷却した脱硫反応液、低硫黄軽油、硫化水素。設置できる液体源とバケツは持たない（工程流体と同じ扱い）。

- **危険性**（`FluidHazards`）：加熱軽油623 K、脱硫反応液650 K・16 bar・腐食性、硫化水素は腐食性の気体。脱硫反応液は強化パイプでだけ安全に運べる。
- **物性**（`FluidPhase`）：
  - 硫化水素：分子量34.08、沸点212.8 K、蒸発熱548 kJ/kg、臨界373.1 K・89.63 bar、液密度0.95。
  - 二酸化硫黄：分子量64.066、沸点263.13 K、蒸発熱389 kJ/kg、臨界430.64 K・78.84 bar、液密度1.46。
  - 軽油系の新しい流体は、既存のCDG軽油と同じ値。
- **触媒**：水素化脱硫触媒（`hydrotreating_catalyst`）。
  - レシピ：鉄触媒の上下にラピスラズリ（コバルトの青に見立てる）、左右に銅板。
  - アイコン：他の触媒と同じ外枠に、青い押出成形品の充填。
- **最低圧力**：`ProcessRecipe` に `minimumPa` を追加した。
  - `ReactorMachineBlockEntity` は、気体の入力槽の圧力（`FluidPhase.pressure(槽, CAPACITY)`）が足りないレシピを実行しない。
  - 原料はそろっているのに圧力だけが足りない場合は、停止理由を `pressure`（「水素を必要な圧力まで上げてください」）にする。
  - 判定はレシピの再選択時だけで、停止中に毎tick計算しない。
  - JEIの注記にも必要な圧力を表示する。
- **燃料**：
  - 低硫黄軽油を `c:diesel`・`c:fuel` の流体タグに追加した。CDGの燃料定義（`#c:diesel`）がそのまま当たる。
  - 工業用加熱器の燃料値は軽油と同じ34000。
  - 別の流体なので、脱硫の入力（CDGの軽油）にはならず、繰り返し脱硫して硫黄を増やすことはできない。

- **生成元**：`tools/generate_desulfurization.py`。触媒の画像・モデル・レシピ、クラウス法のレシピ、タグ、翻訳、Ponderの配置データとカタログ登録を作る。

## 計算方法

- 気体のmBは物質量に比例する（基準圧力1 bar）。そのため、気体どうしの量はそのまま反応式の比にした。
  - 炉：H₂S + 1.5 O₂ → SO₂ + H₂O（500 : 750 : 500）。
  - 反応器：2 H₂S + SO₂ → 3 S + 2 H₂O（1000 : 500 → 3個）。
- 硫黄の粉1個は、硫黄を含む気体500 mBとした。既存の「硫黄の粉1個 → 二酸化硫黄500 mB」と同じ換算なので、粉 → SO₂ → 粉で増えも減りもしない。
- 水素は、硫黄1個につき1分子（チオール型）を消費する。600 mB入れて、500 mBが硫化水素になり、100 mBが戻る。
- 液体（軽油、水）と気体のmBの間の質量は、ゲーム用の量で合わせていない。既存の工程と同じ扱い。

`hydrotreatingNeedsHotDieselHydrogenPressureAndItsCatalyst` で確認したこと：
- 冷たい軽油は受け付けない。
- 水素が30 bar未満なら停止理由 `pressure` で止まる。
- 触媒がなければ反応しない。
- 条件がそろうと、反応液1000 mBになり、水素600 mBを消費する。
- 高温の反応液は分離塔が受け付けない。
- 冷やした反応液は、低硫黄軽油1000・硫化水素500・水素100 mBに分かれる。
- 低硫黄軽油は `c:diesel` に入り、加熱器の燃料になり、もう一度脱硫できない。

## 未検証・制約

- CDGのエンジンで低硫黄軽油を実際に燃やすことは、ゲーム内で確認していない（確認したのはタグへの所属だけ）。
- 液体硫黄の工程とアミン吸収は省略した。クラウス反応器が直接粉を出し、分離塔が硫化水素を分ける。
- 二酸化硫黄の比熱は、気体の既定値（1000 J/kg·K）のまま。実際は約620。熱の計算にだけ影響する。
- 既存ワールドの影響：圧力をかけて貯めた二酸化硫黄は、20 °Cで約3.2 barの蒸気圧を超えると液化として扱われ、圧力の表示が変わる。mBあたりの物質量は変わらない。
- 日本語の字幕は、数字と「mB」の間で改行されることがある。既存のシーンと同じ書き方。
