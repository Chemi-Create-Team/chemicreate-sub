# 配管4種の廃止・気体への定格適用・ハロゲンと塩基・17段階の目盛り

2026-11-21。ユーザー指定：
- 「液体と同じく温度・圧力・腐食すべて」
- 「樹脂パイプとPVCパイプと保冷パイプと強化パイプは一旦消して。それに応じてポンプも削除して」
- 「耐性にハロゲンと塩基も追加して」
- 「目盛りはさっきあげた通りに実装して」

実装コミット：`b60eff3`、本レポートと同じコミット

## 変更

### 配管とポンプの廃止
- 樹脂・PVC・保冷・強化パイプを削除した。
- それに対応する耐圧鋼・保冷・塩ビ・樹脂ポンプも削除した。強化パイプと同じ定格だった気体・大型気体ポンプも削除した。
- 消したものについて、ブロック、アイテム、ブロックエンティティ、モデル、テクスチャ、レシピ、ルートテーブル、翻訳、クリエイティブタブ、ツールの生成スクリプトから外した。
- 既存ワールドの読み替え（`CELegacyIds`、旧mod IDも同じ）：
  - 金属の管（強化・保冷・気体パイプ）→ステンレス鋼管
  - 樹脂・PVC管→セラミック管
  - 削除したポンプ→ステンレス鋼ポンプ
  - 樹脂管のブロックエンティティ→`material_pipe`
- レシピの材料を置き換えた：フレア先端と耐圧タンクの材料は、強化パイプからステンレス鋼管に変えた。
- Ponderの構造ファイル33件で、ブロック名とブロックエンティティIDを置き換えた。
  - 「流体に合う配管を選ぶ」は、残る5種（銅・セラミック・ステンレス・ニッケル合金・ジルコニウム）の6手順に作り直した。
  - 「塩素とエチレンからPVCを作る」は、最後の手順を防護服づくりに変えた。PVC樹脂は防護服と難燃剤に使う。
  - 気体のポンプのPonderは、ステンレス鋼ポンプでノズルの吸気を示す。

### 気体への定格適用
- 配管・ポンプの損傷判定（`PipeMaterial.problem`）から、気体を対象外にする処理を外した。液体と同じく、温度・圧力・腐食で判定する。
- 例：
  - 通常の蒸気は銅管でよい。
  - 高圧蒸気・過熱蒸気・圧縮水素は、ステンレス鋼管などが必要。
  - 塩素ガスはステンレス鋼管を傷める。
- ステンレス鋼管の温度の下限を極低温に広げた。保冷パイプがなくなっても、液体窒素・液体酸素・液体ヘリウムを運べるようにするため。

### ハロゲンと塩基
- 腐食の種類に`HALOGEN`（ハロゲン）と`BASE`（塩基）を追加した。
  - ハロゲン：塩素・塩化水素・塩酸・次亜塩素酸ナトリウム溶液
  - 塩基：苛性ソーダ溶液・アルミン酸ナトリウム溶液
- 配管の耐性：

| 配管 | 耐える腐食 |
| --- | --- |
| ステンレス鋼 | 酸・塩基 |
| ニッケル合金 | 酸・フッ化物・ハロゲン・塩基 |
| ジルコニウム | 酸・熱い酸・塩基 |
| セラミック | 酸・熱い酸・ハロゲン |
| 圧力弁 | 酸・塩基 |

- タンクの扱いは変えていない。ステンレス鋼タンクは、酸・ハロゲン・塩基のどれも入れられる。

### 17段階の目盛り
- `thermal/GradeScale`：温度と圧力を1行の目盛りで表示する。
  - ◆が5つの等級、·がその間の3段。
  - 定格の範囲は緑、範囲外は灰色。
  - 中身の位置は●で示し、範囲内なら白、範囲外なら赤。
- 表示する場所：
  - タンク・配管・ゴーグルのオーバーレイに出す。Shiftを押している間は、範囲の文を出す。
  - 配管アイテムの説明は、Shiftで範囲の文に切り替える。
  - 1行に収めたので、ゴーグルの行数は増えていない。
- 配管の温度計・圧力計：
  - 17段階の値を同期し、針を17段階で動かす。
  - ゴーグルには目盛りと段階名を出す。
  - 比較器と警報は、従来どおり等級で判定する。

## 未確認・注意
- 既存ワールドでの読み替えは、エイリアスによるもので、実ファイルでは確認していない。
  - 強化管・保冷管にあった中身は、ブロックエンティティの種類が変わるため失われる可能性がある。
- 塩素系の配管は、セラミック（常圧のみ）かニッケル合金が必要になった。既存の塩素の設備でステンレス管を使っている場合は、管が傷む。
- 高圧・高温の気体を銅管で運んでいる既存の設備も、管が傷むようになった。
