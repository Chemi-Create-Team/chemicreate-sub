# 現行実装の索引

更新基準：Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10。実行中のレジストリとクリエイティブタブを `CreativeCatalogGameTests` で読み出した[機械可読一覧](plant-maintenance-data/registry.json)を正本とする。過去のレシピJSONや廃止済み登録の一覧は掲載しない。

## 数と分類

- 自MODのアイテム342種。設備・建材と素材・流体の2タブへ、各アイテムを重複・欠落なく1回ずつ配置する。
- 登録ブロック241種。流体用ブロックやアイテム化されない内部表現も含むため、設備数とは一致しない。
- 流体94種（sourceのみ。flowing登録は別数にしない）。
- Ponder137シーン。日英中の全言語キーは各2,499個、機械音は11種類。

建築部材・設備・槽内アタッチメント・防具は設備タブ。鉱石、粉末、燃料、電極、触媒、流体容器、廃棄物容器等は素材タブ。CDG由来の3種類の燃料バケツは連携用として素材タブに残す。

## 廃止済み設備

`ammonia_oxidizer`、`catalytic_cracker`、`distillation_tower`、`asbestos_mesh`、旧`electrolyzer`は現行アイテム・ブロック一覧に含まれない。反応塔・独立吸収塔・旧3×3遠心分離機に相当する処理はふた付き槽の内部部品へ、槽内の分留・蒸留は分留塔へ統合した。

過去の`docs/reports/`は当時の調査記録として残す。現在利用できる設備の判断には、この索引・レジストリ一覧・現行の個別文書を使用する。全アイテムのサバイバル入手性や任意の他MOD構成を、この一覧だけで保証するものではない。
