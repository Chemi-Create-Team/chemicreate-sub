# 蒸気銃と銃剣

実装コミットは `ed4ee9ef302d5426ce4972a02c4e1861b34fd908`。

## 操作とゲーム内の数値

| 操作 | 挙動 |
| --- | --- |
| しゃがみながら蒸気入りの脈動抑制管の端面を右クリック | メインハンドの蒸気銃を最大2,000 mBまで充填する |
| 右クリックを長押し | 銃を画面中央へ寄せてズームする |
| 照準中に左クリック | 1発撃ち、250 mBを消費する。射程32マスの最初の生物に基礎ダメージ32。再使用間隔は20 tick |
| `V`（初期設定） | 通常の近接リーチで銃剣を突き出し、基礎ダメージ6。再使用間隔は13 tick。蒸気消費なし |

銃剣キーはMinecraftの「操作設定」から変更できる。射撃と銃剣は同じアイテムのクールダウンを使う。通常蒸気・高圧蒸気・過熱蒸気を充填でき、異なる流体成分を同じ銃に混ぜない。蒸気バケツを反対の手に持ってしゃがみ使用した場合も、補充できる。説明欄とバーに充填量を表示する。メカニカルクラフターのレシピと、蒸気銃から開くPonderを追加した。

## 実装と保存

- `item/SteamGunItem.java` と `item/SteamGunAction.java` がメインハンド、照準、蒸気量、クールダウンをサーバーで確認し、サーバー側の視線で地形と命中を判定する。プレイヤーへの攻撃にはPvPとチームの許可を適用する。普通の左クリック近接はクライアントとサーバーの両方で取り消す。
- `item/PortableFluidToolItem.java` と `item/PortableToolFluidHandler.java` は従来の携帯噴射器の充填・保存を共有する。既存のアイテムデータコンポーネントID `spray_tool_contents` を使う。
- `client/SteamGunClient.java` は攻撃キーの入力、標準のキー割り当て、FOV、一人称の動きを担当する。`mixin/SteamGunThrustMixin.java` は銃剣の振りを三人称で前方への突きに置き換える。
- `tools/generate_steam_gun.py` で、銅色の蒸気室、真鍮リング、圧力計、歯車、木製ストック、銀色の銃剣を組み合わせた立体モデルと64×64のピクセルシートを再生成できる。同じスクリプトがレシピとPonder構造も生成する。

## 検証

- Java 21、Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10でGradleビルドが成功した。専用サーバーGameTestは新規3件を含む29件すべて合格した。
- GameTestでは脈動抑制管からの有限充填、照準外での射撃拒否、壁での遮蔽、空の銃の射撃拒否、射撃32と銃剣6のダメージを確認した。既存の携帯噴射器、サバイバル到達性、Ponder、アセットの関連試験も実行した。
- RTX 4060で動く日本語クライアントでは、既定の使用・攻撃キーとVの入力を通常のキーマッピングに渡し、照準ズーム、射撃32と250 mB消費、銃剣6と突きアニメーションの通知、Ponderの描画を確認した。仮想デスクトップの音声デバイスが利用できず、実際の音声出力は未確認。
- Ponderと翻訳の静的検証は合格。全体外観検証は従来からある硫黄スクラバー液バケツのモデル参照で失敗した。
- 表示用の実クライアントで、銅の蒸気室、木製ストック、銃身下の銃剣が見えることを確認した。配布用JARは圧縮だけを変更し、全エントリーの内容がGradle出力と一致することを確認した。
