## 見つけて直した不具合

1. **クリエイティブタブへの登録漏れ**
   - 抜けていたもの：現行の小型・大型コンプレッサーと統合圧縮機構、工業用加熱器とその部品4種、色付きの大型はずみ車16種。
   - 原因：圧縮機を新方式へ置き換えたとき、旧4設備はタブから外したが、新設備を追加していなかった。
2. **単体で置いたタービン軸を壊すとアイテムが消えていた**：`turbine_shaft` にルートテーブルがなかったので追加した。タービン本体は軸を別にドロップするので、二重には出ない。
3. **四酸化三鉄の山がサバイバルで入手できなかった**
   - 影響：ハーバーボッシュ反応塔を組めなかった。作成時のレポートでも「入手はクリエイティブのみ」のままだった。
   - 対応：実在の鉄－水蒸気法（3Fe＋4H₂O → Fe₃O₄＋4H₂）にならい、Createの加熱ミキサーで「鉄インゴット3個＋水1000 mB → 山1個」のレシピを追加した。
   - Ponder「ハーバーボッシュ反応塔」の該当手順にも作り方を加えた（日本語は改行位置を確認した文言）。
4. **存在しないレシピを解放する進捗**：合成ゴムのレシピは `mixing` から `pressure_reaction` へ移っていたが、旧IDを解放する進捗が残っていた。削除した。
5. **名前のないブロック**
   - 液体ブロック10種（蒸気、液化酸素、液体空気、各種ガス、硝酸）：流体と同じ名前を付けた。
   - 高圧タービンの部品とエンド：日英の名前を付けた。
6. **開発用クライアントチェックの停止**（どちらもゲーム本体への影響はない）
   - 既定の撮影対象に、削除済み設備のID（旧蒸留制御部など4件）が残っていて、チェックが落ちていた。現行の設備に置き換えた。
   - 加熱のチェックが、流量調節器を旧仕様（1 mB/t刻み）の「17」に設定しようとして停止していた。現在は16 mB/t刻み・16段階なので、48 mB/t（3段目）を狙うように直した。

## 判断が必要な事項（未修正）

1. **旧方式のガス圧縮機（クランクケース式）の扱いが、ゲーム内と文書で食い違っている**
   - 現状：クランクケース・低圧/高圧シリンダー・中間冷却器は、既設設備のための互換用。表示名に「既設設備・互換用」とあり、作るレシピもタブ表示もない。
   - 食い違い：Ponder「二段式ガス圧縮機を組み立てる」「大型の二段式ガス圧縮機を組み立てる」と `INDUSTRIAL_SYSTEMS.md` は、これを現役の設備として説明している。
   - 選択肢：
     - Ponderと文書を新方式（小型・大型コンプレッサー）に寄せる。
     - または、クランクケース式を再び作れるようにする。
2. **Ponderの日本語字幕の改行**
   - 症状：原子炉関係を除く388件のうち153件で、数値と単位が別の行に分かれる（「250」と「mB」など）、または行頭に句読点が来る。
   - 原因：Minecraftは半角スペースでしか改行せず、日本語は文字単位で折り返す。
   - 直し方の候補：
     - 文言を1件ずつ言い換える（今回の冷凍サイクルで行った方法）。
     - 数値と単位の間を改行しない空白にそろえる。
3. **入手手段のないアイテム**
   - 金属インゴット6種：作成時のレポートどおり未実装。現在はクリエイティブ専用。
   - 旧名の羽根 `turbine_blade`：低圧タービンが互換で受け付ける旧アイテムで、入手手段はない。
