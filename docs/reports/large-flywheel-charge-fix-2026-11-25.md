# 大型フライホイールの蓄勢を修正

実装コミットは `5424df5f2c2e0ce06f84c4b35394a3458896dae4`。

## 実装

- [LargeFlywheelBlockEntity.java](../../src/main/java/net/createplant/block/entity/LargeFlywheelBlockEntity.java) は、外部動力を計算するとき、Create が現在のネットワークに計上した同じ連結組の容量と負荷を差し引く。容量には各ローターの発電回転数、負荷には各部品に伝わった軸回転数を使う。これで、ローターの回転が軸より遅い蓄勢中にも、モーターの余力で加速する。
- 応力の登録値や、ローター速度で換算した応力容量の変化を検出し、その連結組の更新をネットワークごとにまとめる。蓄勢中も予備の回転出力を登録し、クラッチ切替時に使用する。既存ワールドの保存形式で動作する。
- [RotationalEquipmentGameTests.java](../../src/main/java/net/createplant/gametest/RotationalEquipmentGameTests.java) に、64 RPMのクリエイティブモーター、実際に切り替えるCreateのクラッチ、直結3台、シャフト、エンケースドファンを使う回帰テストを追加した。

## 計測

Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10。前回の検証と同じ構成を専用GameTestサーバーで再計測した。エネルギーは3台の合計。

| 計測時点 | 修正前の蓄積エネルギー | 修正後の蓄積エネルギー | 修正後のローター | 修正後の送風機 |
| --- | ---: | ---: | ---: | ---: |
| 駆動120 tick目 | 34,957.51 J | 3,388,400.69 J | | |
| 駆動260 tick目 | 34,957.52 J | 6,194,830.68 J | 64.00 RPM | 64.00 RPM |
| クラッチ切替の1 tick後 | 34,956.54 J | 6,194,705.46 J | 64.00 RPM | 64.00 RPM |
| クラッチ切替の160 tick後 | 34,800.82 J | 6,174,828.26 J | 63.90 RPM | 64.00 RPM |

送風機は切替後も過負荷を起こさず、160 tick後の放出は75 Wだった。軸速度には従来の更新しきい値があるため、ローターのわずかな減速中は送風機が直近の軸速度を保つ。3台のエネルギー分担と回転数は一致し、保存したブロックエンティティを別インスタンスで読み取っても蓄積エネルギーと回転数が一致した。1台のローターが約0.9994 RPMまで減速した場合は、送風機の回転と応力容量が0になった。

Java 21で `check` が成功。専用サーバーで回転機器、保存・不正データ、タービン、核融合設備の関連GameTest 40件と、上記の数値を採取した一時計測用GameTest 2件が成功した。クライアント描画、実ワールドのチャンク再読込、最大負荷での長時間運転、最大台数での性能計測は未確認。
