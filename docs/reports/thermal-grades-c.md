# 温度・圧力の等級化 C 完了レポート

2026-11-14。対象は蒸気生成、タービンと、RBMK・核融合炉の外部流体境界。実装コミットはこのレポートを含む `feat: grade steam generation and nuclear plant interfaces` を参照。

## 実装

- `SteamGrades` に通常・高圧・過熱蒸気の固定仕事量と摩耗を集約。高圧段は通常蒸気を出し、低圧段は普通の水を1:1で出す。圧力差による段間移送をやめ、Createのポンプを使用。`SteamMain`・`SteamThermal` を削除。
- 高圧段の仕事は通常0・高圧500・過熱1000 J/mB。低圧段へ直接供給する場合は250・750・1250 J/mB。低圧段は別途1758 J/mBを有限の復水器排熱バッファへ移す。二段合計＋排熱は2008・2508・3008 J/mBとなる。
- 摩耗倍率1・2・4、上限10,000,000,000。空・停止時にレンチで段全体を整備できる。満杯、停止、SIMULATE、再読込で流体・仕事を複製しない。内部の蒸気量は水換算であり、タービン・管束ボイラーの専用バッファは各16,000 mBを維持する。一般貯蔵タンクの等級別気体容量とは区別する。
- Createボイラーは通常蒸気のみ。管束ボイラーは末端の加熱段階で高圧／過熱を選ぶ。熱源段階1当たり4000 J/t、電熱は実際の利用可能熱を引き落とす。固定熱消費と400 kJまでの丸め残りを保存。水と蒸気は1:1。Createの仮想出力との二重発電を防ぐ。
- `ReactorCoolant` はRBMK内部専用の水定数と入口対応を定義。給水束とチャネルは水・加圧給水を受け入れる。炉内の相分率と熱収支を維持して、高圧蒸気・加圧給水・温排水・水を独立した出口在庫として搬出する。分数mBは炉内に残し、取り出した相の分だけ内部エネルギーを減らす。反応度定数・燃料特性・定格765 MWは変更していない。
- 核融合炉は加圧給水を受け、内部で支払った熱209 J/mBに応じて高温炉冷却材を出す。ブランケット・磁石・プラズマの内部温度計算は維持。初期の冷たいブランケットから熱は生成されない。端数熱を有限量で保存する。
- 気液分離器に固定の冷却材分離を追加：12000 mB→加圧給水11000 mB＋高圧蒸気1000 mB。アンモニア分離と在庫を共有しない。RBMKの水と蒸気を別々に通すモードも維持。流体の付随データは物理変換の両出口へ保持する。
- 加圧給水は既存の加熱したふた付き槽で水・温排水から製造。新流体の日英中名称、バケツ、JEIの生成・膨張・分離経路、Ponderと設備文書を更新。

## 制約と次段階

- 既存ワールドへの温度成分・旧湿り水の移行処理は作らない。新しい種類の給水と蒸気で配管・受け先を組み直す。
- 核融合ループの自立給電、全てを実配管だけで連続運転する大規模構成は今回未確認。流体境界の数量・固定仕事・有限排熱と、個別の実配管試験を確認した。
- 旧 `WaterPhase`・`PhaseTank` 等は、炉・タービンからの呼出しを外した。残る汎用設備・試験・表示の整理と削除はD段階で行う。
- 説明書・全Ponderの物理説明とDisplay Linkの旧番号はD・Eで整理する。放射線・炉内の温度・核反応・可燃ガス着火は残す。

- EでPonderの組立図も点検する。今回の画面確認では断面タービンの段間ポンプが図示されず、核融合炉の旧箱形外装が残っていた。これらを正しい現行構造へ更新する必要がある。
