# 作業台で作る撹拌槽ブロック

対象バージョンは `0.5.7`。実装コミットは `25324af4cb5a3a6b72d0ca0e9ccce6b8fa79682a`。

- `recipe/stirred_tank.json` を通常の作業台用の定形レシピに変更した。3×3の中央にステンレスタンク1個、上段中央にシャフト1本、残る7マスに鋼鉄インゴットを1個ずつ置く。出力は撹拌槽ブロック1個で、鋼鉄には共通タグ `c:ingots/steel` を使う。
- レシピ生成元、反応プラントの文書、日・英・中のPonderとゲーム内説明書を更新した。

## 検証

- 関連GameTest 15件が通過。通常クラフトのレシピマネージャーで指定材料から撹拌槽1個を作れることと、既存レシピとの競合がないことを確認した。
- 生成元とレシピJSONの一致、Ponder字幕と説明書のページ行数を静的に確認した。クライアントの作業台画面は今回の検証対象外。
