# 硫黄を空気で燃やすレシピと、装置の内張りの設定の完了レポート

- 日付：2026-11-18
- 実装コミット：このレポートと同じコミット（`git log -1 -- docs/reports/sulfur-in-air-and-lined-equipment.md`で確認）
- 説明：[反応プラント](../reaction-plant.md#硫黄の燃焼)、[装置の内張り](../../DESIGN.md#装置の内張り)、[温度・圧力等級](../thermal-grades.md)
- 前の作業：[セラミック管](ceramic-pipe.md)

## 指示

1. 序盤に電気なしで硫酸を作れるように、硫黄を空気で燃やせるようにする（二酸化硫黄に酸素が必須で、酸素は電解でしか作れなかった）。
2. 機械類はセラミック張りかガラス張りという設定にする。

## 実装

| 部分 | 内容 |
| --- | --- |
| レシピ | `pressure_reaction/sulfur_dioxide_from_air`：加熱した撹拌槽で、硫黄粉1＋空気2400 mB → 二酸化硫黄500 mB＋窒素1900 mB。酸素のレシピ（酸素500 mB）と同じ酸素量で、空気は酸素21%として計算。生成元は`tools/generate_sulfuric_routes.py` |
| 序盤の道筋 | 硫黄粉を空気で燃やす → 撹拌槽で水・空気・鉄ナゲットと混ぜて希硫酸（既存の空気のレシピ）→ セラミック管で送る。空気は配管の口からポンプで吸う（既存の仕組み）。電気も酸素も要らない |
| 製造ガイド「硫酸」 | 2つ目の工程（二酸化硫黄）を空気のレシピにし、字幕を「空気で燃やす。空気は配管の口から吸う。酸素でも燃やせる」に変更。8つ目の工程（液相酸化）も空気のレシピにした |
| 内張りの設定 | `DESIGN.md`に「装置の内張り」を追加：流体を処理する装置は内側をセラミック（ほうろう）かガラスで内張りしてあり、外装の材料に関係なく酸と熱い酸を受け入れる。装置の耐食等級は設けず、耐食で選ぶのは配管とタンクだけ。内張りはモデルに描かない。フッ化物を扱う工程の装置はニッケル合金で内張りしてある設定とし、受け入れを拒否しない。今の実装（装置は酸を拒否しない）と同じなので、コードの変更はない |
| 説明書 | 6ページ：古い「触媒の反応は撹拌翼の代わりに触媒充填バスケット」（槽の触媒モードは削除済み）を「槽の内側はセラミックかガラス張りなので酸も入れられる」に差し替え。10ページ（硫酸）：空気で燃やす、撹拌槽で希硫酸、電気は要らない、セラミック管で送る、に書き直し。21ページ（等級と配管）：装置は内張りで酸を入れられる、を追加 |
| 文書 | `docs/reaction-plant.md`に「硫黄の燃焼」、`docs/thermal-grades.md`に内張りの説明 |

## 制約と未確認事項

- 序盤に酸をためるタンクと、手で運ぶ容器はまだない（ふた付き槽をタンク代わりにする）。
- `DESIGN.md`の「密閉反応槽と分留塔」の最初の段落は、ふた付き槽へ触媒充填バスケットを入れる古い記述のまま（反応塔へ移した後の内容になっていない）。今回は変更していない。
- 空気2400 mBを1バッチで入れるので、配管の口から吸う空気の量が足りるか（ポンプの速さとの釣り合い）はサバイバルで確認していない。
