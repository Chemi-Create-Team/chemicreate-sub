# 往復式コンプレッサーの角筒と上部外装

対象バージョンは `0.7.1`。実装コミットは `5856f825ce6ad3b3632ec3d638a388e74c65c6ee`。

- 左右の角筒を長さ16 px、外寸8×8 px、壁厚1 pxにした。内寸6×6 pxに合わせ、クロスヘッドの横幅を最大5.75 pxに調整した。
- 上部の脈動緩衝器、支柱、緩衝器につながる立ち上がり管とエルボの描画とモデル資産を削除した。不要になった描画範囲を縮め、後部のフライホイールとモーター筐体を範囲に含めた。
- Ponderは各シリンダーの上面と下面へ標準ポンプを直接つなぐ構成に更新した。

## 検証

- 角筒の外寸、壁厚、クロスヘッドの余裕、モデル参照、Ponderの給排気配置を検査した。
- コアModの関連GameTest 10件が通過した。6気筒の圧縮と応力の合算、旧配置の運転を含む。
- RTX 4060の開発クライアントで、日本語Ponderの角筒、上部と駆動側の表示を確認した。既存プレイヤーワールド全体の読み込みは未実施。
