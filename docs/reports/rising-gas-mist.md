# 軽いガスの上昇と消散

実装コミットは `e65efaf78923b30b591b0a5d74522ecbb80b3476`。

蒸気など、既存設定で天井側に集まる色付きガスを、発生位置から上へ流れるもやとして表示する。屋外では雲の上端からさらに上へ抜け、ふくらみながら薄くなる。屋根がある列のもやは天井の下で薄れ、開口部の列では上昇が続く。

## 実装

- `client/RisingGasMist.java` は、同期済みの `CloudVolume` から縦につながる列を抽出する。実ワールドの遮蔽はチャンクの高さ情報から読み、屋根の側面へはみ出さないよう、開いた列の上でも周囲の屋根を越えてから横幅を広げる。
- 一つのもやは発生後、消えるまで高さを増す。屋外ではゲーム内の雲の上限から最大7ブロック上まで描画する。残量と経過で不透明度を落とし、雲の残量が少ないときは低い位置の新しいもやを弱める。屋根判定の間隔は20 tick、描画は1雲あたり最大56枚。
- `client/GasCloudRenderer.java` は空へ昇るもや用に描画のカリング範囲を上へ広げる。ガスの判定範囲と残量は既存のサーバー同期を使う。床側の色付きの雲は地面に沿うもやで表示する。
- `tools/generate_process_gas_recovery.py` の `plume_texture()` で、複数の濃淡が重なり縁が透ける32×32の `gas_plume.png` を生成する。

## 確認

- Java 21、Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10でGradleビルドが成功した。`ToxicGasGameTests`、`GasSafetyLoadGameTests`、`ProcessGasRecoveryGameTests` は計21件が合格した。
- RTX 4060の日本語クライアントのテストワールドで、配管から一度放出した蒸気の上昇、広がり、消散を確認した。ガラス屋根を付けた区画とガス回収ダクトの既存Ponderも確認した。
- 生成したテクスチャの再現性と外周の透過を確認した。配布JARはGradle出力とエントリーの内容が一致する。
- シェーダーパックとの併用と、大量配置時のフレーム時間は未検証。
