# 色のついたガスを現実の色にそろえる

2026-11-23。ユーザー指定：「塩素ガスに色ついてない。二酸化窒素のように色を付けて。すべてのガスで色がついてるやつ検索して現実と同じ色付けて」。

## 原因
二酸化窒素のバケツは、ガス用の密閉型の絵（下に茶色のガスがたまっている）だった。塩素・フッ素のバケツは、液体用の開いたバケツの絵で、上面に小さく色が付いているだけで、ガスに見えなかった。

## 現実で色のあるガスの調べ
この mod の気体 52 種を、現実の色で分けた。
- 色がある：二酸化窒素（赤褐色）、塩素（黄緑）、フッ素（淡黄色）。
- 色がない（無色・白い煙）：水素、酸素、窒素、アルゴン、ヘリウム、アンモニア、一酸化炭素、二酸化炭素、一酸化窒素、二酸化硫黄、三酸化硫黄、硫化水素、塩化水素、フッ化水素、六フッ化ウラン、エチレン、プロピレン、蒸気、など。
- 液体の塩素（琥珀色〜黄色）は液体なので、液体用のバケツのまま、色だけ現実に寄せた。

## 変更
- 塩素とフッ素のバケツを、二酸化窒素と同じ密閉型の絵にして、現実の色（塩素は黄緑、フッ素は淡黄色）を入れた（`tools/generate_process_gas_buckets.py` の `coloured_gas_buckets`）。
- 塩素のガスの色（配管・タンク・雲）を、鮮やかな黄緑（`0xBCD62A`）にした。液体塩素は `0xD8BE1C`。
- 二酸化窒素とフッ素の色は、すでに現実に近いので変えていない。

## 未確認・注意
- ゲーム内の見た目は確認していない。
- 無色のガスのうち、アンモニア（黄色）、三重水素、ヘリウム、重水素の流体色は、現実と違う色がついている。今回は変えていない。必要なら、無色に近い色へそろえる。
