# ゴーグルのツールチップを仕様書の構成にそろえる

2026-11-23。ユーザー指定：添付の「エンジニアゴーグル ツールチップ表示仕様書（統合改訂版）」を読んで実装する。実装後にプッシュする。

## 実装
- `client/GoggleSpec.java`（新規）：1行目の稼働／停止、貯蔵量、環境、設備の行、量の自動換算（mB→B）、割合の丸め（`<0.1%`）、成分リストの上位5件と `他 X 成分...`、Shift での展開を作る。
- `client/ProcessGoggles.java`：
  - 蓋つき容器は `GoggleSpec.vessel` で、従来の行を全部置き換える（反応槽は稼働中か停止中の理由つき、貯蔵槽は貯蔵量のみ）。
  - 複数成分のガスタンクは `GoggleSpec.storage`（貯蔵専用の形）。
  - そのほかの装置は、貯蔵量の行を共通の形式にして、反応中の塔・反応機に `稼働中` を足した。
- `ReactorMachineBlockEntity`：`reactionLabel()`（レシピから化学式の反応式を作る）と `batchEmpty()` を追加。
- 言語：`goggle_spec.*` を日英中に追加。`chemical_ui.warning` を `⚠ 停止中: %s` に変更（既存の停止表示がそろう）。
- 文書：`docs/goggle-tooltip.md`。検査：`GoggleSpecGameTests`（量と割合の表記規則）。

## 仕様との違い・未対応
- 環境と設備の行は蓋つき容器だけ。電解セル・タービン・RBMK・核融合・配管の計器は従来の表示のまま。
- 停止理由のうち、温度の必要値は「炉が点火済みなら超高温、そうでなければ高温」と推定している（レシピの要求温度を直接は読んでいない）。動力の必要値は 32 RPM 固定。
- 「複数反応の同時進行（+他N反応）」は入れていない。蓋つき容器は一度に1つの反応しか持たない。
- 圧力は、貯蔵流体の圧力が大気圧を超えるかどうかで「常圧／高圧」の2段階。
- 字下げは、Create のゴーグル枠の4桁分を足した6桁（1階層目）と8桁（内訳）。

## 確認
- 構文チェックのみ。コンパイルもゲーム内の表示確認もしていない（GameTest は CI の検証ステップが以前から失敗していて届かない）。
- ゲーム内で見る点：反応中／停止中の色と文言、貯蔵量の B 換算、混合ガスの割合（Shift あり／なし）、字下げがゴーグルの絵に隠れないか。
