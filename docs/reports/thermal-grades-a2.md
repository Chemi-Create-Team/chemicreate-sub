# 温度・圧力等級化 A2：タンク

2026-11-14。仕様書4.1に基づく段階別記録。実装コミット：`ce374648`。

## 変更

共通の `TankGrade` 表に、Createタンク、横置きタンク、管束ボイラー、液体槽、水槽、ガス槽、耐圧槽、ステンレス槽、極低温槽、開放槽、伸縮式ガスホルダーの受入範囲を定義した。種類・温度等級・圧力等級・耐食性に合わない流体は搬入を拒否する。水・蒸気もフィルターを通り、蒸気を水に変えて受け入れる例外はない。

気体容量は常圧×1、加圧×16、高圧×64。液体容量はそのまま。既存のCreate結合・分割を用い、保存後も総量を保持する。SIMULATEは内容・拒否理由を変更しない。

貯蔵槽の圧力破損・腐食漏れ・熱損傷、ガスホルダーの混合汚染・混合爆発を除去した。破裂の設定を削除し、可燃ガスの着火・爆発だけ独立設定として保持。ゴーグルは流体の等級・受入範囲・拒否理由を表示し、タンク材質とガスホルダーのPonderを日英中で更新した。

## 制限と後続作業

旧ワールドの容量・状態の移行処理は追加していない。圧力倍率の変更後に過容量となる保存内容は、読込時に増加も削除もしない。

処理装置の旧連続計算・圧力表示はA3以降で順次置き換える。タンクへの付与は除去済みだが、共有クラスの未使用部分を含む最終削除はD段階で行う。A3時の実クライアント確認で、タンク材質Ponderを含む3シーンの実描画、全140シーンのコンパイルが合格。E段階で全シーンを再確認する。
