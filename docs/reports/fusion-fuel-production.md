# 核融合燃料製造ラインの実装記録

実装コミットID：`89ac56166617e5db8ed510489f7da25df4ab3723`。

## 実装

- `registry/CEFusionFuel.java`：重水、重水素を除いた水、He回収原料ガス、Liターゲット2状態、再生冷凍機の機能部材。
- `FuelChannelBlockEntity.java`：既存燃料孔のLiターゲット装填、実際の炉出力に基づく照射、完了棒搬出、保存、解体時ドロップ。核分裂燃料数へ加算しない。
- `BasinElectrolysis.java`：既存電解槽で重水を処理。H₂とD₂を別バッファへ保持し、不正な流体指定の搬出で変換しない。
- `ProcessRecipe.java` と専用圧力反応レシピ：重水濃縮、He回収・分離、T₂抽出、冷却水再利用。
- `CryogenicColdBoxBlockEntity.java`：3×3×3断熱箱と中央の再生芯、回転式ヘッドによる4.2 K液化。有限の軸仕事・冷却水・顕熱・潜熱を計算。
- `tools/generate_fusion_fuel.py`：新規16pxアセット、レシピ、3言語と4つのPonderの再現可能な生成器。中央の既存言語/カタログを勝手に書き換えず、`tools/data`の専用fragmentを親が統合。

## 数値と制約

[核融合燃料の説明](../fusion-fuel-production.md)に全体の工程、入出力、冷凍仕事の式、保存・破壊の扱い、参照資料とゲーム近似を記録。ウラン鉱石からのHe回収量や同位体収率は現実の化学的・核種的収率ではない。既存ブランケットのT増殖は変更しない。
