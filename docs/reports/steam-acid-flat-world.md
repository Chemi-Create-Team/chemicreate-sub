# 蒸気発電と三酸製造のフラットワールド

実装コミット `e02a2351`。Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10、Create: Electro Energetics 1.21.1-1.1.4、Create: Diesel Generators 1.21.1-1.3.15で検証した。

## ワールドを開く

配布ZIPを展開し、`level.dat` が入った `steam-acid-flat` フォルダをMod環境の `saves` に置く。シングルプレイの「蒸気発電と三酸製造」を開く。開始位置はサバイバルで、横の補給チェスト `(21, -58, 20)` に燃料、水、硫黄粉、食塩水、アンモニア、酸素、予備部品が入っている。

| 製品 | ステンレス製タンクの座標 | 保存時の量 |
| --- | --- | ---: |
| 硫酸 | `(27, -56, 18)` | 250 mB |
| 硝酸 | `(50, -57, 32)` | 200 mB |
| 塩酸 | `(31, -57, 32)` | 1,000 mB |

## 運転内容

- 石炭で加熱した3連の管式ボイラーへ水を送り、高圧段5基と低圧段10基をシャフトでつないだ。低圧段からの復水は別タンクに回収した。組み立てから500 tickの時点で高圧段は累計1,169,500 J、低圧段は583,500 Jの機械仕事を記録し、復水は2,334 mBだった。
- シャフトでステーター1基の交流発電機を256 RPMで回し、銅線で食塩水と亜硫酸の電解槽に給電した。電解槽の計器で測った最大電圧は368.4 V、同tickの2槽合計で最大1,185.9 Wだった。各槽が受け取った電力量は食塩水側が8,805.0 J、亜硫酸側が7,449.6 Jだった。
- 硫酸ラインは、硫黄粉と吸い込んだ空気を加熱撹拌し、二酸化硫黄を吸収塔で亜硫酸にして電解した。
- 硝酸ラインは、支給したアンモニアを触媒反応塔で酸化し、冷却ファンと分留塔を通した。一酸化窒素を再酸化し、吸収塔から硝酸を回収した。
- 塩酸ラインは、食塩水を電解して水素と塩素を得た。両方を撹拌槽で反応させ、塩化水素を吸収塔で吸収した。

補機のポンプ、撹拌機、冷却ファンはクリエイティブモーターで駆動した。電解槽の電源は蒸気タービンにつないだ発電機。設備間の中間流体の一部は、テストコードが入出力ポートを通して作業者の移送を代行した。製品はポンプを通ってタンクに溜まる。追加バッチを作るときは原料を補充し、同じ中間流体の移送を行う。

## 再現と確認

[クライアント用の起動設定](../quality/survival-playtest/steam-acid-client.gradle)から、[プレイテストコード](../../src/main/java/net/createplant/client/SteamAcidPlaytestWorld.java)を有効にできる。リポジトリのルートで次を実行すると、試験用の新規スーパーフラットワールドを開いて1バッチを運転する。出力はゲームディレクトリの `saves` と `steam-acid-result.json` に保存される。

```sh
bash gradlew -I docs/quality/survival-playtest/steam-acid-client.gradle \
  -DplaytestDir=/tmp/createplant-steam-acid-client runClient
```

- GPUを使用するクライアントで製造完了、ワールド保存、再読み込みを確認した。[測定記録](../quality/survival-playtest/steam-acid-results.json)
- 配布ZIPの整合性を確認し、ZIP内の保存データからスーパーフラット、サバイバル、製品3タンクの流体IDと量、補給チェスト、電線データを確認した。
- `gradlew --offline build` と、蒸気タービン、管式ボイラー、電解槽、硝酸ライン、吸収塔に関係するGameTest 28件が成功した。長時間の連続生産や複数バッチの自動運転は未検証。
