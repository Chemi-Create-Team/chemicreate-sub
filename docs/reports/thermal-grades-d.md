# 温度・圧力の等級化 D 完了レポート

2026-11-14。実装コミットはこの文書を含む `refactor: remove continuous fluid physics and retired metrics` を参照。

## 変更

- `PhaseTank`、`FlowingWaterTank`、`WaterPhase`、`FluidPhase`、`ThermalMath`、`GasCompression`、`EquipmentSafety`、`PressureVesselBehaviour`を削除。Java・登録・ビルド設定の参照も撤去した。
- `GradeFluidTank` は材質の拒否、有限在庫、気体容量とCreateの結合・分割だけを担当する。旧圧力・二相状態・気化率・蓄熱は持たない。SIMULATE・読取で状態を変えず、実操作で拒否理由を同期する。
- `FluidMaterials` へ化学量と分留順序に必要な固定値だけを移した。`PhaseChange` は8組の固定液化・気化対応表だけを残す。核分裂・核融合内部の温度と反応定数は変更していない。
- 蒸気の冷却で得る水には既存の蒸留由来マークを保持する。純水フィルターは同じ有限在庫から純水として取り出す。普通の水と混ぜると由来を失い、別のデータ成分は混ぜない。温度・二相計算は使わない。タービンは普通の水を出す。
- 燃料プールは崩壊熱を有限の蒸発費用へ積み立てる。流体温度の上昇計算は撤去し、水を消費する分だけ潜熱の固定費用を引き落とす。乾いたラックの装荷停止と放射線遮蔽は残す。
- Display Linkから汎用の温度・圧力・配管損傷等を撤去し、138項目へ整理。核分裂・核融合の内部計器は維持。旧選択番号は変わる。
- `vapour_fraction` の登録、未使用の配管損傷・温度破壊・圧力差ポンプ設定を撤去。可燃ガスの着火設定は残す。未使用の熱傷・凍傷ダメージ種別とタグ、旧表示88キーを削除した。霜の窓描画は等級で動作しているため維持した。
- 単一流体の予熱レシピが、他の仕掛品や試薬のある反応へ割り込まないようにした。出力満杯で待つ反応の水だけを先に消費しない。
- 旧物理専用試験を置換。タンクと輸送の試験を、新しい流体種類・容量・耐食に合わせた。ふた付き槽から実ニッケル合金管とポンプで遠心分離機へ送り、両製品を回収する試験も合格した。
- 圧力・温度を手調整する旧`FusionPlantGameTests`と専用Gradleタスクを撤去した。Cで追加した`FusionGameTests.controlDeskRunsGradedCoolantThroughSeparatorAndBothTurbines`が、現行の同一ワールド・有限在庫境界を検証する。旧コマンドへの互換ラッパーは作らない。
- アンモニア製造Ponderに専用の気液分離器工程を追加し、古い分留塔を撤去。生成元と対象NBT・カタログ・3言語を同時更新した。
