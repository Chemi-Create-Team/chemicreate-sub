# サバイバル実機試験 ― 希硫酸と鉄鉱石の浸出

Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10、Create: Electro Energetics 1.1.4。作業開始時の `main` は `5923eb7a`。途中で合流した `main` は `223f5d93`。試験ワールド実装は `8cbaff98`。[硫黄燃焼までの試験](survival-playtest-sulfur-continuation.md)

## 判定と計測

| 工程 | 結果 | 実測 |
| --- | --- | --- |
| ネザーラック破砕 | 24個から硫黄粉6個 | 3回、各1,112 / 1,120 / 1,128 tick |
| 開放口から吸気 | 最初の2,400 mB、投入前に7,200 mB | 気体ポンプ8 RPMで最初の2,400 mBまで722 tick |
| 硫黄燃焼 | 3回で二酸化硫黄1,500 mBと窒素5,700 mB | 109 / 100 / 100 tick |
| 希硫酸 | 3回で3,000 mB | 二酸化硫黄が到達するまで183 tick、搬送開始から1～3回目が582 / 1,142 / 1,702 tick |
| セラミック管で搬送 | 浸出槽に希硫酸が到達 | ポンプ起動から171 tickで初回到達 |
| 水の電解 | 陽極の酸素を浸出槽へ供給 | 初回生成182 tick、ピーク92.01 V |
| 鉄の浸出 | 9個を3回に分けて処理し、鉄浸出スラリー12,000 mB | 225 / 225 / 225 tick |

浸出3回の消費は希硫酸2,250 mBと酸素750 mB。終了時に浸出槽へ残った希硫酸は750 mB。

新しいフラットワールドで鋼鉄から通して再現した。ふた付き槽は3×3・1段、撹拌翼は32 RPM。硫黄燃焼槽と浸出槽を通常加熱し、希硫酸の槽は無加熱。ボイラーの給水ポンプは32 RPMで16 mB/tickを供給し、蒸気エンジンは発電機を64 RPMで回した。工程の所要時間はゲーム内tickで記録した。

## 経路

1. ネザーラックを破砕し、回収チェストから硫黄粉を燃焼槽のホッパーに入れた。前回は空気がたまるたびに硫黄粉を追加すると、先に生成した気体が加熱され出力枠が分かれた。今回は開放口から空気7,200 mBをためてから硫黄粉を3個投入した。
2. 燃焼槽の上から二酸化硫黄をステンレス鋼管とステンレス鋼ポンプで希硫酸槽へ送った。作業台で作った鉄ナゲット、別口から吸った空気、水源からポンプで給水した水を反応させた。水は1バッチごとに1水源から供給し、製造後は給水口をふさいだ。
3. 粘土玉9個から未焼成管6本をクラフトし、かまどで焼いた。製造槽から浸出槽への液体経路はセラミック管とCreate標準ポンプ。ポンプ用水路を1ブロック上げて製造槽の外装を避けた。
4. 銅線リールを両端子に使い、Createの小型蒸気エンジンからCEE交流発電機を回して電解セルに給電した。水を電解し、陽極側の酸素を気体パイプと気体ポンプ経由で浸出槽に送った。
5. 鉄の原石9個をCreateの破砕ホイールで加工し、得た砕いた鉄鉱石を3個ずつホッパーへ投入した。液体・気体の移動は各機械の通常tickで行い、槽の内容は読み取りだけに使った。

## 操作の制約と未検証

- 採集・採掘相当の素材を起点にし、前段の鋼板、硫黄粉、二酸化硫黄、希硫酸、酸素を実際に使用した。スターターとして配置したCreate・CEE部品の作り直しは省略し、入手条件を上表で照合した。装置のタンクへの直接代入、直接のレシピ適用、クリエイティブ電源・動力は使用していない。
- 始めの試行では搬送ポンプ用水車の水路が槽の角に重なり、マルチブロックを分割した。水路と配管を1段上げて解消した。電解セルの給水管と酸素管は、上下に1ブロック空けて自動接続を避けた。ボイラーの給水は本体側につなぎ、水源を囲った。変更対象は試験ワールドと計測コード。
- 鉄の浸出までを対象にした。銅の浸出、円形沈殿池への搬出、電解採取、通常の硫酸、JEI・Ponder・実績の画面は今回未検証。
- スクリーンショットは `runClient` で通常の20 tick/sに戻して撮影した。[配管と浸出槽](../quality/survival-playtest/wet-progression-overview.jpg)、[槽の保存値](../quality/survival-playtest/wet-progression-product.jpg)

## 再現

[起動設定](../quality/survival-playtest/progression-client.gradle)と[実測データ](../quality/survival-playtest/wet-progression-results.json)を使う。配布ワールドの `survival-dilute-acid-leaching` フォルダーを `saves` に置いてサバイバルで開く。燃焼槽は `(64, -44, 34)`、希硫酸槽は `(68, -44, 37)`、浸出槽は `(68, -44, 45)`、電解セルは `(78, -44, 50)`。手元で再試験する場合は以下を実行する。

```sh
mc-debug bash gradlew --no-daemon -I docs/quality/survival-playtest/progression-client.gradle \
  -DsurvivalSprint=80000 runClient
```

専用サーバーでも同じ配置を `SurvivalProgressionGameTests` で試験した。専用サーバーとクライアントの両方で、製造3回、鉄の浸出3回、希硫酸残量750 mBが一致した。Gradleの `build` は成功した。
