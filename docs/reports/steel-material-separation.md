# Create標準鋼材と設備用鋼鉄の分離

作業日: 2026-11-12

実装コミットID: cf6fb62443878b3467cbef6d62c32e248e997ffc

## 依頼と確定仕様

Createの鋼材ブロックを標準レシピへ戻し、別素材として鋼鉄インゴットと鋼鉄ブロックを追加した。ユーザーへの確認で、次を確定した。

- パドル法と転炉は鋼鉄インゴットを出力する。インゴット9個とブロック1個を相互変換する。
- 外装・大型設備は鋼鉄ブロック、管束・軸・ラックは鋼鉄インゴットへ置き換え、レシピ内の必要個数を維持する。
- 設備へ直接置く構造材も鋼鉄ブロックにする。
- CEEの磁石も鋼鉄へ変更し、Create本体の窓・水洗いは標準仕様のままにする。

新規の装置・板材・錆びた鋼鉄は追加していない。直前に調整した鉄の原石の配合量、蛍石入りのパドル鉄増産、石臼の蛍石50％、フッ素製造経路を維持した。

## 製法と登録

| 素材・工程 | 入力 | 出力 |
| --- | --- | --- |
| Create標準鋼材 | 鉄インゴット1、石切台 | 鋼材ブロック2 |
| パドル鉄 | 鉄インゴット4、鉄の原石2、加熱 | パドル鉄4 |
| 融剤入りパドル鉄 | 上記と蛍石1 | パドル鉄5 |
| 連続組立 | パドル鉄1、同じ加工品を5回プレス | 鋼鉄インゴット1 |
| 酸素製鋼 | 鉄インゴット48、鉄の原石24、酸素64,000 mB | 鋼鉄インゴット64、転炉ガス128,000 mB |
| 圧縮 | 鋼鉄インゴット9 | 鋼鉄ブロック1 |
| 分解 | 鋼鉄ブロック1 | 鋼鉄インゴット9 |

酸素製鋼は800 tickと液化酸素92 mBによる代用を維持した。AOD精錬・ステンレス鋼の配合は変更していない。

- `create_heavy_indusstry:steel_ingot`: `CEItems.STEEL_INGOT`。英語Steel Ingot、日本語鋼鉄インゴット、中国語钢锭。
- `create_heavy_indusstry:steel_block`: `CEMetals.STEEL_BLOCK`。英語Block of Steel、日本語鋼鉄ブロック、中国語钢块。BlockItem、通常の採掘・ドロップ、鉄ツール条件、金属ブロック用の共通タグを持つ。
- 共通素材タグ: `c:ingots/steel`、`c:storage_blocks/steel`。
- マテリアルタブへ両素材を追加した。16×16の専用テクスチャを生成し、インゴットには面ごとの陰影、ブロックには灰色の鋼板・縁・継ぎ目を描いた。

Createの鋼材・錆びた鋼材の石切台レシピを無効化していた上書きJSONを削除した。旧 `sequenced_assembly/industrial_iron_block` を削除し、`sequenced_assembly/steel_ingot` に置き換えた。酸洗いはCreateの錆びた鋼材をCreate鋼材へ戻すままとし、安価な装飾材から鋼鉄を得る抜け道は作っていない。

| 熱交換器の支え | ブロック | 1 → 1 |
| 熱交換器の管束 | インゴット | 1 → 2 |
| 高圧タービン外装 | ブロック | 4 → 4 |
| 工業用加熱器 | ブロック | 4 → 1 |
| 工業用加熱器の屋根 | ブロック | 1 → 1 |
| 大型フライホイール | ブロック | 8 → 1 |

CEEは元の `electroenergetics:crafting/magnet_block` を生成データで上書きし、同一グリッドの別レシピは追加しない。Createの窓、水洗い、錆びた鋼材への加工は標準の鋼材を使い続ける。

## 設備の構造材

転炉の可動炉体75個、ガスホルダー球の球殻、ヘリウム液化器の外殻26個、燃料プールの全周壁を鋼鉄ブロックへ変更した。ガスホルダーは成立時の外殻モデル、採掘時のドロップ、ブロック選択、修理用の素材、配置ガイドを揃えた。

各設備の寸法・容量・処理・保存形式は維持し、原子炉や核融合炉の反応計算・制御は変更していない。関連するクレーンの燃料プール模型・試験用設備も同じ壁材を使う。Create鋼材で作った装飾の通路・支柱や、既存機械の共有テクスチャは一括変更していない。

必要な鋼鉄量は、ブロック1個あたりインゴット9個で数える。転炉の炉体と固定部品は鋼鉄ブロック83個相当、インゴット747個相当が必要になる。これは元の個数を維持してブロックを使うという選択の結果で、供給ラインの増強が必要になる。

## 生成元とPonder

- `tools/generate_steel_materials.py`: 鋼鉄インゴット、共通タグ、CEE磁石、球殻のドロップ・外観、既存構造テンプレート、関連する3言語文言。
- `tools/generate_metal_blocks.py`: 鋼鉄ブロックのモデル・テクスチャ・レシピ・ドロップ・タグ。対象を絞る引数を設け、既存のステンレス鋼・チタンの外観を再生成していない。
- `tools/generate_crafting_recipes.py`: 設備用素材と5回プレス。熱交換器の外装類は `generate_thermal_control_assets.py --steel-only` で生成する。
- `tools/generate_converter.py`、`tools/generate_fuel_pool_assets.py`: 転炉・ラックの原料と鋼鉄の生産。
- `tools/generate_converter_ponder.py`、`tools/generate_manufacturing_ponder.py`: 新素材から開ける転炉・鋼鉄系列。系列には9インゴットの圧縮と分解の説明を追加し、レシピ量は実行時に取得する。
- 燃料プール・液化器・ガスホルダーの説明と構造テンプレートを更新した。クレーン模型は燃料プール部分だけを置換し、その他の支柱を維持した。

生成順は、鋼鉄素材 → 設備レシピ → 転炉Ponder → 製造Ponder。製造Ponderは `manufacturing_steel` と `manufacturing_liquid_helium` に絞った。翻訳ファイルの元のLFを維持した。廃止したCreate鋼材への特例リンクをPonder検証器からも除いた。

## 確認結果

対象: Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10、CEE 1.1.4、CDG 1.3.15、Java 21。

最終確認は関連GameTestを2つのプロセスへ分け、合計55件が合格した。

1. `bash gradlew --no-daemon --max-workers=2 build runGameTestServer`。`createplant.gameTestClasses=CraftingRecipeGameTests,ManufacturingPonderGameTests,ConverterGameTests,FuelPoolGameTests,FusionFuelGameTests,StructureGuideGameTests,SurvivalReachabilityGameTests` を指定。50件合格、試験本体16.49秒、コマンド全体42秒。
2. 同じサーバータスクを `createplant.gameTestClasses=GasHolderGameTests` で起動。5件合格、試験本体1.899秒、コマンド全体25秒。

両方で `JAVA_TOOL_OPTIONS=-XX:ActiveProcessorCount=4 -Dcreateplant.gameTestClasses=...` を使った。標準の石切台、9対1の圧縮・分解、旧組立レシピの不在、全設備レシピの素材、CEE磁石、Create窓・水洗いの維持、序盤からの到達性、転炉の実コントラプション、ガス球の破損・修理・気体保持、液化器と燃料プールの標準ポートを確認した。

生成物の検証4本はすべて合格した。

- `validate_plant_tutorials.py`: 追加Ponder100章、527組の文、243個の部材リンク、製造27系列。
- `validate_ponder_language.py`: 実行時Ponder138シーン、英・日・中。
- `validate_visual_identity.py`: 完成品343種、意図しない同一画像なし。新インゴットを粉末以外の素材として分類した。
- `test_ci_validators.py`: 15件合格。

実クライアントは `mc-debug` とNVIDIA GeForce RTX 4060の直接描画を使い、鋼鉄系列・転炉の2シーン、3表示対象を確認して正常終了した。[実行結果](../quality/steel-materials-client.json)、[鋼鉄インゴットの表示](../quality/steel-ingot-ponder.jpg)、[鋼鉄製の転炉](../quality/steel-converter-ponder.jpg)を保存した。画像はComputer Useで撮影し、目視した。`git diff --check` も合格した。

## 試験で残った問題と未検証事項

初期の55件同時実行では、ガスホルダーの形成待ちが時間切れになった。ガス試験を別バッチにしても同一サーバーでは再発し、独立したサーバーで実行した5件はすべて合格した。多数の鋼鉄製構造物を同時配置する試験が共有の探索待ち列へ負荷をかけている可能性があるが、待ち列の計測による原因確定や処理方式の変更は行っていない。55件を同一プロセスで同時実行した結果を合格とは扱わない。

旧設備のBlockEntityやCEE装置IDに対する試験テンプレートの読込警告・例外がログに残る。関連する最終試験は上記のとおり合格したが、古いテンプレート全般の整理は対象外とした。

全件GameTest、長時間の連続生産、全任意MODの組合せは未実施。英語・中国語はリソースと実行時キーを自動確認し、実クライアントの目視は日本語で行った。

## 既存ワールドと次回の注意

Createの登録IDは変更していない。新素材は新IDで追加し、設備のインベントリや気体・液体の保存形式を維持した。

既存の転炉・液化器・燃料プールでは、Create鋼材の構造部材を鋼鉄へ交換する必要がある。旧部材を自動変換しない。完成済みガス球の専用外殻と内容物は維持し、修理・解体では鋼鉄を使う。

組立連続工程はレシピIDを変更したため、旧IDを記録した途中の加工品は更新前に加工を完了するか、更新後に作り直す必要がある。外部データパックがCEE磁石を上書きする場合は、データパックの優先順位を確認する。
