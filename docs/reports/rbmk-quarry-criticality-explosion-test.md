# 引き継ぎ：最大原子炉・燃料プール・クレーンの稼働試験（燃料交換・採掘・臨界・爆発）

- 実装コミット：`3bfa3eaa`（試験の作り直し）、`c33f6880`（燃料交換の段階を追加）
- 対象ブランチ：`work`
- Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10 / Java 21

## 実装内容

実クライアントの新規ワールドで、最大炉心・燃料プール・原子炉保守クレーン・クォーリー用クレーンを建て、運転する開発用試験を作り直した。`-Dcreateplant.rbmkPlaytest=plant`、または`tools/create_rbmk_playtest.ps1`で実行し、結果を`run/rbmk-plant-result.json`、画像を`run/screenshots/rbmk-plant-*.png`へ保存する。GameTestではなく、統合サーバー上の実クライアント試験である。

- `client/RbmkPlaytestPlant.java`：サーバー側の建設と段階進行。
- `client/RbmkPlaytestWorld.java`：ワールド作成、撮影要求への応答、結果の書き出し。
- 旧版は燃料プールもクレーンも含まず、制御方式も古かったため置き換えた。

## 試験の段階

1. **建設・装荷**：有効径13 m、外径17 m、厚さ2 mのシールドの炉心を建てる。炉の隣に3×3セルの燃料プールと、両方を覆う原子炉保守クレーンを置く。制御棒51本を全挿入で装荷し、燃料は4か所だけ空けて393本を装荷、最下部の冷媒入力部から満水にする。燃焼済みの燃料1本をプールへ戻す対象として用意し、プールには新燃料4本を置く。
2. **燃料交換**：クレーンを動かし、使用済み燃料をプールへ戻し、新燃料を空いた穴へ入れさせる。
3. **クォーリー**：炉心から離れた位置に別のクレーン（レール長7、レール間5、脚3）を建て、土・石の2層（計28マス×3段）を掘らせる。水の1マスは残る想定。
4. **臨界**：制御棒リンクとコントローラー（0〜100）で制御棒を抜く。反応度が約+0.25 $を超えない間隔で1段ずつ抜き、出力が定格の3%に達したら保持へ移る。
5. **保持**：定格397 MWの3〜10%（12〜40 MW）を1,500 tick保つ。
6. **爆発**：冷却水の補給を止めて制御棒を全部抜き、蒸気だけを搬出する。炉心が失われるまでの時間と、炉心領域の残存ブロック数を測る。

## 注意点・制約

- **爆発の被害は小さい。** 厚さ2 mのシールドの爆破耐性により、炉心領域のうち約3.7%しか壊れなかった。仕様どおりか、爆発が弱すぎるかは判断が必要。
- **爆発中の出力は上限で頭打ち。** 最大約153万 MWは中性子レベルの上限（定格の10⁶倍）による値で、物理的な出力ではない。
- **給水と蒸気の搬出はポートを直接呼んだ。** 配管・ポンプは使っていない。入口・出口ポートのCapabilityは使うが、実際の配管接続は未確認。
- **非常停止（AZ-5）はこの回では実行していない。** 手順上は、出力が定格の45%を超えると作動する。以前の実行（3×3の設計）で、全制御棒の挿入が131 tickで完了することは確認した。
- **燃料交換の規模は小さい。** 炉心の新燃料への入れ替えは4本、使用済みの回収は1本だけで、満杯の炉心全体の交換や、プール満杯時の待機は試していない。
- **クォーリーの水が流れ出した。** 掘った穴へ水のマスから水が広がり、床の外まで流れた（画像で確認）。試験の副作用で、クォーリーの不具合ではない。
- 保持中の出力は12〜41 MWで、目標の範囲（12〜40 MW）をわずかに超えた。運転員役の簡易制御のためで、炉の不安定さではない。
- 複数台の同時稼働、長時間運転、MSPT・FPSの計測は行っていない。

## 次回の注意

- 試験は炉心設計（区画数・外径・縦構造）を定数で参照する。設計を変えたら、建設位置とクレーン高さ（`RAIL_Y`、プール位置）を確認する。
- 実行中にMinecraftのウィンドウを操作するとポーズされ、試験が中断する。
- 実行は約15分かかる。サーバーの速度は途中で100 TPSに上げる（撮影時は20 TPSへ戻す）。
