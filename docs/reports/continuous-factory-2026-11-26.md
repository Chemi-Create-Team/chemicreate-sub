# 大型連続加工設備 実装報告

実装コミットは `d82323b0da37a1bd8fb9b6350946a73f6f92b902`。配置寸法、回転動力の接続、復旧手順、ゲーム内の画像は[組立ガイド](../continuous-factory.md)に記載した。

## 実装

- 7〜15ブロックのロータリーキルン。2.7°の傾斜、中空のドラム、胴のガースギア、ピニオン、支えローラー、投入・排出部、加熱口、排気筒を備える。複数の材料を順次送り、火力と滞留時間で焼成、未焼成、固着が決まる。
- 2〜5段の連続圧延ライン。各段で上下のロールが逆転し、赤熱した材料が移動しながら薄く長く伸びる。段間の速度差に応じて座屈や破断が起こる。
- 大型巻線・撚線機。4個のボビンが公転・自転し、ワイヤーがガイド点と巻き取り面を結び、コイルの外径が変化する。張力が弱いと巻きが緩み、高すぎると断線する。
- 14件のデータ駆動加工レシピ。鉱石、生石灰、使用済み触媒、極厚鋼板、H形鋼、レール材、銅箔とアルミ箔、核融合炉の磁場コイル2種、鋼心アルミ撚線、極太ワイヤーロープに対応する。Createのアイテム搬送、ゴーグル、ディスプレイリンク、JEI、Ponderにも対応する。

## 計算と主要ファイル

- `factory/FactoryProcess.java` はキルンの送り量を `RPM / 960` ブロック毎tickとし、通常加熱と過加熱の焼成量を 1 と 1.6 に設定する。圧延は各段で厚さが75%、長さが逆比で伸びる。目標回転数は前段の `RPM / 0.75`、許容誤差は ±10%。巻線張力はブレーキトルクと主軸トルク、進捗に応じて増す巻き径から計算する。いずれもゲーム用の単位で計算する。
- `block/entity/ContinuousFactoryBlockEntity.java` が在庫、進捗、異常、入出力を管理・保存する。周辺変更は `factory/FactoryWatch.java` が必要な設備だけに通知する。
- `factory/FactoryGeometry.java` と `factory/FactoryPose.java` の部品形状と変換を、Createのからくり `contraptions/FactoryBodyEntity.java` および `client/FactoryBodyVisual.java` が共有する。サーバーでは各tickの姿勢に追従したCreateの回転衝突を使い、クライアントは同期した姿勢を補間して描く。F3+Bのオレンジ色が描画姿勢の部品形状、白色が標準の外接枠。
- レシピは `data/create_refinery_n_reactors/recipe/continuous_processing/`、解説は `ponder/ContinuousFactoryPonderScenes.java` にあり、JEIと日本語UIから参照できる。

## 確認範囲

- Java 21のGradle `build` が成功。専用サーバーの `runGameTestServer` では、大型連続加工設備12件と大型プレス・反応塔・クラフト・クリエイティブ一覧・リレー計算機の回帰を合わせた45件が通過した。
- 大型連続加工設備のGameTestは、連続投入と途中保存、未焼成と固着の復旧、圧延と座屈・破断、巻線と断線・巻き緩み、部品の撤去と再形成、使用済み触媒、姿勢・ワイヤー端点・中空部を対象にした。
- RTX 4060で日本語クライアントを起動し、3設備の可動部、ヒットボックス表示、JEIカテゴリとPonderを確認した。クライアント終了時にワールド保存後のX11エラーが出た。この環境はOpenAL機器も開けず、警告音の聴取は未確認。
- 見た目は添付画像のドラム、鋼材、銅の縁、歯車、スタンドと赤熱材を採用した。撮影に写る工場建屋、足場、外部コンベヤーなどは別に組み立てる。
- 多数の設備を同時設置した際のフレーム時間・サーバーtick時間、遅延のあるマルチプレイヤー環境での同期は未計測。
