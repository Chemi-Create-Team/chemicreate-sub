# サバイバル進行の実プレイテスト

[希硫酸の製造と鉄鉱石の浸出](survival-playtest-dilute-acid-leaching.md)では、希硫酸3,000 mBを製造・搬送し、鉄の浸出を3回確認した。[硫黄粉修正後の試験](survival-playtest-sulfur-continuation.md)では、ふた付き槽での吸気計測と硫黄の3回連続投入まで進めた。以下は初回の計測。修正直後の破砕試験は[硫黄粉の回収レポート](netherrack-sulfur-yield.md)に記録した。

対象は Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10、Create: Electro Energetics 1.21.1-1.1.4。依頼時の `main` は `a052d237`。作業ブランチも `main`。確認ワールドと検証コードのコミットは `6402edf3`。

## 判定

| 段階 | 判定 | 実際に確認したこと |
| --- | --- | --- |
| A　鋼鉄からステンレス鋼板まで | 合格 | 鋼鉄3バッチの12個、ステンレス鋼3バッチの板30枚をチェストに回収。 |
| B　ステンレス鋼の化学設備 | 不合格 | 説明書の硫黄入口で停止。ネザーラックを8個ずつ3回破砕して、硫黄粉は0個。 |
| C　吸収塔、接触法、ジルコニア、アルミ | 未実行 | 段階Bの入口で運転を止めた。実績の親子関係だけリソースで照合した。 |

## 守ることの確認

1. 装置間はホッパー、ファンネル、鉢の排出口、デポ、チェストで搬送した。溶岩は配管とポンプで注液器へ送った。完成したブレイズケーキはデプロイヤーがバーナーに使った。テストコードは配置、原料のドロップ、レバーや燃料投入の通常操作、tick計測を行う。
2. 製造設備は水車で駆動した。破砕ホイール・石臼・ポンプ・デプロイヤーは8 RPM、ミキサー・プレスは32 RPM。石炭で通常加熱し、超加熱には製造したブレイズケーキを使った。
3. 試験の投入物は鉄の原石、石炭、ペントランド鉱、クロム鉄鉱、ネザーラック、卵、砂糖、水源、溶岩源。設備はサバイバルで製作可能な段階のものを、プレイヤーと同じ状態で配置した。設備の材料は後述。
4. 1つのワールドで鋼鉄、ニッケル、フェロクロム、ステンレス鋼板へ進めた。酸化ニッケルと鉄塊、ニッケル、フェロクロム、ステンレス鋼の各工程間は実際の搬送を使った。板を次の設備へ使う段階は硫黄工程で止まったため未達。
5. 鋼鉄3バッチ、ペントランド鉱焙焼3バッチ、ニッケル還元3バッチ、フェロクロム6バッチ、ステンレス鋼3バッチ、ネザーラック破砕3バッチを運転した。運転できた範囲では、搬出を続けて回収できた。B後続設備の連続運転は未検証。

## 自動検証と計測

開発専用の確認ワールドは既存の機械のサーバーtickで運転する。GameTestでも同じワークショップを使い、出力を確認した。クライアントでは段階Aのみバニラのtick sprintを使用し、硫黄の採取試験に切り替えた直後に停止した。段階Bは通常の20 tick/sで、以下は実際のゲーム内tick。確率で増えるシンダー粉によって、次のブレイズケーキに必要な追加破砕の回数が変わる。

最初のペントランド鉱4個から酸化ニッケル2個と鉄塊6個が出た。通常加熱の焙焼は運転済み。鋼鉄の全材料をそろえて通常加熱だけで試す対照操作は未実施。

ペントランド鉱とクロム鉄鉱の入手負担の目安として、ペントランド鉱石はY −56～16に最大6ブロックの鉱脈を毎チャンク3回、クロム鉄鉱石はY −48～32に最大7ブロックの鉱脈を毎チャンク3回配置する設定だった。初回の板16枚はペントランド鉱4個とクロム鉄鉱8個を要した。フラットワールドに採集相当の原料を持ち込んだため、実際の探索時間、採掘時の発見率、ネザーでのブレイズ捕獲と原料収集は未計測。

### 段階B

1. 8 RPMで互いに逆向きに回る破砕ホイールを設置し、排出口を下向きにする。下にデポ、ホッパー、回収チェストをつなぐ。
2. ネザーラック8個を入れ、各バッチが完全に排出されてから次を入れる。
3. 回収チェストにはシンダー粉が入り、JEIに出る硫黄粉は入らなかった。Createの `create:crushing/netherrack` とこのModの `create_refinery_n_reactors:crushing/netherrack_to_sulfur_dust` は両方ロード済みで、入力はいずれもネザーラック。Createの破砕ホイールは一致するレシピを1件選んで処理する。各バッチでシンダー粉が出たため、今回選ばれたのはCreate側のレシピと判断した。

| 破砕 | ネザーラック | 所要tick | シンダー粉 | 硫黄粉 |
| --- | ---: | ---: | ---: | ---: |
| 1 | 8 | 1,088 | 11 | 0 |
| 2 | 8 | 1,096 | 12 | 0 |
| 3 | 8 | 1,112 | 14 | 0 |

保存データでも、鋼鉄12個、ステンレス鋼板30枚、シンダー粉37個を確認した。

同じ入力で2件を競合させず、既存のシンダー粉を維持したレシピへ硫黄粉を統合するか、硫黄粉が得られる別の原料・工程を明示することを提案する。JEIにはブレイズパウダーからの手分解もあったが、今回のネザーラック経路の試験には使用しなかった。

ふた付き槽はレシピ上1ブロックにステンレス板4枚・鉄のトラップドア1個・鉢1個が必要で、3×3では板36枚・トラップドア9個・鉢9個になる。今回の30枚は試験で指定された3バッチの出力。電解セルの4個分は板4枚・ガラス2個・銅板2枚・鉢1個。ふた付き槽の組立、電極のSTART/STOP、開放口から空気2,400 mBを吸う時間、粘土からセラミック管の製造、銅管と強化管の停止、浸出・円形沈殿池・鉄と銅の回収率、酸保管の使い勝手は未実測。

## クライアント画面と説明の照合

- Ponderの「鉄原料から鋼鉄とステンレス鋼を作る」は、木炭の章で「石臼では石炭・木炭とも染料になる」と表示した。実機の石臼は石炭から炭素粉を作った。木炭は既存のmillingレシピの確認まで。[Ponderの画面](../quality/survival-playtest/ponder-carbon.png)
- JEIは硫黄粉の用途別製造画面にネザーラックの破砕レシピを表示した。実機の選択とは食い違う。[JEIの画面](../quality/survival-playtest/jei-netherrack-sulfur.png)
- 説明書のリソースは、鋼鉄・ニッケル・ステンレス鋼の配合とプレイテストの出力が一致し、硫黄の入口は実機と食い違った。説明書の該当ページと実績画面の操作自体は未検証。
- 実績の定義は鋼鉄→ニッケル→ステンレス鋼→ふた付き槽→電解セル→硫酸。硫酸取得の条件は硫酸バケツで、説明書の希硫酸工程で作る希硫酸バケツは条件に入っていない。浸出とジルコニアは硫酸から分岐し、アルミ実績の親はジルコニア。希硫酸の章と実績の条件を説明書で区別すると、次の目標を確認しやすい。ゴーグルの表示は未確認。
- 稼働後のワールドと回収在庫は通常速度に戻して撮影した。[工場全景](../quality/survival-playtest/workshop-overview.jpg)、[破砕ホイールと3つの回収チェストの記録](../quality/survival-playtest/world-products.jpg)

## 再現

[起動設定](../quality/survival-playtest/progression-client.gradle)、[計測結果](../quality/survival-playtest/progression-results.json)、[確認ワールドのコード](../../src/main/java/net/createplant/client/SurvivalProgressionWorld.java)を使用する。配布ZIPの `survival-progression` フォルダを `saves` に置き、シングルプレイの「序盤〜中盤のサバイバル確認」を開く。鋼鉄は `(28, -53, 18)`、板は `(50, -53, 48)`、破砕結果は `(5, -33, 6)` のチェストにある。測定時の新規ワールドを再作成するには、リポジトリ直下で実行する。

```sh
mc-debug bash gradlew --no-daemon -I docs/quality/survival-playtest/progression-client.gradle \
  -DsurvivalSprint=33000 runClient
```

テストは `SurvivalProgressionGameTests`。ビルドと追加GameTestは成功し、既知のテストは作業前後で同じ結果だった。調査で分かったレシピ競合・表示差は提案として記録した。
