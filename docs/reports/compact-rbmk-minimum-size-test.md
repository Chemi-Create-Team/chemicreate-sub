# 小型RBMK炉（燃料部3マス）最小サイズの動作試験

## 結論

燃料部3マスの小型RBMK炉は、直径5と7では出力運転を続けられない。起動して一時的に定格付近まで上がるが、キセノンが増えると制御棒を全引抜しても反応度が足りず、出力0に落ちて再起動できなくなる。直径9以上は定格出力を保持できた。燃料部7マスの炉は直径5でも定格を保持した。

形成、寸法の比例、保存、制御棒行程などの既存試験はすべて合格した。問題は、それらの試験が扱っていない「長時間の出力運転」で出た。修正方針（最小寸法の制限か、物理定数の調整か）は設計判断なので、コードは変更していない。

## 対象

- 試験日：2026-11-10
- 対象：Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10 / Java 21.0.11（Windows 11）
- 試験したコミット：`55f05128bca0f5ec62919928748496a875698810`（`main`）
- 小型炉を追加した実装コミット：`022c6fe462609bfb9593e10852ef07481571c9c9`（[統合報告](powders-compact-reactor-sounds.md)、[小型炉の引継ぎ](compact-rbmk-core.md)）

## 実施した試験

| 試験 | 結果 |
| --- | --- |
| 全GameTest（`runGameTestServer`） | 515件中512件合格。失敗3件はRBMKと無関係（後述） |

| 一時的な運転試験（下記） | 7構成を各60,000 tick運転。試験コードはコミットしていない |

### 一時的な運転試験の条件

`CompactRbmkGameTests`に一時的に追加したGameTestで、実際の燃料チャネル束、給水細管束、制御棒、遮蔽体駆動部（クリエイティブモーター128 RPM）を組んで運転した。

- 燃料：全燃料チャネルに燃料棒を装荷。制御チャネルには制御棒を全挿入で装着
- 給水：270 °C（543.15 K）の水を給水細管束から補給
- 循環：最大炉の実測循環流量165,888 mB/tを、燃料本数と炉心高さ（3/7）で比例させた量を、毎tick出口から抜き取る
- 制御：10 tickごとに、出力が定格の98%未満かつ反応度0.001未満なら挿入率を1%下げる。反応度0.002超か出力102%超なら1%上げる。原子炉の自動制御盤が使う`setAutomaticTarget`経由で制御棒を動かした
- 終了：59,400 tickでAZ-5（`setConsoleScram`）を押し、600 tick観察

この調整方法は、制御の速さを抑えた試験用の操作であり、ゲーム内の自動制御盤の制御則とは別である。試験装置の妥当性は、燃料部7マスの直径5と燃料部3マスの直径13が、文書の定格どおりの出力を保持したことで確認した。

| 燃料部3マス・円形7 | 99／13 | 81.8 MW | 維持できない。tick約42,000で全引抜、出力0 | 362.7 MW | 1,778 K |
| 燃料部3マス・円形9 | 182／26 | 150.3 MW | 定格を保持。終盤の挿入率0.08〜0.14 | 228.0 MW | 1,716 K |
| 燃料部3マス・円形11 | 279／37 | 230.4 MW | 定格を保持。挿入率0.15 | 324.3 MW | 1,741 K |

出力を保持できた構成は、いずれもAZ-5後に制御棒が全挿入され、反応度が約-0.09〜-0.13になった。600 tickで出力は定格の1%前後まで下がった（崩壊熱を含む）。燃料温度はどの構成でも破損温度2,400 Kに達しなかった。

### 直径5で止まる経過（燃料部3マス・円形5）

| tick | 出力 | 反応度 | キセノン | 挿入率 | 状態 |
| ---: | ---: | ---: | ---: | ---: | --- |
| 14,000 | 34.19 MW | -0.00043 | 0.076 | 0.13 | `critical` |
| 18,000 | 28.96 MW | -0.00353 | 0.309 | 0.06 | `unstable` |
| 20,000 | 6.46 MW | -0.00562 | 0.516 | 0.00 | `unstable` |
| 22,000 | 0.03 MW | -0.01343 | 0.897 | 0.00 | `unstable` |
| 26,000 | 0.00 MW | -0.02823 | 1.368 | 0.00 | `az5_danger` |

出力が落ちると、ヨウ素の崩壊でキセノンがさらに増え（最大1.55）、いわゆるキセノンの谷に入る。試験終了まで再臨界しなかった。この間の状態表示は、制御棒全引抜の`unstable`／`az5_danger`である。

## 原因の見立て

反応度は`ReactorCore.tick`で次のように決まる。

`FUEL_WORTH × 燃料割合 − 漏れ − STRUCTURE_ABSORPTION + 制御棒 + ボイド + ドップラー − XENON_WORTH × キセノン`

漏れ（`ReactorPhysics.leakage`）は、半径方向と高さ方向の幾何学的バックリングの和に比例する。燃料部3マスでは高さ方向の項（π²/9）が7マスの約5.4倍になる。

| 構成 | 漏れ |
| --- | ---: |
| 燃料部7マス・円形5 | 0.0485 |
| 燃料部3マス・円形13 | 0.0530 |
| 燃料部3マス・円形11 | 0.0554 |
| 燃料部3マス・円形9 | 0.0594 |
| 燃料部3マス・円形7 | 0.0675 |
| 燃料部3マス・正方形5×5 | 0.0811 |
| 燃料部3マス・円形5 | 0.0869 |

定格出力時は、ドップラー効果（約-0.0135）と平衡キセノン（-0.028）を、制御棒を抜いた余剰反応度で補う必要がある。漏れが約0.06を超える構成では、この余裕が残らない。

[組立説明](../rbmk-reactor.md)は小型構成でも「平面の5～13マス」が共通だと説明しているが、燃料部3マスで連続運転できるのは実測で直径9以上である。直径5と7の小型炉は形成も起動もできるので、プレイヤーは運転途中で必ず停止する炉を作れてしまう。

## 併せて確認した事項：自動制御盤の起動時の行き過ぎ

最初の探索では、ゲーム内の自動制御盤と同じ`ReactorAutomaticControl.nextTarget`で冷態から起動した。この制御則は、燃料最高温度1,500 K未満・出口550 K未満の間、10 tickごとに挿入率を1%ずつ下げ続け、出力や反応度を見ない。そのため次の結果になった。

| 構成 | 尖頭出力 | 最高燃料温度 | その後 |
| --- | ---: | ---: | --- |
| 燃料部3マス・円形5 | 12,013 MW | 1,959 K | 全挿入、キセノン蓄積で停止したまま |
| 燃料部3マス・正方形5×5 | 21,455 MW | 2,129 K（警報2,073 K超） | 同上 |
| 燃料部7マス・円形5 | 114,234 MW | 2,347 K（破損2,400 Kまで53 K） | 同上 |

燃料部7マスの炉でも起きるため、小型化とは独立した既存の挙動である。最大炉で同じことが起きるか、ゲーム内の自動制御盤（制御卓に隣接して使う構成）でも再現するかは確認していない。
