# ハーバーボッシュ反応塔の反応・熱・圧力 完了レポート

## 仕様
- 反応塔ブロックはタンクとしての機能を持たない（液体を保持せず、通常のタンク用ポートも公開しない）。見た目と連結・3×3一括設置はCreateのタンクのまま。
- 成立した塔の底面中央ブロックが所有者となり、状態（気体のモル数・触媒層温度・ジャケット液・過熱）を保持する。`ReactionTowerBlockEntity`、物理は`chemistry/HaberBoschBed`（ワールド非依存）。
- ポート（Create標準の流体ハンドラー）
  - 底面中央の下面：H2/N2混合気体の入口。受け入れは`synthesis_gas`、`interstage_synthesis_gas`、`hot_interstage_synthesis_gas`、`compressed_synthesis_feed`、`heated_synthesis_feed`のみ。
  - 上面中央の上面：アンモニア（`ammonia_gas`）の出口。触媒層の温度で出る。未反応のH2/N2は塔内で再循環する（既存の閉ループ方針）。
  - 上下の外周8個（中央以外）の外側の面：冷却ジャケット。どれも同じ容量4,000 mBの槽につながり、任意の流体を出し入れできる。
- 加熱：底面の下の9か所のブレイズバーナー（FADING 20 kW、KINDLED 60 kW、SEETHING 120 kW）が触媒層を加熱する。炎の上限は1,400 K。
- 自己加熱：反応熱（発熱）が触媒層を温めるため、十分な圧力と温度では加熱なしで進む。

## 計算
- 気体はモル数で保持し、圧力は分圧の和（ドルトンの法則、`p_i = n_i R T / V`）。体積は山1個あたり0.008 m³（Createのタンク1ブロック=16バケツと同じ縮尺）。
- 平衡定数：標準ギブズエネルギー −32.8 kJ/反応、反応エンタルピー −92.4 kJ/mol（温度依存、ΔCp = −45.3 J/mol·K）からファントホッフ式を積分。`Kp [bar⁻²] = Q = p(NH3)² / (p(N2)·p(H2)³)`。
- 各ステップで`Q = Kp`となる反応進行度を二分法で解く。ルシャトリエの原理（高圧で増加、高温で減少）はこの式から自然に出る。反応速度はアレニウス式（Ea = 100 kJ/mol、700 Kで約0.4 /s）で平衡へ近づく。
- 反応熱 = −ΔH(T)·進行度を、触媒層（山の段数＋上下の蓋×60 kJ/K）と気体の熱容量で割って温度へ反映する。流入気体は熱容量で重み付けして混合する。
- 外周ジャケット：触媒層とジャケット液の熱交換は伝導率400 W/Kを上限に、両者の平衡温度を超えない。外殻の放熱は既存の`PassiveHeat`（外気温、1段あたり3 W/K）。
- 溶融：触媒層が600℃（873.15 K）を超えると損傷が累積（超過が大きいほど速い）し、20秒相当で外殻の反応塔ブロックがすべて消え、中心の山が溶岩になる。気体は大気へ放出（雲の演出）。`vesselRupture`設定が無効なら溶融しない。
- 圧力：既存の`PressureVesselBehaviour`（定格300 bar、過圧は歪み→破裂）に接続。既存のポンプ・圧力計・安全弁の解決先は塔の所有者になる。

## 気液分離器（アンモニア凝縮・分離）
塔の出口から出る混合気体を冷やしてアンモニアを液化し、液体を底から、未反応ガスを上から取り出す装置。貼付された説明（冷却による結露、気液分離、液封、高圧での押し出し、未反応ガスの循環）に沿う。

- **構造**：Createのタンクと同じ連結（1〜3幅、2層以上）。`ammonia_separator`ブロック。モデルとテクスチャはCreate自身の`fluid_tank`（銅色）をそのまま使用（独自テクスチャなし）。レシピは銅板・流体パイプ・Createの流体タンク。
- **ポート（標準の流体ハンドラー）**
  - 上層の側面：入口。`hot_synthesis_mixture`（塔の出口）のみ。
  - 下層の側面：冷却ジャケット（任意の流体、4,000 mB）。
  - 最上面：未反応のH2/N2を`compressed_synthesis_feed`として取り出す（塔の入口へ戻す）。
  - 最下面：液体アンモニア（既存の`ammonia_gas`流体を低温で渡す。液体用の別流体は追加していない）。フロート弁が一定量（0.5 mol）の液を残し、ガスが漏れない。
- **塔の出口の変更**：塔の上面中央は純粋なNH3ではなく、実際の組成を持つ反応排出ガス（`hot_synthesis_mixture`）を出す。組成（NH3モル分率）は新しいデータ成分`ammonia_fraction`で運ぶ。温度の異なる混合気体は既存どおり混ざり、組成はモル数で加重平均する（`FluidThermal.mix`）。
- **計算**（`chemistry/AmmoniaSeparator`）：NH3は分圧が冷却後の蒸気圧（既存`FluidPhase`の蒸気圧曲線）まで下がるまで凝縮し、凝縮熱（ワトソン式の潜熱）で温度が変わる。臨界温度（405 K）以上では液化しない。H2/N2は気相に残る。圧力は分圧の和。冷却ジャケットとは伝導で熱交換する。例：200 bar・20%NH3の気体を約15℃まで冷やすと、NH3分圧が約9 barの蒸気圧に落ちる（現実と同様に一部は気体に残る）。
- **圧力**：既存の`PressureVesselBehaviour`（定格300 bar）に接続。破壊時と制御ブロック撤去時は内容物を雲の演出とともに放出する。
- **確認**：`runGameTestServer` 294件成功（組成の混合、凝縮と蒸気圧・保存、液封、ポートの配置と取り出し）。実クライアントでCreateの銅タンクのテクスチャで描画されることを確認。
- **未実装・制約**：Ponder、液面の描画（Createのタンクの液面は使わない）、ディスプレイリンク対応、液体アンモニア専用の流体。液体の押し出しにはCreateのポンプが必要（既存のパイプは自律的に流れないため）。`ammonia_separator`の窓はCreateの標準のまま。
- 実装コミット（気液分離器）：316e63a
