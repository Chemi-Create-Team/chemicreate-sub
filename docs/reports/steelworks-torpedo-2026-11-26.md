# けい石レンガ・溶銑トーピードカー・転炉製鋼 実装報告

実装コミットは `a8d0f7b14ec53b3bcbe769abcf2ccf7edafd89da`。Modのバージョンは `0.3.0`。設置と運転方法は[製鋼ライン](../steelworks.md)、既存設備の接続口は[転炉ガイド](../converter.md)に記載した。

## 実装

- Createの鉢を使う超過熱プレスで砂2個と生石灰1個からけい石レンガ4個を成形する。転炉の炉殻のクラフトと内張りに使用する。既設のジルコニア耐火レンガ内張りも形成条件を満たす。
- 耐火内張り横型タンクは横型タンクの連結と定置時の流体Capabilityを継承し、常圧・最高温度段階の溶銑、脱硫溶銑、溶鋼を1種類ずつ運ぶ。移動中はCreateの積荷として扱われ、ポータブル流体インターフェースで移送できる。
- 銑鉄1個から溶銑100 mB。溶銑800 mBは生石灰で脱硫して同量の脱硫溶銑とスラグ1個になる。転炉は脱硫溶銑6,400 mB、鉄インゴット8個、生石灰4個、酸素64,000 mB（または液化酸素92 mB）を800 tickで吹錬する。溶鋼6,400 mB、スラグ8個、転炉ガス128,000 mBが得られる。
- 溶鋼800 mBを鉢とプレスで鋳造鋼スラブ1個にし、多段圧延ラインで極厚鋼板3枚へ加工できる。従来の鋼鉄ブロックの再圧延も同じレシピを使う。
- 旧酸素製鋼レシピのIDは、保存済みで開始済みのチャージを完了できるよう保持する。新しいチャージとJEIでは脱硫溶銑を使う。既存のAOD精錬は引き続き利用できる。

## 主要箇所

- `registry/CEConverter.java` が内張り材、車載タンク、鋳造スラブとCreateの積荷型を登録する。`block/entity/TorpedoTankBlockEntity.java` と `contraptions/TorpedoStorage.java` が固定・車載の流体判定を共有する。
- `mixin/TorpedoContraptionMixin.java` はタンクの一部分だけが車両化されるのを防ぐ。Createが車体の回転時にコントローラーの位置を移す前に、実際の積荷を車載データから受け渡す。
- `recipe/ConverterRecipe.java` が追加の液体原料・製品を定義する。`block/entity/ConverterTrunnionBearingBlockEntity.java` がガス・液体・固体を取り置きし、すべての出力に空きがあれば完了時に一度だけ確定する。
- `data/create_refinery_n_reactors/recipe/` に材料と工程、`ponder/SteelworksPonderScenes.java` に製鋼ラインの解説がある。転炉の既存Ponderと製造ガイドも更新した。

## 検証

- Java 21でGradleのビルドと専用サーバーGameTest 47件が成功した。Createの鉢で、通常加熱ではレンガが作れないこと、超過熱でのレンガ成形、銑鉄の溶解、脱硫、溶鋼の鋳造を確認した。圧延の既存テストを鋳造スラブの投入に切り替えて検証した。
- `CarriageContraption` とポータブル流体インターフェースで積荷を抜き、積荷の保存・再読込・180度回転した分解で同量が戻ることを確認した。列車の長距離走行と時刻表による自動運転は未検証。走行中の溶湯の冷却・凝固は計算しない。
- 転炉では酸素と液化酸素、溶鋼とスラグの出鋼、転炉ガスの回収、進捗の停止・再開、ガスの搬出先がない場合の消費防止、AODを確認した。
- RTX 4060の日本語クライアントで、トーピードカーと転炉のPonder、転炉のJEIカテゴリを表示した。[Ponderの画面](../quality/steelworks/torpedo-car.jpg)
