# 化学工業と化学肥料の統合

実装コミットは `1fc6d9dd788d4c8b3fef1db90745439645fd64e7`。対象は Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10。

## 調査で確認した既存機能

- 鉄鋼・ステンレス鋼・合金・鉱石は既存の製造体系にある。蓋付き容器にはステンレス鋼板を使う製造経路があり、撹拌翼、回転、加熱、複数の流体入力、アイテムと流体の各出力を備える。既存の分留塔、触媒反応塔、圧縮機、加熱機構、Createミキサー、タンク・配管に接続した。
- ガス化炉の水性ガス、水素、転炉ガスから回収する一酸化炭素、一酸化炭素の酸化で得る二酸化炭素、アンモニア・硝酸・硫酸・リン酸、食塩水、不凍液は既存の登録と配管を使った。硝酸のアンモニア系製造、硫酸と骨粉からリン酸・石膏を得るレシピ、硝酸アンモニウムの製造も既存。
- 硫酸アンモニウムと硝酸アンモニウムは、1個で周囲3×3を即時成長させる肥料だった。作物ごとに残る施肥状態、自然成長への加算、追加収穫は今回追加した。既存品の登録IDと製造レシピはそのまま使う。
- 圧力反応はデータパック、触媒反応・分留は共有の処理表で登録する。JEIは両方を既存の機械カテゴリーに表示する。バニラの成長・収穫、Createデプロイヤーのアイテム使用とハーベスターの搬送先に接続した。

## 追加した登録と製造

固体は、生石灰、炭酸水素ナトリウム、炭酸ナトリウム（ソーダ灰）、尿素、リン酸肥料、カリ灰、NPK肥料の7品。流体は、メタノールと塩化アンモニウム母液の2種。流体登録に付随するバケツと流体ブロックも追加した。製造には既存機械、材料には既存鉱石、操作には既存の設備画面を使う。

| ゲーム内の製造工程 | 使用する設備・条件 | 出力と用途 |
| --- | --- | --- |
| 方解石の焼成 | 撹拌式の蓋付き容器、超加熱 | 生石灰と二酸化炭素。回収・ガラス、尿素・ソーダ灰へ |
| 水性ガスの分離 | 2×2断面、最小2段の分留塔 | 下部で一酸化炭素、上部で水素。水素は既存圧縮機の2段を通す |
| 一酸化炭素と圧縮水素の反応 | 加熱した反応塔と既存の水素化処理触媒 | メタノール。水とCreateミキサーで混ぜると不凍液 |
| 液体アンモニアと二酸化炭素の反応 | 撹拌式の蓋付き容器、加熱 | 尿素と水 |
| 食塩水・アンモニア・二酸化炭素の反応 | 撹拌式の蓋付き容器、3流体入力 | 炭酸水素ナトリウムと塩化アンモニウム母液 |
| 炭酸水素ナトリウムの焼成 | 撹拌式の蓋付き容器、加熱 | ソーダ灰と再利用できる二酸化炭素 |
| 母液と生石灰の処理 | 撹拌式の蓋付き容器、加熱 | アンモニアを元の工程に戻せる。中和排水を別の出力から取り出す |
| ソーダ灰・砂・生石灰の混合 | Createミキサー、超加熱 | バニラのガラス。砂タグを使うので赤い砂も使用可能 |
| リン酸と方解石の反応 | 撹拌式の蓋付き容器、加熱 | リン酸肥料 |
| 乾燥昆布からカリ灰 | Createミキサー、加熱 | NPKのカリウム原料 |
| 尿素・リン酸肥料・カリ灰の混合 | Createミキサー | NPK肥料 |

## 肥料の効果と保存

各肥料は、未成熟の作物を右クリックすると、同じ高さの3×3にある対象作物を1段階成長させる。1個で最大9株に適用する。その後の自然成長が成立したとき、肥料に応じて成長段階を追加する。骨粉による成長は通常どおりで、追加回数を消費するのは自然成長だけ。肥効中の成熟収穫で、通常ドロップに作物の追加分が乗る。

| 肥料 | 製造原料 | 自然成長への加算と上限 | 最長時間 | 追加収穫 |
| --- | --- | --- | --- | --- |
| 硫酸アンモニウム | 既存のアンモニアと硫酸の工程 | +1段階、2回 | 20分 | 25%で+1 |
| 硝酸アンモニウム | 既存のアンモニアと硝酸の工程 | +1段階、3回 | 20分 | 45%で+1 |
| 尿素 | 液体アンモニアと二酸化炭素 | +1段階、4回 | 30分 | 55%で+1 |
| リン酸肥料 | リン酸と方解石 | +1段階、2回 | 30分 | 65%で+1〜2 |
| NPK肥料 | 尿素、リン酸肥料、乾燥昆布由来のカリ灰 | +2段階、4回 | 40分 | 100%で+2〜3 |

最長時間はサーバーのゲーム時間。成長加算の上限を使ったあとも、期限まで収穫分の効果は残る。同じ株では肥効中は最初の施肥が有効。新たに施肥できる株があるときだけアイテムを消費する。

データはディメンションごとの `SavedData` に、施肥した株の座標・ブロックID・肥料・期限・成長加算の残数を保存する。チャンクの読込状態とは独立して保持される。成熟株の収穫でデータを先に消費するので、同じ収穫でボーナスが重複しない。作物の破壊や植え直しに対応し、期限切れの記録を定期的に解放する。バニラがブロック除去の後にドロップを判定する経路では、そのtickだけ元の成熟株の収穫を受け付ける。

## 制約と次の拡張

バニラの小麦、ニンジン、ジャガイモ、ビートルートを対象とし、同じ成長・収穫経路を使う他の `CropBlock` は通常の収穫物からボーナスを選ぶ。独自収穫装置、独自の右クリック収穫、および `CropBlock` 以外の作物Modは個別の互換テストを行っていない。二酸化炭素は既存ラインと方解石焼成から、一酸化炭素は既存の転炉ガスと水性ガスから供給する。メタン改質は追加の供給経路として保留した。ソルベー工程の回収後の排水は既存の中和排水として扱う。

次に拡張するなら、作物ごとに追加収穫の対象品と独自の収穫動作を定義できるデータを用意すると、農業Modに合わせて互換性を積み上げられる。
