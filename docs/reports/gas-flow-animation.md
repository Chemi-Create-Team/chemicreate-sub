# ガス雲の流れと薄まり

実装コミットは `dd12f6944b8e9b119f07e226b5939b6af26933d2`。

床側のもやは足元に沿って流れ、白い蒸気は天井の下で広がる。霧の濃い筋は横へ移動しながら曲がり、立体的に厚みを増して透けていく。

## 実装

- `client/GasCloudRenderer.java` は、雲の各マスに対して最大5×5マスの描画範囲を求める。行を広げるときは角も含めて `CloudVolume` の内側であることを確認する。範囲は雲の同期範囲が変わった後の最初の描画時に更新する。
- 各筋の周期はおよそ42〜71 tick。位置で決まる速度と位相をずらし、近くの筋は共通の曲がり方を持つ。進むにつれて上がる向きは床側と天井側で反転する。2枚の傾斜面を重ね、動きの端で不透明度を落とす。
- 雲全体の濃さは残量の同期値から求め、変化を12 tickかけて補間する。ガスの範囲と残量は既存のサーバー同期を使う。
- 追加の描画用パーティクルは使わず、透明面は範囲内1マスにつき最大2枚。ガス回収ダクトの既存Ponderも同じ描画を使う。

## 確認

- Java 21、Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10でGradleビルドが成功した。 `ToxicGasGameTests`、`GasSafetyLoadGameTests`、`ProcessGasRecoveryGameTests` の計21件が合格した。
- RTX 4060の日本語クライアントで、石床の塩素雲が横へ流れ、濃淡と形が変わる様子を確認した。ガス回収ダクトのPonderでも天井側の白い蒸気の描画を確認した。
- 描画位置の式を周期全体で走査し、面が各筋の描画範囲と高さに収まることを確認した。配布JARの全エントリーをGradle出力と比較した。
- シェーダーパックとの併用と、大量配置時のフレーム時間は未検証。
