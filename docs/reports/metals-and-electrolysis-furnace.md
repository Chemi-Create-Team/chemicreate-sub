# 金属6種の入手手段と溶融塩電解炉 実装レポート

## 基準と実装コミット

- 作業ブランチ：`main`
- 作業開始時の基準コミット：`4d4c85e`
- 実装コミット：
  - `d26d05d`：鉱石6種と精錬反応
  - `1054445`：溶融塩電解炉とCEEへの直接接続、Ponder、JEI、文書

## 依頼と決定事項

- 依頼：金属インゴット6種の入手手段を確立する（使い道は今回は対象外）。
- ユーザーが選んだ方針：
  - 鉱石：B案。6金属に対応する鉱石を6種追加する。
  - 電力：このMODの電力はCEEのもの。アルミニウムの電解はCEEの回路に直接つなぐ。既存のFE設備は今回は変えない。
  - 電解炉：マルチブロックにする。
  - 製法：硫酸塩法、焙焼と水素還元、テルミット法、FFC法の案で進める。

## 実装内容

### 鉱石と精錬（`d26d05d`）

- 登録：`registry/CEMetals.java`
  - 鉱石：石版と深層岩版で12ブロック。
  - 鉱物アイテム6種、酸化物アイテム5種。
  - 硫酸塩の溶液3種。腐食性で、物性も登録した。
- 生成スクリプト：`tools/generate_metal_ores.py`
  - 鉱石・鉱物・酸化物のテクスチャ。鉱石の重ね絵は、ウラン鉱石と同じ方式で鉱物ごとに色と粒の配置を変えた。
  - モデル、ルートテーブル（幸運・シルクタッチに対応）、Createでの粉砕。
  - タグ（`c:ores/<鉱物>`、石・深層岩、ツルハシ、鉄以上の道具）。
  - ワールド生成（高さは実在の産状に合わせた）。
  - 撹拌反応槽の11反応、翻訳。
- 表と数値は `docs/metals.md` にまとめた。

### 溶融塩電解炉（`1054445`）

- ブロック：
  - 外殻（`electrolysis_furnace_shell`）、炭素陽極（`electrolysis_furnace_anode`）：`ElectrolysisFurnacePartBlock` と、制御部への入出力を中継するブロックエンティティ。
  - 母線（`electrolysis_furnace_busbar`）：`compat/electro/FurnaceBusbarBlock`。CEEの `SimpleElectricalDeviceBlock` を継承する。
- 制御部（`block/entity/ElectrolysisFurnaceBlockEntity`）：
  - 構造の確認、在庫、浴の温度、進み具合、停止理由、ゴーグル表示、保存を受け持つ。
  - 1秒ごとに構造を確認し、各部品に制御部の位置を記録する。
- CEEへの接続：`compat/electro/FurnaceBusbarDevice`
  - 構造が完成している間だけ、端子0（陽極）と端子1（陰極）の間に2 Ωの抵抗を回路へ登録する。
  - 解いた回路から端子間電圧の2乗を受け取る。交流でも、電圧の2乗の平均から正しい電力になる。
  - 装置の種類は `compat/electro/ElectroDevices` で、CEEの装置レジストリに登録した。
- ビルド：CEEを `runtimeOnly` から `implementation`（推移依存なし）に変えた。CEEはすでに必須依存である。
- JEI：カテゴリ「溶融塩電解炉」。背景はPonderの構造。

## 計算方法

| 量 | 値 |
| --- | --- |
| 抵抗 | 2 Ω。電力は V²/R（200 Vで20 kW） |
| 熱容量・放熱 | 1,000 J/K、外気との差1 Kあたり5 W |
| 溶融・運転温度 | 960 °Cで溶け、運転中は970 °Cを保つ |
| 金属1個の電力量 | アルミニウム200 kJ、チタン・ジルコニウム400 kJ |

- 毎tickの処理：
  - 入る電力量から、外気への放熱を引く。
  - 浴が溶けるまでは全部を加熱に使う。
  - 溶けて原料がそろっている間は、970 °Cを保つのに必要な分を除いた残りが電解の進みになる。
- 外気20 °Cで浴を保つには約4.7 kWが要る。それより弱い電源では溶けない。

## テスト

| 確認 | 結果 |
| --- | --- |
| `bash gradlew build runGameTestServer`、`-PwithJei=false runGameTestServer` | 両方で270件すべて合格 |
| CIの検証スクリプト4本 | 合格 |
| 実クライアント | Ponder全90シーンが合格。電解炉と精錬のPonderを撮影して目視した |

新しいGameTest `ElectrolysisFurnaceGameTests`（3件）：

- 形成：外殻・陽極・母線で炉になる。
- 搬入・搬出の面：上面から酸化物と石炭が入り、他のアイテムは拒まれる。金属は底面からだけ出る。
- 電力：
  - 電流がないと何も起きない。
  - 60 Vでは浴が溶けない。
  - 200 Vで浴が溶けてアルミニウムができ、1個ごとにアルミナと石炭を1個ずつ使う。
- 状態：陽極が光る。再ロード後も温度が残る。外殻が欠けると、炉と電流が止まる。
- チタン：二酸化チタンからチタンができる。ジルコニアにはアルミナの2倍の電力量が必要。
- CEEとの実配線：CEEのクリエイティブ電池（200 V、直流）と炉の端子を、CEEの銅線で実際に接続する。炉に1 kWを超える電流が流れることを確認した。

撹拌反応槽の総当たりテストにも、精錬の11反応が自動で含まれ、合格した。監査テストでも、新しいブロック・アイテム・流体の欠けはなかった。

## 未検証・制約

- 確認していないもの：
  - プレイヤーがCEEの電線アイテムで配線する操作。
  - 発電機（オルタネーター）からの交流での運転。
  - CEEの電流計での表示。
  - 実際のワールド生成での鉱石の出方（ワールドを生成しての確認はしていない）。
- CEEの内部クラス（デバイス・回路・ノード設定）を直接使っている。CEEの更新時には `compat/electro` の3クラスと、CEE配線のGameTestを確認する。
- 電解炉の日本語字幕は、手順2で「20」と「kW」が別の行に分かれる（改行の問題は後回しの指示どおり）。
- 金属インゴットの使い道は未実装（今回の範囲外）。
- 熱は1個の集中定数で近似した。陽極の消耗は、炭素アイテムの消費で表した。

## 次回の注意

- 電解できる酸化物を増やすときは、`ElectrolysisFurnaceBlockEntity.reductions()` に、酸化物・金属・電力量を加える。JEIとゴーグルには自動で反映される。
- 既存のFE設備をCEE直結に移す場合は、`FurnaceBusbarDevice` と同じく「抵抗を登録し、電圧の2乗を受け取る」形が使える。
