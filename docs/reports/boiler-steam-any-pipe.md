# ボイラーの蒸気をどの配管でも送れるようにする レポート

## 基準と実装コミット

- 作業ブランチ：`main`
- 作業開始時の基準コミット：`01a50a7`
- 実装コミット：`69bf5b7`

## 依頼

- Createのボイラーから蒸気タービンへ蒸気を送る配管は、気体パイプと超耐圧パイプしか使えなかった。
- 圧力と温度が合っていれば、どの配管でも使えるようにする。

## 原因

- ボイラーの蒸気は、Createの流体の搬送ではなく、`BoilerSteamOutput`が配管をたどって見つけたタービンへ直接渡している。
- この処理が付いていたのが気体パイプと超耐圧パイプだけで、たどる配管もその2種類に限られていた（削除済みの蒸気管の代わり）。

## 実装内容（`block/entity/BoilerSteamOutput.java`ほか）

- 処理を付ける配管を広げた。
  - Createの配管・ケース入り・ガラス付き、ステンレス鋼管の一族、樹脂パイプ、材質パイプのすべて（`MaterialPipeBlockEntity`）、気体パイプ。
  - Createとステンレス鋼管は、`PipeWearBehaviour.attachToCreate`で劣化と一緒に付ける。
- 経路の探索は、この処理を持つ配管ならどれでもたどる。バルブとスマート流体パイプは含めない（そこで止まる）。
- 出口として数えるもの：
  - ボイラーに接する配管のうち、高圧タービンへつながるもの。
  - 気体パイプ（タービンがなくても蒸気をためる。従来どおり）。
  - 給水用のCreateの配管は、タービンにつながらないので数えない。そのため、Createの蒸気エンジンの出力は変わらない。
  - 超耐圧パイプも、タービンにつながるときだけ出口になる（以前は常に数えていた）。
- 温度と圧力の確認：
  - 蒸気を送るたびに、経路のすべての配管へ、蒸気の温度とその温度の飽和蒸気圧を記録する（`PipeWearBehaviour.pressurized`と`transported`）。
  - 耐えられない配管は、ほかの流体と同じく警告・劣化・破損（設定による）になる。
- 負荷の軽減：ボイラーに接していない配管は、1秒に1回だけ周りを確かめる。
- Ponder「タービンの運転」の手順5の字幕を、この仕組みの説明に替えた（`tools/generate_turbine_thermal_ponder.py`、翻訳）。
  - 生成スクリプトはPonderの並びと構造データも書き直すため、字幕だけを反映した。
- 文書：`docs/pipes-and-tanks.md`に「ボイラーの蒸気」の節を追加した。

## 未検証・制約

- 経路の配管すべてに、毎tick温度と圧力を記録する。長い配管（最大256本）では処理が増える。計測はしていない。
- バルブで蒸気を止める操作には対応していない（バルブを挟むと経路が切れる）。
- ゲーム内での見た目（劣化の表示など）は撮影していない。
- 使われていない古い翻訳キー（`ponder.high_pressure_turbine_preview.text_7`、`ponder.high_pressure_turbine_multiblock.text_6`）に「蒸気パイプ」の記述が残っている。今回は変更していない。
