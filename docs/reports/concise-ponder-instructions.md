# Ponder説明の簡潔化

2026-11-12。開始コミット：`8d229bae`。実装コミット：`666309b9211e83e65fc97b6a7d572e80d9f238b0`。

## 変更

Ponder本文672項目のうち355項目を日英中で書き直した。組立・接続・操作・停止時の確認を中心に、原則1〜2文で説明する。長い計算説明、開発上の注記、変更履歴、レシピ欄と重複する数量を省いた。短く、既に手順が明確だった文章は維持した。

- 沸騰の潜熱・密度換算・気体の状態方程式・磁場の蓄積エネルギー・PIDの内部計算などを省略。
- 寸法、入出力面、回転数、操作ボタン、必要な温度・圧力、排気・冷却・安全弁の条件を維持。
- 原子炉・核融合炉・タービン・配管・冷却・反応槽・分留・電解・製造工程などを整理。円形タンクの各寸法例も短くした。
- 生成スクリプトと既存の文章データも対応。中国語を英語の代替文で上書きしていた再生成処理では、既存の中国語Ponder文を保つようにした。
- DESIGN.mdに、Ponderは短い操作説明を基本とする方針を追記。

例：槽の沸騰説明は「1 kgの蒸発に2.257 MJ、昇温の約540倍」という説明から、「開いた槽は約100 °Cで沸騰。密閉中は100 °Cを超えるため圧力も確認」という案内にした。CO工程はゲーム内の近似についての説明を省き、塔への投入位置と回収位置を示した。

登録キー、見出し、シーン構成、NBTの配置、レシピ、処理ロジックは同じ。レシピの`%s → %s`表示引数も維持している。
