## 実装内容

### Ponder

- **ガスホルダー球**（`gas_holder`）：原稿は `generate_plant_tutorials.py` に残っていたが、存在しない `gas_tank` に紐付いていたためカタログから外れていた。ユーザーの選択で気体パイプから開けるようにし、配置の送り元を Create の流体タンクに替えた。
- **横型流体タンク**（`plant/horizontal_tank`、`HorizontalTankPonderScenes`）
  - Java のシーンで、描いたタンクに Create の連結情報（コントローラーは最小座標の角、`Size`＝断面、`Height`＝軸方向の長さ）を与え、1つの連結したタンクとして表示する。
  - 説明：置き方（向いた方向／当てて延長／スニーク）、断面1×1～3×3と長さ、ボイラー、配管。
  - 配置データの生成元は `tools/generate_horizontal_tank_ponder.py`。

### 空気の液化（ユーザーの選択：コールドボックス方式）

- 原因：液体空気を作る手段がなく、エアーフィルターの空気の行き先もなかった。空気分離塔が使えず、窒素が得られないため、アンモニア・硝酸のラインがサバイバルで始められなかった。
- 修正：空気分離塔の原料フィード段（3段目の東面）が、液体空気に加えて、次の空気を受け付ける（`FractionatingColumnBlockEntity.compressedAir`）。
  - 送り元の圧力が6 bar以上（`GasInflow.pressure`。ポンプや気体パイプで送ったときに設定される）。
  - 温度が313.15 K以下。
- 空気1000 mBは、液体空気1000 mBと同じ1バッチとする。出力の窒素780 mB（気体）とも物質量が合う。
- 弁での膨張冷却（ジュール・トムソン）による液化は検討したが、採用しなかった。このMODの気体は1 barの体積で質量が小さいため、配管の放熱ですぐ外気温に戻り、成り立たない。
- 空気分離塔の3つのPonderの手順1に圧縮空気の説明を加え、エアーフィルターからも開けるようにした。`docs/distillation-plant.md` に組み方を追記した。

- **水素化脱硫触媒のレシピが読み込まれていなかった**（パターンの行幅の不一致。前回の私の作業の誤り）。`[" L ", "CIC", " L "]` に直し、レシピが読み込まれていることを確かめる確認をGameTestに加えた。
- **`create:non_movable` タグ全体が読み込まれていなかった。** 削除済みの `insulated_tank` を参照していたため。項目を削除した。
- **電解槽の蓋のテクスチャ `basin_plain`（16×14）が、ブロックアトラスのミップマップを下げていた。** 16×16にし（下の2行は使わない余白）、モデルのUVを14/16倍にして見た目を変えていない。生成元（`generate_basin_plain.py`・`generate_electrolyzer_lid.py`）も同じにした。
- **削除済みのブロックやシーンを復活させる生成スクリプト**
  - `generate_insulated_tank.py` を削除した。
  - `generate_transport_assets.py` から断熱パイプ（採掘タグに戻すとタグ全体が壊れる）を除いた。
  - `generate_petrochemical_ponder.py` から旧3シーンと、存在しないブロックを置く処理を除いた。
  - `generate_heating_tutorials.py` の断熱タンクを流体タンクに替え、出荷版と一致させた。
- **現行の仕様書の古い記述**：`docs/pressure.md`（断熱タンク・単体ガスタンク）、`docs/thermal-equipment.md`（断熱・蒸気パイプ）、`docs/water-two-phase.md` から、削除済みの設備を除いた。検証記録は当時の記録として残した。
- **新しく書いたGameTestの不具合**：分離塔の形成前に出口を参照してサーバーを止めていたため、null を扱うようにした。

## 未検証・制約

- エアーフィルター → 大型コンプレッサー → ラジエーター → 容器 → 分離塔の一連の流れは、ゲーム内では通しで確認していない。各段の単体テストと、タンクから分離塔への送液だけを確認している。
- 気体パイプや Create のポンプを通さない送り方（他MODの搬送など）では、送り元の圧力が分からないため、圧縮空気は受け付けられない。
- 原子炉の部品4種は、思案に紐付いていない。他メンバーの担当のため未対応。
