# アスベスト入り電解板とノズルの吸気

実装コミットは `32ddcf1a26674e3e1704f53e7d4e00e4967db9b7`。

- 電解板のクラフトで、左右の列にある灰色の羊毛6個をアスベスト6個へ差し替えた。銅板2枚・鉄板1枚と合わせて4枚作る。レシピJSONと `tools/generate_electrolysis_plate.py` を更新した。
- Create標準のノズルを配管の先やポンプの吸い込み側に付けられるようにした。正面の隣が空気なら、配管がつながる背面から1回の要求につき最大1,000 mBの空気を搬出できる。ポンプの回転と向きで流れを制御する。ファンに装着したノズルはCreate標準の送風に使える。主な処理は `NozzleIntake` と `NozzleBlockMixin`。
- エアフィルター専用の登録・レシピ・モデルを削除した。旧ブロック・アイテム・ブロックエンティティのIDをノズルに対応付け、読込時に配管またはポンプがつながる面の反対へ口を向ける。ノズルの接続面は1面。気体ポンプと空気分離のPonderを更新した。

## 確認

- Gradleビルドと専用サーバーのGameTest 28件が通過。電解板を実際の合成判定に通し、アスベスト6個から4枚作れることを確認した。ノズルの直付けと配管経由、口を塞いだときの停止、旧IDの読込と向きの移行、ファン取り付け、空気分離ラインも確認した。
- Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10、RTX 4060で2本の吸気ラインを稼働させた。配管経由と直付けで、同じ時点にそれぞれ4,256 mBの空気を受け取った。Ponderは構造データと文言を確認した。
- 配布JARは8,386,820バイト。8 MiB以内に収めるため開発用GameTestクラスファイル37個を省き、残りのすべてのファイルが通常のビルドと一致することを確認した。SHA-256は `e0993242504b0a19fa7c7bf250f9585efae95f6ea314f900633f037eeb76f8cb`。
