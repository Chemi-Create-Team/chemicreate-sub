# 引き継ぎ：制御棒ウインチ、7段炉心と燃料棒の穴、バイオロジカルシールドと放射線、制御棒全引抜の不安定

ブランチ `work`。設計の正本は[rbmk-reactor.md](../rbmk-reactor.md)、クレーンは[gantry-crane.md](../gantry-crane.md)。前の経緯は[rbmk-playtest.md](rbmk-playtest.md)。

## ユーザー要求と決定

- 制御棒を全部抜くと揺らぎ・ボイド効果が起き、最悪は爆発する。
- メカニカルピストンをやめ、ロープ・プーリーを元にした専用の「制御棒ウインチ機構」で上下させる。
- 制御棒は下が炭素（黒鉛）6、上がホウ素7。燃料棒は7ブロックの燃料の上に7ブロックのただの柱。
- 蛇紋岩と、それから作るバイオロジカルシールドを追加する。覆わないと放射線で吐き気・めまいなどが出て、最後は急性放射線障害で死亡する。
- 実機RBMKと同じく、上部シールドの下に7ブロックの空間（全引抜のホウ素、ウインチ、配管の鉛直→水平）を設ける。
- クレーンで各燃料チャネルの穴へ1本ずつ燃料棒を挿入する。
- 確認して決めたこと：炉心は高さ7で固定。シールドは側面・上・下の全部。線量は出力と漏れで決まる。

## 実装

- **炉心**：高さ7固定（`ReactorCoreStructure.HEIGHT`）。下6ブロックが制御棒空間、上7ブロックがホール、その上が上部シールド。
- **制御棒ウインチ**（`ControlRodWinchBlock`、`ControlRodWinchBlockEntity`）：Createの`PulleyBlock`、`PulleyBlockEntity`を継承し、ロープ・プーリーの描画（`PulleyRenderer`、`RopePulleyVisual`）をそのまま使う。モデルはロープ・プーリーの色違い。
  - 棒は制御棒アイテムをウインチに使うと吊られる。`ControlRodContraption`がワールドにブロックを置かずにコントラプションを作り、保存は通常のプーリー形式。
  - 目標はハンドル角かアナログ信号。1/512ブロックに丸め、目標で正確に止める。
  - 入力反転時のCreateの整数丸めは、ウインチ側で深度を戻して打ち消す。そのため旧ピストン用Mixinは不要。
  - 行程の両端から1/512内側で止め、端での毎tickの衝突判定を避ける。
  - AZ-5は回転なしでも5秒で落下挿入する。固着中は保持する。応力は4。
- **削除**：
  - 制御棒駆動装置（ブロック・BE・描画・モデル・テクスチャ・レシピ・ルート・翻訳）
  - `ControlRodPistonStopMixin`、`MechanicalPistonAccessor`
  - 吸収体・ディスプレーサのアイテム、レシピ、ルートテーブル
  - 使用済み吸収体アイテム
- **燃料**（`FuelChannelBlockEntity`）：列の最下段が穴4つの状態（空・新・使用済み）と燃焼量を持つ。上面の搬入口は1穴1スロット。燃料棒1本＝28 GJ。燃焼は列の新しい棒で均等に分ける。ホールに立つ上半分は`FuelChannelRenderer`で描画する。
- **クレーン**（`CraneDriveBlockEntity`）：
  - 上部シールドの最も高いブロック（ホールの上、最大3段）に吊り具を下ろし、1回に1本、穴ごとに使用済みを抜くか新しい燃料棒を入れる（60 tick）。
  - 掴んだ14ブロックの燃料棒が滑り込む／抜ける様子を`CraneRenderer`で描画する。
  - 制御棒交換は、全引抜の棒を制御棒アイテムと入れ替え、使用済み制御棒を格納する。
- **物理**（`ReactorCore`、`ReactorPhysics`）：
  - **制御棒の位置**：全引抜では黒鉛が炉心の上6段、最下段は水になる。
  - **AZ-5の先端効果**：AZ-5の時点より黒鉛が増えた層の効きを(1＋100h)倍にする。以前は先端1区間に30倍を掛けていたが、今回は押し出した水の分だけに掛ける方式に変えた。
  - **不安定度** = clamp((1/6 − 吸収体挿入率)×6)。不安定度に比例して次の揺らぎと強化が入る。状態表示は「不安定」。
    - 反応度の揺らぎ（標準偏差0.4 $）
    - 出力の左右の傾き（標準偏差35%、4秒で元に戻るランダムウォーク）
    - ボイド効果（最大3倍）
  - **燃料による倍率**：制御棒・ボイド・揺らぎの反応度に、燃料の装荷割合を掛ける（燃料が無い炉心では効かない）。
  - **中性子レベルの上限**：定格の10⁶倍で頭打ちにする。
- **放射線**（`Radiation`）：
  - **遮蔽の判定**：100 tickごとに、炉室6面の各列・各段から外向きに一定範囲（上下3、側面8ブロック）以内にシールドかウインチがあるかを調べる。無い割合を面ごとの漏れとする。
  - **線量**：毎秒、64ブロック以内のサバイバルのプレイヤーに加える（距離の2乗で減衰）。炉室内では漏れ100%として扱う。停止中は定格の0.2%を崩壊熱分の放射線源とする。
  - **線量の保存**：プレイヤーのアタッチメント`radiation_dose`と`radiation_sickness_stage`に保存し、死亡で消える。
  - **症状**：1 Svで吐き気、2 Svでめまい（移動・採掘低下）、4 Svで衰弱・空腹、6 Svと8 Svでダメージ。ダメージは専用のダメージタイプ`acute_radiation_syndrome`（防具無視）で、死亡メッセージは「急性放射線障害で死亡した」。段階が上がると画面に表示する。回復は20分で1 Sv。
  - **ゴーグル**：炉心の漏れを表示する。
- **蛇紋岩**：地下0～96に大きな塊（大きさ48、1チャンク2回）で生成する。バイオロジカルシールドは蛇紋岩5と鉄板4で4個作る。
- **レシピ**：
  - 燃料棒：ウランペレット7、鉄板2
  - 制御棒：鉄板5、石炭ブロック2（炭化ホウ素の代わり）、黒鉛1
  - ウインチ：ロープ・プーリー、電子管、真鍮板
- **Ponder**：「RBMK炉心を組み立てる」（炉室、シールド、ホール、クレーン、AZ-5）と「制御棒とウインチ機構」を作り直した。
- **生成**：`tools/generate_rbmk_assets.py` を更新した。GameTest用の部屋は20×32×20。

## 見つけて直した問題

- 燃料の無い炉心で、強化したボイド効果と抜いた棒の黒鉛によって反応度が正になっていた。その間に中性子レベルが10⁵⁰まで増え、燃料を入れた瞬間に爆発した。制御棒・ボイド・揺らぎに燃料の装荷割合を掛け、レベルに上限を設けて直した。
- 棒1本の効きが増えたため、運転員役のスクリプトが臨界の手前で行き過ぎた。全ウインチの停止を待ち、臨界付近ではハンドルを1°ずつにし、+0.5 $を超えたら差し込む操作にした。

## 未確認・注意

- **全引抜で揺らぎから爆発に至る経路は、単独では実機で確認していない。** プレイテストでは不安定度0.9を観測した。ただし出力はテスト用のキセノン調整で保持したので、揺らぎが爆発に至る過程は見ていない。揺らぎの統計は単体テストで確認した。
- 放射線の症状（吐き気→死亡）は実機で進行させていない。確認したのは、線量が増えることとダメージタイプの定義まで。
- ボイド率の計算は既存の`voidFraction(kg, specific, height)`で、容量に「高さ（ブロック数）」をkgとして渡している。列の水が1/4未満にならないとボイドが出ない（既存仕様、今回は未変更）。容量は列の水量にすべき可能性があり、ユーザー判断が必要。
- 旧形式のセーブ（1ブロック4本の燃料、ピストン式制御棒）は読み込まない（本格運用前のため互換処理なし）。
- 以前の報告にある「ゲーム時間が実時間より速く進む」現象は、今回は起きなかった（17.4～19.7 tick/秒）。

## 追記：円柱のシールド、シールドの入出力部、上部キャップ、穴を狙うクレーン

ユーザー要求：
- 燃料チャネルを最上部まで延ばし、燃料棒とその上の棒を覆う。
- バイオシールドも円柱にし、隙間を作らない。

実装：
- **燃料チャネル上部管** `reactor_fuel_channel_tube`：燃料列の上、ホールからウインチの層まで。上部管がある所では、燃料棒の上半分を描画しない。
- **原子炉上部キャップ** `reactor_top_cap`：ウインチの1段上の最上層。下がウインチなら色付き（赤いカバー）、それ以外は灰色で、写真の上部プレートに合わせた。遮蔽として数える。レバーとハンドルはこの上に置き、レバーの信号はキャップを通ってウインチに届く。ハンドルは2段下のウインチが読む。

- **バイオシールド冷媒入力部・出力部**：
  - 入力部は受けた水を全燃料列へ順番に分配する。シミュレーションでは何も入れない。
  - 出力部は炉心の出口（蒸気を優先）。
  - どちらも遮蔽として数える。
- **シールドの形**：プレイテストとPonderは、炉心に接する1ブロック厚の円柱壁にした。下は円盤、壁は最上層まで。
- **クレーン**：燃料の作業位置を、穴の中心（列の中心から±1/4ブロック）にした。穴の座標は`FuelChannelBlockEntity.HOLES`で、描画と共通。
- **Ponder**：両シーンを作り直した。説明に、入出力部、シャフト不要、上部管、上部キャップを追加した。

## 追記：テクスチャ、制御棒の円形配置、制御棒リンク、給水細管束

ユーザー要求：
- 使用済み燃料プールとバイオロジカルシールドのテクスチャで、側面を上面・下面と同じにする。
- 制御棒を円状に配置する。
- 制御棒ウインチ上の上部キャップに、レッドストーンリンクのような周波数を付ける。
- 新ブロック「制御棒リンク」と、100段階の新しいレバー「制御棒ウインチコントローラー」で微調整できるようにする。

- 細い管の束のブロックを燃料チャネルの下に置いたときだけ水を入れられ、その束に接するバイオシールド冷媒入力部からだけ入るようにする。

前提：作業開始時点で、ユーザーのコミット「RBMK_update」（4dab646、前回の燃料プール作業を含む）と、Codexによる燃料プールの実装（9748215、f432aac：水槽構造・冷却水・専用GameTest）が入っていた。今回はその上に積んだ。

実装：
- **テクスチャ**：
  - バイオロジカルシールドは全面を上面と同じテクスチャにした。シールドに組み込む入出力部・回転動力入力部も、縁の模様を上面と同じものに揃えた。

- **燃料列の上部キャップ**：上面を4分割にした。燃料棒の4つの穴に対応する小さな鋼の角材が4つ並び、それぞれに栓がある。
