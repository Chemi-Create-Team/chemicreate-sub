# 槽の汚れの仕様の削除と、ガスのもやのシェーダー対応

2026-11-23。ユーザー指定：「タンクが汚れる仕様は削除して」「ガスのもやもやを影mod(シェーダー)に対応させて」。

## 槽の汚れの仕様を削除
蓋つき容器の汚れ（バッチごとにたまり、400で停止、ブラシで清掃、下面のドレンで洗浄排水）を全部消した。
- 削除：`chemistry/VesselFouling.java`、`VesselFoulingGameTests`。
- `LiddedVesselBlockEntity`：汚れの状態・保存・毎tickの処理・ドレンの出口・移動不可の条件・処理速度の低下を削除。古いセーブに残る `Fouling` のデータは読まずに捨てる。
- `LiddedVesselBlock`：ブラシでの清掃と、下面を空手で右クリックしてドレンを開く操作を削除。下面を右クリックしても、ほかの面と同じくハッチの開閉になる。ブラシを持って右クリックしても、特別な扱いはしない。
- 描画：槽の中の汚泥と、下面のドレン金具の変化を削除。
- ゴーグル：「汚れ」「排水」の行と、停止理由の「排水開放」を削除。
- 表示リンク：`vessel_fouling`、`vessel_drain`、`vessel_waste` は、保存済みの表示リンクの番号を保つため項目を残し、常に0を返す。
- Ponder：「流体の等級と清掃」を「流体の等級と冷却」にして、ブラシ・デプロイヤー・洗浄・ドレンの場面とその文を削除。
- 言語：上の文と、汚れ・排水の表示の文を、日英中から削除。
- 洗浄排水の流体（`wastewater`）は、水処理などほかの工程でも使うので残した。

## ガスのもやをシェーダーパックに対応
- 原因：地面に広がるもやは、専用のシェーダー（`ground_gas`）で描いていた。シェーダーパックはゲームの描画プログラムを入れ替えるため、専用のシェーダーは正しく動かず、もやが見えないか、おかしく見える。上に立ちのぼるもや（`RisingGasMist`）は、標準のプログラムなので以前から対応していた。
- 修正：シェーダーパックが有効なときだけ、地面のもやを、標準のプログラムで描く板ポリゴン（カメラを向く煙の絵）に切り替える（`FallingGasMist.renderPuffs`）。もやの範囲・濃さ・薄れ方は、専用シェーダー版と同じ値を使い、描き方だけが簡単になる。
- シェーダーパックの検出は、Iris の API を反射で呼ぶ（`ShaderPackCompat`）。Iris がなくても動き、ビルドにも要らない。
- シェーダーパックがないときは、これまでどおり専用のシェーダー。

## 未確認・注意
- ゲーム内の見た目は確認していない（構文チェックと、コンパイル上の新しいエラーがないことだけ）。シェーダーパックでの見え方は、実際に入れて見る必要がある。
- もやの板ポリゴンの大きさと濃さ（`FallingGasMist.renderPuffs` の `.62f`、`170`）は目分量。見て調整する。
