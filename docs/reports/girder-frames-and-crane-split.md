# メタルガーダーの枠・地面まで伸びる脚・クレーンの役割分割：完了レポート

## 実装内容

### 共通の枠（`block/CraneFrame`、`block/CraneStructure`）

- レールはガントリーシャフトから、横向きの`create:metal_girder`に変えた。脚は縦向きのメタルガーダー。
- 脚は、レール端から下へたどった最初の固いブロック（地面）まで伸ばす。
  - 角ごとに高さが違ってよい。最大64段（RBMK炉を跨ぐ約45段の脚が届くよう、32段から引き上げた）。
  - 脚の下は、上面が固いブロックでなければならない。レール端を固いブロックの上に直接載せてもよい（脚0段）。
- 枠の計画は`CraneFrame.plan`：
  - 各角の脚の高さを、その場の地面から求める。
  - 地面が範囲内に無い角があれば、その角を障害の位置にして`legs`で止める。
- 建設の共通処理（`placed`・`progress`・`place`）を`CraneFrame`にまとめた。クァーリーと両クレーンで使う。
- `CraneStructure.Result.legs`は、いちばん高い脚の段数。
- 長さ・幅の設定は`CraneRangeSetting`に共通化した（もとはクァーリーの内部クラス）。

### クァーリー駆動部

- 枠の材料はメタルガーダーだけ。不足表示は「メタルガーダー・ドリル」の2項目になった。
- 角の下にあるブロックは、その脚の地面として扱う。レールの位置にある障害物は、これまでどおり掘って格納庫へ入れる。
- Ponderの構造（`crane/quarry_frame`）をガーダーにした。チェーンドライブの状態名を`axis_along_first`に直し、以前から失敗していた構造検査も通るようになった。

### クレーンの分割（`CraneDriveBlock`、`CraneDriveBlockEntity`、`registry/CECrane`）

- `crane_drive`をRBMK燃料交換クレーン駆動部、新しい`fusion_crane_drive`を核融合炉保守クレーン駆動部にした。
  - 作業モードの切り替え（`ScrollOptionBehaviour<Mode>`）と、その翻訳を廃止した。
- 駆動部に向き（`facing`）を追加した。レールは正面へ延び、奥のレールは右側に建つ。
- 左側の面でレールの長さ、右側の面でスパンを設定する。
- 範囲がまだ形成されていなければ、レッドストーン信号がある間、格納庫のメタルガーダーで脚・レールの順に1 tickに1個ずつ建てる。壊れた部分も建て直す。
  - 障害物は掘らず、`frame_blocked`で止める。
- ゴーグルは、建設中なら進捗と不足ガーダー数を表示する。
- 格納庫に入れられる物：
  - どちらのクレーンも：メタルガーダー
  - RBMK用：燃料と制御棒
  - 核融合炉用：ブランケット・ダイバータ・照射カートリッジ
- レシピ：核融合炉用は、ガントリー台車・ロープ滑車・精密機構・核融合炉強化外装。
- 見た目は両方とも従来のモデル。状態は軸×向きの12通り。

### Ponder・翻訳・文書

- Ponderの手順の順番を変えた。
  - 門型クレーン：駆動部を置いて範囲を設定 → ガーダーを入れる → 脚 → レール → 保守。
- Ponderの構造をガーダーにした：`gantry_crane`、`crane_refuelling`（脚の代わりに建屋の柱）、`fusion_maintenance`（核融合炉用の駆動部）。
- 翻訳（英・日・中）を更新した。対象は、状態表示（レール・脚・材料不足・回転）、新しい範囲の名前、不足表示。
- 文書（`docs/gantry-crane.md`、`docs/quarry.md`、`docs/power-plant-expansion.md`）を今の仕様に合わせた。

## 確認

- **GameTest**：次の11クラス、48件がすべて合格した。
  - `CraneGameTests`、`PowerPlantGameTests`、`QuarryGameTests`、`QuarrySpeedGameTests`、`AuditGameTests`、`CreativeCatalogGameTests`、`CraftingRecipeGameTests`、`PlantTutorialGameTests`、`SurvivalReachabilityGameTests`、`NuclearSavedValueGameTests`、`AssemblyGameTests`
  - 核融合炉保守クレーンが格納庫のガーダー94本で枠を自分で建て、劣化した部品を交換する。
  - 手で組んだ枠でも同じく交換できる。
  - クァーリーの角の下の石が脚の地面になり、レール位置の石は掘られる。
  - 壊れた脚は「ガーダー不足」で止まる。
- **画面での確認**（Ponder）：クァーリー、RBMKクレーン、核融合炉クレーンの枠が、ガーダーで表示されることを確かめた。

## 未確認・制約

- **実ワールド**：サバイバルで、高い場所や斜面に置いたときの脚の建ち方は、自動テストの範囲（平らな床）だけ確かめた。
- **障害物**：クレーンは枠の位置の障害物を掘らない。クァーリーは掘る。
- **既存ワールド**：ガントリーシャフトのレールで組んだ既存のクレーン・クァーリーは形成されなくなる。旧型の作業モード設定も読まない。本格運用前のため、互換処理は入れていない。
