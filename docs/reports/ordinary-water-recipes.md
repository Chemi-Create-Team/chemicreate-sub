# 精製水の廃止と普通の水への統合

実装コミット: `b910cdd4b40a396e967ef7d076aa0d8a063ff8a3`

## 変更内容

精製水の流体・バケツ登録を廃止し、利用していた全6工程を `minecraft:water` に変更した。水の必要量、他の原料、生成量、処理時間、加熱条件は維持している。

| 工程 | 普通の水の必要量 / バッチ | 主生成物 |
| --- | ---: | --- |
| 塩水 | 250 mB | 塩水 250 mB |
| 不凍液 | 500 mB | 不凍液 1,000 mB |
| 硫酸 | 250 mB | 硫酸 250 mB |
| 塩酸 | 500 mB | 塩酸 1,000 mB |
| リン酸・石膏 | 250 mB | リン酸 1,000 mB、石膏 3個 |
| 硝酸の吸収工程 | 100 mB | 硝酸 200 mB、一酸化窒素 100 mB |

普通の水で不良品になる旧分岐は全6件削除した。用途がなくなる規格外混合液も登録・アセットごと削除した。洗浄排水、中和、沈殿、ろ過、汚泥回収の既存工程は維持している。

蒸気の復水は普通の水になる。復水を蒸留水として記録するデータコンポーネントと、タンクの同じ水を別流体として抽出する専用処理を撤去した。通常の温度・圧力・熱等級の処理は維持している。

精製水の製造と水質ペナルティを扱う2つのPonderを削除し、硝酸・硫酸・塩水・不凍液などの説明、日英中の翻訳、製造用ジェネレーター、現行文書を更新した。過去の試験結果や画像は履歴資料として残している。

## 確認結果

- Java 21で `bash gradlew --no-daemon assemble`: 成功。既存の非推奨API警告のみ。
- `tools/validate_translations.py`: 成功。日英中それぞれ4,604キー。
- `tools/validate_ponder_language.py`: 成功。全140シーンの見出し・説明を確認。
- `tools/validate_plant_tutorials.py`: 成功。追加96シーン、対訳512件、部品リンク237件、製造系列28件と構造参照を確認。
- JSONレシピ5件を変更前と構造比較し、精製水から普通の水へのID変更だけであることを確認。競合する不良品レシピ5件の削除も確認。
- Java固定レシピの硝酸吸収を普通の水へ変更し、既存の硝酸GameTestの期待値・他の運転試験の投入水を更新。削除した機能専用の試験・構造参照を除去した。
- 現行ソースと生成スクリプトに旧登録・専用Ponderへの参照がないこと、変更したPythonの構文、`git diff --check`を確認。

ユーザーのデバッグ方針に従い、実クライアントとGameTestの運転は実施していない。JEI上の表示、実配管での搬送、既存ワールドの読込は未確認。

## 既存ワールドへの影響

廃止した `purified_water` / `flowing_purified_water`、`off_spec_solution` / `flowing_off_spec_solution` と対応バケツ、`distillate` データコンポーネントに互換登録や移行処理は設けていない。既存在庫やフィルター設定、蒸留済みの印を持つ水は普通の水へ自動変換されない。更新前に在庫を使い切るか排出し、更新後はフィルターを普通の水へ設定し直す必要がある。

作業中に追加されたリモートの別件仕様書はrebaseで取り込み、内容を維持した。
