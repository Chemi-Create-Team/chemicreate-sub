# 液体ブロックの翻訳とバケツの液面

## 実装内容

- 設置できる液体のブロック43種に、英・日・中のブロック名（`block.create_heavy_indusstry.<液体>`）を追加した。名前は液体自体の翻訳と同じ。`tools/generate_world_liquids.py`が、`fluid.`・`fluid_type.`・`block.`の順に既存の液体名を探してブロック名とバケツ名を書くように修正した（中国語は従来の`CHINESE`表を優先）。新しい液体（澄明水など）で生成が止まっていた不具合も直った。
- 液体入りバケツ52種のテクスチャを、バケツの縁いっぱいだった塗り方から、バニラの水入りバケツと同じ形に変更した。最上段はバケツの内壁の灰色を残し、その下の3段だけが液体になる。液面の陰影は水入りバケツの明暗を各液体の色に移したもので、縁側が暗く、中央に明るい反射が入る。
  - 色は液体の登録色（設置した液体と同じ色）。名前ごとに±2程度の差をつけ、同じ色の液体どうしでもテクスチャが重複しないようにした。
  - 耐食合金バケツでは内壁の灰色も合金の色味にした。
  - 気体入りバケツ16種は別デザインのため変更していない。
- 基準となる水入りバケツの画素を`tools/vanilla_bucket_template.json`の`water`に記録した（Minecraft 1.21.1クライアントから取得）。
- 液体入りバケツの生成元を`generate_world_liquids.py`に一本化し、`generate_quality_assets.py`と`generate_fusion_assets.py`にあった重油・ナフサ・潤滑油・硝酸・液体酸素・液体ヘリウムのバケツ描画を削除した。
- 不良混合液は腐食性の液体として耐食合金バケツに入るため、バケツ名を「不良混合液入り耐食合金バケツ」に揃えた（見た目は以前から耐食合金だった）。
