# 大型フライホイールのテストワールドを作成

検証したワールドは[配布ZIP](../playtests/large-flywheel-test-world.zip)。対応環境と操作は[テスト手順](../playtests/large-flywheel.md)を参照。検証したModのコミットは `4d6e68b` で、蓄勢修正 `5424df5` を含む。

平坦なクリエイティブワールドに、64 RPMのクリエイティブモーター、レバー付きクラッチ、大型フライホイール3台、Createの回転計とエンケースドファンを直結した。初期セーブではクラッチが開いていて蓄積エネルギーは0 J。ゴーグル装備、足場、案内看板、予備のゴーグルを用意した。

## 配布ZIPの検証

ZIPを別の `saves` に展開し、Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10のシングルプレイで開いた。レバーのブロック操作を通じて蓄勢、切替、再蓄勢を検証した。蓄積エネルギーは3台の合計。

| 状態 | 蓄積エネルギー | ローター | 回転計・送風機 |
| --- | ---: | ---: | ---: |
| 初期状態 | 0 J | 0 RPM | 0 RPM |
| 蓄勢120 tick後 | 3,497,576 J | 48.09 RPM | 64 RPM |
| 蓄勢260 tick後 | 6,194,831 J | 64.00 RPM | 64 RPM |
| クラッチを開いた1 tick後 | 6,194,705 J | 64.00 RPM | 64 RPM |
| クラッチを開いた160 tick後 | 6,174,828 J | 63.90 RPM | 64 RPM |
| 接続し直して60 tick後 | 6,194,831 J | 64.00 RPM | 64 RPM |

切替後の送風機に過負荷は発生せず、160 tick後の放出は75 Wだった。GPU描画でゴーグル表示が約6.2 MJ、64 RPM、連結3台になることを確認した。ZIPの整合性とセーブ内の初期位置・装備・クラッチの状態も確認済み。検証の負荷はワールドにある送風機1台。
