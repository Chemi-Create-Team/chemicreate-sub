# 横型ボイラーの接続テクスチャと蒸気等級

実装コミットは `a593a37714c020be5e92491b2bb31538303d963a`。

- 横型流体タンクとステンレスボイラーで、横に回したモデルのUV方向に沿って隣接ブロックを調べるようにした。Createが表裏と下面で行う軸の反転を補正し、側面の帯と3×3の端面の枠をつないだ。主な変更は `HorizontalTankCTBehaviour`。
- 蒸気等級は外装で決まる。ステンレスボイラーは高温・高圧、横型流体タンクは高温・常圧。水1 mBが蒸気1 mBになり、熱源1台あたりの流量は通常加熱で65.536 mB/s、超加熱で131.072 mB/s。最大流量の表示には底面全体を超加熱した値を使う。旧等級の蒸気はそのまま搬出でき、空になると現行の等級で生成を再開する。
- `SteamGrades` と `TurbineThermal` で給蒸の等級に応じた仕事を計算する。直接供給時、高圧蒸気は高圧段500・低圧段750 J/mB、常圧蒸気は250・375 J/mB。高圧段の排気には膨張済みの状態を保存し、高圧段での追加仕事は0 J/mB、低圧段は250 J/mB。配管とタンクの蒸気の登録IDは共通で、膨張済みの状態は流体スタックに保存される。
- JEIの蒸気生成、タービンの膨張レシピ、および設備・組立のPonderの説明を更新した。

## 確認

- リモートの採掘機描画の更新を取り込んだ状態でGradleビルドと専用サーバーのGameTest 54件が通過した。通常加熱のバーナー27台でステンレス約884,736 SU、横型流体タンク約442,368 SU。ステンレスの超加熱時の倍増、長さによる比例、旧蒸気の搬出、Createのポンプでの搬送、膨張状態の保存も確認した。
- Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10、RTX 4060で両種類をX・Z軸に組み、上面・側面・端面を確認した。3×3断面・長さ5で露出した408面のUVを元モデルの向きと照合し、ずれは0件だった。Colorwheelでの比較とPonder全シーンの再生は未実施。
