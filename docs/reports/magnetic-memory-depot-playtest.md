# 磁気コアメモリのデポ搬入修正

対象は `Chemi-Create-Team/chemicreate-sub` の `main`。実装コミットは `d6464fc`。比較元は `7ec88bb`。

- [産業用アーム](../../src/main/java/net/createplant/block/entity/IndustrialArmBlockEntity.java)は作業デポを選べても、材料取得時にデポとベルトをまとめて除外していた。取得先に設定した部品供給用デポを材料候補に加え、現在の作業位置と他設備が保持中の品を除く。既存の在庫照会で必要数以上ある場合だけ取り出す。中断・再読み込み時は部品を空きのある取得先へ戻す。
- [テストワールドと実機画像](../playtests/magnetic-core-memory-line.md)を現行の鉄板・デポ方式に差し替えた。供給はフェライトコア64＋64＋16個とエナメル線25本。作業デポへ鉄板1枚を置くと、素のアーム2台とトーチ付きアーム1台が作業し、チェストへ磁気コアメモリ1個を搬出する。
- [GameTest](../../src/main/java/net/createplant/gametest/ArmAssemblyGameTests.java)で修正前の失敗を再現した。修正後は、部品の全量をデポから使うケースと、同種の材料でも作業台上の土台を誤って取り出さないケースを含め、アーム関連14件が通過した。Gradleのビルドも成功した。
- Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10の組み合わせで、RTX 4060を使ったシングルプレイで設置時の選択同期を確認した。ワールドを開き直し、ゲーム内で鉄板を置いて、素のアーム2台の配線・チェストへの搬出・全材料の消費まで検証した。
- 全設備のGameTestとマルチプレイは未検証。全体のPonder翻訳検査は既存のPVC製造シーンの書式で停止する。供給デポのPonder説明は日本語・英語・中国語を更新した。
