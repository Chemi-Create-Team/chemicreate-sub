# タンクの成分一覧・密度分離とボイラー表示

実装コミット `7a8b9cc490aa324c97f1fae231fb25b98f7c8e7f`
Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10

## 変更内容

- ゴーグルでタンクに照準を合わせると、混合気体を上層から順に、各成分の名前・化学式・体積で表示する。配管と液体の装置概要は最大4行。空気などの固定組成の流体は登録済みの化学式を列挙する。個々の分子の体積を持つ混合気体は、各成分の体積も表示する。
- 攪拌槽では貯蔵部分、反応の原料・生成物バッファー、混合原料の素通し分を合わせて密度順に扱う。天面は最軽量の気体、液体のないときの底面は最重量の気体を搬出する。液体がある場合は底面から液体を搬出できる。液の分離表示と上下の出口には同じ密度順を使う。
- 窓付きタンクは成分ごとに色を分ける。気体の並びには同じ温度・圧力に換算した密度に比例するモル質量、液体の並びには登録された質量密度を用いる。混合物から取り出した量は該当成分の整数mBだけを差し引く。
- ふた付き槽の空き容積には常圧の空気が入る。初期空気を密閉中に抜いた分は保存し、ハッチを開けると周囲の大気に戻る。通常のCreate液体タンクなどで中身が空の場合はゴーグルに空気を表示する。液体在庫を初期空気で埋める処理は行わない。
- 横型流体タンクとステンレスボイラーは、ボイラー運転中にCreateの `BoilerData.addToGoggleTooltip` を呼ぶ。末尾に、配管式では現在／最大の蒸気生成流量、蒸気エンジン接続時は給水流量をmB/sで追記する。各寸法の最大値と既存の蒸気等級は従来の設定に従う。
- ふた付き槽・流体混合・横型ボイラーのPonder説明を更新した。

## 主要ファイル

- `thermal/TankLayers.java`、`thermal/GradeFluidTank.java` — 密度の順序、面別の搬出口、成分体積の引き算。
- `block/entity/LiddedVesselBlockEntity.java`、`mixture/GasPassThrough.java` — 槽の層、初期空気の保持、原料ガスと生成ガスの取り出し。
- `mixture/MixtureGoggleHelper.java`、`client/ProcessGoggles.java`、`block/entity/HorizontalTankBlockEntity.java` — ゴーグルとボイラーの表示。
- `client/LiddedVesselRenderer.java`、`client/TankLayerColors.java`、`mixin/TankLayerRendererMixin.java` — 槽とCreateの窓越しに見える層。

## 制約と次回の注意

- 既存の固定組成ガスは登録済みの化学式を表示する。化学式や各分子の体積が保存されていない流体は、判明している情報の範囲で表示される。
- プレイヤーが気体を下から取る場合は、底の出口まで液体を抜いておく。液体を残して気体を出す場合は天面や液面より上の接続を使う。
- 旧セーブに初期空気の残量がない槽は、大気が入った状態として読み込む。
