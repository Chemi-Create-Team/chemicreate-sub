# 消火器・火炎放射器・液体噴射器の追加

2026-11-15。mainをpullし、`ac69c40a` が最新であることを確認した。

実装コミット：`6ecd3d22962cea2a9e28c37911ba8655a7ada736`。

## 実装内容

以下の3アイテムを追加した。

- `fire_extinguisher`：容量2,000 mB、射程6マス。水または既存の二酸化炭素を使って消火する。
- `flamethrower`：容量4,000 mB、射程8マス。既存の軽油・ガソリン・ナフサ等を使う。液体燃料は `spray_fuels` タグで定義する。
- `chemical_sprayer`：容量4,000 mB、射程10マス。水・硫酸・硝酸・塩酸などの液体を噴射する。

いずれも右クリック長押しで使用。サーバーが4 tickごとに20 mBを消費し、残量不足で停止する。クリエイティブでは内容物が入っていれば消費しない。既存の気体・液体の種類、温度等級を使い、武器専用の物理化学シミュレーションは追加していない。

## モデル

添付の消火器写真から、赤いボンベ、黒いホース、細いノズル、操作レバー、安全ピン、圧力計とラベルを形にした。火炎放射器・液体噴射器はCreate 6.0.10のポテトキャノンのアイテムモデルと表示変換を確認し、もう1枚の画像の二連ボンベ・グリップ・配管の意匠を取り入れた。

専用の立体JSONモデルを各アイテムに用意し、使用中のモデルではレバーが動く。火炎放射器は太い燃焼口と種火、液体噴射器は細いノズルと銅のポンプ部を備える。素材は既存の鋼材、Createの真鍮・銅、黒いホース、既存の赤い塗装などの16pxテクスチャを参照し、写真テクスチャは使っていない。GUI・地面・一人称・三人称の表示変換を定義した。

実残量はネイティブの残量バーと説明欄で表示。小さい圧力計はモデルの意匠であり、容器圧力や針の連続計算はない。クライアント専用の登録で使用中モデルと銃型器具の両手姿勢を設定する。

## 保存・補充・効果

中身は永続・同期コンポーネント `spray_tool_contents` にFluidStackとして保存する。ハンドラーは読取・確定時ともコピーを使い、SIMULATEでは変更しない。異種や異なる成分の混合は拒否し、最大容量を超えて受け入れない。

NeoForgeのItem FluidHandlerを公開し、Shift＋右クリックでタンク、逆の手のバケツ、Createの注液口から補充できる。液体の出入は既存のFluidUtilと有限量のハンドラーを使う。アイテム排液口による排出にも同じハンドラーを公開する。GUIは追加しない。

消火は通常の炎、焚き火、ろうそく、フレアの種火と燃えている生物に対応。酸は既存の `corrosive_contact` ダメージ種を使い、塩水を除外する。水と一般液体は押し流す弱いノックバックを持つ。火炎は着火と火属性ダメージを与え、既存の可燃ガス雲には既存の `FlammableGas.ignite` を使う。地面への着火は `doFireTick` に従う。

射線は最初の固体で切り、命中範囲にも視線判定を適用する。プレイヤーへの直接攻撃はPvP設定・チームの制限に従い、PvP無効でも水や消火器による消火はできる。ブロック操作はMinecraftの操作可否を確認する。未ロード範囲へ向けた射程も切り詰める。

通常クラフト1件・メカニカルクラフト2件、設備カテゴリへの追加、日英中の翻訳、3アイテム共通の専用Ponderを追加した。操作は [portable-sprayers.md](../portable-sprayers.md) を参照。
