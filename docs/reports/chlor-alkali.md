# ソーダ工業（食塩の電気分解）レポート

## 基準と実装コミット

- 作業ブランチ：`main`
- 作業開始時の基準コミット：`1a9c1de`
- 実装コミット：`dbcb1d1`

## 依頼と決定事項

- 依頼：A1の食塩の電気分解から進める。
- ユーザーの決定：
  - 塩の入手：岩塩鉱石と、海・砂浜の開放円筒タンクの天日塩の両方。
  - 苛性ソーダの使い道：バイヤー法のアルミナ（硫酸塩法も残す）。
  - 塩素の使い道：塩酸（酸洗い）と塩化ビニル樹脂・塩ビ管。

## 実装内容

### 登録（`registry/CEChlorAlkali.java`、新規）

- アイテム：塩`salt`、塩化ビニル樹脂`pvc_resin`。
- ブロック：岩塩鉱石`halite_ore`、深層岩塩鉱石`deepslate_halite_ore`（`DropExperienceBlock`、経験値0〜2）。
- 流体（バケツなし。ほかの処理中間流体と同じ）：塩水、塩素、苛性ソーダ液、アルミン酸ナトリウム溶液、塩化水素、塩酸、二塩化エチレン、塩化ビニル。
- 流体の物性：
  - `FluidHazards`：温度・気体か・腐食性。塩素・塩化水素・塩化ビニルは気体。二塩化エチレンと塩化ビニル以外は腐食性（酸の区分）。
  - `FluidThermal`：密度と比熱。
  - `FluidPhase`：塩素・塩化水素・塩化ビニル・二塩化エチレンの分子量・沸点・蒸発熱・臨界点・液密度。

### 天日塩（`block/entity/TankCasingBlockEntity.java`）

- 持ち主（中央の床）の1秒ごとの処理`dryInTheSun`に追加した。
- 条件：成立している、中身が水、昼（`isDay`）、雨でない、上面の中央の1つ上が海・砂浜のバイオームで空が見える。
- 計算：
  - 蒸発量（mB/秒）＝床のマス数（`TankFootprint.blocks`）×1（`EVAPORATION_PER_CELL`）。
  - 塩の数＝これまでの蒸発量÷1,000（`WATER_PER_SALT`）。端数は`evaporated`に残す。上限64個。
- 取り出し：`Capabilities.ItemHandler.BLOCK`を登録し、取り出しのみの1スロット（`SaltPort`）。どの構成ブロックからも、成立中のタンクの塩を取り出せる。
- 保存：`Salt`、`Evaporated`。0のときは書かない。
- 中央の床を壊すと塩を落とす。小さいタンクが大きいタンクに取り込まれるときは、塩も引き継ぐ。
- 空手の右クリックで塩の数を表示する（`message.create_heavy_indusstry.tank_casing.salt`）。

### 塩水の電気分解（`basin/BasinElectrolysis.java`）

- 溶液の選び方：水（3 mB/極板）、次に塩水（2 mB/極板）、次にフッ化水素（2 mB/極板）。
- 塩水1サイクル：水素1 mB、塩素1 mB（`State.chlorine`、保存キー`Chlorine`）、苛性ソーダ液2 mB。
- 苛性ソーダ液は、鉢の出力側のタンクへ入れる。
  - Createの鉢と同じく、`allowInsertion`→`fill`→`forbidInsertion`で入れる（出力側は外からの注入を拒むため）。
  - 先にシミュレーションで入る量を確かめ、入る分だけサイクルを回す（満杯なら止まる）。
- 陽極のガス：酸素、塩素、フッ素の順。流体フィルターで指定もできる。

### 塩ビ管（`transport/PipeMaterial.java`ほか）

- 材質`PVC`：253〜333 K、10 bar、酸に耐える。外気との熱は樹脂と同じ係数。
- 333 Kを超えると「軟化」（樹脂と同じ扱い）。
- アセット：`tools/generate_plant_tank_assets.py`の`PIPES`に、暗い灰色の本体とゴムのフランジとして追加した。

- 「鉢の電解槽」に塩水の手順を追加した（`ponder/ElectrolyzerPonderScenes.java`）。蓋の両端のガスの字幕で、陽極を「酸素か塩素」に直した。
- 「流体に合う配管を選ぶ」に塩ビ管の列を追加した。

## 未検証・制約

- 天日塩は、実際の海辺のワールドでは試していない（GameTestでバイオームを書き換えて確認した）。
- 岩塩鉱石のワールド生成は、実際のワールドで分布を見ていない。
- 撹拌反応槽の新しい7工程は、反応ごとのGameTestで個別に確かめた。塩素を電解槽から反応槽までポンプで送る一続きの流れは、ゲーム内で試していない。
- 苛性ソーダ液で出力側が満杯のとき、電解槽のゴーグル表示は「稼働中」のまま（気体がたまって止まったときと同じ既存の表示）。
- 天日塩は昼・晴れ・空が見えることだけを見る。気温や湿度は見ない。
- 塩ビ管の見た目は、Ponderの画面だけで確認した。

## 次回の注意

- 鉢の出力側のタンクに入れるときは、`allowInsertion`／`forbidInsertion`で囲む（外からの`fill`は0を返す）。
- 撹拌反応槽のレシピを追加するときは、既存のレシピと材料の組が重ならないようにする。
- 配管の材質を追加したら、`TransportQualityGameTests`の「未分類の流体」の期待値（温度による軟化・過熱）を見直す。
