# 反応塔を触媒バスケット式にした完了レポート

> **追記（同日）**：続く指示で、壁を6 pxにして中を完全な空洞にし、3×3用の大きいバスケットをはめる形に直した。バスケットのない塔は高圧気液分離タンクとして使え、分離中はのぞき窓から中が見える。下の「中空化と気液分離（追記）」を参照。

- 日付：2026-11-17
- 実装コミット：このレポートと同じコミット（`git log -1 -- docs/reports/reaction-tower-baskets.md`で確認）
- 説明：[反応プラント](../reaction-plant.md#反応塔)
- 前の形：[ハーバーボッシュ反応塔を復活させた完了レポート](haber-bosch-reaction-tower.md)

## 指示

ほかの触媒も反応塔で使えるようにする。反応塔の内部は、ふた付き槽のように厚み12 pxの壁があるタンクの見た目にし、その内部に今の触媒バスケットをはめられるようにする。ユーザー確認：四酸化三鉄の山はバスケットに置き換える（使い切った山と再生レシピは削除）、バスケットは1段に1個。

## 実装

| 部分 | 内容 |
| --- | --- |
| 構造 | 反応塔はCreateのタンクとしてつながる。幅3・高さ3～12段で成立。中心の山の柱、`HaberBoschStructure`、輪のまとめ置き、輪用の接続Mixinを削除 |
| 外観 | 各ブロックの状態に外壁の向き（north/east/south/west）を持たせ、コントローラーがつながりの変化時に全ブロックへ設定する。モデルは3×3のどの位置かで、縦穴（幅24 px、塔の座標で12～36 px）を切り抜いた形。最下段の縦穴には2 pxの床。外面は旧テクスチャとCreateのつながったテクスチャ、縦穴の内側はふた付き槽の鋼板。上は開いていて、中のバスケットが見える。当たり判定は全ブロックで1ブロック（縦穴に落ちない） |
| バスケット | 既存の`reactor_catalyst_basket`（24 pxのモデル）。上面に使うと下の段から1個ずつ入る。各段の中央ブロックがバスケットと触媒を持つので、塔を伸ばしても中身は動かない |
| 触媒 | `ProcessRecipe`で触媒を使う10レシピ（鉄・酸化・分解・重合・水素化脱硫・水素化分解）。全段で同じ触媒にそろえる。触媒と原料でレシピが決まる |
| 処理 | 働いている触媒の段ごとに1バッチを同時に処理し、その段の触媒の耐久を1減らす。回転は不要。熱はレシピどおり（底面の下の3×3のブレイズバーナー） |
| 入出力 | 原料：最下段の外側面（原料2つの槽、同じ配管でよい）。製品：最上段の外側面（製品2つの槽）。触媒：最上段の上面（アイテム）。1段あたり液体2,000 mB、気体64倍 |
| 取り出し | 上面のファンネルは使い切った触媒だけを出す。上面のレンチでいちばん上の触媒、次にバスケット。壊したブロックの中身は落ち、最下段中央の気体は放出 |
| 描画 | `client/ReactionTowerRenderer`が最下段中央から各段のバスケットを描く |

## 制約と未確認事項

- 縦穴の上は開いている（ユーザーの「ふた付き槽のような内部」の見た目に合わせた）。気体を扱うが漏れはない。
- 触媒そのものは描いていない（バスケットだけ）。
- バスケットは手でだけ入れる。触媒の搬入・使い切った触媒の搬出はファンネルで自動化できる。
- 反応塔の処理量はふた付き槽の触媒バスケットより多い（最大12段）が、回転が不要。釣り合いはサバイバルで確認していない。
- 3×3以外の大きさに置いた反応塔は、ただの1ブロックの外殻として表示される。

## 中空化と気液分離（追記）

### 指示

「縦穴」は指示の誤解だった。ふた付き槽と同じく壁を6 pxにして中を完全に空洞にし、3×3用の大きいバスケットをはめる。バスケットのない塔は高圧気液分離タンクとして使え、気液分離中はのぞき窓で中が見える。

### 実装

| 部分 | 内容 |
| --- | --- |
| 外観 | 壁6 px（内側36 px）、上は開放、最下段に2 pxの床。各面の中央のブロックに`window`状態を追加し、開くと壁に開口とガラス（`minecraft:block/glass`）が入るモデルに切り替わる |
| バスケット | ふた付き槽の`reactor_catalyst_basket_wide`を、壁の厚さに合わせて水平に36/44倍で描く |
| 気液分離 | バスケットがないときは`AmmoniaSeparatorBlockEntity.recipes()`（`GAS_LIQUID_SEPARATOR`の2レシピ）を、1段につき1バッチ同時に処理する。熱は不要 |
| 出口 | 反応器では製品はすべて最上段から。分離では気体が最上段、液体が最下段の外側面から出る（同じ最下段のポートが原料を受ける） |
| 切り替え | 流体が残っている間は、最初のバスケットを入れられず、最後のバスケットを取り出せない（反応と分離の在庫が混ざらないように） |
| のぞき窓 | 分離モードで流体があるときだけ開く。最下段中央が変化時に各面中央のブロックの状態を書き換え、開閉状態を保存する |
| 描画 | 窓が開いているときは、液体を床から量に応じた高さで、最初の気体を薄い霧として描く。光は塔の上の明るさを使う |

- JEI：「アンモニア分離器」の触媒欄に反応塔を追加。
- Ponder：「反応塔を気液分離に使う」（`plant/reaction_tower_separator`）を追加。

### 確認

- `ReactionTowerGameTests`7件すべて合格（新規：分離はバッチ完了時だけ確定、3段で3バッチ、分離中は各面中央の窓だけ開く、流体がある間はバスケットを入れられない、気体は上・液体は下からだけ出る、空になると窓が閉じてバスケットを入れられる）。
- 関係する8クラスと合わせた9クラスを最後に再実行し、以前からの2件（`cooledInputsAndAllManufacturingRecipesRemainValid`、六フッ化ウランのバケツ）以外合格。
- 実画面（Xvfb、日本語）：反応器の場面で大きいバスケットが空洞いっぱいに入ること、分離の場面で各面の窓が開き、中が見えることを確認した。液体アンモニアは淡い灰色で目立たないため、一時的に水へ差し替えて液面が窓から見えることを確かめた。

### 制約

- 液体アンモニアの色が淡く、窓越しの液面は分かりにくい。
- 窓は分離中だけ開く。反応器として使うときは開かない。

## 天板（追記）

ユーザーの指示で、上面の開口を2 pxの天板で閉じた（最上段の空洞部分。モデルは`top`状態で切り替え、形状も合わせた）。バスケットと触媒は従来どおり上面への右クリックと上面のファンネルで出し入れする。中は気液分離中ののぞき窓からだけ見え、反応器として使っているときのバスケットは外から見えない。窓越しの流体は、最下段中央の2ブロック北（窓の外）の明るさで描く。

## 中央の穴（追記）

ユーザーの指示で、天板と最下段の床の中央ブロックを、上面テクスチャに描かれたノズルの穴（半径3.5 px）の形にピクセル単位でくり抜いた（`tools/generate_reaction_tower.py`の`plate`）。穴の内側の面は鋼板。実画面で、天板の穴から奥が見えることを確認した。ブロックの選択枠と当たり判定は穴を考慮しない。

## 計器盤と触媒劣化による温度分布の移動（追記）

### 指示

外筒に、合成ループの圧力（15～25 MPa相当）と1段目・2段目・3段目の各温度を示すアナログ計器盤を置く。触媒が劣化すると上段の温度が上がらなくなり、下段の温度が上がる実機特有の挙動も表す。

### 実装

| 部分 | 内容 |
| --- | --- |
| 計器盤 | 新規ブロック`reaction_tower_gauge_panel`（`block/ReactionTowerGaugeBlock`、`block/entity/ReactionTowerGaugeBlockEntity`、`client/ReactionTowerGaugeRenderer`）。反応塔の側面にだけ置け、塔が外れると落ちる。厚さ3 pxの板に4つのダイヤル（左上：圧力0～30 MPa・15～25に緑の帯、右上・左下・右下：上段・中段・下段の温度0～600 ℃・550以上に赤の帯）。針と数字は電解槽制御盤の部品（`ElectrolysisControllerRenderer.needle`・`readout`を同じパッケージから使えるようにした）。文字盤は`tools/generate_reaction_tower.py`の`gauge_face`で生成 |
| 流れの向き | 反応器では原料を最上段から入れ、製品を最下段から出す（下向きの流れ）。原料が足りないときは上の段から先にバッチを回す。気液分離の向きは変えていない |
| 計算 | `ReactionTowerBlockEntity.instruments`。圧力＝25 MPa×（塔内の気体）÷（気体の緩衝槽1つの容量）、上限30。温度は上の段から順に、各層が残りの平衡までの量×(1−exp(−k×活性))を反応させ（k＝1.6×3÷段数、活性＝残り寿命の割合）、その段の温度＝熱源温度＋150 ℃×その段の反応量。新しい触媒の3段塔で約500／404／385 ℃、寿命半分で約462／417／397 ℃ |
| 表示 | 読みは時定数3秒（圧力1秒）で目標へ近づき、1 ℃・0.1 MPa以上変わったときだけ同期する。クライアントの針はさらに毎フレーム滑らかに追う |
| レシピ | 鉄板3・銅板2・時計1・ガラス板3（作業台、基本段） |
| Ponder | 「反応塔」に計器盤の設置と、新しい触媒→劣化した触媒の読みの変化を追加 |

### 確認

- `ReactionTowerGameTests`8件すべて合格（新規：新しい触媒では上段＞中段＞下段、緩衝槽8割で15～25 MPa、寿命半分の触媒では上段が20 ℃以上下がり中段・下段が上がる。既存のテストは原料を上・製品を下に変え、原料が足りないときは上の段から回ることを確認）。
- 関係する9クラスは、以前からの2件以外合格。
- 実画面（Xvfb、日本語）：計器盤が外筒に付き、圧力計の針が約21 MPaを指し、温度計の針が振れていることを確認した。数字表示は小さく、この距離では読みにくい。

### 制約

- 温度・圧力は表示用のモデルで、生産量や触媒の減り方には影響しない（固定レシピのまま）。
- 圧力は塔内の気体量からのゲーム上の換算で、気体の状態方程式ではない。
- 計器盤は1ブロックに4つのダイヤルを並べたので小さい。

## Createのボイラー計器を各段に（追記）

ユーザーの指示で、計器盤ブロックをやめ、Createの蒸気エンジン用ボイラーの計器（`AllPartialModels.BOILER_GAUGE`・`BOILER_GAUGE_DIAL`、針の振れ145°）を外筒に直接描くようにした（`client/ReactionTowerRenderer`）。

- 温度計は、バスケットの入った段ごとに各面の中央。3段なら3つ、5段なら5つ（各面）。温度は3段の区分をやめ、段ごとに計算する（上の段から順に反応、熱の上昇は塔の高さの3分の1で150 ℃分、上限600 ℃）。
- 圧力計は上から2段目の、温度計の隣（時計回り側の角のブロック）。デザインの違いとして本体と針を赤銅色に着色した。
- Createのボイラーと同じく、計器の前のブロックが置き換え可能でない面には描かない。描画範囲を塔の幅まで広げた。
- 計器盤ブロック`reaction_tower_gauge_panel`とそのモデル・テクスチャ・レシピ・ルート・タグ・翻訳を削除し、電解槽制御盤の描画メソッドを元の非公開に戻した。
- 確認：`ReactionTowerGameTests`8件すべて合格（温度のテストは上の段から順の各段の値で比較）。関係する9クラスは以前からの2件以外合格。Ponderの実画面で、各段の温度計と2段目の着色した圧力計、配管のある面に計器が出ないことを確認した。

## 計器の色・大きさ・位置の修正（追記）

ユーザーの指示で次のように直した。

- 色：Createのボイラー計器のテクスチャ（`create:block/boiler_gauge`）を写し、文字盤以外の銅色を外筒の暗い鋼色に塗り替えた自前のテクスチャと部品モデル（`block/reaction_tower/gauge`・`gauge_dial`）を`tools/generate_reaction_tower.py`の`gauge`で生成する（Createのjarから読む。`electrolysis_hardware.create_texture`に透明度を残す引数を足した）。圧力計は着色をやめ、針だけを赤くした。
- 大きさ：取り付け面の中心を基準に半分に縮小した。
- 面：正面だけに描く。正面は、ブロックを置いたプレイヤーの側（各ブロックが`Front`として保存し、最下段の中央ブロックの値を使う）。
- 圧力計：下から2段目に移した。
- 確認：Ponderの実画面で、正面だけに半分の大きさの鋼色の計器が並び、下から2段目に圧力計があることを確認した。

## 計器の配置（追記）

ユーザーの指示で、温度計を正面の左側のブロック、圧力計を右側のブロック（下から2段目）へ寄せ、大きさを元（Createのボイラー計器と同じ）に戻した。Ponderの実画面で確認した。

温度計は半分の大きさに戻し（取り付け面の中心を基準に縮小）、圧力計だけを元の大きさにした。Ponderの実画面で確認した。
