# 石油化学の下流工程と資源回収

対象は Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10。実装コミットは `4e59642b7b4e977dfcffeee67ba6c8313828e16c`。

## ゲーム内の工程

- 白金・ゼオライト触媒コアを入れた反応塔を超加熱すると、溶融パラフィンまたは残渣油を圧縮水素とともに再分解できる。合成ナフサを分留・改質へ、軽質オレフィンガスをエチレン・プロピレンの分留へ戻せる。新しい設備は不要。
- BTXは分留塔でベンゼン、トルエン、キシレンに分かれる。合成ナフサの別レシピではブタジエン、ヘキサン、低硫黄軽油が出る。エチルベンゼンから得たスチレンとブタジエンを密閉撹拌容器に送ると、既存のベルトやガスケットに使える合成ゴムを作れる。
- クメン触媒と酸化触媒を使った反応塔の別工程からフェノールとアセトンを得る。フェノールとメタノール酸化からのホルムアルデヒド水溶液を密閉撹拌容器でフェノール樹脂にする。機械プレスで樹脂板に加工でき、制御弁アクチュエータの材料に使える。
- PE・PPは既存の重合触媒（チーグラー・ナッタ触媒コア）、冷却ミキサー、機械プレスが担当する。両方から作れるプラスチック板をプレスすると成形プラスチックブロックになる。PVCは既存の配管工程に加え、リン酸塩系難燃ペレットにも使える。
- クロロベンゼン、クロロトルエン、キシレン、アセトン、ヘキサンはミキサーで工業樹脂を抽出する溶剤に使える。回収溶剤も同じミキサーに戻せる。塩素系溶剤の工程から出る塩化水素は既存の吸収塔に送れる。
- リン酸塩配合材をPVCと加工すると難燃ペレット、尿素・カリ肥料・液体アンモニアと加工すると液体肥料になる。難燃ペレットは耐熱被覆材へ。被覆材をデプロイヤーで高圧導線に塗り、耐火ケーブルとして敷設できる。被覆材は既存の耐火れんがにも加工できる。
- 液体肥料をCreateのスポウトに送り、デポ上の薬剤散布機に充填する。作物かその耕地に向けて右クリックすると、遮られていない周囲3×3の作物へ散布する。

## 数値と処理

- ワックス側は1バッチからナフサ100 mBと軽質ガス50 mB、残渣油側はナフサ350 mBと軽質ガス150 mB。どちらも圧縮水素を追加投入する。ここで回収するのは原料の重質留分で、プラント全体のエネルギーと物質の閉ループは検証対象外。
- ミキサーは1バッチに溶剤200 mBを使い、150 mBを回収する。処理を続けるには補給がいる。
- 耐火ケーブルのシミュレーション上の上限温度値は950、従来の高圧ケーブルは700。電気抵抗、絶縁抵抗、最大スパン128ブロックは同じ。
- 散布機は容量4,000 mB。少なくとも1株に施肥したときだけ100 mBを使う。作物の判定・成長・収穫には既存のNPKプロファイルを使用する。適用済みの株への再散布、保護された株、壁越しの散布では肥料を消費しない。
- 白金・ゼオライトコアの材料タグには白金と既存のニッケルを登録している。白金がない構成でも既存の資源で製作と再生が可能。

## 検証

- フェーズ1で Gradle ビルドと関連 GameTest 57件。全件成功。
- 追加の5件は実際の分留塔・触媒塔・密閉撹拌容器の出入口、Createのミキサーとスポウト、散布機を使用する。フェノール樹脂板と耐火導線はCreateのレシピ解決と入出力を検査した。ケーブルの温度値はWireTypeを直接検査した。
- Gradle のビルドと専用 GameTest サーバーで全673件が成功。混合物6,004チェック、原子炉物理1,668チェック、原子炉制御テストも成功。追加レシピの読込エラーなし。
- RTX 4060で動く日本語クライアントでJEIを起動した。新規16流体と対応バケツのR/U、触媒コア3種、仕上げ材と回収用途を確認した。反応塔と液体肥料のJEI画面を保存した。反応塔と散布のPonderを開き、散布の画面を保存した。
- 日本語・英語・簡体字中国語で翻訳キー集合、166のPonderシーン、構造ファイルと接続先を検証。追加の専用装置やモデルはゲーム内既存形式に準拠。
- 新規16種の容器について既存バケツの外形と色の区別を検証した。全体の外観監査は、変更前からある塩化アンモニウム溶液バケツの外形で停止する。
- 未確認は、第三者の追加MODを組み合わせた長時間運転と、敷設した耐火ケーブルを実際に限界温度まで加熱した場合の挙動。
- 実在の爆薬・推進剤を作る系統、砲弾装薬の連携、危険な有機リン中間体につながる工程は未実装。耐火材と農業の分岐はリン酸塩配合材で構成した。
