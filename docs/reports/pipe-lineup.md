# 配管の種類の整理（塩ビ管の追加後）レポート

## 基準と実装コミット

- 作業ブランチ：`main`
- 作業開始時の基準コミット：`5a10812`
- 実装コミット：`838f71c`

## 依頼と決定事項

- 依頼：塩ビ管が加わったので、配管の種類をもう一度整理する。
- 見直し：10種のうち、超耐圧パイプが酸にも耐え、ステンレス鋼管の上位互換になっていた。ジルコニウム管は熱い酸で樹脂パイプと役割が重なる。
- ユーザーの決定：
  - 超耐圧パイプの耐食を外す。
  - ジルコニウム管は残す（熱い酸を25 barまで運ぶ上位の管）。
  - 樹脂パイプは今の分担で残す（熱い酸を2 barまで。ジルコニウムの浸出液はジルコニウム管より前に要るため）。

## 実装内容

- `transport/PipeMaterial.java`：
  - `ULTRA`（超耐圧パイプ）を1400 K・300 bar・耐食なしにした。
  - 減圧弁・背圧弁はこれまで `ULTRA` として扱っていたため、そのままでは酸で腐食するようになった。新しい材質 `VALVE`（1400 K・300 bar・耐酸、修理は頑丈な板）に分け、弁のふるまいを変えないようにした。
- 翻訳：ゴーグルの材質名に `material.valve`（圧力弁）と、抜けていた `material.pvc`（塩ビ管）を加えた（英・日）。
- Ponder「流体に合う配管を選ぶ」の手順6を、超耐圧パイプは酸に腐食されると書き直した。
- `tools/generate_pipe_material_ponder.py`：凍傷の作業で入れた英文のアポストロフィで構文エラーになっていたのを直した。
- 文書：`docs/pipes-and-tanks.md` に用途ごとの配管の表を加え、腐食の表・配管の表・注記を直した。`docs/reaction-plant.md`（腐食性の反応流体は超耐圧パイプでも可、としていた）、`docs/thermal-equipment.md`（削除済みの黒鋼管が残っていた）を直した。

## 計算・根拠

- 腐食性の流体で一番厳しいのは高温の脱硫反応液（650 K・16 bar）などで、1000 K・25 barを超えるものはない（`FluidHazards` の表を確認）。超耐圧パイプから耐食を外しても、運べなくなる工程はない。
