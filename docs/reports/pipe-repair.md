# 配管の修理（C4）レポート

## 基準と実装コミット

- 作業ブランチ：`main`
- 作業開始時の基準コミット：`00fcb10`
- 実装コミット：`f606292`

## 依頼

- C4：劣化した配管を、交換せずに材料を使って直す。
- ユーザーの追加の指定：劣化した配管は、シルクタッチでも壊したときにドロップしないようにする。

## 実装内容（`transport/PipeWearBehaviour.java`、`transport/PipeMaterial.java`）

- 劣化の段階：1（警告）、2（劣化：接続部の圧力が低下）、3（重度の劣化）。
- 修理：
  - `PlayerInteractEvent.RightClickBlock`：劣化の段階が1以上の配管を、その材料の修理品（`PipeMaterial.repairItem`）で右クリックすると直す。
  - 修理品：銅パイプ→銅板、樹脂→プラスチック板、塩ビ→塩化ビニル樹脂、耐圧鋼→鉄板、超耐圧→頑丈な板、ステンレス鋼・保冷→ステンレス鋼板、ニッケル合金→ニッケルインゴット、ジルコニウム→ジルコニウムインゴット。
  - `repair()`：薬品の接触時間・熱損傷・段階を0にし、下げていた接続部の圧力を戻す。サバイバルでは修理品を1つ使う。金床の音。
  - クライアントでも同じ判定で右クリックを止めるので、修理品を配管の横に置いてしまうことはない。
- ドロップしない配管：
  - `BlockDropsEvent`：段階2以上の配管を壊したとき、ドロップのうち、そのブロック自身のアイテムと、流体パイプのブロックのアイテムを取り除く。ツールに関係なく（シルクタッチでも）働く。
  - ケーシング・支持具など、配管以外のドロップは残す（ケース入りの配管は、配管だけが消えてケーシングは戻る）。
- ゴーグル：段階1以上で「修理：〇〇を1つ持って右クリック」、段階2以上で「今壊すと配管は戻りません」。重度の劣化の表示を「停止して配管を修理か交換」に直した。
- Ponder「流体に合う配管を選ぶ」の手順8に修理とドロップしないことを追記した。
- 文書：`docs/pipes-and-tanks.md` に「配管の修理」の節。

## 未検証・制約

- シルクタッチの道具で壊す操作は、テストではしていない（ドロップの取り除きは道具に関係なく働く）。
- 配管が自然に破損したとき（`allowPipeBreakage`）は、以前からドロップしない。

## 次回の注意

- 配管の材質を追加したら、`PipeMaterial.repairItem` に修理品を決める（switch がすべての材質を要求するので、決めないとコンパイルできない）。
