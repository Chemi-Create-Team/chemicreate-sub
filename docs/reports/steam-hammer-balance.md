# 蒸気ハンマーのダメージと移動速度低下

実装コミットは `f4e5b0bab220f157728caec4222a3328e847fe4b`。

- `SteamHammerItem.java` は打撃に基礎ダメージ45を使う。メインハンドの属性は通常の素手ダメージ1に44を加える。
- 命中して生存した相手に、14 tickのめまいと80 tickの移動速度低下Vを同時に付与する。移動速度低下Vはバニラの移動速度属性に約0.25倍を掛ける。めまいが解けると、移動速度低下が切れるまで約4分の1で移動する。
- `tools/data/ponder_lessons.json` と生成済みの3言語のPonderに、ダメージ45と減速の説明を反映した。

## 確認

- Java 21、Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10でGradleビルドが成功した。`SteamHammerGameTests` と `SteamGunGameTests` の計6件が合格した。
- ハンマーの打撃試験で、メインハンドのダメージ修正、体力100から55への変化、めまい中の速度0、解除後の約0.25倍、減速終了後の速度の復旧を確認した。
- Ponderと3言語の翻訳の静的検証に合格した。クライアント画面の再確認は未実施。
