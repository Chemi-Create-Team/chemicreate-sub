# 往復式コンプレッサーのくびれとシリンダーヘッド

対象バージョンは `0.7.2`。実装コミットは `eedd4c703fe76e0157b2930d94f85dc46e816b3a`。

- 筐体をつなぐ角筒は外寸8×8 px・壁厚1 px。側面開口を広げ、その下の連続した装飾台座を取り除いた。シリンダーの胴は16角形にして、端に向けて最大径約16 pxまで広げた。
- シリンダーの外端にガスケット、丸蓋、周囲8本のボルト、中央のアンローダーを模した突起を追加した。角筒側は細く接続し、左右でヘッドが外を向くよう片側を180度回す。アンローダーは外観上のディテール。
- 単体モデルを上下の配管口と中央のケーシングに絞り、組立後に横向きの胴が隠れないようにした。既存の上下ポートと往復運動を使う。

## 検証

- 生成したJSONとOBJで、角筒の外寸と側壁厚、シリンダーの外径、ボルト8本の位置、アンローダーがブロック範囲内であることを検査した。
- コアModの往復式コンプレッサーと硝酸ラインの関連GameTest 10件が通過した。
- RTX 4060の開発クライアントで、駆動中の3列6気筒を左右から確認した。両側のヘッドが外を向き、角筒の上下にくびれが見える。既存のプレイヤーワールド全体は未ロード。
- Ponderの構造と翻訳キーの静的検査を通過した。
