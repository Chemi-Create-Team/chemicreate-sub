# 掘った閃ウラン鉱がスタックしない不具合の修正レポート

- 日付：2026-11-18
- 実装コミット：このレポートと同じコミット（`git log -1 -- docs/reports/uraninite-stacking.md`で確認）

## 指示

鉱石を掘ったときにスタックされないので直す。実プレイテストは行わない。

## 原因

ウラン鉱石を掘って出る閃ウラン鉱（と、イエローケーキ・ウランの粉など）は、プレイヤーの持ち物や地面にある間、1秒ごとに`RadiationSources.shed`が呼ばれ、周りにごく少量のアルファ汚染を落とす。このとき、スタック自体にも放射能の記録（`radionuclides`、その時点のゲーム時刻つき）を書き込み、毎回わずかに減らしていた。そのため、時刻の違う2つのスタックや、まだ記録のない新しく掘った物とは、データが一致せず重ならなかった。

ほかの6種の鉱石（ボーキサイト・ペントランド鉱など）が落とすアイテムには、このmodのデータは付かない。コードを調べた範囲では、スタックしない原因はこの1つだけだった。

## 修正

`nuclear/RadiationSources.java`の`shed`で、スタックへの書き込みをやめた。周りに落とす汚染の量（スタックの放射能×1e-9×個数）は変えていない。1秒あたり1e-9の減り方は表示や線量に表れない大きさなので、スタックに記録しなくても結果は変わらない。

## 確認

- `compileJava`成功。
- GameTest：`RadiationGameTests`の`alphaDustHasNoExternalFieldButCanBeInhaledAndLifetimeSurvivesDeath`に、汚染を落とした後の閃ウラン鉱2つと新しい閃ウラン鉱が同じアイテムとして重なることの確認を追加。修正前のコードでは、この確認は失敗する（落とした後のスタックにだけ記録が付くため）。`RadiationGameTests`・`UraniumFuelGameTests`の22件が合格。
- 実プレイでの確認は指示どおり行っていない。

## 注意

- 修正前に既に記録が付いた閃ウラン鉱は、新しく掘った物とは重ならない（本格運用前のため移行処理は作らない）。
