# 四酸化三鉄の山とハーバーボッシュ反応塔 完了レポート

## 実装内容
- `triiron_tetroxide_pile`（四酸化三鉄の山）：バニラの砂利と同じ`ColoredFallingBlock`、砂利と同じ硬さ・音（`ofFullCopy(GRAVEL)`）、ショベルで採掘（`mineable/shovel`タグ）。自身をドロップ。
- テクスチャは参照画像の3面（正面・側面・上面）を16pxへ標本化（`tools/generate_triiron_tetroxide_pile.py`）。上下は上面、南北は正面、東西は側面を使用。背面側は元画像に写っていないため推定。
- ハーバーボッシュ反応塔：3×3の反応塔の底面・上面（9個ずつ）と、中間段は中心を四酸化三鉄の山にした周囲8個の反応塔。山は1〜4個、全高3〜6段（`block/HaberBoschStructure.java`）。
- 成立判定は状態を持たず、反応塔のゴーグル表示時にだけ周囲を検査する（tick・保存・キャッシュなし）。成立時は高さ、不成立時は最初に不足する反応塔の座標を表示。

## Ponder追加
- `ponder/HaberBoschPonderScenes.java`、`tools/generate_haber_bosch_ponder.py`（構造NBTと日英字幕）。反応塔と四酸化三鉄の山から開ける。底面→外周の壁→中心の山→上面→ゴーグル表示→欠け（座標表示）の順。
- 実クライアント確認：`-Dcreateplant.clientQualityCheck=true -Dcreateplant.clientQualityTargets=reaction_tower@0`で全シーンのコンパイル・日本語タイトル・翻訳を検査し、時刻を変えて4段階を撮影。底面・壁（中心が空洞）・山・上面・ゴーグル・欠けの表示を確認。日本語のみ。英語は未起動。
- 不具合と修正：反応塔モデルの描画層が`translucent`だとPonder上で反応塔が描画されなかった。`cutout_mipped`に変更。これに伴い窓の薄い青赤の板（半透明）は廃止し、窓は枠だけで内部が見える。参考画像の計器窓の青赤は、アイテム・ブロックでは表現していない。
- 未確認：既存の`water_tank`も`translucent`のため、Ponderで同様に描画されない可能性がある（未調査）。
- 実装コミット（Ponder）：0d1ec52
