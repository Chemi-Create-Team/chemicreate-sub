# クリエイティブの流体バケツと状態選択

実装コミットは `c4b2add`。旧状態のバケツをタブに登録すると、読み込み時に同じ物質のバケツへ置き換わった後も状態データが違うため、一覧上では別々の枠に入っていた。`CECreativeModeTabs` は `StatefulBuckets.retired` で判定した旧状態を一覧と検索から外し、蒸気と水、液体窒素と気体窒素などを既定状態の1枠にまとめる。既存セーブの旧バケツを読み替える処理は従来どおり使う。

`CreativeInventorySectionsMixin` は対応するカタログ枠に操作案内を表示し、空のカーソルで右クリックすると `FluidStatePickerScreen` を開く。検索結果からも同じ操作が使える。温度と圧力はそれぞれ0から16の段階を使い、`FluidState` で相を求めてバケツの見た目とともに表示する。「受け取る」を押すと状態を含むバケツがカーソルに載る。戻ったときは検索語とスクロール位置を復元する。水とMod内の対応バケツのほか、既存の一覧にある原油バケツも選択対象に含む。動的な混合流体や二相流の設定には従来の制約を適用する。 [操作仕様](../fluid-states.md#6-見た目バケツワールド上の流体)

- Java 21で `check jar` が成功した。関連GameTest 21件が合格し、カタログと検索用コレクションの流体IDの一意性、既定状態、旧液体窒素バケツの読み替え、流体の取り出しを確認した。
- RTX 4060の実クライアントで、右クリック、温度と圧力の設定、矢印キーによる1段階の変更、高温・高圧の水バケツを気体としてホットバーに移す操作、検索からの液体窒素の取得、検索語と一覧のスクロール位置の復元を確認した。原油の選択画面は個別に操作していない。操作結果の保存後、クライアントの終了時に環境のNVIDIA EGLライブラリが異常終了した。 [ゲーム内の設定画面](../quality/creative-fluid-state-picker.jpg)
