# 液体タンク整理・脈動抑制管の完了レポート

実装日：2026-11-17。主要実装コミット `dfe48f5d3748db4edba9aa36220a3599c9edc673`、最終アセットと検証を含む実装コミット `a3b7b2e48e81f6de78a3309604251be6d5d266c5`。上流の採掘機更新 `8328779d` も保持しています。

## 対応内容

黒鋼液体タンク `liquid_tank` と水タンク `water_tank` を撤去しました。ブロック・アイテム・BlockEntityの登録、クラフト、戦利品、タグ、モデル、テクスチャ、翻訳、クリエイティブタブ、Ponderの学習入口から削除しています。Create標準タンクへ置き換え、生成スクリプトからも再登録・再生成されないようにしました。

脈動抑制槽は追加指定「縦も横も行けるパイプ型の脈動抑制管」に従い、X・Y・Zの3軸に設置できる直管に変更しました。登録ID `gas_receiver` は維持します。同じ軸の1列だけで在庫を共有し、横に並ぶ別の列や異なる軸は連結しません。両端だけにCreateの標準Capabilityを公開します。供給用と搬出用のポンプの間で気体を蓄え、在庫量の差を受け持ちます。

レンチで軸を変更できます。連結を分割しても全成分・気体量を保存し、変更前の向きのハンドラーからは搬出できなくなります。液体は受け付けません。容量は従来のCreateタンクの設定値を1ブロックあたりの基準とし、高圧等級の気体換算64倍を維持します。長さ上限もCreateのタンク設定に従います。

灰緑色の八角形の胴、補強帯、段付きの端部、両端の配管フランジを持つ4種の終端モデルを作りました。3軸の12通りのブロック状態で使います。1台の共有在庫に1つのCreate式圧力計を描き、流体の圧力等級へ補間して追従します。空の場合は0です。指針は在庫割合や連続的な実圧ではなく圧力等級を示し、独自の圧力波シミュレーションは加えていません。

Createの標準縦型タンクと既存の横型液体タンクは、気体・蒸気を受け入れなくしました。通常のfill、SIMULATE、実際の面別Capabilityで拒否します。水・通常液体と液体だけの混合液は使用できます。気体の識別には既存の気体情報とFluidTypeの空気より軽い判定を使います。耐圧タンク、ステンレス、熱交換設備などの必要な気体扱いは維持しています。

## Ponder・アセット

新Ponderは脈動抑制管から開けます。3方向の配置、入口と出口のポンプ、共有在庫、圧力計、液体タンクとの使い分けを日本語・英語・中国語で説明します。旧レシーバーを側面から出入していたPonderは、単独管なら隣の配管の軸へ合わせ、縦型の槽として使っていた構造は耐圧タンクへ差し替えています。材質ガイドも新モデルに合わせて再生成しました。

Ponder構造の整理は開発用データだけを対象とし、ゲームのワールド移行ではありません。共通のStructure保存処理からも正規化を呼び、再生成で旧配置が戻ることを防ぎます。原子力設備の共通素材や気液分離ドラムは維持しています。
