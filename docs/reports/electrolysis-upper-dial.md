# 電解槽の上段パネルと1％ダイヤル 完了レポート

2026-11-11 UTC。開始時 `b5d55540`。実装コミット：`b87d9f95b978406671571af4c0a1815f8cf16789`。この後の記録用コミットで実装IDを追記した。

## 内容

添付画像の電圧計・電流計を残し、2×2の上半分に操作を集約した。上段左はV/A計と緑のSTART・赤のSTOP、上段右は回転する稼働率ダイヤルとCEEの2端子。下段の2ブロックはタンク材質の立方体1個ずつで、計器・スイッチ・隠れたクリック操作がない。2×2の構造判定、電解セルの寸法、電源端子の接続規則は維持した。

- ブレーカーレバー、非常停止、プリセット、±25ボタン、補助計器、液面管、ニキシー管を描画・操作・不要アセットごと撤去。電圧計と電流計の精細な文字盤・針・ガラスを残した。
- STARTで主電源を接続、STOPで切断する。ダイヤル右半分を右クリックで＋1％、左半分で－1％。しゃがみ時は±10％。1～100％へ制限し、37％などの任意の整数値を既存の `Limit` にそのまま保存する。
- ダイヤルの指標は `−135°＋270°×設定率`。針とともにBERで減衰補間し、数字は実設定値を表示する。独自GUI・メニュー・追加の操作用パケットはない。
- 旧非常停止ボタンの状態は廃止。読み込み時に古い `EmergencyStop=true` は停止状態へ変換するので、自動再起動せず、新STARTで起動できる。新しい保存にはその旧フラグを書かない。
- 赤石停止、開ハッチ、極板不足、出力満杯、実CEEの抵抗・供給仕事、有限在庫と使用仕事の保存を維持した。下段からの計器・手操作を撤去しても、共通の在庫・構造所有者と標準搬送は変えない。
- 電解槽および水素製造Ponderの日英中を更新。電解槽Ponderは上段のSTARTとダイヤルを指し、37％の設定を表示する。Ponderの電流も設定率に合わせる。

新しい画像生成は行わず、既存のCreate材質と計器エクスポーターを編集した。高精細な質感とわずかなドット感、側面窓を設けない仕様を維持する。内部液面は上部ハッチから確認できる。

## 実装箇所と計算

`tools/electrolysis_hardware.py` が空の下段・上段2モデル・回転ノブを書き出す。旧3可動モデルと4テクスチャを削除し、数字アトラスを1024×128へ縮めた。`ElectrolysisControllerRenderer` と `ElectrolysisDisplayState` はV/A・給液面・稼働率だけを共有補間し、下段をBERで描画しない。

`ElectrolysisControllerBlock` は上段の実ボタンとノブの円内だけを判定する。ブロックや配線アイテムを持っている間は通常の設置・接続へ渡す。`ElectrolysisControllerBlockEntity.setRunning` と `selectLoad` が所有者を操作する。使われなくなった旧 `operate` APIは削除し、呼び出す試験も更新した。

抵抗は既存どおり、設定率に比例した電解仕事から求める。通常極板1枚・400 Vなら100％＝1 kW、37％＝370 W、1％＝10 W。受け取った仕事を有限バッファへ貯め、1サイクル50 Jを払ってから水3→水素2＋酸素1の反応を行う。細かい設定のための無条件生産や材料の端数切り捨ては加えない。
