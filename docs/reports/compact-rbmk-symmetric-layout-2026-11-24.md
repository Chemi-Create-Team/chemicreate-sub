# 52チャンネルの円形RBMK炉心を回転対称に配置

実装コミットは `bb7af43`。対象はMinecraftの直径5ブロック・52細分チャネルの円形炉心と、最小RBMK・CEE発電ワールド。 [配置図](../rbmk-reactor.md#52チャンネルの初期配置) · [プレイテストワールド](../playtests/compact-rbmk-cee.md)

## 実装

- 旧初期配置は細分座標を3で割った余りと中央2区画で制御棒位置を決めていた。直径5の円形炉では配置が片側と中央行に偏った。
- 10×10の内部格子上の8点を新しい初期配置にした。有効チャネルだけを表示すると縦横8区画の範囲になる。各制御棒は上下左右に有効チャネルを持つ。90度回転で同じ配置になるので各象限に2本ずつあり、制御棒同士の縦・横・斜めの間隔は1区画以上ある。
- 配置の適用は炉心の形成時に行う。旧初期配置と全列が一致し、燃料・制御棒・照射標的が全区画で空の炉は再形成時に更新する。装荷済みの炉および手動で区画種別を変えた炉は保存済みの配置を読み込む。制御盤は従来のDisplay Linkを通じて実物の装荷位置を表示する。
- 配布済みの最小炉セーブは停止状態のコピーを更新した。新旧で役割が入れ替わる区画だけを交換し、燃料44本・制御棒8本の種類、燃耗量、挿入量と摩耗の記録を保存した。保存前後で52区画のアイテム状態の多重集合が一致することを確認した。
- 核分裂炉のPonderに新配置の説明を追加し、小型炉で制御棒の装荷位置を示す矢印を新しい区画へ移した。役割の手動切替は上部キャップの既存のレンチ操作を使う。

## 主な変更箇所

- `nuclear/ReactorCoreVariants.java` と `nuclear/ReactorCoreStructure.java` に新しい初期配置。 `nuclear/ReactorCore.java` と `block/entity/FuelChannelBlockEntity.java` に旧空炉の更新条件。
- `gametest/RbmkGameTests.java` に、配置・表示・旧炉データの回帰試験。
- `ponder/RbmkPonderScenes.java` と `tools/data/ponder_lessons.json` にPonderの表示位置と説明。

## 検証

- 関連GameTest 35件が合格。有効52区画、燃料44区画、制御棒8区画、内周、90度対称、斜めを含む間隔、各内側行と列、Display Linkと炉心図の一致を確認した。旧空炉の再形成、装荷済み炉、手動変更した空炉も試験した。
- `check jar runGameTestServer` が成功し、専用サーバーのGameTest全752件が合格した。
- 配布ZIPを展開してRTX 4060の実クライアントで開き、停止状態で燃料44本と制御棒8本の実位置と炉心図を照合した。AUTOで1,200 tick連続して定格の85%以上で発電し、終了時の熱出力は34.87 MW、CEEの電圧計は2,926.99 V、抵抗負荷は71,416.28 Wだった。運転中の炉心図を撮影した。
- カバーを開けてAZ-5を作動させ、8本の全挿入と熱出力の低下を確認した。炉の熱出力が下がった後も1,400 tick時点では発電が続いていた。冷却を進めてから電圧と負荷電力が0 V・0 Wになったことをゲーム内で読み取った。
- 変更したPonder字幕は日本語・英語・中国語で確認した。Ponderの再生とJEIは今回の実クライアント確認の範囲外。ゲーム終了時のNVIDIA EGLの異常終了に先立ち、画面と測定値を取得済み。実運転試験は配布ワールド1構成で行った。
