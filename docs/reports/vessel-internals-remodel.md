## 変更内容

ユーザーの「配置した4装置が簡素すぎる、特に羽根が少ない」という指摘に合わせ、材質と立体形状を作り直した。槽外装、天板、はしご、登録ID、レシピ、処理量、回転数条件、保存形式は変更していない。

| 部品 | 最終形状 |
| --- | --- |
| 撹拌翼 | 十字4枚から、6枚の放射状垂直羽根を上下2段にした計12枚へ。段ごとの位相を30度ずらし、円板・ハブ・ボルト・連続軸を追加。 |
| 触媒籠 | 幅24pxの網かご、補強リング、起伏のある粒状の充填層、押さえと吊り手。網目は透明模様ではなく実際の開口。 |
| 分離棚段 | 幅26pxの穴あきデッキ2段、左右に分けた降液管と堰、支持柱と桁。孔は実際の形状で表現。 |
| 遠心ロータ柱 | 4本の密閉した段付きロータ、端蓋・ハブ・細軸・帯と、軸受穴を持つ静止支持枠。2×2・3×3で別の支持枠を使い、各管だけが回転。 |

撹拌翼は[INDCOの6枚Rushton翼](https://www.indco.com/shop/product/6br-14/rushton-impeller-6-blade-14-diameter)と[SPX FLOWの放射流型翼](https://www.spxflow.com/assets/pdf/lightnin-c200-b-956-us.pdf)、棚段は[Sulzerの棚段・降液管](https://www.sulzer.com/en/products/separation-technology/trays)の構造を参考にした。写真の貼り付けや他MODの画像コピーはしていない。ゲームの槽内に収まる縮約モデルであり、実機の混合性能・分離効率を再現するものではない。

## 材質・生成

材質は落ち着いた鋼の灰色、暗い真鍮の軸受・締結部、酸化鉄系の充填粒で描き分ける。使用するPNGは10枚、全て16×16・不透明・3～8色。材質の粒は2px単位で、1モデルpxに1テクセルの密度を保つ。

形状は整数pxの占有領域から外表面を生成する。内部に埋まった面を省き、同一平面を長方形へまとめ、UVが16pxをまたぐ位置で分割する。Minecraft JSONが許可しない60度の要素回転は使わず、6方向の輪郭をピクセルの段で作る。動作時の全体回転は従来のCreate/Catnip経路を使う。

| モデル | quad数 | 外接寸法px |
| --- | ---: | --- |
| 触媒籠 | 788 | 24×12×24 |
| 撹拌翼 | 556 | 24×16×24 |
| 棚段 | 520 | 26×12×26 |
| 遠心支持枠・2×2 | 922 | 26×12×26 |
| 遠心支持枠・3×3 | 890 | 30×12×30 |
| 回転ロータ1本 | 230 | 10×16×10 |

遠心機のアイテムモデルにも4本のロータを含めた。ワールド描画では支持枠にロータを重複して含めず、従来どおり別々に描く。GUI用表示倍率は0.36で、大きな部品がアイテム枠からはみ出しにくくした。

限定再生成：

```python
import sys
sys.path.insert(0, "tools")
import generate_lidded_vessel as vessel
vessel.internal_textures()
vessel.internals()  # 新ロータの限定生成と、組立アイテムモデルの生成も含む
```

外装や天板を巻き戻さないため、この作業では生成スクリプト全体のmainを実行していない。

## クリアランス

可視本体は床上面Y2から天板下面Y14までに収め、連続軸だけY0..16へ延ばした。2×2内壁との余裕は籠2px、棚段・支持枠1px。撹拌翼の最大回転半径は12.529964pxで、内壁半幅14pxに対して全角度で1.470036px以上の余裕がある。

遠心ロータの最大回転半径は5.385165px。2×2の壁まで0.614835px、3×3の実際の段状斜壁まで1.017959pxの余裕を保つ。支持枠のハブ穴との同じ高さの半径方向余裕は最小0.443274px。Y3/13の端面は支持板と接するため、3D面同士の最短距離自体は0だが体積貫通はない。

## 検証

- ビルド成功。関連GameTest `DriveLessVesselGameTests` は8/8合格（787.6 ms）。回転入力・応力・切断時停止・在庫保存・触媒操作などを確認。
- 既定buildの物性25、ハーバー・ボッシュ1,019、原子炉物理1,670チェックと炉制御テストも合格。
- 独立した幾何監査で、6モデルと4アイテムのUV、参照材質、元の占有領域との外表面一致を照合。欠落面・内部面・同向き／逆向き重複面は全て0。羽根は外周の連結成分から6枚×2段を別に数えた。
- 20アセットを限定再生成し、生成前後のSHA256一致を確認。最終JARに入ったモデル・材質もソースとバイト一致した。
- Ponder静的検査成功。既存追加90シーン・454字幕・131部品リンクと、全出荷NBTを確認。今回の専用シーンは4部品と槽から登録し、原寸のItemDisplayで静止展示する。
- RTX 4060 / OpenGL 4.6の実クライアントで115シーンの日本語検査、4部品の展示と4装置の場面を確認。展示画像は1260×740で保存し、2×2・2段の槽へ撹拌翼を装着してハッチを開いた場面も別に確認・保存した。対象にmissing textureや不自然な欠落は見つからなかった。

全体GameTestの再実行はしていない。変更はモデル・材質・Ponderと描画モデルの選択であり、前回の全体実行には長い保存I/O停止があったため、今回の確認は関連範囲に絞った。大規模配置のMSPT/FPS比較はしておらず、性能向上は主張しない。
