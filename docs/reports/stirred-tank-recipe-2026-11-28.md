# 撹拌槽ブロックのクラフトレシピ

対象バージョンは `0.5.6`。実装コミットは `6df2545f7d0e2c2f77c49984b4bc01c530a698cd`。

- `recipe/stirred_tank.json` をCreateのメカニカルクラフター用に更新した。3×3の中央にステンレスタンク1個、周囲に鋼鉄インゴットを8個配置し、その上の中央にシャフト1本を置くと撹拌槽ブロック1個になる。鋼鉄には共通タグ `c:ingots/steel` を使う。
- レシピ生成元、反応プラントの文書、日・英・中のPonderとゲーム内説明書を更新した。

## 検証

- GameTest 15件が通過。指定配置の10個をCreateのレシピ処理に渡し、撹拌槽1個を得ることを確認した。
- 生成元とレシピJSONの一致、Ponder字幕の一致、説明書のページ行数を確認した。設置したクラフターの回転と搬出は検証の対象外。
