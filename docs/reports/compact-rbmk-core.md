# 燃料3マスの小型RBMK炉：引継ぎ

既存の7 m炉心を維持し、同じ部材で3 m炉心を組める構成を追加した。新しい炉や入出力専用ブロックは登録していない。既存テクスチャ・モデルは変更していない。

## 寸法・計算

| 部分 | 小型 | 従来型 |
| --- | ---: | ---: |
| 下部保守空間／遮蔽 | 2＋1 | 5＋2 |
| 有効炉心 | 3 | 7 |
| 上部遮蔽／懸架部 | 1＋3 | 2＋12 |
| キャップ | 1 | 1 |
| 全高 | 11 | 29 |
| 炉内集合体 | 7 | 21 |
| 制御棒移動量 | 3 | 7 |

平面5～13マス、側面遮蔽2マスは共通。対応高さは3または7のみで、中間高さ・列ごとの高さ混在・途中欠損は形成しない。最大397燃料チャネルの7 m型は765 MWを維持し、3 m型は約327.857 MW。定格は燃料チャネル数×765 MW÷397×有効高さ÷7で求める。

燃料棒1本の総エネルギーは4 GJ/m×有効高さ（小型12 GJ／従来28 GJ）。燃料・束内固体の熱容量、濡れ面の熱伝達、冷却水の有限容量も実際の高さに比例する。沸騰伝熱の無次元負荷を同じ高さの定格で割るため、比例出力時の温度応答が揃う。円形外縁で無効になる細分チャネルは出口容量にも含めない。

制御棒は吸収体3 m、接続部約0.536 m、黒鉛部約1.929 mを連続して動かす。通常駆動の行程は実高さ、AZ-5落下は全行程100 tick。従来型の形状・速度は維持する。クレーンの装荷／抽出行程と吊った集合体も対象キャップの7／21マスに追従する。使用済み燃料プールは従来の21マス集合体も収めるため既存深さを維持する。

## 保存・改築

各列に`AssemblyHeight`を保存する。旧保存では対応する`CoreHeight`、それも無ければ7 mとして読む。燃料棒・使用済み燃料棒・制御棒がある列は異なる高さへ変更できず、`fuel_height`で形成を停止する。燃料の燃耗率を新しい長さへ引き伸ばして残存エネルギーを増やす処理は行わない。元の寸法へ戻すと同じ在庫・燃耗・深度で復帰する。

改築には元寸法で燃料を使い切って使用済み棒を搬出し、全引抜した制御棒を回収する。現仕様で未使用／部分燃耗の燃料棒を回収する新操作は追加していない。棒・冷却水・余剰熱がある旧最下段を中段へ隠す形の改築も形成を拒否する。

空の列を拡張すると、追加構造材を293.15 Kとして`Tnew=293.15+(Told−293.15)×旧高さ÷新高さ`で混合し、既存材の余剰蓄熱を保存する。短縮は残部の温度を保ち、撤去材の熱を残部へ集中させない。冷却水の量・比エネルギーは変更せず、新容量を超えた分には既存の有限放出を用いる。

高さ変更・解体時は旧バイオシールド入力の負荷と旧出口リンクを解除する。出口は現在の炉室範囲も検証し、保存済み旧リンクや取得済みハンドラーから短い炉を排水できない。

## 主な変更先

- `nuclear/ReactorPhysics`：2つの寸法構成と長さに比例する定格。
- `nuclear/ReactorCoreStructure`：対応高さ・列の一致・装荷長の形成条件。
- `FuelChannelBlockEntity`：実高さの燃料／熱／給水、長さの保存、装荷済み改築拒否。
- `ReactorCore`、`Radiation`、`ReactorCores`：実高さの制御、炉室、放射線、冷却容量。
- `RodCapBlockEntity`：短縮した実チューブ経路の解決、短い棒の深度表示。
- `FuelChannelRenderer`：上部細管・プラグと制御棒の実寸描画。
- `ShieldPortBlockEntity`：現在の炉室への所属と各ハンドラー操作の検証。
- `CraneDriveBlockEntity`／`CraneRenderer`：対象炉に合う吊り長さ・行程と保存。
- `MachineReadings`：実行程に対する制御棒深度。
- `gametest/CompactRbmkGameTests`：8件の専用回帰試験。

## 検証・未確認

専用Python生成・Python構文解析・新規captionを含むJSON解析・`git diff --check`は通過した。GameTestは、小型／大型の共存と容量、無効高さ、短いキャップと実給水capability、比例燃耗／温度／保存、破損修復時の水保存、装荷済み改築拒否と復帰、空熱構造の改築と旧出口／動力無効化、実モーター／キャップ／AZ-5の3 m行程を用意した。

統合後のビルドは成功し、専用8件と従来の炉・クレーン・製作関連の計39件が合格した。別の全登録アセット監査1件は、取り込み済み液体ブロック44種の既存の翻訳キー不足で失敗し、本変更から切り分けた。
