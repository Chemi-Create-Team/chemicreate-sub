# 気液分離プラントの実機検証

Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10のシングルプレイに、蒸気供給タンク、冷却水供給タンク、2段の熱交換器、2段の気液分離器と3基の回収タンクを設置した。実装コミットは `a3fea98`。 [テストワールドと操作ガイド](../playtests/gas-liquid-separation-plant.md)

## 試験条件と結果

- 供給タンクには常圧162.5 ℃の蒸気4,800 mBと常圧6.25 ℃の冷却水4,800 mBを入れた。どちらも単相の流体を供給した。配管の駆動は128 RPMのクリエイティブモーターと、歯車・クラッチ・ステンレス製Mechanical Pumpを使った。
- 熱交換器の2回路は並行流で、蒸気の一部が凝縮する。温められた冷却水は手前の回収タンクへ戻す。熱交換器でできた二相流を分離器の上段側面へ送り、天面と底面から別々に搬出した。
- 修正前は両回路が同じ沸点で温度差を失った後も、熱量探索が潜熱を移し続けた。実機で蒸気の回収は0 mB、凝縮水の回収は4,800 mBだった。
- `thermal/ThermalEquipment.java` の並行流で最初に温度が一致した地点を採用するように修正した。片側の相変化に必要な潜熱は計算に含める。同じ沸点で冷却水が沸騰し始める直前の熱量と、蒸気側の乾き度を比較する回帰試験を `gametest/TwoPhaseGameTests.java` に追加した。 [熱交換器の計算](../internal-temperature.md#42-熱交換器)

| 計測点 | 修正後 |
| --- | ---: |
| 熱交換器の搬出口の乾き度 | 7/8 |
| 気液分離器の天面から回収した単相蒸気 | 4,200 mB |
| 気液分離器の底面から回収した単相の凝縮水 | 600 mB |
| 別回路で回収した液体の冷却水 | 4,800 mB |
| 供給タンク・熱交換器・分離器の残量 | 0 mB |

蒸気と凝縮水の合計は4,800 mB。レバーで蒸気ポンプを起動してから140 tickで回収が完了した。初回は配管に摩耗がないことも確認した。配布ZIPを別のゲームディレクトリへ展開してワールドを開き直した場合も、同じ回収量と単相を確認した。再試験の完了は143 tick。

## 確認範囲

- `check jar runGameTestServer` が成功し、GameTest全748件が合格した。
- 熱交換器と分離器の処理および機器間の搬送はサーバーの通常tickで実行した。計測時は各ポートと回収タンクを読み取り、材料投入は最初の供給タンクだけに行った。
- RTX 4060で描画を確認した。オフライン起動でJEIを無効にし、ゲームを保存して閉じる段階で環境のNVIDIA EGLライブラリが異常終了した。試験結果とワールドは終了前に保存済み。
- 乾き度の配管表現は1/8刻み。今回のワールド試験は常圧の水・蒸気と並行流で行った。
