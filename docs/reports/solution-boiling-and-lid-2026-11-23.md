# 水溶液の濃縮と蓋の蒸気（2026-11-23）

未検証（ゲーム内では動かしていない）。

- 攪拌槽（ふた付き槽）の主液が水溶液（`chemistry/fluids.json` の `aqueous`）で、ほかの供給液・チャージが何もないとき、バーナーで加熱すると沸点（100 ℃）まで温まり、残りの熱が水を飛ばす（2257 J/mB）。
- 飛んだ分だけ溶液が減り、`concentration` コンポーネント（千分率）で濃さを持つ。2倍で止まる（体積は半分）。濃い溶液を使うレシピは、濃さに応じて少ない量で1バッチ分になる（`ReactorMachineBlockEntity.takeFluid`）。薄い溶液と混ぜると溶質が保たれる。
- 蓋を閉じていれば蒸気は槽のガス空間にたまり、満杯なら蒸発しない。蓋を開けると、たまった蒸気や空気より軽いガスは出ていき、開いている間に出る蒸気もその場で抜ける（蒸気の雲と音）。
- 沸点が表にある液体（水・不凍液など）、混合物、気体には働かない。
- 2倍を超えて結晶にするには、従来の蒸発レシピ（`*_evaporation`）を使う。
