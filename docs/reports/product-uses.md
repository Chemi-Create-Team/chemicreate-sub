# 今ある設備で作れる製品の使い道を増やす レポート

## 基準と実装コミット

- 作業ブランチ：`main`
- 作業開始時の基準コミット：`66b1619`（Codexの転炉の後）
- 実装コミット：`5a5e9b6`

## 依頼と決定事項

- 依頼：大型の機能追加はやめ、今ある設備で作れるレシピ・アイテムを揃える。どのアイテムにも、できるだけ使い道を持たせる。
- ユーザーの決定：
  - 提案のうち「見送り」（二酸化硫黄・窒素ガス）と、顔料での大量の着色（B3。今後も実装しない）以外をすべて実装する。

## 実装内容

| 項目 | 内容 | 主なファイル |
| --- | --- | --- |
| 肥料 | 硝酸アンモニウム（骨粉2回分）と、新しい硫酸アンモニウム（骨粉1回分）を、作物に右クリックで使える。硫酸アンモニウムは撹拌反応槽で、アンモニア250 mB＋硫酸125 mBから作る | `item/FertilizerItem.java`、`CEItems` |
| 漂白剤 | 新しい流体の次亜塩素酸ナトリウム溶液（撹拌反応槽：塩素250 mB＋苛性ソーダ液500 mB → 500 mB）。ミキサーで、色の付いた羊毛・カーペット・ベッドを白に戻す | `CEChlorAlkali`、`FluidHazards`（腐食性）、`FluidThermal` |
| 石けん | 加熱した鉢で、CDGの植物油＋苛性ソーダ液から作る。使うと、牛乳と同じく状態異常（有毒ガスを含む）を消す | `item/SoapItem.java` |
| 塩の融雪 | 氷を水に、雪を消す。氷塊・青氷は溶けない | `item/DeIcingSaltItem.java` |
| 酸洗い | 錆びた鋼材ブロック＋塩酸100 mB → 鋼材ブロック（ミキサー） | 鋼の唯一性の試験を、酸洗いを除いて数えるように直した |
| 紙やすり | 紙＋アルミナ → Createの紙やすり1（砂の代わり） | Createの紙やすりは重ならないため、1枚にした |
| 劣化六フッ化ウラン | 撹拌反応槽（加熱）で水と反応させ、フッ化水素500 mBに戻す。劣化ウランは廃棄物として扱う | |
| 板3種 | アルミ・チタン・ニッケルのインゴットをプレスで板にする（`c:plates/*`）。冷却器のラジエーター・保冷タンク（アルミ板）、低圧タービンの羽根（チタン板）、燃料電池（ニッケル板）のレシピを板に替えた | `CEMetals`、`generate_crafting_recipes.py` ほか |
| モリブデングリース | 空カートリッジ＋輝水鉛鉱＋潤滑油250 mB（ミキサー）。圧縮機で潤滑油の3倍（230,400 mB）もつ | `GasCompressorBlockEntity.lubricantIn`、Display Linkの潤滑の上限も合わせた |
| ニッケル電極板 | 鉢の電解槽で、1回の電解の仕事を50 Jから35 Jに減らす。ニッケルの分を先に使い、しゃがんで取り出すとニッケルから戻る | `BasinElectrolysis`（`nickel` を保存） |
| 片付け | 削除済みの蒸気パイプの翻訳キー（`item.steam_pipe`・`goggle.steam_pipe`）を消した | |

### ついでに直したもの

- 電極板を入れた鉢を壊すと、電極板が消えていた（Createの鉢は自分の在庫しか落とさない）。電極板を種類ごとに落とすようにした（`BasinBlockEntityMixin` で `destroy` の後）。
- `generate_electrolyzer_ponder.py` の「ガスの出口」の文が、言語ファイルより古いままだった。言語ファイルの今の文（塩素にも触れた文）に合わせた。

## Ponder

- 新規「ソーダ工業の製品を使う」（3手順）：漂白剤・石けん・塩の融雪と酸洗い。石けん・塩から開く。Ponderの手順は8までなので、「塩・塩素・苛性ソーダ」とは分けた。
- 既存に追記：
  - 「硝酸を作って使う」：肥料（硫酸アンモニウムから開く）。
  - 「鉱石から金属を作る」：板（3種の板から開く）。
  - 「鉢の電解槽」：ニッケル電極板（電極板から開く）。
  - 「潤滑油カートリッジを充填する」：モリブデングリース。
  - 遠心分離機：劣化六フッ化ウランの回収。

## テスト

| 確認 | 結果 |
| --- | --- |
| `bash gradlew build runGameTestServer`（全件） | 345件すべて合格 |
| CIの検証スクリプト4本 | 合格 |

- 新規 `ProductUseGameTests`：
  - 肥料2種が小麦を育て、1個だけ減る。石には使えない。
  - 塩が氷を水に、雪を消し、氷塊は残す。
  - 石けんが有毒ガスと毒を消し、状態異常がなければ減らない。
  - グリースが潤滑油の3倍。
  - ニッケル電極の仕事の計算、出し入れの順番、鉢を壊したときに電極板が落ちること。
- 撹拌反応槽の新しい3レシピ（硫酸アンモニウム・漂白剤・劣化UF6）は、既存の `everyStirredReactionRunsWithItsHeat` で実際に動くことを確かめた。
- すべてのレシピの読み込みは `everyRecipeFileOfTheModLoads` で確かめた。紙やすりを2枚出すレシピが拒否されたのを、この試験で見つけて直した。

## 未検証・制約

- 実クライアントでの見た目（新しいアイテムのテクスチャ、新しいPonder）は撮影していない。テクスチャは拡大画像で確かめた。
- ニッケル電極板は、鉢の中では石綿の電極板と同じ見た目で描かれる。
- 漂白・石けん・酸洗いのミキサーのレシピは、読み込みは確かめたが、実際の鉢で動かしてはいない。
- Createの搬送機（デプロイヤー）で肥料や塩を使えるかは確かめていない。
