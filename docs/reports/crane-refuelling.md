# 引き継ぎ：燃料交換クレーン

実装コミット：`26767e794ec24ece282cbf27929a521d04ec6e01`。対象ブランチ：`work`。操作・構造は[門型クレーン](../gantry-crane.md)、水槽は[燃料プール](../fuel-pool.md)を参照。

## 実装

- 既存の2本のCreateガントリーシャフト、回転入力、レッドストーン、標準Value Settingsを再利用。4端をCreateの鉄骨・頑丈な建屋の梁で支持する天井走行方式を追加。既存の同じ高さ3～32段の4脚方式も維持した。
- 参考写真をもとに黄土色の走行桁、青灰色のトロリーフレーム、赤褐色の手すり、淡い白の伸縮マスト、落ち着いた緑のアクチュエータを生成。写真は同梱せず、16×16の専用ピクセルテクスチャとJSONモデルを使用する。高さ16ピクセルを越す部材は分割し、UV密度を保つ。
- 同じレールの範囲に隣接する炉とプールを置く。使用済み燃料を炉の穴から引き抜いてプールへ戻し、プールの新燃料を空いた炉の穴へ装荷する。吊り具は穴中心に合わせ、水面・炉上部キャップへ降りる。
- 水槽が存在する場合は燃料の行き先を水槽へ保つ。満杯なら回収を始めず、搬送中に未準備となれば燃料を保持して復帰を待つ。プールの無い配置では従来の駆動部格納庫を利用する。
- 満杯・プール未準備・新燃料不足・水面に対するレールの高さ不足・対象炉なしを、ゴーグルと標準Display Linkの状態で区別する。ゴーグルは4行以内。
- レッドストーン／動力停止では作業途中の残り時間を保持し、再開時に同じ取り出し元を再消費しない。サーバーでの保存復元時は掴んだ燃料を保持して再計画する。解体では格納庫・搬送中の燃料・ドリルを一度だけ返す。
- クライアント側で同期された残り時間を進め、棒の昇降を描く。PonderのNBT読込では説明用の描画構造を保持する。棒が動く範囲を描画境界に含める。
- 日本語・英語の燃料交換Ponderを追加し、既存のクレーンPonderとともに画角を調整。駆動部、燃料プール、炉上部キャップから参照できる。

## 計算・動作条件

レール長5～32、レール間隔4～18（外幅5～19）。位置移動は毎tick `min(0.49, abs(RPM)/256)` ブロック、燃料の取り出し・挿入はそれぞれ60 tick。燃料棒は14ブロックで描く。炉側の昇降距離はキャップ位置から炉心下端まで、プール側は水槽深さに合わせる。原子炉保守の応力は8 SU/RPM、採掘は16 SU/RPM。構造再検証は40 tickごと、移動位置は4 tick間隔で同期して補間する。

プールの使用条件は既存仕様を使用し、形成済み・1セル15,000 mB以上・90℃未満。今回、熱計算や炉心物理の式は変更していない。新規のGUI、独自の輸送網、追加の動力源は導入していない。
