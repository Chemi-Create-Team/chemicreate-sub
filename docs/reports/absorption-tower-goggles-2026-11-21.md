# 吸収塔のゴーグル表示の見切れ修正

実装コミット `f84a825a3fb5800aaf92d8c3b7019872c1c05494`

## 変更内容

- 吸収塔の段数と各槽の容量、上下段の入出力案内を短い表記にして、状態と工程を含む4行の概要を読みやすくしました。対象の翻訳は日本語・英語・簡体字中国語です。
- `src/main/java/net/createplant/mixin/GoggleOverlayMixin.java` で吸収塔本体と外壁を対象に、Createが計測した最長行と余白40 GUI pxが画面幅を超える場合だけ、描画を横幅に合わせて等比縮小します。Createに渡す配置計算用の横幅と高さも同じ倍率に合わせています。
- 側面や底面、角の配管条件は、既存Ponderの吸収塔の配管説明で確認できます。

## 確認

- NVIDIA GeForce RTX 4060を使ったMinecraft 1.21.1の日本語クライアントで、形成済みの4段吸収塔の外壁を見たときの描画を確認しました。通常の表示幅426 GUI pxでは最長行236 GUI pxで、以前の配管案内は単体で603 GUI pxでした。GUIを拡大して表示幅を160 GUI pxにしたときも、枠・アイコン・4行が画面内に収まりました。
- 最新の main を取り込んだ後、吸収塔・化学設備UI・気体混合・混合液のGameTest 28件がすべて通り、ビルドが成功しました。
- 配布JARは8,385,116バイトです。添付容量内に収めるため、開発用GameTestの52ファイルとZIPの空ディレクトリエントリを省き、残りの全ファイルがGradle出力と一致することを照合しました。

## 制約と引き継ぎ

- ゲーム内の実描画は日本語の外壁で確認しました。別言語の描画、第三者製のHUD変更は未確認です。
- Createを更新する場合は、`GoggleOverlayRenderer.renderOverlay` の描画順、最長行のローカル変数名、描画座標を測る位置を確認してください。
