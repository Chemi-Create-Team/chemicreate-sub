# 鋼材ブロックの用途調査

調査日: 2026-11-12

調査対象コミット: `8c96369a1fe0db7cf4bc36a64109759f0d2a35ce`

調査記録コミットID: 720cb6286ccba25bab6636c9e84ef68b8d0782d4

## 対象と結論

対象は、鋼材統一で製法を変更した `create:industrial_iron_block`。現行の本体レシピで直接材料に指定するものは13件ある。さらに、構造材として直接置く用途が4系統あり、Create標準の窓・錆びた鋼材への加工、必須MODのCEEの磁石にも使う。

本体、Create 6.0.10、CEE 1.1.4、CDG 1.3.15の出荷データと構造判定コードを調査した。追加のデータパックや、その他のMODのレシピは対象外。ゲームの仕様・レシピ・生成スクリプトは変更していない。

型付きレシピのJSONを調べ、成形レシピはパターン内の該当記号数、石切台レシピは入力1個として数えた。出力数もJSONから取得した。上の本体レシピIDの名前空間はすべて `create_heavy_indusstry`。

これらの部品を使う熱交換・加熱・発電・圧縮設備には、間接的な需要がある。完成品1個だけで設備全体が完成するという意味ではない。

## ブロックを直接置く用途

| 設備 | 必要な箇所・個数 |
| --- | --- |
| ガスホルダー球 | 外殻。直径4で24個、8で144個、16で632個 |
| 使用済み燃料プール | ラックを囲む全周の壁。内寸2×2の最小構成でも壁だけで276個 |
| 転炉 | 接着する炉体に75個。左右のトラニオン2個、炉底9個、外周64個 |
| 4.2 Kコールドボックス | 3×3×3の本体のうち、中央の再生熱交換器を除く26個 |

### 構造材の数え方

- ガスホルダー球: `GasHolderStructure.contains` と `isShell` の格子球判定を用いて外殻セルを数えた。形成後は専用の外殻状態に変換されるが、設置・回収する材料はCreateの鋼材ブロック。
- 燃料プール: `FuelPoolStructure` は内寸2～9、壁の高さは `DEPTH + 1`。現行の `ReactorPhysics` では燃料集合体長が `7 + 2 + 12 = 21`、`DEPTH = 22` のため、ラックの高さを含む23段の壁を要求する。内寸を幅W・長さLとすると壁の個数は `(2W + 2L + 4) × 23`。内寸2×2では276個で、ラック4個の製作に別途鋼材6個が必要となり、両方を合わせて282個。内寸9×9では壁920個、ラック81個を新規製作する41クラフト分が鋼材123個で、合計1,043個（ラック1個余り）。これは指定された壁とラックの分だけで、クレーン等は含まない。
- 転炉: `ConverterStructure.buildMovingCells` の指定は `2 + 3×3 + 4×16 = 75`。これに固定部品の製作分が加わる。固定部の炉殻5個を新規製作すると2クラフトで鋼材4個、軸受1個が鋼材4個なので、指定構造の分は合計83個（炉殻3個余り）。鉄骨・配管等の他材料は別途必要。
- コールドボックス: `CryogenicColdBoxBlockEntity.structure` が検査する27マスの中央1マスだけが専用再生熱交換器で、残り26マスが鋼材指定。駆動部・再生熱交換器の材料はこの26個に含めていない。

## Create・必須連携MODの用途

| 対象 | 製作・変換 |
| --- | --- |
| Createの鋼材窓 | 鋼材3個＋無色ガラス1個 → 窓2個 |
| Createの鋼材板窓 | 上記窓6個 → 板窓16個。鋼材を間接的に使用 |
| Createの錆びた鋼材ブロック | 鋼材1個を水洗い → 錆びた鋼材1個。窓・板窓の水洗いによる錆びた変種もある |
| CEEの磁石 `electroenergetics:magnet` | 鋼材4個＋アンデサイト合金1個 → 磁石4個。CEEの発電設備に間接的な需要がある |

本体には錆びた鋼材1個と塩酸100 mBから鋼材1個へ戻す酸洗いもある。これは鋼材を新規に消費する13件には数えていない。転炉の酸素製鋼やパドル鉄の組立連続工程も、鋼材を生成する側なので使用レシピの件数から除いた。

Create標準の鉄インゴットから直接鋼材・錆びた鋼材を作る石切台レシピ2件は、本体の偽条件データによる無効化を確認した。今回の調査対象では、CDGのレシピにこのブロックの直接指定入力はなかった。

## 見つかった文書の不一致

`docs/metals.md` の「設備14種」という一覧には、旧撹拌反応槽・触媒反応槽関係の部品の記述が残っている。現在の用途を確認する根拠としては古い。現行の直接消費レシピは上記13件で、別途、転炉・コールドボックス・CEEの磁石なども考慮する必要がある。この調査では当該文書やゲームの仕様は変更していない。

`docs/converter.md` は軸受1個にシャフト4本と記載しているが、現行レシピのパターン `ISI / SMS / IBI` ではシャフト3本。鋼材4個という記述は一致しており、上の鋼材集計には影響しない。この調査では製作レシピや元の文書は変更していない。

## 確認範囲と次回の注意

JSONの読み取り・材料数集計と構造判定コードの静的調査を実施した。ゲームの動作を変更していないため、ビルド・GameTest・クライアント撮影は実施していない。実行中のワールドに追加されたデータパックによるレシピの変更は未確認。

開始時に最新の `origin/main` を取り込み、更新された開発・デザイン規則も確認した。記録の保存前にもリモート更新がないことを確認した。今後、製造コストを変える場合は、レシピ13件だけでなく、外壁を大量に必要とするガスホルダー球・燃料プールと、CEEの磁石への影響も確認すること。
