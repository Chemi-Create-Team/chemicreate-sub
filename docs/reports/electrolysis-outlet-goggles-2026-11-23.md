# 電解槽の搬出口ゴーグル表示

実装コミットは `55936bb`。

- `ProcessGoggles` がCreateの既存ゴーグル表示に、カーソルが当たった面のラベルを先頭に追加する。`ElectrolysisCellBlockEntity` の流体ポートと同じ接続判定・流路番号を使う。
- 陰極・陽極・液体の搬出口は、搬出待ちの内容物を優先表示する。空の場合は投入した原料のレシピを参照し、原料未投入と製品のない流路も表示で区別する。底面は原料の搬入・排出を表示する。
- `ElectrodeHeadBlockEntity` は金属の搬出口に製品名を表示し、ヘッドが下りている間はSTOPの操作を案内する。電解槽のPonderと説明書も更新した。
- Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10でJARをビルドし、`ElectrolysisCellGameTests` 15件が成功した。塩水での物質の振り分け、接合面・上面の非表示、搬出待ちの液体の優先表示、ヘッドの上下を確認した。日本語・英語・中国語の翻訳キーとPonder字幕を確認した。クライアント画面での目視確認は省略した。
