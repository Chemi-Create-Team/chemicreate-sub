# ステンレスタンク・ボイラーと吸気・レシピ

実装コミットは `0bb1e87e4d856278d680d05b906951923cf462d9` と `c147c9981f0354b8a638534012702e5b58e0771b`。

- 旧タンク型分離機のモデルと画像を履歴 `c00ecc9faf0bc7a04040ffe8ad2d946718917440` から復元した。ふた付き槽は元の登録IDと在庫で「ステンレスタンク」と表示し、旧外装・接続模様に既存のふたと窓を組み合わせた。横置きの「ステンレスボイラー」は旧モデルを水平に使い、横型タンクの形成・給水・蒸気・計器を再利用する。作業台で両者を1個ずつ相互に組み替えられる。
- エアフィルターは旧IDと履歴 `341d65a1e19ade5262ccd1eb68b34ad938d08d95` のアイテム・モデル・製造レシピを復元した。開放端での直接吸気を廃止し、フィルターのブロックエンティティが空いている面からCreate配管へ最大1,000 mB/要求の空気を供給する。ポンプ直付けと吸気管経由に対応する。フィルターに貯蔵や継続tickはない。開放端からの排気は有効。
- `pressure_reaction/sulfur_dioxide.json` は密閉槽向けの加熱反応とし、硫黄・酸素を入力に超加熱で作動する。槽の既存のアイテム・流体のバッチ処理と製品バッファを使う。回転や内部部品なしで稼働する。酸素入り上面ポートから製品を回収する。
- JEIの槽反応と対象の工程レシピは、一般的な素材の経路を先頭へ寄せる。鉱石・基本素材・水・空気などに低い優先点を与え、廃物・残渣・工程数・触媒・副産物などで優先度を下げる。自MODの流体・容器の出力フォーカスでは、対象の製造レシピを比較し、バケツの排液や注液のタブを後ろへ送る。生産タブを並べ替えるフックは確認したJEI 19.27.0.343のクライアントのみで使う。
- Createのメカニカルクラフターの製造寸法は高圧断面5×5、低圧断面7×7。専用の封口・外装・羽根・軸を使う。ボイラー・フィルター・硫黄の反応・タービン製造寸法のPonderを更新した。

## 確認

- Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10。Gradle `build` 成功。対象GameTest 53件が成功し、JEIを外した専用サーバーでも成功した。ステンレスタンクの通常加熱・超加熱、硫黄と酸素の受け入れと二酸化硫黄の取り出し、実ポンプによるエアフィルターの直付けと配管経由、ステンレスボイラーの蒸気量、クラフトの寸法を検査した。
- RTX 4060のクライアントでステンレスタンク・ステンレスボイラー・エアフィルターの実画面を確認した。JEIで二酸化硫黄の流体とバケツの両方を検索して、先頭タブの1/5ページに硫黄と酸素が出ることを確認した。Ponderの字幕キーとリソース参照は検査した。通し再生は未確認。途中のクライアント終了時にNVIDIAのネイティブライブラリで終了時クラッシュが起きたが、起動中のチェックと画面撮影は完了した。
