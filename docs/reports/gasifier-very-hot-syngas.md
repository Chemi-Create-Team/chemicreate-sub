# ガス化炉の合成ガスを超高温にした完了レポート

- 日付：2026-11-18
- 実装コミット：このレポートと同じコミット（`git log -1 -- docs/reports/gasifier-very-hot-syngas.md`で確認）
- 説明：[噴流床ガス化炉](../entrained-gasifier.md)

## 指示

1. 石炭を熱してガスを作る設備（噴流床ガス化炉）に酸素が要るのはおかしくないか（質問）。
2. 合成ガスを超高温（超過熱）で出るようにする。

## 実装（2）

- `recipe/EntrainedGasificationRecipe.java`の`hotGasResult()`：合成ガスの温度等級を高温 → 超高温（500 ℃以上）にした。噴流床の出口は実際に1,300〜1,600 ℃。炉内・上面の出口・JEIの表示はこの値を使う。
- 上面の出口から出す配管は、超高温を通せるもの（ステンレス鋼管・強化管など）が必要。銅管は通らない（説明書の手順は以前からステンレス鋼管）。
- `docs/entrained-gasifier.md`とPonderの字幕（`entrained_gasifier.output`）を「超高温の合成ガス」に変更。

## （1）への回答

噴流床ガス化炉は、実在の設備でも酸素（または空気）を使う。炭素の一部を燃やす熱で炉を1,300 ℃以上に保ち、残りの炭素を水蒸気と反応させる方式（部分酸化）。酸素なしで石炭を熱するだけの方法は乾留（コークス炉ガス）で、外から熱を加える水蒸気ガス化もある。どちらにするかはユーザーの判断待ち。

## 範囲外で見つけたもの（未変更）

- ガス化炉の製品は、アンモニア合成の原料と同じ`synthesis_gas`（合成ガス）。アンモニア合成の合成ガスは水素3：窒素1（撹拌槽で混ぜる）だが、ガス化炉の合成ガスは実際には一酸化炭素と水素。今のままでは、ガス化炉のガスを圧縮して反応塔に入れるとアンモニアができてしまう（現実にはCOは鉄触媒を傷め、窒素もない）。名前と使い道を分けるかは未定。
