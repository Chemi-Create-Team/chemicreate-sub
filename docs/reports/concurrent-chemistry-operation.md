# 硝酸・ウラン・硫酸・塩酸の同一ワールド同時稼働試験

実施日: 2026-11-12。開始点: `a53f645b`。実装コミット: `1018e16afa9678971b1c66b6a498a50044301d48`。

## 結果

4系統を1つのGameTest・同じServerLevelに実配置し、通常のワールドtickで6,000 tick運転した。20、1,520、3,020、4,520 tickに有限量の材料を追加し、4回すべての製造を完了した。4系統の先頭反応器すべてが同時に `running` だった時間は400 tick。13基の槽は試験中ずっと形成状態を維持した。

6,000 tickは20 TPS換算で5分に相当する。GameTestサーバーは加速して進むため、現実時間5分のクライアント連続運転を意味しない。各投入の間には材料待ち時間を含む。

| 系統 | 試験した工程 | 最終製品の合計 |
| --- | --- | ---: |
| 硝酸 | アンモニア酸化→ラジエーター冷却→分留→NO酸化→水吸収 | 800 mB |
| ウラン | ウラン原石の焙焼→還元→グリーンソルト化→フッ素化→遠心濃縮→再転換 | 濃縮二酸化ウラン粉末4個 |
| 硫酸 | 硫黄酸化→接触酸化→純水との反応 | 2,000 mB |
| 塩酸 | 水素・塩素の反応→純水吸収 | 4,000 mB |

回収した副生成物はNO 400 mB、劣化六フッ化ウラン7,000 mB、フッ化水素3,000 mB。硝酸系の分留で分かれた水1,800 mBは塔内に保持し、他工程へ再利用していない。数値はMOD内のレシピ単位であり、実機の化学収率を表すものではない。

槽13基の全体最高値は圧力1.5351 bar、温度1,226.85 °C。温度は強加熱を含む全槽の最大値であり、酸製品の温度ではない。圧力・温度は各tickの槽の公開値を読み取った値で、任意の高負荷や閉塞に対する安全性を保証するものではない。

| フッ化水素 | 16,000 mB |

槽の配置は `ConcurrentChemistryGameTests` の相対座標で再現できる。硝酸は触媒槽1段×2基と吸収棚2段×1基、3×3×4のファン付きラジエーター、2×2×14段の分留塔。硫酸は撹拌槽1段×2基と触媒槽1段×1基。塩酸は撹拌槽1段×2基。ウランは吸収棚2段×2基、撹拌槽1段×2基、1×1遠心槽1段×1基。酸化用の槽には既存の酸化触媒を装荷した。

回転を必要とする槽は32 RPM、ラジエーターファンは128 RPM、冷却設定は30 °C。硫黄酸化・ウラン還元・グリーンソルト化は通常加熱、UF₆生成は強加熱。固体原料が残る間だけ加熱し、処理後は加熱を切る。ブレイズバーナーの燃料維持と回転供給は試験側で行っている。

## 見つかった不具合と修正

修正前は硫酸のみ目標を満たさず、硫酸1,000 mBと規格外液1,000 mBになった。純水500 mBとSO₃ 500 mBをまとめて投入すると、最初の250 mB反応後、残った純水が通常の水に変わっていた。

原因は `LiddedVesselBlockEntity.commitMixingFluids` が、反応後の水系残液を裸の `new FluidStack(Fluids.WATER, ...)` で再構築していたこと。既存の `WaterPhase.as` を使い、純水の種類と元のコンポーネントを維持したコピーへ変更した。残液の量・内部エネルギー・気液計算の式は変えていない。

修正後は4回で硫酸2,000 mBを製造し、他の3系統も同じ予定量を維持した。この同時試験自体が複数バッチにまたがる純水残液の回帰試験になる。

試験作成中には、未形成出口や形成前に保持したポートへのアクセスも修正した。これらは試験コード側の問題であり、製品側の不具合件数には含めていない。

## 未確認事項・制約・引き継ぎ

- 機械の処理は実際のワールドtickに任せ、`tickProcess` の手動反復や製品の直接挿入はしていない。一方、設備間搬送は試験側が標準のアイテム／流体ハンドラーへ行い、流体はシミュレーションで受入量を確認してから搬送する。実物のパイプ・ポンプ・ベルト・ファンネルで組んだ工場の全搬送網は未確認。
- ウランの焙焼はCreateの実際のBLASTING処理を呼んでいるが、設置した溶岩ファンにアイテムを通す試験ではない。鉱石採掘・粉砕、粉末以降のプレス・焼結・燃料棒製造は含まない。
- アンモニア、水素、酸素、塩素、HF、フッ素、純水は外部から有限量を供給した。空気分離、水電解、ハーバー・ボッシュなどの原料製造までを含む同時運転ではない。
- 生存プレイでの燃料補給・電力供給・SU収支、配管閉塞時の事故、再ロード、長時間の汚泥蓄積、実クライアントでの見た目・操作は今回未確認。全GameTestは実行していない。
- 外観・操作・レシピ仕様は変更していないため、Ponderや翻訳の変更はない。次に搬送網を含めて試験する場合は、今回の材料収支を基準にし、上流製造・エネルギー・物理配管を追加した範囲を区別して報告する。
