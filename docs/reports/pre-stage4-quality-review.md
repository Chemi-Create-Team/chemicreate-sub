## 対象と変更

第3段階に加え、追加指示に従い第1・第2段階も点検対象とした。AGENTS.md・DESIGN.mdと既存の気液・温度・区間圧力・安全弁・蒸気設備のコードを基準にした。第4段階の設備は追加していない。

Ponderは既存98シーンを保持し、次の10シーンを追加した。日英それぞれ70の説明段階を追加。基本の組立・拡張・連携の既存シーンから、詳細操作・診断へ進める。1シーンに全機能を詰め込まず、各シーンは5〜7段階に分けた。

| 段階 | 新しいシーン | 説明内容 |
| --- | --- | --- |
| 1 | phase_energy | 水・蒸気の質量換算、密閉／開放容器、上下の取り出し、潜熱、圧力依存の沸点、混合 |
| 1 | thermal_environment | バイオーム・時間・天候、通常配管と断熱区間、未ロード期間、温度耐性と損傷 |
| 2 | pressure_operation | 圧力室、高圧ポンプの動力、絶対圧設定、能力不足、区間別の計測 |
| 2 | pressure_regulation | 減圧弁と背圧弁の違い、接続方向、停止条件、減圧時のフラッシュ蒸発 |
| 2 | pressure_recovery | 真空・圧壊、安全弁の回収出口と大気放出、満杯・高圧・閉塞への対処 |
| 3 | steam_ports | 装置正面を基準にしたポートの違い、別系統の冷却水、ポンプ動力、起動順 |
| 3 | steam_heat_budget | 潜熱と熱源、圧力・温度設定、熱供給不足、流量と能力の調節 |

| 3 | steam_monitoring | ゴーグル概要、表示リンク1項目制、単位、数値／割合／バーと能力不足の判読 |

既存の実寸構造を再利用し、モデル・テクスチャ・完成済み設備の形状は変更していない。蒸気設備の異常説明には安全弁と煙道の一時閉塞・復旧を、計測説明には標準Display Link・Display Board・Nixie Tubeを配置した。追加の説明シーンが意図せず凝縮状態や燃焼演出を呼び出さないよう、Ponder用の在庫・演出の適用対象を明示した。

第1段階の自然放熱シーンを再利用する際は、複数ブロックタンクのコントローラー設定も継承するようにした。

## 発見した仕様説明の不整合

旧圧力Ponderに「Createと本MODのタンクは密閉容器」「放出蒸気は回収できない」という説明が残っていた。開放型タンクを除外し、安全弁前方からの回収と、回収不能時の上方大気放出に修正した。翻訳だけでなく旧ジェネレーターも修正し、再生成で古い説明に戻らないようにした。

圧力の設定値は供給圧力を生成しない、背圧弁は上流を維持し減圧弁は下流を制限する、安全弁は大気圧以下から無条件に大気放出しない、断熱は温度・圧力の定格を無制限にしないことを、現行コードと照合した。今回、物理計算や設備性能の仕様変更は行っていない。

## 未検証・次段階への注意

- 全108シーンを人が最初から最後まで操作して評価したわけではない。機械的な全シーン検証と代表5画面の実描画を区別する。追加説明は現行のポート・計算方式を基準にしているが、理解しやすさはプレイテストで引き続き確認する。
- チャンク復元試験の間欠失敗が残る。第4段階で設備を増やす前に、失敗時の所有者・部品ロード・形成状態を追跡する。成功した再実行だけを根拠に、既存ワールドの復元が常に正常と断定しない。
- 複数人の同時操作、通常サーバーの別プロセス再起動、大規模MODパック負荷、全配管・全圧力機器組合せの新たな長期プレイテストは未実施。
- 従来Createボイラー→旧タービンの専用互換経路は、引き続き独自の水・蒸気換算モデル。新しい質量・エネルギー基準と統合済みとして説明しない。次のタービン改修時に境界の設計が必要。
- Ponderの確認用在庫・状態演出は学習用であり、実ワールドの無料加熱・無料生成処理ではない。新しい機械や熱力学機能を今回追加したわけではない。
