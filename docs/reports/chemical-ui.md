# 化学設備のゴーグル表示とワールド操作

対象は Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10。実装コミットは `a4a03267e9ec7a2f527dc349523d12d8594d3cf1`。

## 流体情報

登録済みのMOD流体143種とバニラの水・Create Diesel Generatorsの燃料3種を、共通のJSON定義にまとめた。流れる流体は元の流体と同じ定義を使う。分子式に下付き数字を使い、石油留分や工程液は代表組成で表示する。組成がスタックに保持される混合液は記録済み成分を表示し、組成が未定義の流体は組成可変と表示する。腐食・可燃性・有毒性は既存のゲーム内判定も参照し、粘度、冷媒、酸化剤の情報を合わせる。Shiftで条件を満たす読取欄に性質を表示する。

## ゴーグルとホース

通常のCreateゴーグル表示を使い、流体名に水色の分子式を添える。貯蔵量と容量は読み取れた範囲で同じ行に表示する。パイプは実際に見えている流体を表示する。設備の表示は4行以内で、停止理由を最上段、既存の理論・実測生産量を残る行に表示する。

温度は既存の5等級を使う。反応塔の加熱範囲は選択レシピのバーナー要件に対応する。ガス化炉は現在温度と反応開始温度の間を4区間に分け、始動条件に達すると最終段階になる。圧力は既存の3等級を5マスの段階1・3・5へ対応させる。追加の圧力等級や反応条件の変更はない。◆が現在の位置、緑色の■が表に対応する適正範囲を表す。高圧ポンプの圧力表示は内部の流体の等級を使う。

ホースは両端で実行された転送量を20 tickごとに集計し、mB/tと流体名をクライアントに同期する。接続口とカテナリー曲線に照準を合わせて読める。転送量が変わった時点に同期を絞る。分子式・性質・診断文は日本語・英語・簡体字中国語に対応する。

## ポート表示と直接操作

レンチかゴムホースをどちらかの手に持つと、12ブロック以内の吸込口は青、吐出口・ホース口は橙、回転動力入力は黄、ハッチとドレンは緑に表示する。照準横には対象部位で使える操作を出す。触媒ハッチでは原料を持って右クリックで取り付け、素手でShift＋右クリックすると回収できる。反応塔、ふた付き槽、電極ヘッドの既存の取り付け描画と個別条件を使い、ガス化炉、湿式処理、キュービックプレス、電解炉、転炉、燃料サイクル機器、燃料プール、出荷機器は既存のアイテムCapabilityを直接操作に再利用し、投入ハッチにスロットのアイテムを表示する。

ドレンと、残留液を搬出できる開放された吐出口は、レンチか素手Shift＋右クリックでパージする。背後のタンクから搬出できる液体を1種類ずつ排出し、液滴と効果音を出す。隣接ブロックと既存配管を確認して、開放された液体の搬出口で実行する。既存の輸送Capabilityを通し、排出やアイテムの増減はサーバーが確定する。

## 確認結果

- 最終版の `build runGameTestServer` が成功し、必須GameTest 686件が全件合格した。MODの登録済み全流体と外部燃料の定義、分子式と腐食性、5マス表示、専用サーバーでの覆われたドレンと開放ドレン、ホース両端の実測流量を確認した。
- GeForce RTX 4060のクライアントで、硫酸12,500/64,000 mBの分子式、反応塔の加熱不足と緑の適正範囲、重ならないハッチヒント、レンチ所持時の青・橙・黄の枠、ホース本体照準での流体名と実測mB/tを確認した。
- 翻訳キーの全言語一致、Ponder 170本の実行時見出しと解説、構造参照を検証した。
- 外部MODの専用ハッチや、第三者の流体ハンドラーを含む全追加構成の手動確認は今回の範囲外。
