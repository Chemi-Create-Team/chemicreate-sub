# 鉢（Createのベイスン）の電解槽（ChatGPT引き継ぎ用）

> 履歴資料：この鉢式はフィルタープレス型へ置き換え済み。現在の組立・配管は[電解セル](../filter-press-electrolysis.md)を参照。

## 実装内容

Createのベイスンを一直線に2〜5個並べると、1つの長い鉢として扱うマルチブロックにした。仕切りの壁は消えて、長辺の壁は並んだ全体でつながる。この鉢に、アスベスト袋入り電解板を差し込むと、水を電気分解する電解槽になる。電解スタックのブロックは、これに置き換えて削除した。

- 成立：同じ向きに一直線に並んだ2〜5個のベイスン。横に別のベイスンが隣接していると成立しない（6個以上、曲がった並びも不成立）。コントローラは並びの低い座標側の端。
- 流体：どのベイスンからも水を入れられる（並び全体で均等に分配される。既存の大型鉢の仕組み）。
- 電解板：1個のベイスンに最大8枚。右クリックで1枚入れ、しゃがんで素手の右クリックで1枚戻る。1枚が1つの電解セル。
- 運転：1枚が1tickに水3 mBとFE 32で水素2 mBと酸素1 mBを作る。水・電力・出力バッファ（鉢の数×1,000 mB）の範囲で動き、足りなければ停止して何も失わない。レッドストーン信号で停止する。電力のバッファは64,000 FE、1回の受入は最大512 FE。
- 出力：低い座標側の端のベイスンから水素、高い座標側の端から酸素が、標準のNeoForge流体ハンドラーで排出のみできる。間のベイスンは何も出さない。電解板が1枚も無い並びは、従来のベイスンの出力のまま。
- 電力：並びのどのベイスンの面からもFEを受け取る（Create標準のベイスンには電力入力が無い）。
- ゴーグル：状態、電解板の枚数/最大。運転中は電気の火花（青白いパーティクル）が出る。
- 見た目：仕切りの壁・縁・隙間を消し、並び全体の縁を描き直す。電解板は並びの中に細い板として立って見える。

## 主要ファイル

- `basin/BasinElectrolysis.java`（電解の処理、電解板の出し入れ、ガスの排出、電力ポート）、`basin/BasinClusterManager.java`（並びの検出）、`basin/BasinCluster.java`
- `mixin/BasinBlockEntityMixin.java`（ベイスンに電解の状態を持たせ、保存・同期、tickの先頭で電解を実行）、`mixin/BasinBlockMixin.java`（電解板の右クリック）、`mixin/TankSegmentAccessor.java`
- `client/LargeBasinFilteredModel.java`、`client/LargeBasinOverlayRenderer.java`（並びの壁の描き直しと電解板の描画。ベイスンの描画をこの描画に置き換えて登録）
- `registry/CEElectrolysis.java`（電解板アイテムと電力の登録）、`tools/generate_electrolysis_plate.py`（アイテム・板のテクスチャ、モデル、レシピ）
- レシピ：灰色の羊毛6・銅板2・鉄板1 → アスベスト袋入り電解板4

## テスト結果

- GameTest：全体309件が成功。並びが2〜5個で成立し、6個以上と曲がった並びは不成立であること、水900 mB・FE 9,600で水素600 mB・酸素300 mB、シミュレーションで在庫が変わらないこと、ポートのフィルター、端のベイスンを壊すと排出が止まって在庫が残ること、水素から先の生産ラインが通ること。
- 実クライアント：4個の並びで仕切りが消え、長辺の壁と縁がつながり、電解板が見えることを確認した。

## 未検証・制約

- 並んだベイスンはすべて並びとして一体になる。Createのミキサーなどで隣り合ったベイスンを別々に使っていた設備は、水の分配と描画が変わる。
- 電解板を入れても、電解板が無い並びと同様に、ベイスンの上でCreateの加工は動く。両立時の挙動は未検証。
- ベイスンの描画を置き換えているため、他のアドオンのベイスン描画とは干渉しうる。
- 手の持ち物の電解板のアイテム画像は、描画のみで、ゲーム内の見た目を確認していない。
- 電解槽のPonderは追加していない。旧電解スタック・旧電解槽は削除済み。
