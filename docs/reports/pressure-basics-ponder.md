## 追加・変更したPonder

### 新規「圧力のきほん」（`pressure_basics`、8手順）

開く場所は、耐圧鋼管・ステンレス鋼管・圧力計・ステンレス鋼タンク・保冷タンク・気体レシーバーの6つ。Createの銅管とタンクは他のMODのものなので、開く場所には入れていない。

| 手順 | 内容 |
| --- | --- |
| 1 | 圧力は「中の流体が壁を押す強さ」。単位はbarで、まわりの空気が1 bar |
| 2 | 配管・タンクには耐えられる圧力がある（銅管2 bar、耐圧鋼管16 bar、Createのタンク16 bar）。圧力計とゴーグルで見られる |
| 3 | 圧力を上げるもの、その1：押し込む（ポンプ・コンプレッサー。自転車の空気入れのたとえ） |
| 4 | その2：温度。温まった液体は蒸気になろうとして壁を押す（水は100 °Cで1 bar、150 °Cで約5 bar、180 °Cで約10 bar） |
| 5 | 沸点は圧力で変わる（圧力鍋のたとえ）。加熱器の出口圧力を上げると、100 °Cより熱い水を液体のまま運べる |
| 6 | 液化ガスは常温でも強く押す（20 °Cで約7〜8 bar）。0 °Cより冷やしたものは保冷タンク・保冷配管へ。そうしないと沸騰して圧力が上がる |
| 7 | 耐えられる圧力を超えると、警告、傷み、破損の順に進む。爆発することもある（サーバー設定）。修理のしかた |
| 8 | 安全に使う4つの方法（耐える配管・タンクを選ぶ、減圧弁、安全弁、冷ましてから送る） |

数値は実装の計算と合わせた。

- 150 °Cの水：4.7 bar。
- 180 °Cの水：9.6 bar。
- 20 °Cの液体アンモニア：8.3 bar。
- 20 °Cの液体塩素：6.7 bar。

### 「流体に合うタンクを選ぶ」に手順6を追加

タンクの圧力は中身で決まること（気体は詰めた量と温度、液体は温度）、耐えられる圧力を超えると傷み、2倍で破裂すること、安全弁で逃がせることを足した。手順は5から6になった。
