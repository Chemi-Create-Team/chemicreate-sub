# 統合流体の分子式・構造式表示

実装コミット `e439a5b`

## 変更内容

- このMODに登録された流体の式と構造データを照合しました。バケツとJEIの流体は、統合先の物質IDから同じ構造を取得します。蒸気は水、液体窒素は気体の窒素と同じ式・構造を使い、温度と圧力はそれぞれの流体スタックから表示します。
- 溶融ポリエチレンと溶融ポリプロピレンに、高分子の組成式、繰り返し構造、回転する繰り返し単位モデルを追加しました。図の両端は隣接する単位との結合を示します。[IUPACの繰り返し単位の定義](https://goldbook.iupac.org/terms/view/C01286)
- 溶質が1種類に定まる水溶液は溶質の式・構造を表示します。合成ガス、留分、混合物は組成を表示します。容器のプレビュー判定は、成分一覧へ分解する前の流体を使います。
- 混合流体のPonderに繰り返し単位の説明を追加しました。構造データの生成時に、対象流体の追加漏れと重複、式と繰り返し単位の整合を検出します。

## 主要ファイル

- `chemistry/FluidChemicalRegistry.java` と `chemistry/FluidItemChemistry.java` は式と容器内の流体を取得します。
- `client/MoleculeStructures.java` と `client/FluidItemTooltips.java` はバケツとJEIで使う構造を選びます。
- `tools/data/molecule_structures.json` と `tools/generate_molecule_structures.py` は構造の定義と生成を担当します。
