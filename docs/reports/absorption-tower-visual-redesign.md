# 吸収塔 外観刷新 完了レポート

実装コミット：`379fec75d1fb9703989ab572e4b8289895309bb1`

## 実装内容

- 反応塔モデルの流用を廃止し、吸収塔専用の3×3連結モデルへ置き換えた。形成時に外殻各ブロックへ、底部・胴部・保守デッキ・上部鏡板と3×3内の位置を記録する。未形成時は単体外殻モデルへ戻る。
- 添付資料を基に、段付き八角円筒胴、段間フランジ、上部鏡板、給水ノズル、上部常設デッキ、保守デッキ、手すり、梯子、点検口、支持脚、閉じた外部循環配管を設けた。外部配管には開放端を作らず、実際の上下流体ポートと誤認しにくい形にした。
- ステンレス外板、暗色フランジ、銅系配管、グレーチング、点検窓、警告板の専用16×16テクスチャ6枚を追加した。アイテムモデルも専用品へ変更し、吸収塔と反応塔の視覚同一性例外を削除した。
- 外部デッキ、手すり、梯子、点検口、循環配管、上部ノズルに、モデルの張り出しと対応する選択・衝突形状を追加した。
- 所有ブロック破壊時に、残った外殻の連結外観と所有キャッシュを即時解除するようにした。再形成前の外殻が完成塔の見た目で残らない。
- 組立ガイドと硝酸工程Ponderへ形成済み外観の位置情報を追加した。既存の3×3構造、棚段数、レシピ、4流体ポート、反応塔は変更していない。
- 完成塔と棚段カットモデルを6段構成で生成するクライアントチェックへ更新した。

- `gametest/NitricAcidGameTests.java`：形成時の部位・デッキ・張り出し形状と、所有ブロック破壊時の解除を検証。
