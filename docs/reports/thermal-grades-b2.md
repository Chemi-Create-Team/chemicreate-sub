# 温度・圧力等級化 B2：槽と反応条件

2026-11-14。仕様書4.5の段階別記録。

## 変更

槽自身の温度・圧力・沸騰・自然凍結を扱っていたVesselClimateを削除した。反応は下面のCreate熱源（加熱・超加熱）と入力流体の種類で判定する。電熱ヒーターも同じ段階を出し、反応進捗への熱供給は実際に支払った電力で制限する。出力ダイヤル、CEE配線、出力設定の共有は維持した。

ナフサ分解・重合・エチレン酸化・水素化脱硫・水素化分解を指定の熱源条件へ変更。水素化反応は高圧水素が必要で、通常水素を増量しても代用できない。予熱した原油を追加し、原油の加熱混合レシピから分留塔へ送る。液体アンモニアの加熱蒸発、水と液体窒素による製氷も固定レシピとした。既に撤去されていた6種類の加熱名流体は復活させず、冷却前後の流体を温度で別名扱いする処理も廃止した。

HaberBoschBed・BedGas・GasMixture・AmmoniaSeparatorのモル平衡と、未使用の旧HaberBoschProcessおよび専用単体試験を削除。鉄触媒は100 tickごとに加圧原料10,000 mBから高温混合ガス9,000 mBを作り、触媒耐久を1消費する。気液分離器は60 tickごとに冷混合ガス9,000 mBから液体アンモニア1 mBと加圧循環原料8,000 mBを作る。液体アンモニア1 mBは加熱混合でアンモニアガス934 mBになる。比率はゲーム用で、実機の平衡収率ではない。

原料・製品の有限バッファ、触媒再生、汚れ・清掃、標準配管・ファンネルを維持した。満杯停止・途中保存・再形成で材料を二重処理しない。試験で発見した「分離器の上方増設で在庫を排出する」「表示照会で空の触媒状態が初めて保存される」問題を修正した。実際の破壊時の放出は残る。

触媒槽・分離器のPonder、製造Ponderの原料と熱源表示、JEI、反応プラント文書を更新。槽の温度設定を観測する旧ヒーター表示は削除した。

同じワールドの実設備を順番につなぎ、各段の搬入・搬出を実ハンドラーで確定した。電解セルは実際の電力を払い、圧縮機・ラジエーターは駆動を与えた。プレイヤーによる実プレイではなくGameTestである。

| 空気の圧縮・分留 | 空気14,000 mB→窒素10,920 mB・アルゴン140 mB・酸素相当2,940 mB（液化分と塔の残量を合算） |
