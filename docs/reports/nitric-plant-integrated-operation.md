# 硝酸プラント一貫運転試験

- 実装コミット：`dc754fed`
- 対象：Minecraft 1.21.1 / NeoForge 21.1.219 / Create 6.0.10 / Java 21
- 結果：水と大気から硝酸までの一貫GameTestに成功。関連63件のGameTestとGradle `build`も成功。

## 試験した系統

既存マルチブロックを次の順で接続し、前段から取り出した有限在庫を後段へ渡した。

1. 5槽・40極板の電解槽で水を水素と酸素へ分解。
2. エアフィルター、大型圧縮機、フィンファン式ラジエーター、3x3x14分留塔で大気を分留。
3. 4段撹拌反応器で水素3：窒素1の合成ガスを製造。
4. 3触媒層のハーバー・ボッシュ反応塔をバーナーで起動し、冷却ジャケットを使用して運転。
5. 1x1x2アンモニア分離器を冷却し、液体アンモニアと未反応ガスを分離。
6. 3段反応器、ラジエーター、3段気液分離器でアンモニア酸化、NO分離、NO酸化を実施。
7. 3段吸収塔でNO2と工程内生成水から硝酸を製造し、NOを回収。

装置間は各装置が公開する標準Fluid Capabilityを使用した。空気圧縮系では、圧縮機を40 barまで実際に蓄圧してから冷却器へ送り、全吐出で上流圧が下流圧を上回ることも検査した。

## 検出・修正した不具合

`FluidPhase`の合成ガス、圧縮合成ガス、加熱合成ガスの平均モル質量が8.515 g/molへ丸められていた。一方、反応床は `0.75 x 2.016 + 0.25 x 28.014 = 8.5155 g/mol` を使用していたため、2,000,000 mBの合成ガスが反応塔を通ると約39.37 mg、0.0056%の見かけの質量が生成されていた。

3状態の物性を8.5155 g/molへ統一した。修正後の反応塔は投入0.698740740 kg、排出0.698739086 kgで、差は整数mBへの排出丸めによる約1.65 mgとなった。アンモニア分離器も、最終実行の排出製品0.418947509 kgと内部残留0.279791578 kgの合計が投入0.698739086 kgに一致した。

初回試験条件では圧縮機設定8 barに対し、冷却器の最終在庫が26.6 bar相当になっていた。これは装置実装の不具合ではなく試験操作の圧力条件不足だったため、40 bar蓄圧・逐次冷却へ変更した。最小の吐出圧余裕は13.65 barだった。

## 自動検証

- 新規 `NitricPlantIntegrationGameTests`：一貫運転、有限在庫、圧力差、温度条件、反応塔定格、質量台帳、各生成量を検証して成功。
- 関連GameTest：`CircuitGameTests`、`ModularPortsGameTests`、`DistillationGameTests`、`GasCompressionGameTests`、`ReactorGameTests`、`HaberBoschGameTests`、`NitricAcidGameTests`、新規一貫試験の合計63件が成功。
- Gradle `build`：成功。FluidPhase 25 checks、HaberBoschProcess 1019 checks、ReactorPhysics 1670 checks、Reactor control testsを含む。

外部依存由来の既知警告として、Create Diesel Generatorsの欠落loot登録、Sableクラスの任意Mixin、Mojang/ModrinthへのDNS失敗が出たが、GameTest結果には影響しなかった。

## 制約

- 処理メソッドをテストから直接進めるGameTestであり、記載tick数はシミュレーション上の処理時間。TPS/MSPTの性能ベンチマークではない。
- 各入出力面と標準Capabilityは実ブロックで検査したが、全工程を一本のCreate配管として同時に長時間放置する試験ではない。実Createポンプ・配管の個別接続試験は既存回帰に含まれる。
- 大量の上流原料から吸収塔1 batchを完結させる機能試験であり、連続プラント全体の定常流量最適化ではない。
- サーバー側の物資・熱・圧力試験。クライアント描画やPonderの変更はない。
