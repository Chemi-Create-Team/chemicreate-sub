## 実装内容と数値

### 1. 苛性ソーダの排ガススクラバー

- 後続指示に合わせ、任意の流体ハンドラーを使う初期仕様を、専用1ブロック装置「安全弁用スクラバー」へ置き換えた。安全弁の真上へ直接置いた場合だけ接続し、普通の流体タンクはスクラバーとして扱わない。
- 容量は8,000 mBとし、正面の印がある1面だけからCreateの流体配管で苛性ソーダ液を補給できる。破壊・再設置時は内部の苛性ソーダ液をアイテムへ保存する。
- 塩素、塩化水素、硫化水素、二酸化硫黄、三酸化硫黄、二酸化窒素、フッ化水素、フッ素を対象とし、アンモニアは対象外とした。
- ガス1 mBにつき苛性ソーダ液1 mBを消費し、生成物は廃液として破棄する。不足分と対象外のガスはスクラバー上面から従来どおり雲として放出する。
- 回収配管を優先する既存の順序は維持した。上部キャップの動作、ゴーグルの接続・残量・洗浄状態、Display Linkの状態と流体量を追加した。
- `FluidHazards`の既存区分を確認した。対象流体の腐食区分は変わらないため、同ファイルの変更は不要だった。

### 2. 使用済み燃料の再処理

- 加熱した撹拌反応槽へ次のPUREX再処理レシピを追加した。
  - 使用済み燃料棒1＋硝酸1,000 mB → 硝酸ウラニル溶液3,500 mB＋ジルコニウムインゴット1
  - 使用済み制御棒1＋硝酸500 mB → 原子炉用黒鉛1
- 硝酸ウラニル溶液3,500 mBは脱硝後に三酸化ウラン14個となり、濃縮比1/8と既存ペレット工程を通すと、新燃料棒に必要な7ペレットのおよそ半分になる。被覆管も新燃料棒に使うジルカロイ被覆管2本より少ないジルコニウム1個だけを戻すため、再処理だけでは燃料も被覆材も増えない。
- 新しいPonder「使用済み燃料を再処理する」を追加し、使用済み燃料棒と使用済み制御棒の両方から開けるようにした。原子炉担当範囲のJavaは変更していない。

### 3. アルゴンを使うステンレス鋼精錬

- 超加熱したCreateのミキサーで、鉄7・クロム2・ニッケル1・アルゴン100 mBからステンレス鋼インゴット12個を作るAOD経路を追加した。
- アルゴンを使わない既存経路の10個に対して2個増やし、空気分離後のアルゴンを使う意味を持たせた。既存経路は残した。

### 4. 石綿隔膜

- 鉢の電解槽のどれかの入力枠に石綿があると、塩水電解で苛性ソーダ液だけを1.25倍にする。水素、塩素、消費電力は変えない。
- 端数を4分の1 mB単位の保存値として持ち越し、整数mBへ正確にまとめる。隔膜を通した塩水10,000 mBごとに石綿1個を消費し、処理量と端数は保存・再読込する。
- 水とフッ化水素の電解には適用しない。JEIへ、石綿1＋塩水10,000 mBから水素5,000 mB、塩素5,000 mB、苛性ソーダ液12,500 mBを得る隔膜ありの例を追加した。
- 既存Ponder「塩・塩素・苛性ソーダ」に隔膜の手順を追加した。

### 5. 合成ルチル法

- 加熱した撹拌反応槽で、チタン鉄鉱2＋塩酸500 mBから二酸化チタン1＋鉄塊3を作る経路を追加した。
- 塩酸法は硫酸法より工程が1段短いため、同じチタン鉄鉱2から得る二酸化チタンを1個に抑えた。比較を明確にするため、既存の硫酸チタニル溶液の焼成結果は二酸化チタン1個から2個へ変更した。これにより、硫酸法は樹脂配管と長い工程の代わりに収率2、塩酸法は短い代わりに収率1となる。

### 6. ジルコニア耐火物

- 工業用加熱器の炉室4個の中央材料を鉄インゴットからジルコニア1へ置き換えた。
- 溶融塩電解炉の外殻8個の中央材料を石炭ブロックからジルコニア1へ置き換えた。
- ジルコニアは、ジルコンと硫酸から硫酸ジルコニウム溶液を作り、ブレイズバーナーで加熱した撹拌反応槽で製造できる。この経路には工業用加熱器も溶融塩電解炉も不要なため、初回製作の循環は発生しない。

### 7. 蛍石フラックス

- 鉄鉱石版と粗鉄版の既存パドル鉄レシピへ、蛍石1を追加すると出力が4個から5個になる追加経路を用意した。
- 従来の蛍石なしレシピは残し、蛍石は必須化せず歩留まり向上の選択肢とした。

### 8. 工業用ガラス・工業用樹脂・液化酸素

- 圧力計、温度計、流量計へ工業用ガラスを各1個追加した。既存材料は維持した。
- 流量調節器へ工業用樹脂1個を追加した。燃料電池は3×3の9枠を使い切っていたため、ニッケル3個のうち1個を電解質膜に相当する工業用樹脂1個へ置き換えた。
- 計器と流量調節器は設備の初回進行に必須ではなく、燃料電池以外のCEE電源でガラス・樹脂工程を開始できるため、進行循環は発生しない。
- 液化酸素を`PhaseChange`の気液組へ登録した。密度比から液化酸素1 mBを酸素699 mBとして質量を保つ。保冷タンクでは外気熱を受けず液体のまま残り、普通のタンクでは外気熱で沸騰し、流体熱交換器でも酸素へ気化する。
