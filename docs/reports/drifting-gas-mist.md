# ガス雲のもやの描画

実装コミットは `e03c1dbc92f227cc15342200e08ba28f2a3efc2e`。

床に溜まるガスを低く流れる半透明のもやにした。水蒸気は同じ形を上下反転して天井側に寄せ、色と表示の有無は流体の既存設定を使う。見た目の参考は [Particle Rain の雨上がりの霧](https://modrinth.com/mod/particle-rain/gallery)。

## 実装

- `client/GasCloudRenderer.java` は、雲が占める1マスにつき傾斜した面を2枚重ねる。隣の列に面を伸ばす場合は斜めのマスも含めて `CloudVolume` を確認する。位置由来のハッシュで向きと位相を決め、クライアントの描画時刻で漂いと高さを補間する。
- 不透明度は残量と距離に連動する。範囲が変わった後の最初の描画時に面の配置を更新し、薄まる際の高さと濃さは既存の値から算出する。半透明の描画面は奥行きを読み取り、奥行きバッファへの書き込みを無効にした。
- `tools/generate_process_gas_recovery.py` の `mist_texture()` が色付け用の `textures/entity/gas_mist.png` を生成する。横長の形を低周波の濃淡と透明な縁で作り、線形補間で描画する。
- ガスの範囲、カメラが雲に入ったときの視界、効果、保存・通信は既存の処理を使う。

## 検証

- Java 21、Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10でGradleビルドが成功した。`ToxicGasGameTests`、`GasSafetyLoadGameTests`、`ProcessGasRecoveryGameTests` は計21件が合格した。
- RTX 4060の日本語クライアントで、屋外の配管そばに同期した塩素雲の低い位置、透け方、揺れ、壁や床の手前での表示を確認した。
- ガス回収ダクトから既存のPonder「水蒸気のもやの検知と回収」を開き、ガラスの天井側で白いもやが描画されることを確認した。
- テクスチャを再生成してバイトの一致と外周の透過を確認した。配布用JARの圧縮を調整し、Gradle出力と全エントリーの内容が一致することを確認した。
- シェーダーパックとの併用と、雲が多数ある場合のフレーム時間は未計測。描画の変更は色付きの雲に適用される。
