## 変更内容

指定された工程を通常燃料・小型炉用燃料の両方へ接続した。新しい装置やGUIは追加していない。

**鉱石粉砕 → ウラン原石 → 溶岩ファンで焙焼 → 棚段＋水素＋加熱で還元 → 撹拌翼＋フッ化水素＋加熱でグリーンソルト化 → 棚段＋フッ素＋超加熱でガス化 → 遠心分離 → 濃縮気体・水・水素の同時反応 → 粉末 → プレス → 焼成 → 燃料棒**

- `uraninite`の登録IDを保ち、表示名をウラン原石へ変更。焙焼物は既存のイエローケーキを使う。
- 棚段を「反応・吸収棚段」へ改称し、アイテムと流体を使う加熱反応を可能にした。3×3・2〜4段、回転不要。硝酸吸収は維持。
- 還元とガス化は棚段専用。グリーンソルト化と濃縮後の粉末化は撹拌翼専用。ガス化だけはCreateの`superheated`が必要。
- 濃縮後の2つの中間処理を、濃縮六フッ化ウラン・液体水・水素の3流体反応へ統合。バーナーを要求せず、濃縮二酸化ウラン粉末と回収フッ化水素を作る。
- メカニカルプレスの既存レシピを維持。ペレット焼成は通常のかまど、燃焼中のブレイズバーナーを通したファン、加熱した棚段入り槽で可能。焼成段階の追加水素は不要。
- 鉱石の旧湿式処理、硫酸ウラニル溶液、通常・小型炉用フッ化ウラニル中間アイテムと関連アセット・翻訳を削除。再処理用の硝酸ウラニル・三酸化ウランは維持し、三酸化ウランも棚段の還元へ戻せる。
- 日英中のPonderを2本追加。小型RBMKのPonderも更新。JEIは加熱棚段反応と撹拌反応を分けて表示する。

詳細なレシピ・配置・搬送は[ウラン燃料製造](../uranium-fuel-line.md)、再実行は[品質確認手順](../quality/uranium-route/README.md)を参照。

| `tools/generate_uranium_route_ponder.py` | 新しい2本の構造・教材・日英中の文章の生成元 |
| `gametest/UraniumFuelGameTests.java` | 新規7試験。投入順、保存、熱条件、閉塞、圧力、製造の接続を確認 |

3流体を既存の2つの原料バッファと大きな貯蔵空間だけで扱う初期試験では、水が貯蔵空間に入ったときに一部蒸発し、ちょうど1バッチ分の液体水が不足した。この投入順依存を解消するため、撹拌用の3番目の原料バッファを追加した。

既存の`Tank0`・`Tank1`原料と`Tank2`〜`Tank6`生成物の保存位置は維持。新しい原料だけを`Tank7`へ追加し、生成物として排出されないようにした。既存ディスプレイの貯蔵相・触媒出力の位置も維持し、新しい原料表示を最後に追加。気体配管のバンク識別、温度計算、圧力計算、安全弁、ハッチからの放出、破壊時の回収にも新しい在庫を含める。

反応バッチは全入力と出力先の空きをコピー上で確認してから一度だけ確定する。シミュレーションでは消費・生成しない。通常の槽は構造確認後に再開する。廃止した中間物の自動変換は追加していないので、該当する既存在庫は更新前に処理・回収する。

## 試験結果

最終実行は`build runGameTestServer`で**ビルド成功、関連GameTest 80/80合格**。GameTest実行部分の経過は9.684秒。内訳は品質確認用の[verification.json](../quality/uranium-route/verification.json)に保存。

| 確認 | 結果 |
| --- | --- |
| 原石からの順次製造 | 原石8個 → 焙焼物8個 → 二酸化ウラン8個 → グリーンソルト8個 → 六フッ化ウラン2,000 mB → 濃縮気体250 mB → 濃縮粉末1個 → 未焼結ペレット2個 → 完成ペレット2個 |
| 3流体の投入順 | 通常・小型炉用の2系列それぞれ6通り、計12通りで成功 |
| 1バッチの粉末化 | 濃縮気体250 mB＋液体水250 mB＋水素250 mBを消費。粉末1個と回収フッ化水素750 mB |
| 材料不足・出力閉塞 | 不足中・満杯中に入力を消費しない。空きができると1バッチ分だけ再開 |
| 加熱と内部部品 | 無加熱の還元と通常加熱のガス化を停止。加熱・超加熱と正しい部品で再開。撹拌翼では棚段専用反応を実行できない |
| 保存・再読込 | 還元中、両系列の粉末化中、3番目の原料保存後に在庫と進捗を保持。余分な生成なし |
| 3番目の原料の圧力・安全弁 | 気体ポートが在庫を公開し、圧力へ反映。排出のシミュレーションは無変更、実排出は返した量だけ在庫と圧力が低下 |
| ネットワーク同期 | 部品指定、3流体、加熱条件の往復シリアライズに成功 |
| 既存設備 | 槽の搬送・窓・沸騰・冷却、硝酸吸収、1×1遠心分離、気体配管・保管・負荷試験に合格 |
| ビルド内の数値試験 | FluidPhase 25、HaberBoschProcess 1,019、ReactorPhysics 1,670チェックと制御試験に合格 |

関連GameTestは新規7件、既存73件。最初の回帰実行で、旧「撹拌槽でウラン還元」の条件と旧バッファ数を前提にした3つの試験が失敗したため、新仕様の設備と原料へ更新し、最終の80件実行ですべて合格した。

順次製造試験は実際の槽・遠心分離機のハンドラーと`tickProcess`を使い、工程間は試験コードで搬送する。ファンはCreate本体の加工API、プレスは標準のPressingRecipeで確認した。全設備をパイプ・ベルトで一体接続した長時間連続試験を行ったという意味ではない。

## 未確認事項と次回の注意

- 全工程を実搬送で連結したサバイバル工場の長時間運転、プレイヤーが操作する実かまど・プレスの一連の搬送は未実施。今回の工程試験とCreate標準レシピ確認とは区別する。
- 全既定GameTestの一括実行はしていない。範囲外の既知不具合を便乗修正していない。
- 原子炉・核融合炉の新たな運転試験は行っていない。燃料棒の性質、濃縮分配、燃耗、炉心反応度と765 MW校正の実装は変更していない。
- 性能改善の比較計測は行っておらず、TPS改善は主張しない。探索範囲と既存の変更時再評価方式を維持した。
- 再生成は対象のレシピ関数と新しいPonder生成器に絞る。既存の外装・燃料棒・粉末テクスチャの一括再生成は不要。
