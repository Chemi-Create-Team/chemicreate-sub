# 核融合炉・閃緑岩ケーシングのCreate配色への更新

実装コミット: `d28f749cafeaa337badc37182aff7b6ca6f0e150`

## 変更内容

ユーザーが提示した「Create Palettes」を参考に、核融合炉の構成部材と閃緑岩ケーシングを16×16で描き直した。金属・石・銅・真鍮・絶縁材をそれぞれ少数の段階色で描き、写真ノイズや滑らかなグラデーションは使用していない。

| 対象 | 描き分け |
| --- | --- |
| 強化支持材 | 暗い安山岩地、灰色の補強筋、真鍮の締結部 |
| トロイダル磁場コイル | 銅の環状巻線、暗い青緑の絶縁材、金属の保持具 |
| 中央ソレノイド | 銅巻線と横向きの鋼製保持帯 |
| 真空容器 | 灰色の圧力板、中央の継目、銅ガスケット |
| 増殖ブランケット | 抑えたオリーブ色の面と銅の冷却流路 |
| ダイバータ | 暗いタングステンタイルと保持枠 |
| 流体口7種 | 鋼のフランジ、燃料の点記号、極低温の記号、冷却水の入出力矢印と色 |
| 給電盤・電動発電機・真空ポンプ | 共通の金属枠に端子、巻線、回転部、状態表示を配置 |
| 制御卓 | 真鍮枠、暗いパネル、計器・機能記号と起動・停止表示 |
| 保守ハッチ | 圧力蓋の専用面と銅のシール。実体ハンドルはCreateの真鍮材を参照 |
| 閃緑岩ケーシング | 白い石目、灰緑色の合金枠、小さな真鍮締結部。既存の連結方式を維持 |

核融合系の不透明画像は33枚（既存32枚の更新＋保守蓋1枚追加）。閃緑岩は単体16×16と接続用128×128の2枚。核融合系は各面4～10色、閃緑岩の単体は11色。1素材ごとの基本明暗は4段階とした。

プラズマ画像は変更前とバイト単位で同じ。炉の寸法・形成条件・熱出力・レシピ・物資処理・操作・モデル形状・UVは変更していない。保守ハッチはモデルの材質参照だけを変更し、他設備が使う共有画像は変更していない。開発用展示に閃緑岩の単体と3×3接続壁を追加した。

## 生成元と確認方法

- `tools/generate_fusion_assets.py` が核融合のゲーム用画像の正本。新しい `--textures-only` でブロック画像だけを再生成し、`--check` で再生成結果との完全一致を確認できる。モデル・レシピ・翻訳等をこの作業で一括再生成していない。
- `tools/generate_diorite_casing.py` が閃緑岩と接続シートの正本。`--check` で同様に確認。
- `tools/generate_plant_systems.py` にも保守ハッチの材質指定を反映した。関数を分離実行し、配布モデルと同じ出力になることを確認。
- 組込のimagegenツールで意匠の参考案を生成し、`docs/quality/fusion-palette-reference/design-study.png` に保存した。これは配布用テクスチャではない。[使用プロンプト・参考案と実画像の区別](../quality/fusion-palette-reference/art-direction.md)を記録している。

```sh
python3 tools/generate_fusion_assets.py --textures-only
python3 tools/generate_fusion_assets.py --check
python3 tools/generate_diorite_casing.py
python3 tools/generate_diorite_casing.py --check
```

## 確認結果

- Java 21の `bash gradlew --no-daemon assemble`: 成功（7秒）。
- 両生成元の `--check`: 成功。変更したPythonの構文と `git diff --check` も成功。
- 不透明な核融合画像33枚が16×16・24色以内・アルファ255であることを確認。
- 6機能すべての制御卓で起動・停止の画像が異なることを確認。真空計の下側ランプは、計器の縁に隠れない位置で描く。
- 閃緑岩の単体と接続シートのタイル0が一致。既存のCreateの全256入力・47種類の接続マスクが矛盾なく生成され、露出する外周の枠が残ることを確認。
- NVIDIA RTX 4060で実クライアントを起動し、通常の炉、部材・全7流体口、制御卓の起動・停止サンプル、電動発電機・ポンプ、閃緑岩単体と3×3接続壁を表示。対象に欠落テクスチャがないこと、閃緑岩の内側の枠が消えることを実画面で確認し、computer-use-linux MCPで撮影した。

実画面は[核融合炉](../quality/fusion-palette-reference/reactor.jpg)、[構成部材](../quality/fusion-palette-reference/materials.jpg)、[制御卓](../quality/fusion-palette-reference/consoles.jpg)、[閃緑岩](../quality/fusion-palette-reference/diorite.jpg)。各画像は8 MiB未満で、同じ画像を `/workspace/outputs/fusion-palette-*.jpg` にも保存した。

クライアントは表示確認・撮影とワールド保存を終えた後、終了時に既知の `libEGL_nvidia.so.0` のSIGSEGVが再発し、`runClient` は終了134となった。`runClient` の正常終了としては扱わず、その後の配布用 `assemble` の成功と区別する。外部MODの任意連携素材・音に関する既存の警告は変更していない。

## 未確認事項・注意

今回は外観の更新であり、全GameTestや長時間の炉運転は再実行していない。比較用制御卓は固定したBlockStateの展示であり、運転中の実プラントではない。既存炉の組み直しは不要で、更新JARで起動するかリソースを再読み込みすると反映される。

資料文書にある他設備の古いレシピ一覧や、他設備の外装は今回の範囲外。元画像の色数・明暗構成を参考にし、他MODや提示画像の画素を配布テクスチャへ転載していない。
