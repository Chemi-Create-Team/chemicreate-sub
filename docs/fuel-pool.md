# 使用済み燃料プール

開放水槽と底面の格子ラックを鋼鉄で構成し、門型クレーンで新燃料の搬出と使用済み燃料の回収を行う。専用GUIや独自搬送網は無い。

## 組立

1. 燃料プールラックを縦横2～9枚の隙間のない長方形に並べる。最小2×2、最大9×9。
2. 外周を鋼鉄ブロックで囲み、ラック床と同じ高さから23段積む。上面は開放する。
3. 各ラック上の22ブロックを空ける。21 m燃料集合体と上部1 mの水深余裕に使う。
4. ラック下面へCreateのパイプとメカニカルポンプを接続して給排水する。
5. ラック1枚につき22,000 mB以上、90 ℃未満で燃料を搬入できる。最大容量は23,000 mB。

最小外寸は4×23×4ブロック。ラック上の空間に水源、パイプ、搬送ブロックなどを置くと構造は成立しない。水面はラックが実際に保持する冷却水量から描画し、バニラの水源ブロックは使わない。

固定長クレーンを使う場合、プール水面のY座標を原子炉上部キャップとそろえ、レールをその15マス上へ置く。通路、手すり、照明は構造判定外なのでCreateの既存部品を組み合わせられる。

## 搬送

| 面・位置 | 機能 |
| --- | --- |
| ラック下面 | 水の搬入・排出。形成済みの全ラックが同じ共有流体エンドポイントを公開 |
| ラック下面のアイテム搬送 | 上昇シュートなどで新・使用済み燃料を搬入し、使用済み燃料を搬出 |
| ラック上面 | APIから同じ4スロットを参照可能 |
| 水面上の門型クレーン | 各ラック2×2＝4本の位置へ水平移動し、新燃料を炉へ、使用済み燃料を空き位置へ1本ずつ搬送 |
| ラック側面・流体上面 | パイプ接続不可 |

入力・排出のシミュレーションと在庫照会は内容を変更しない。使用済み燃料は水位不足や解体途中でも標準アイテム搬送で回収できる。

## 冷却後の再処理

十分に冷却した使用済み燃料棒は、ラック下面のファンネル・シュートなど通常のアイテム搬送で撹拌反応槽へ送れる。原子炉や燃料プールに専用の再処理搬送は追加しない。

| 入力 | 出力 | 条件 |
| --- | --- | --- |
| 使用済み燃料棒1、硝酸1,000 mB | 硝酸ウラニル溶液3,500 mB、ジルコニウムインゴット1 | 撹拌反応槽・加熱 |
| 使用済み制御棒1、硝酸500 mB | 原子炉用黒鉛1 | 撹拌反応槽・加熱 |

硝酸ウラニル溶液は既存の三酸化ウラン以降の工程へ戻す。新燃料棒はウランペレット7個とジルカロイ被覆管2本を使うのに対し、再処理で戻るウランはその約半分、ジルコニウムは1個だけなので、再処理だけで燃料や被覆材は増えない。

ガス遠心分離機で濃縮した残りの劣化六フッ化ウランは、撹拌反応槽（加熱）で水と反応させてフッ化水素に戻せる（劣化六フッ化ウラン250 mB＋水250 mB → フッ化水素500 mB）。フッ化水素はフッ素の電解へ戻る。劣化ウランの酸化物は廃棄物として扱い、アイテムにしない（濃縮へ戻すと燃料が増えてしまうため）。

## 冷却と表示

使用済み燃料1本につきゲーム用の残留熱1,000 Wを冷却水へ加える。20 tickごとに共有水量に比例して各ラックの水を加熱し、熱容量と混合には既存の `ThermalFluidTank` と `FluidThermal` を使う。

90 ℃以上では新たな燃料搬入とクレーン作業を止める。100 ℃に達した後の余剰熱は2,260 J/mBで水を蒸発させる。無限水や蒸気アイテムは生成しないため、外部の冷却・給水設備が必要になる。

ゴーグルは状態、燃料棒数、冷却水量、温度を表示する。Display Linkは状態、水量、温度、形成、ラック枚数、新・使用済み燃料数、残留熱を公開する。

## 保存と破損

- 各ラックは4本の燃料状態、自身の水と温度、蒸発熱の端数を保存する。
- 壁欠損、内部障害物、チャンク未読込では搬入と加熱を停止し、修復後に再集約する。
- ラックを壊すとそのセルの燃料だけを一度ドロップし、そのセルの水だけを失う。他のラックの水は残る。
- 旧3×3の `Slots` 保存は四隅を新しい2×2へ引き継ぎ、廃止される5区画の燃料は読み込み時にアイテムとして返却する。旧構造は22 m深の水槽として組み直す必要がある。

探索は最大9×9セル、高さ23に制限し、形成結果を20 tick共有する。ラックのPonderで組立、下面配管、水位、固定長クレーン、外部循環を確認できる。
