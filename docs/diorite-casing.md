# 閃緑岩ケーシング

閃緑岩へ安山岩合金を1個使うと、閃緑岩ケーシングを1個作れます。置いた閃緑岩を、合金を持って右クリックしてください。同じ加工をデプロイヤーでも行えます。

隣接するケーシングのパネルはつながります。白い工場の壁、柱・梁、機械の下の台座、設備の背景として組み合わせます。通路と、機械の操作面・配管口・回転入力・搬送経路へ届く空間を残してください。

在庫や加工は既存のタンク・機械が担当します。Ponder「閃緑岩ケーシングで白い工場を組む」では、製作、連続した壁、柱と梁と台座、Createタンクとの組合せを順に示します。

次の製作レシピでは、安山岩ケーシングの枠に閃緑岩ケーシングを代用できます。材料の配置はJEIで確認できます。

- 小型コンプレッサー
- 統合圧縮機構
- パルス式溶媒抽出塔
- 核融合炉計器卓
- 原子炉制御卓区画

ケーシングの画像は、Pillowを使えるPython環境で次のように再生成・確認します。ケーシング本体と接続用シートの2点だけが対象です。

外観は白い閃緑岩の石目、灰緑色の合金枠、小さな真鍮の締結部を組み合わせています。1面の密度は16×16で、連結した面の内側には外枠が出ません。配色はユーザー指定の「Create Palettes」を参考にしています。

```sh
python3 tools/generate_diorite_casing.py
python3 tools/generate_diorite_casing.py --check
```

Ponderの再生成は `python3 tools/generate_diorite_casing_ponder.py`。専用のモデル・テクスチャや登録はこのPonder生成処理では変更しません。
