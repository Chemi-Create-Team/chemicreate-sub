# フィルタープレス型電解槽

電解セルを1列に1～8マス並べ、各セルの上に電極ヘッドを1個ずつ載せ、片方の端面に電解セルコントローラー2個を縦に積んで外向きに取り付ける。X・Zの両方向に対応する。最大構成はセル8個＋電極ヘッド8個＋制御盤2個で、制御盤を含む外寸は1×2×9マス。欠けたセルやヘッド、横に並ぶ別のセル、9マス以上の連続セル、追加の制御盤は形成しない。設計は[電極ヘッドの設計](specs/electrolysis-electrode-head.md)。

隣接する同じ向きのセルは内壁を消し、1本の長い槽になる。壁は2ピクセルの厚みを持ち、内部は中空。天面は開いており、電極ヘッドがふたを兼ねる。ヘッドはCreateのメカニカルミキサーと同じ安山岩ケーシングの意匠で、上部はミキサーの側面テクスチャの箱、上面はプレスの天板。電極板はCreateのプレスのヘッドと同じ見た目の横桁から吊る。横桁の棒はCreateのメカニカルミキサーの棒と同じ形で、上の箱を通って天板から上へ突き出す（上げたとき10 px、下げたとき4 px）。電極板を下ろすと横桁と棒も一緒に下り、天板の上の棒が沈む。その下の四隅は安山岩の柱で、柱の間の4面にガラスをはめて、気体が漏れない密閉したフードにする。セルの外側の面の上端と下端には安山岩ケーシングの縁の帯が半ピクセル張り出し、上面には幅3 pxの縁がある。どちらも電極ヘッドを載せても残り、壁の厚みを見せる。中の電極板と液面はガラス越しに見える。陰極板と陽極板は1本の槽の中に交互に並ぶ。セルの外装はCreateの安山岩ケーシング（安山岩の縁と木の板）と同じ意匠で、隣のセルとつながる面は縁を消して板が続く。制御盤は全面がCreateの安山岩合金ブロックのテクスチャで、正面に計器・ボタン・ダイヤルと黒い文字を描く。計器とボタン・ダイヤルは独立した可動部として描く。側面窓はない。

制御盤は上段に電圧計・電流計とSTART/STOPボタン、下段に稼働率の回転ダイヤルを備える。針とダイヤル、ヘッドのガラス越しに見える液面はBERで滑らかに追従する。

## 組み立てと装填

1. 電解セルを1列に並べる。1マスから運転でき、最大8マス。
2. 各セルの上に電極ヘッドを置く。向きは下のセルに合わせて決まる。
3. 片方の端面へ、同じ向きのコントローラー2個を外向きに縦に積む。
4. ヘッドが上がっている間に、アスベスト袋入り電解板またはニッケル電極板を持ってヘッドを右クリックすると1枚入る。1個のヘッドに16枚まで、最大128枚。アスベストの隔膜も同じように入れる。上面や露出した側面のCreateのファンネルも使える（入れるだけで、極板は抜き取らない）。しゃがんで素手で右クリックすると1枚取り出す。
5. 底面か奥の端面へ給液配管、長い両側面へ独立した2系統のガス回収配管をつなぐ。上の制御盤の上面に立つ2本の端子（CEEのコネクターと同じ形と色で、大きさは2/3）へCEEで配線し、上の制御盤のSTARTボタンを押す。

### 電極ヘッドの上下

STARTでヘッドが下降を始め、STOPで上昇を始める。回転動力は要らず、ヘッドがひとりで16 tickで全行程を動く。すべてのヘッドが下がりきるまで電解しない。電極板・隔膜・金属の出し入れは、ヘッドが上がりきっているときだけ。下がっているときに右クリックすると、先にSTOPで上げるよう表示する。

構築用ブロックを持った右クリックは通常の配置へ渡す。

## 入出力

すべて標準のNeoForge流体・アイテムハンドラーを使い、Createのポンプ・パイプ・ファンネルへ接続できる。内部で接する面はポートを公開しない。

| 面 | 接続先 |
| --- | --- |
| 底面 | 原料（水・重水・塩水・フッ化水素・亜硫酸、電解採取の精製溶液）の搬入と、残った原料の排出。原料の切り替え前に完全に抜く |
| 列方向の端面（制御盤の反対側） | 原料の搬入と、苛性ソーダ液・再生酸の搬出 |
| 小さいX側の側面（軸Xなら小さいZ側） | 陰極ガス：水素または重水素 |
| 反対の側面 | 陽極ガス：酸素・塩素・フッ素 |
| 天面 | 電極ヘッドで塞がり、ポートなし |
| 上がった電極ヘッドの上面・側面 | 極板2種と隔膜の搬入、電解採取した金属の搬出 |

各セルが原料・陰極ガス・陽極ガス・苛性ソーダの4槽を各4000 mB保持する。形成中はそれぞれを共有して使うため、最大各32000 mB。原料の異種混入を受け付けない。陽極・陰極の製品も既存内容物と異なる種類には混ぜないため、工程を切り替えるときは残った製品も回収する。

| 1回の電解 | 入力 | 陰極 | 陽極 | 液体製品 |
| --- | --- | --- | --- | --- |
| 水 | 3 mB | 水素2 mB | 酸素1 mB | ― |
| 重水 | 3 mB | 重水素2 mB | 酸素1 mB | ― |
| 塩水 | 2 mB | 水素1 mB | 塩素1 mB | 苛性ソーダ2 mB |
| フッ化水素 | 2 mB | 水素1 mB | フッ素1 mB | ― |
| 亜硫酸 | 2 mB | 水素1 mB | ― | 硫酸1 mB（奥の端面から） |

亜硫酸の電解はハイブリッド硫黄法（SO₂＋2H₂O → H₂SO₄＋H₂）で、陽極では気体が出ず、硫酸が液に残って奥の端面から出る。陽極で水の代わりに二酸化硫黄を酸化するので電圧が低く、1回の電解に要る電力は水の4割（20 J）。

隔膜を入れた塩水電解では苛性ソーダを4分の1増量し、塩水10000 mBごとにアスベスト1個を消費する。端数と摩耗をアイテムのデータに保存する。水・重水・フッ化水素では隔膜を消費しない。

## 電力と制御

CEEの実回路へ抵抗を登録し、実測の端子間電圧から `P = V²/R`、1 tickの電気仕事を `P/20 J` として受け取る。FE入力や固定の無条件給電は使わない。回路へ負荷を登録するのは端子ヘッドだけで、ほかのヘッドや制御盤が重複して電力を受け取ることはない。

通常極板1回50 J、ニッケル極板1回35 Jを使う。全負荷・400 Vで通常極板1枚は160 Ω・1 kW、ニッケル極板1枚は約228.57 Ω・700 W。混載時はニッケル極板を先に使い、実際に処理した枚数で仕事を差し引く。仕事は上限40 kJの有限バッファに保存し、1回分を受け取るまで生成しない。

負荷設定は1～100％の1％刻み。1％なら通常極板1枚・400 Vで10 W、100 tickに1回分の50 Jを蓄えて反応する。1枚でも25%なら400 V・250 Wで4 tickに1回処理できる。低電圧でも受け取った仕事に応じた頻度になる。例えば通常極板1枚、100%設定、200 Vなら250 W。数値は既存のゲーム内工程を継承した校正であり、実機の必要電圧や反応熱を再現する値ではない。

| 制御盤の位置 | 操作 | 計器・表示 |
| --- | --- | --- |
| 上 | 緑のSTARTボタン、赤のSTOPボタン | 電圧計・電流計と数値 |
| 下 | 稼働率ダイヤル。右半分を右クリックで＋1％、左半分で－1％。しゃがみ時は10％刻み | ダイヤルの指示と設定％ |

操作は素手で実物のボタンとダイヤルを右クリックし、専用GUIは開かない。指針は実測値に機械的な減衰を模した補間で追従し、架空の脈動を加えない。いずれかの制御盤へのレッドストーン入力でも停止する。ゴーグルは最大4行で停止理由、V/A/kW、気体・苛性ソーダの生成量、極板数と負荷、4系統の在庫を表示する。電極ヘッドをしゃがんで見ると、そのヘッドの極板と上下の状態を確認できる。Display Linkには同じ所有者から電圧・電流・電力・仕事バッファ・極板数・負荷・生成量・各在庫・状態を公開する。

電極の在庫はゴーグル・Display Linkから確認する。制御盤にコンパレーターを付けると装填率を15～0の信号で出力する（1枚でもあれば1以上）。極板0枚は「極板待ち」で停止する。

従来のブレーカー、非常停止、プリセットスイッチ、補助計器、液面管、ニキシー管は廃止。旧セーブの非常停止は停止状態で読み込み、新しいSTARTで起動できる。赤石入力・ヘッドの上昇・製品満杯の停止は維持する。点検ハッチは電極ヘッドに置き換えて廃止した。2×2断面・4区画の制御盤の旧構成も、1列・2段の制御盤に置き換えた。

外装はCreateの流体タンク（横型流体タンクと同じ）のリベット留め銅板を使い、締付ボルトと上部の取手は真鍮色にした。制御盤は銅の枠の中に灰色のエナメル盤を収め、4区画が1枚の盤としてつながる。配電盤用メーター、真鍮の圧力計、ランプと押しボタンの写真を参考にしたが、1面16×16の密度は維持している。

下がりきっていないヘッド、給液・極板不足、出力満杯、構造欠損、停止信号では通電・反応を止める。製品全量を格納できることをシミュレーションで確認してから、原料・電気仕事・隔膜を一度だけ消費する。CEEの電線抵抗、電圧降下、発熱・許容電流は変更していない。台数・装填数を増やす際は配線もCEE側の定格に合わせる。

## 保存・解体・処理量

流体と極板は各セルのBlockEntityに保存し、形成・解体で別の所有者へ移し替えない。採掘で落ちるセルの `BLOCK_ENTITY_DATA` に同じ内容物を入れ、再設置で復元する。極板・隔膜・電解採取の金属は電極ヘッドに保存し、ヘッドを壊すとドロップする。

電気仕事と設定は端面左下の所有者が保存する。制御盤を壊すとその部品の仕事バッファは放電する。キャッシュした古いポート、内部へ隠れた面、取り外されたBlockEntityから内容物を取り出せない。

探索は32セルまで。許容値を超えた探索を正常と見なさず、未ロードの隣接チャンクは読み込まない。形成の再試行は20 tickごと、成立中の同一tickの整合性結果と極板集計を再利用する。物資・構造変更でキャッシュを無効化し、出力空き量は上限128回の逐次試行の代わりに二分探索する。内容物の変更通知は10 tick単位へまとめ、制御盤は前回の同期内容と異なる場合に送信する。性能の比較測定はしていない。

旧 `electrolyzer_lid` と鉢の自動連結、専用レンダラー、Basin内の電解状態は廃止。通常のCreate Basinは本来の独立した鉢へ戻し、開放鉢の気体搬入拒否を維持する。旧電解槽の保存内容を自動変換する処理はない。既存ワールドの旧装置は更新前に原料・製品・極板を回収し、新しいセルで組み直す。

新規の機械Ponder `plant/electrolysis_cell` と、水素・塩素アルカリ・重水素の製造系列Ponder、JEIを新方式へ更新した。
