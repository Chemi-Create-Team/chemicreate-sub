# 気液二相の流れ

2026-11-24のユーザー指定：「気液分離機があるのに、気体と液体を1つに丸めたら意味がない」。対象は、水系と、液化・気化するすべての物質（`FluidState.phaseSensitive`）。温度と圧力は17段階に丸めたままで、気体と液体の割合は丸めない（2026-11-24のユーザー指定）。

## 今の問題

- 装置の中（`ThermalFluidTank`・`HeatContent`）は、沸点にある中身の「乾き度」（気体の割合、0〜1）を持つ。
- 外へ出す配管やバケツ、Createのタンクでは、流体スタックは温度と圧力の段階しか持たない。出すときに、液体か気体のどちらか1つの相へ丸める。
- そのため、沸騰途中や凝縮途中の流れが気液分離機に届かず、分離機の仕事がない（直接つなぐタンク間の `fillAt(..., quality)` だけは乾き度を運べる）。

## 決定案

| 項目 | 案 |
| --- | --- |
| 乾き度の持ち方 | 流体スタックの Data Component（仮名 `vapour_quality`）。0または未設定なら今と同じ単相。量子化は1/8（0〜8の整数）にする |
| 量の単位 | 二相スタックのmBは液体換算。気体にする分は分離機の中でだけ `PhaseChange.ratio` で換算する |
| 端数 | 割り切れない分は元の相のまま残す。物質は増えない（[流体の状態](fluid-states.md)3章と同じ） |
| 混ぜるとき | 同じ物質の二相スタックどうしは、量で重み付けした乾き度を最寄りの1/8に丸める（`FluidState.average` と同じ場所）。Createのタンクが「同じスタック」と見なせるのは、乾き度が同じときだけなので、量子化は必須 |
| 出す側 | 沸点で乾き度を持つ中身は、丸めずに乾き度付きで出す。温度の段階は今と同じ（相が変わらない段階を選ぶ規則は、乾き度が0より大きく1未満のときは適用しない） |
| 受ける側 | 配管・Createのタンクは、乾き度付きのスタックをそのまま運び、貯める。タンクの中で層に分けず、二相のまま持つ（要確認） |
| 分離 | 気液分離機（`AmmoniaSeparatorBlockEntity`）を、二相スタックの汎用の分離にする。液体は下、気体は上へ出す。新しいブロックは作らない |
| 配管の定格・貯蔵倍率 | 二相は液体として数える。気体の貯蔵倍率は適用しない（要確認） |
| 漏れ・雲 | 乾き度の分だけ気体として放出する |
| ゴーグル・バケツ・JEI | 「液体／気体」の代わりに「気液二相（乾き度 n/8）」と表示する |

## 影響範囲

`FluidState.gas(`・`liquidWater(`・`PhaseChange.`・`levelFor(` の呼び出しは、装置・配管・表示を合わせて約110か所（`ReactorMachineBlockEntity`、`ThermalStreams`、`HeatContent`、`CryogenicColdBoxBlockEntity`、`ReactionTowerBlockEntity`、`LiddedVesselBlockEntity`、JEIなど）。それぞれ、二相スタックに対する答えを決める必要がある。

## 要確認

- 二相スタックをタンクの中で層に分けるか、二相のまま持つか（案は二相のまま）。
- 二相の配管の定格の数え方と、気体の貯蔵倍率の扱い。
- 量子化の細かさ（案は1/8）。
- 既存のワールドの移行は不要（乾き度がないスタックは今と同じ単相）。
- 実装後に更新するもの：気液分離機のPonder、`docs/reaction-plant.md`、`docs/internal-temperature.md`、`CELegacyIds`は変更なし。
- 検証：サンドボックスではGradleのビルドが通らない（NeoForgeのパッチ適用の段階）ため、ビルド・GameTestが動く環境で確認が要る。

## 実装した範囲（2026-11-24）

- 流体スタックのData Component `vapour_eighths`（気体の割合、1〜7の8分率）。ない場合は今までの単相。
- `thermal/TwoPhase`：印を付ける（`mark`）、外す（`plain`）、液体と気体に分ける（`split`）。分けるときは `PhaseChange` の換算を使い、割り切れない分は元の相に残す。
- `ThermalFluidTank`：沸騰・凝縮の途中の中身（乾き度が1/16〜15/16）を出すときは、二相の印を付けて出す。受けるときは印を外し、気体の割合を中身の乾き度として、沸点の温度で持つ。
- 気液分離機（`AmmoniaSeparatorBlockEntity`）：入口（側面）へ二相の流れを入れると、液体は下の出口、気体は上の出口へ分ける。水は水・蒸気のバッファー、それ以外の物質は液体・気体のバッファーを使う。レシピの処理中や、他の内容物があるときは受けない。
- 表示：相の名前は「気液二相」。

### まだ二相を出さない・受けないもの

- `ThermalFluidTank` 以外の在庫（Createの流体タンク、RBMK、熱交換器・ラジエーターの出口、往復式圧縮機など）。二相の印付きスタックを受けた場合は、そのまま保持するだけで分けない。
- Createの流体タンクが二相のスタックを受けると、同じ印のスタックしか混ぜられない（空にすれば戻る）。
- 同じ混合の二相スタックどうしを混ぜたとき、乾き度は空のタンクへ入れるときだけ引き継ぐ。入っているタンクに足すと、乾き度は沸点での状態から決め直す。
- Ponderと `reaction-plant.md` の気液分離器の説明は未更新。
- Gradleのビルド・GameTest（`TwoPhaseGameTests`）は、この環境で実行できていない。
